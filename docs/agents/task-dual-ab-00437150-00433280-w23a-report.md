## AutoCore impact

- **`RefCountedSlot_ReleaseAndClear`:** client smart-pointer teardown / SEH cleanup. Server ports should use ordinary refcount or `IDisposable`; preserve null-after-release semantics. Callers that double-invoke with already-null slots are no-ops.
- **`NDAssetImage_WriteAlphaPlaneByte`:** 32bpp TGA/PNG alpha channel fidelity for map/UI assets (`map.tga` path via LoadTGA → uncompressed row). Server asset pipelines that reimplement TGA 32bpp need a mono alpha buffer at image `+0x1b0` semantics if matching client visuals.
