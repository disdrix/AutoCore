## `0x00480970` — Mem_Move200B_Blocks_Inferred

### Sealed facts

1. **Body** `0x00480970`–`0x004809a0` (**49 bytes**).
2. **ABI:** cdecl stack **(src, srcEnd, dest)**; bare **`RET`**. Callers often push a **4th dummy** and `ADD ESP, 0x10`.
3. **Loop:** while `src != srcEnd`: `REP MOVSD` with **`ECX = 0x32`** (50 dwords = **200 / `0xC8` bytes**); advance both pointers by **`0xC8`**.
4. **Leaf** — no callees.
5. **Callers / use:** erase tail-shift then `end -= 200`:
   - `FUN_0071ffc0` (`CSoundManager_EraseNamedRecordByName`) @ `0x0072003a`, `0x00720067`
   - `FUN_00480560` (vector erase-one) @ `0x00480579`
   - `FUN_00721d30` @ `0x00721f0e`
6. Decompiler `param + 0x32` is **dword-scaled** (= +200 B) — matches bytes.

### Gaps

1. Product/CRT symbol.  
2. Full overlap contract if dest > src (erase path is left-shift only).  
3. Element product type beyond shared 200 B stride.  
4. Runtime / bit-exact / image diff.

## `0x00724870` — CSoundManager_ProbeSoundFileExists_Inferred

### Sealed facts

1. **Body** `0x00724870`–`0x007249b0` (**320 / `0x140` bytes**).
2. **ABI:** **EAX** = path C string; stack **`(CSoundManager* this, char* outPath, int* outKind)`**; **`RET 0x0C`**; return **bool AL**.
3. **Flow:**
   - Copy path → stack; **`FUN_00722790(this, buf)`** appends **`.ogg`** or **`_lxx.ogg`** (`this+0x308`).
   - **`FUN_007b6a20()`** config; if `cfg+4 & 1`:
     - **`PathFileExistsA(buf)`**
     - Else walk **`DAT_00d1e574` … `< 0x00d1e7a4`** stride **`0x1c`** (20 MSVC strings): `root + basename` via **`FUN_007b6420`**, then `PathFileExistsA`.
   - Fallback **`FUN_007b66c0(cfg)`**; fail → **0**.
   - Success: optional `strcpy(outPath, buf)`; optional **`*outKind = 2`**; return **1**.
4. **outPath** is the **normalized input buffer**, not the rooted trial path.
5. **Callers:** `FUN_007249c0` (ResolveSoundPath) ×2, `FUN_00726390`, `FUN_00727140`.
6. **Root BSS** static image zeros — runtime-filled (content not in EXE data).

### Gaps

1. Product helper name and kind-`2` English.  
2. Root table population site.  
3. Dual of `FUN_00722790` / `FUN_007b66c0` / path-config object.  
4. Runtime / bit-exact / image diff.
