## 1. Purpose

**Binary-tree lower_bound** on an MSVC-style `map`/`set` node graph:

- `this+4` → head/sentinel node pointer.
- Node layout used here: `[0]=left`, `[1]=parent`, `[2]=right`, `[3]=int key`, `+0x19` = nil/is-nil byte (head child).

Walk from root (`head[1]`) while not nil:

```
if (node.key < *pKey) go right; else go left (and remember node as candidate).
```

Then:

```
if (candidate != head && candidate.key <= *pKey) *pOutIt = candidate;
else *pOutIt = head;   // end()
```
