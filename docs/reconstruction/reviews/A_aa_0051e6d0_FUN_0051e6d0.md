## 1. Purpose

**CNDHash insert(key, value)** specialized by **node vtbl** `PTR_FUN_009cb968` — same control flow as named `CNDHash_Insert` (`0x0053c560` / vtbl `009cefd4`), different node method table.

Sole static caller: **`Skill_EnsureLoadedInTree`** (`0x0051a980`) on miss path — inserts materialized skill runtime into owner skill-tree hash at **`owner+0x70`**, key = skill id, soft-flag = **0** (hard-fail on duplicate).

Signature (byte-sealed):

```c
// __thiscall  ret 0x0C (3 stack args)
int FUN_0051e6d0(CNDHash *this, uint key, void *value, char softIfExists);
```

Control flow:

1. `value == NULL` → **`0x80004003`** (`E_POINTER`).
2. If `*(char*)(this+0x1d)` (traversal lock) ≠ 0 → log `"HashError:insert, already locked for traversal"` + `"VOG_DEBUG_STOP"`; **does not abort**.
3. If `softIfExists != 0` and `CNDHash_LookupByKey(this, key)` hits → **return 1** (no insert).
4. Else if lookup hits → log `"Duplicate hash insert %u, failing out"` → **`0x80004005`** (`E_FAIL`).
5. Alloc node: `LEA ECX,[this+0x20]; call FUN_0053ada0` (freelist header at **`this+0x20`**).
6. Init node: vtbl `0x009cb968`, touch `+0x04=0`, value `+0x08`, key `+0x10`, list links 0; bucket head-insert at `buckets[key & mask]+4`; `FUN_00537d30` (bucket integrity).
7. Append to global list (`this+0x14` head / `this+0x18` tail); `count++` (`this+0xc`); return **0**.
