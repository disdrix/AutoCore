### Algebra (bit-exact)

| Expression | Equivalent |
|---|---|
| `~(EAX >> 2) & 2` | `2` iff **EAX bit 3 is clear**; `0` iff **EAX bit 3 is set** |
| Domain | **only {0, 2}** — never `1` |
| Alias | `(EAX & 8) ? 0 : 2` |

TNL `RPCGuaranteeType` (`lib/TNL.NET/TNL.NET/Entities/RPCEvent.cs`):

| Value | Name |
|------:|------|
| 0 | `RPCGuaranteedOrdered` |
| 1 | `RPCGuaranteed` |
| 2 | `RPCUnguaranteed` |

So arg4 can only select **GuaranteedOrdered (0)** or **Unguaranteed (2)** — never Guaranteed (1).
