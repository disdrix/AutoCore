## 1. Purpose

**Process the host’s attached FX-entry list** at **`this+0x1EC`**, optionally filtered by name, and play/attach interface sounds / positioned FX for each matching entry.

High-level stages:

1. **Master enable gate:** if **`this+0x1F0 == 0`**, return immediately.
2. **Resolve target object `param_3`:** if null, try `vtbl+0x1CC` on object at **`this+0x10`**.
3. **Early reject (when target non-null):** CNDHash lookup on a type key from target; under several field tests (`this+0x28==0`, type `!=0x11e`, hash value `+0x148==0`, vtbl `+0x1CC` non-null) → **return** (suppress play).
4. **Build TFID / coid context `TStack_50`:**  
   - If global `DAT_00b036f0` set and target present: may resolve via vtbl `+0x1D8` occupant TFID `@+0x228..`, `Object_ResolveFromTFID`, vtbl `+0x210`, `TFID_EqualsObjectId` vs `DAT_009cb2a0`; for certain `this+0x28` modes (`0,0xb,0xa,0x9,0x2`) **return**.  
   - Else if target has valid coid mask fields `@ target+0x164..` use those.  
   - Else mint synthetic id from `Client_GetMissionCompleteAudioTable` singleton field **`+0x2E8`** (decrementing counter).
5. **Walk list `this+0x1EC`:** payload `node[2]` = FX entry (`pbVar16`).
   - If **`param_2 != 0`**: force entry type dword **`+0x104 = 0x32`**.
   - If **`param_4` name filter non-null**: strcmp-style match against entry name when entry `+0x10A != 0`; else require empty-name path.
   - Per-entry branches on flags `+0x108/+0x109/+0x10C/+0x131`, type range `+0x104`, attach TFID at `+0x120..`, position via vtbl `+0x1A0/+0x214`, then play via  
     `Client_GetMissionCompleteAudioTable` / `Client_PlayNamedInterfaceSound` / `FUN_007258a0` / `FUN_00723120` (site-dependent).
6. Optional world-position path when entry needs attach and `param_5..7` vector non-zero (normalize via `FUN_004e9530`).

Called from **`FUN_004b8dc0`** activate path with all-zero optional args, and many other combat/UI sites.
