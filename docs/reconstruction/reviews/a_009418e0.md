## Flag bits `skill+0x614` (asm Confirmed masks; names open)

```
MOV  EAX, [pSkill+0x614]
TEST AH, 0x8          ; bit 0x800
JZ   resolve_tfid     ; 0x800 clear → entity TFID/aim fill
TEST AL, 0x20         ; bit 0x20
JNZ  do_cast          ; both set → RequestCast with seed invalid TFID + zero aim
; else PromptSkillTargetSelect(client,1); return
```

| Mask | Behavior | Semantic name |
|------|----------|---------------|
| `0x800` clear | Resolve TFID (+ aim) from selection/self | **Open** (not sealed) |
| `0x800` set, `0x20` clear | Target-select prompt; no cast | Role sealed; enum name **Open** |
| both set | Fall-through cast with invalid TFID seed + zero aim | Intentional vs bug **Open** (runtime) |

Selection arm: `selected[0x5f]>>5 & 1 == 0` → goto cast **without** aim fill (aim stays zero). Unchanged.
