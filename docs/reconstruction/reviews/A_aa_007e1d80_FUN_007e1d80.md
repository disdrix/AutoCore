## 1. Purpose

**DBReader connection enter** used as the first half of the ensure-load bookend on every XP/credits table ensure:

- `EnsureQuestCreditsLookupLoaded` `0x00512830`
- `EnsureQuestBaseCreditsLoaded` `0x00512870`
- `Experience_EnsureQuestXpTableLoaded_INFERRED` `0x005127f0`
- `Experience_EnsureLevelTableLoaded_INFERRED` `0x005128b0`
- `Experience_EnsureCreatureXpTableLoaded_INFERRED` `0x005128f0`

Fastcall `this` = DB reader context (`ECX`, from ensures: `*[0x00b0469c]`). Always ends by **incrementing refcount at `this+0x20`** on the success/fast path. Cold path opens the Resource Manager connection from the wide connection string at `this+0x2c`, opens an RM session into `this+0x28`, sets `*this = 1`, optionally verifies `vogversion` / `dcver`, then bumps the same refcount.
