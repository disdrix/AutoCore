**Product seal for skill path:** while target-select is active for a cast, **`client+0x30c0` holds the pending skill id**. Completion (`FUN_00941ac0`) casts that id; cancel/clear writes **-1**.

**Multi-mode note (not overclaimed as skill-only):** small values `{0,2,3,4,5}` are non-skill UI pick modes sharing the same dword; default switch arm (any other value, including real skill ids) uses skill-cursor chrome. Do **not** treat every write to `+0x30c0` as a skill id — only the skill prompt path and values that later feed `RequestCastSkill`.
