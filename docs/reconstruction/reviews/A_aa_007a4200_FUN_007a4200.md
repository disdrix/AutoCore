## 1. Purpose

**Seed and pre-generate** a large uint32 table on the RNG object:

1. Free existing table at `this+8` if non-null; clear pointer.
2. `operator_new[](0x200000)` → store at `this+8` (capacity **0x80000** dwords = 512 Ki dword = 2 MiB).
3. On success: store seed at `this+0x10`; re-init engine via `FUN_00424890` / `FUN_004248c0`.
4. Loop `i = 0 .. 0x7ffff`:
   - If engine counter `engine+0x9c4 == 0`, call `FUN_004248c0` (refill engine).
   - Decrement `engine+0x9c4`; take next raw dword from `*(engine+0x9c0)++`.
   - Temper: `x ^= x>>11; x ^= (x & 0xff3a58ad)<<7; x ^= (x & 0xffffdf8c)<<15; x ^= x>>18`.
   - Store tempered value at `table[i]`.
5. Zero cursor `this+0xC`; set ready flag `this+4 = 1`.

Called from ctor when ready flag is still 0, with `time(NULL)` as seed.
