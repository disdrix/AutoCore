### Algebra notes

| Topic | Sealed fact |
|-------|-------------|
| Free prefilter vs full free | Corner free is **AND** prefilter only; full rect is CanPlace |
| `(lo & hi) == -1` | ≡ both halves `0xFFFFFFFF` (allocate fill) |
| Y uses `char` | Height / pageH / sizeY truncated in band math; index mult uses full `i32` height |
| X uses `sizeX & 0xff` | Bound is i32 arithmetic on width |
| Zero size | Client **success** at (0,0); AutoCore **rejects** at port (intentional) |
| Side effects | Writes only `*outX`/`*outY` on success; **no** cell stamp |
