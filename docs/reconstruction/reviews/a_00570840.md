## Seal: height*x+y index + page rule

```text
// __thiscall InventoryGrid_CanPlace(this, sizeX, sizeY, originX, originY, conflictOut)
// this in ECX; all size/origin args are byte-wide in the decompile
// returns 1 fit / 0 reject (low byte is the flag; upper bits junk/cleared)

if (conflictOut != NULL) {
  conflictOut[0] = 0xFFFFFFFF
  conflictOut[1] = 0xFFFFFFFF   // empty COID pair sentinel
}

endX = originX + sizeX
if (width(+0x08) < endX) return 0          // X OOB (signed compare)

endY = originY + sizeY
height = *(i32*)(this+0x0c)
pageH  = *(i32*)(this+0x1c)

// Y bounds AND page non-span (both required):
if (!(endY <= height)) goto fail
if (!((originY % pageH) + sizeY <= pageH)) goto fail
// note: decompile computes originY / pageH as a side effect of DIV; only remainder used

// Full footprint scan: X outer, Y inner
for x = originX .. endX-1:                 // outer (byte)
  for y = originY .. endY-1:               // inner
    idx  = height * x + y                  // full i32 height * x + y  ★ SEALED
    cell = *(this+0x28) + idx * 8          // 8-byte COID pair
    lo = cell[0]; hi = cell[1]
    if ((lo & hi) != 0xFFFFFFFF) {         // occupied (not empty)
      if (conflictOut == NULL) goto fail
      if ((conflictOut[0] & conflictOut[1]) == 0xFFFFFFFF) {
        conflictOut[0] = lo; conflictOut[1] = hi   // capture first conflict
      } else if (conflictOut[0] != lo || conflictOut[1] != hi) {
        goto fail                              // second distinct COID → reject
      }
      // same COID as already captured → continue (multi-cell same item OK)
    }
return 1
```

### Page rule — SEALED

```text
(originY % pageH) + sizeY <= pageH
// pageH = *(i32*)(this + 0x1c)
// Cargo: pageH = 13 (VehicleCargoCapacity / ctor)
```

- Checked **once** at the origin Y (not per-cell). Combined with `endY <= height`, a rect that starts in-page and has height ≤ remaining page rows cannot cross a page boundary.
- Equivalent prose: **items may not span cargo pages**.

### Empty / conflict predicate

```text
empty cell: (lo & hi) == 0xFFFFFFFF     // both dwords all-ones (allocate fill)
occupied:   (lo & hi) != 0xFFFFFFFF
```

ConflictOut (nullable `uint[2]` COID pair):

- **null** (FindFree / Place typical): any occupied cell → fail.
- **non-null**: init to `(-1,-1)`; first occupied COID captured; second **different** COID → fail; same COID tolerated across cells.
