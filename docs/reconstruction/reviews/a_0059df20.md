## Seal: ROUND = post-`ceil` FISTP with RC=chop

Image bytes at `0x0059dfca` (read_memory 2026-07-29):

```text
FLD   [obj+0x148]          ; CreditScaler
FMUL  [fracRow+0x10]       ; rlLevelCredits
FMUL  flBaseCredits
FSTP  qword [esp]          ; arg for ceil
CALL  [ceil IAT]
FNSTCW ...
MOVZX EAX, cw
OR    AH, 0x0C             ; RC bits = 11 → chop toward zero
FLDCW modified
FISTP dword                ; double → int
FLDCW restore
RET  EAX
```

Ghidra `ROUND(dVar2)` is **not** a nearest-int library; it is the standard MSVC float→int convert (RC=chop) after `ceil`.

| Case | Behavior | Confidence |
|------|----------|------------|
| Positive product | `ceil` → integer-valued double → FISTP identity | **High** |
| Exact integer after ceil | Exact | **High** |
| Negative product | `ceil` toward +∞ then chop; can return **negative** int | **High** (static) |

Plate comment “`(int)ceil(...)`” matches positive path. AutoCore `ExperienceService.ComputeMissionCredits` uses `Math.Ceiling` and **clamps negative scaler → 0** (server-safe; not bit-identical to client on negative).

**Disposition:** ROUND exactness → **Sealed High** as FISTP/RC=chop after ceil.
