## 1. Purpose

**Special-FX host “trigger by event id”.** On `this` host object:

1. Call `FUN_004eb3b0(this)` — lazy-ensure resource pointer at **`this+0x88`** (loads from related asset name field when empty; see sibling body).
2. If **`this+0x88 == 0`**, return **0**.
3. Else call **`FUN_004a16d0(host+0x88, eventId, 1, 0xffffffff)`** and return its result.

Caller evidence (`FUN_0056d160`, `FUN_0056bab0`) passes small integer event codes (`4`, `7`, `8`, `0xc`, `0xe`, `0x14`, `0x15`, …). Callee `FUN_004a16d0` formats `"%s_FOR_EVENT_%d"` against the loaded FX script name — confirms **event-id dispatch**, not free-form string play.
