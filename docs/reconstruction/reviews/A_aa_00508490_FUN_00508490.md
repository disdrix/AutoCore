## 1. Purpose (behavioral)

Thread-safe **insert-by-key** into a doubly-linked list of heap nodes owned by a list-manager object:

1. SEH frame + `EnterCriticalSection(this+0x04)`.
2. If **`*(this+0x28) != 0`** (traversal lock / busy): log `"VOG_DEBUG_STOP"`, throw HRESULT **`0x80070005`** (`E_ACCESSDENIED`) — does **not** return.
3. Allocate node via **`(*this->vtbl)(+4)(0)`**. Null → throw **`0x8007000e`** (`E_OUTOFMEMORY`).
4. If head `*(this+0x1c) == 0`, set head = new node.
5. Link at **tail** `*(this+0x20)`: `new+0xC = old_tail`; if old_tail: `old_tail+0x8 = new`; store **key** at `new+0x4`; **`*(this+0x24) += 1`**; tail = new.
6. `LeaveCriticalSection`; return **0**.

Structural twin of remove `FUN_005085b0` (`0x005085b0`). **Not** `CVOGHBList_Enqueue` (different layout). Primary HB caller: `CVOGHBBase_AttachOwnerObject` with **ECX = listMgr** `*(owner+0xB0)`, stack = HB*.
