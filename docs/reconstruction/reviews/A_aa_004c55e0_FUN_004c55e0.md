## 1. Purpose

**Speed-derived float scale** leaf. Primary DriveControlTick consumer multiplies the SECTION look vector (`local_d0/cc/c8/c4`) by this return before `FUN_0091a5f0`. Sibling consumers compare result to **0** (zero-speed gates).

Two return paths:

```
// this = ECX (__fastcall); saved ESI; stack local via push ecx
obj = *(this + 0x250)
comp = *( *( *(this+4)+4 ) + this + 0xa8 )
if obj != 0 && *(u8*)(comp + 0xf5) == 0:
    // early: min of two f32 on secondary object
    return min( *(f32*)(obj+0x110), *(f32*)(obj+0x10c) )

// default: base-max leaf + flag adjust, then scale by this+0x1f0
base = FUN_004c4e20(this)           // aa_004c4e20 → this+0x1f4 (± driver+0xd48)
flags = *(u32*)( *( *(this+4)+4 ) + this + 0xb8 )
if flags & 0x1000:                  // TEST AH,0x10 — priority
    base -= DAT_00a0f710            // 0.7
elif flags & 0x4000:                // TEST AH,0x40
    base += DAT_00a0f70c            // 0.2
return (base + g_flOne) * *(f32*)(this + 0x1f0)
```

**Return:** x87 `float10` / ST0. **No stores** to entity drive axes; pure float return.
