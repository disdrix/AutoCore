## Seal: control flow (High)

Classic MSVC `std::map::insert` / insert-or-find:

1. `head = *(this+4)`; start at root `head[1]`; `goLeft = true`.
2. While child `isnil@+0x19 == 0`:
   - `goLeft = (value->key < node->key)` (`cmp [node+0xc]`)
   - left = `*node`, right = `node[2]`
3. Candidate parent = last real node.
4. If `goLeft`:
   - If parent == leftmost (`**head`): **insert** via `FUN_0051c1c0(..., insertLeft=1, ...)` → out `{it,1}`; return
   - Else: `FUN_005ae050(&parent)` — **tree predecessor** (in-place on candidate)
5. If `parent->key < value->key`: **insert** via `FUN_0051c1c0(..., goLeft, ...)` → out `{it,1}`; return
6. Else **equal key**: out `{parent, inserted=0}`; **return without writing start/duration**

## Caller semantics implication (High for this unit)

Both callers **ignore** `inserted` / do not rewrite value on equal. Therefore:

- First arm of a category → new node with start+duration from pack.
- Re-call while key still present → **no refresh** of start/duration inside this unit.
- Expired entries are removed by `Skill_GetCategoryCooldownRemaining` erase path before a later insert can re-arm.

"Update" language belongs to the **API narrative** only if higher layers erase first — **not** to this mutator alone.
