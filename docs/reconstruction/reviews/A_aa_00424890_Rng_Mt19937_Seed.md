## 1. Purpose

**MT19937 seed / state fill** for the game's Mersenne Twister engine block (`0x9c8` bytes at alloc sites).

- State array base in **EAX**.
- Seed in **EDX** → `mt[0]`.
- Loop `i = 1 .. 623` fills with standard init recurrence:
  `mt[i] = 0x6c078965 * (mt[i-1] ^ (mt[i-1] >> 30)) + i`.
- Leaf; does **not** set extract cursor/remaining (twist sibling owns those).

Used from RNG ctor (`FUN_007a42d0`) and 2 MiB table fill (`FUN_007a4200`) before/with twist.

## 3. Byte seal (summary)

```
mov  ecx, 1
mov  [eax], edx              ; mt[0] = seed
push esi
loop:
  mov  edx, [eax]
  mov  esi, edx
  shr  esi, 0x1e
  xor  esi, edx
  imul esi, 0x6c078965
  add  esi, ecx
  mov  [eax+4], esi          ; mt[i]

  add  eax, 4
  cmp  ecx, 0x270

pop  esi
ret
```
