## 1. Purpose

**Meyer-style once-init singleton** for the interface/FX sound subsystem object at **`DAT_00d20070`**.

1. If **`(DAT_00d20200 & 1) == 0`**:
   - Set **`DAT_00d20200 |= 1`**.
   - **`FUN_00720a40(&DAT_00d20070)`** — construct/init table object.
   - **`_atexit(LAB_009c3720)`** — register destructor.
2. Always **return `&DAT_00d20070`**.

Used as the `this` provider for methods like `FUN_007203b0` / `FUN_00720670` / play helpers. Call-site decompiles that show `FUN_00720d40(p, 1)` are **mis-attributed args** (next call’s stack); this unit itself takes **no parameters**.
