## 1. Purpose

**Grow the block-pointer map** of the cast-slot deque used by `Skill_QueueDeferredCastId`.

`__thiscall` on the same 0x14-ish slot object:

| Offset | Role |
|---:|---|
| `+0x4` | `map` — pointer to array of block pointers |
| `+0x8` | `mapsize` — number of map slots |
| `+0xC` | `off` — element offset (used as `off>>2` = start block index) |

Algorithm (MSVC `deque` map reallocate shape):

1. If `mapsize + grow` overflows `0x0FFFFFFF` → `FUN_0051b5f0()` (**`"deque<T> too long"`** throw path; does not return).
2. `prefer = max(mapsize/2, 8)`; if `requested < prefer` and no overflow, **raise grow to prefer**.
3. `operator_new((mapsize+grow)*4)` new map.
4. **Rotate/copy** old map entries around `off>>2` so front block index is preserved; zero pad new slots.
5. If old map null: install new map, `mapsize += grow`, return.
6. Else `operator_delete(old map)` — decompiler marks noreturn after delete (tail / EH); size update still occurs on the null-old path; live MSVC deque also updates mapsize before free on non-null path (verify residual).

**Sole caller:** `Skill_QueueDeferredCastId` (`0x0051d3b0`) with `PUSH 1` when the ring needs more map capacity.
