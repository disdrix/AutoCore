## 1. Purpose (behavioral)

Thread-safe **remove-by-key** from a doubly-linked list of heap nodes owned by a list-manager object:

1. If **`*(this+0x28) != 0`** (traversal lock / busy), return **0** immediately (no CS).
2. `EnterCriticalSection(this+0x04)`.
3. Walk head `*(this+0x1c)` via node **next** at `node+0x08` until `node+0x04 == key` (`param_2`).
4. On hit: clear `node+0x04`, unlink from prev/next (updating list head `+0x1c` / tail `+0x20`), **`*(this+0x24) -= 1`**, call **scalar-deleting dtor** `(*node->vtbl)(1)`, set success **1**.
5. `LeaveCriticalSection`; return **0** (miss / empty) or **1** (removed).

Primary structural twin of insert `FUN_00508490` (`0x00508490`). **Not** `CVOGHBList_Enqueue` / pending pointer-array list (different layout).
