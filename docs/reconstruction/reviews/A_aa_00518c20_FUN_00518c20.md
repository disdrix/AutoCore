## 1. Purpose (behavioral, not product name)

Lazy getter for a **0xC-byte** map-like header stored at **`this+0x68`**. First call allocates the header, builds a head node via `FUN_0058d9c0` (`operator_new(0x30)` node, self-linked L/R/parent, size `+8 = 0`), stores the pointer, and returns it. Later calls return the cached pointer. Structural twin of **`Skill_GetCategoryCooldownMap`** (`0x00518d70`, slot **`+0x6c`**) with a different node factory (`FUN_0058d9c0` vs `FUN_005ae2b0`).

Used by active-cast binding lookup/clear/insert paths and by LocalCastValidate (map size `+8 != 0` + skill form flag → eSkillResponses **10**).
