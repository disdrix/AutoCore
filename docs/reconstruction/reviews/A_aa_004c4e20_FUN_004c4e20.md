## 3. Sealed gates (OWN charter)

### 3.1 Entity/host **`this+0x1f4`** — always-path base

| Item | Sealed fact |
|---|---|
| Offset | **`+0x1f4`** (decimal **500**) |
| Type | **f32** (`fld dword ptr [esi+0x1f4]`) |
| Role | **Core base max-speed** return value |
| Paths | Loaded on **both** returns: plain path (`004c4e69`) and additive path (`fadd` after `fld [eax+0xd48]`) |
| Confidence | **High** |

Machine:

```
// plain return
D9 86 F4 01 00 00    fld dword ptr [esi+0x1f4]
// additive path
D9 80 48 0D 00 00    fld dword ptr [eax+0xd48]
D8 86 F4 01 00 00    fadd dword ptr [esi+0x1f4]
```

### 3.2 Driver **`+0xd48`** — dual AND-gate (optional additive)

| Item | Sealed fact |
|---|---|
| Offset on driver | **`+0xd48`** |
| Type | **f32** (`fld dword ptr [eax+0xd48]`) |
| Combine op | **ADD** to `this+0x1f4` (not multiply) |
| Gate A | `driver = vfunc_0x210(...)` result **≠ 0** |
| Gate B | **`DAT_00b037d4 != 0`** (byte compare) |
| Combine | **AND** — both required; short-circuit: null driver skips flag path without second vfunc call when first probe is null |
| Image default | `DAT_00b037d4 = 0` → **additive path dead** in stock image |
| Confidence | **High CF** |

Driver resolve (identical on probe + re-call):

```
// ESI = this
// host = lea ecx, [ *( *(this+4) + 4 ) + this + 4 ]
// vtable = *host; call [vtable + 0x210](host, 0) → EAX = driver
```

