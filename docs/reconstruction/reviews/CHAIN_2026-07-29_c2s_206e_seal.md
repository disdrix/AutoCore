## What is sealed vs still open

### Sealed (static, high confidence)

- Response opcode is **0x206E**, not 0x2070.
- Opcode stamp site: Prepare @ `0x008abd70` → `dialog+0x650`.
- Payload fill site: HandleButton state 1.
- Send site: Flush @ `0x008ab8f0`, buffer at `dialog+0x650`, size `0x20`, sector conn vtbl+0x18.
- AutoCore packet class + unit test layout match size and opcode.

### Open (do not claim complete)

1. ~~**Virtual invoker** of Flush~~ **Sealed static 2026-07-29 residual** — `FUN_008aec40`/`FUN_008af020` → `FUN_007fca10` → `vtbl+0x440` on `client+0x1058` (vtable `0x00a4a51c`). HideMissionDialogIfOpen is **not** the invoker.
2. **Early prepare on show / UF-011** — cancel/close (`0x9c40`) still flushes 0x206E; Flush does not clear `+0x650`.
3. **Accepted field polarity / turn-in overload** of `+0x658` with reward COIDs vs bool.
4. **State 0 dual-packet risk** — success after 0x206F still runs close → may also flush 0x206E.
5. **Abandon → FailMission** is outside this seal (HandleButton state 2 is modal only).
6. **Runtime / capture** verification not run this session.
