### Local early-return predicates (when binding valid)

Return `0x11` **without** apply iff any of:

1. Binding TFID equals packet first target (`+0x40..+0x48`), **or**
2. `skill+0x614 & 1` (raw: `this[0x26].bHeatAtMaxDebounce & 1`), **or**
3. Packet first target is invalid TFID (`TFID_EqualsObjectId` vs `g_abTfidInvalid_*`)

Note: decompiler emits the bit0 test twice in an `||` chain — same flag, not two fields.

If binding valid but predicates false: clear binding, continue apply, still return `0x11` (caller discards).
