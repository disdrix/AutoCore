## 1. Purpose

**Release / fade-stop an attached handle, then invalidate a slot index.**

On weapon (or same-shaped) object `this`:

1. If **`this+0x30 != 0`** (active handle / instance id):
   - Load object at **`this+0x24`**
   - Virtual-call **`(*(this+0x24)->vtbl + 0x18)`** with args  
     **`(handle=@+0x30, float 0.2f, int 0)`**
2. Unconditionally store **`*(this+0x78) = 0xFFFFFFFF`** (−1).
3. Return.

Single known direct caller in this image batch: **`FUN_0056d160`** (weapon fire / heat path that also uses `Weapon_CanFireHeatCheck` and FX host `FUN_004ec010` / `FUN_004b8dc0`) — on the fire-stop branch after event `7` FX attempt.

Constant **`0x3e4ccccd` = 0.2f** (IEEE-754).
