## 1. Purpose

**Client inventory host dual-widget refresh** when both child widgets at `host+0x568` and `host+0x56c` are non-null.

Host in **EDI**; stack `char doExtraReset` (`param_1`); **`ret 4`**.

1. Gate: both `*(EDI+0x568)` and `*(EDI+0x56c)` non-null else return.
2. Snapshot state via vtbl **`+0x44c`** on each widget (returns saved handle; first is 8-byte, second 4-byte in decompiler surface).
3. If `param_1 != 0`: each widget vtbl **`+0x458`** (extra reset).
4. `FUN_0089bc30(EDI)` — intermediate rebuild (uses TraverseToNext family).
5. Widget A (`+0x568`): vtbl **`+0x484(0,1)`**, **`+0x488(1,0)`**, **`+0x488(0,0)`**.
6. Widget B (`+0x56c`): vtbl **`+0x484(0,1)`**, **`+0x488(0,0)`** (no middle `(1,0)`).
7. Restore snapshots: A **`+0x448(savedA)`**, B **`+0x448(savedB, 0)`**.
8. `FUN_0089b090(EDI)`; `FUN_0089c330()`; `FUN_0089bf50()` (craft affordability sibling).
9. Two `FUN_007fbd30()` calls with widgets A/B and companion ptrs `EDI+0x570` / `EDI+0x574` (machine: load each widget into EAX, companion into ESI).

Does **not** pack network; pure local UI rebind after inventory mutation.
