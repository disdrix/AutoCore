## Seal: stamp index formula (byte-level)

### Outer setup (`0x00571760+`)

Decoded from `read_memory` hex:

```text
; after vtbl+0x260(quantity)
MOV AL, [ESP+sizeX_slot]
TEST AL, AL
JBE  skip_stamp                 ; sizeX == 0 → no stamp
MOVZX EDX, AL
MOV  [ESP+dx_slot], 0
MOV  [ESP+outer_count], EDX     ; outer bound = sizeX
TEST BL, BL
JBE  …                          ; sizeY == 0 → empty inner
MOVZX EAX, byte [ESP+originX]
MOV   ECX, [ESP+dx]
MOVZX EDX, byte [ESP+originY]
ADD   EAX, ECX                  ; baseX = originX + dx
MOV   [ESP+0x14], EAX           ; [ESP+0x14] := baseX
```

### Inner core (`0x005717b0` region — hex from `0x005717a0`)

```text
; key opcodes (contiguous):
;  8B 57 0C          MOV  EDX, [EDI+0x0C]     ; height = grid+0x0c
;  0F AF 54 24 14    IMUL EDX, [ESP+0x14]     ; height * baseX
;  8B AE 60 01 00 00 MOV  EBP, [ESI+0x160]    ; COID lo
;  8B 5F 28          MOV  EBX, [EDI+0x28]     ; cells
;  03 D0             ADD  EDX, EAX            ; + dy  (EAX starts 0, ++ each iter)
;  03 54 24 18       ADD  EDX, [ESP+0x18]     ; + originY
;  83 C0 01          ADD  EAX, 1              ; dy++
;  83 E9 01          SUB  ECX, 1              ; inner count (sizeY)
;  89 2C D3          MOV  [EBX+EDX*8], EBP    ; cells[idx].lo
;  8B AE 64 01 00 00 MOV  EBP, [ESI+0x164]    ; COID hi
;  89 6C D3 04       MOV  [EBX+EDX*8+4], EBP  ; cells[idx].hi
;  75 D4             JNZ  inner
; outer: ADD dx; SUB sizeX_count; JNZ outer
```

```text

// dx ∈ [0, sizeX), dy ∈ [0, sizeY)
```
