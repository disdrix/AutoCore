## 1. Purpose

**Stop active sounds** on the audio/FX table object (`this`) that match caller criteria. Used from `FUN_004b8dc0` deactivate path on list `+0x1EC` entries (with TFID fields at entry `+0x120/+0x124/+0x128` and name payload).

High-level:

1. If **`this+0x258` (600 decimal) == 0`**, return 0 (subsystem off).
2. Count of active slots: **`this+0x210`**; slot pointer array base **`this+0x31C`**.
3. **Mode A — wildcard TFID** when **`(param_2 & param_3) == 0xFFFFFFFF`** (both id halves are `-1`):
   - Require non-null **`param_5` name**.
   - For each live slot with `entry+0x1C5 != 0` and (`entry+0x36 != 0` **or** `param_6 != 0`):
     - `strcmp`-style compare name at **`entry+0x48`** vs `param_5`.
     - On match: **`FUN_00723ab0()`** (stop that entry; `this`/entry via registers — decompile drops explicit args).
4. **Mode B — specific TFID** otherwise:
   - Match `param_2 == entry+0x40`, `param_3 == entry+0x44`, `param_4 == entry+0x35`.
   - Also require live flags (`+0x1C5` or `+0x3A`).
   - Name null: stop if `entry+0x36 != 0` and type `entry+0x2C != 0x46`.
   - Name non-null: strcmp vs `+0x48`; on match stop; additional branch for `entry+0x37` with optional suffix from `DAT_00aa9268` when `this+0x25A == 0`.

Always returns **0**.
