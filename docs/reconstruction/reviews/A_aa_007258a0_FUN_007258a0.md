## 1. Purpose

**Try to queue a positioned FX/sound play** derived from an FX entry (`param_2`) and world position (`param_3` float3), on audio table `this` (often mission/interface audio manager).

1. If **`this+0x258` (600) == 0`**: return **0** (`ret 8`).
2. If entry type **`param_2+0x104` is `0xC` or `0xD`**: call **`FUN_00722b80(entry+0x120, entry+0x124, type)`**; if non-zero return **0** (suppress duplicate/conflict).
3. Distance / range gate:
   - If `‖param_3‖ <= g_flZero` → **in range** (pass).
   - Else compare planar-ish delta of `this+0x220/0x228` vs `param_3.x/z` against **`(entry+0x114)^2`**; if **outside** range → return **0**.
4. Resolve source name/path: **`FUN_007249c0(entry, DAT_00d1a614)`**; null → return **0**.
5. Allocate/get dest buffer via **`FUN_00480460` / `FUN_00480170`**, **`strncpy(dest, source, 0x104)`**.
6. Copy entry fields into dest (TFID `+0x120..+0x12C`, flags `+0x10B`, inverted attach `+0x131 = (entry+0x109==0)`, type `+0x104`, params `+0x110/114/118/11C`, `+0x10C`, scale `+0x154 = g_flOne`, clear `+0x150..153`).
7. **`FUN_00480350(this+0x310)`** — push into queue.
8. Return **1** on success, **0** on failure.
