- **ABI (bytes):** `__thiscall` — **ECX** = item; one stack arg desired (low **byte** via `movzx`); **`ret 4`**.
- **Flag dword:** `item+0x17c` (`object[0x5f]`).
- **Mask sealed:** **`0x100000`** = bit **20** (`shr`/`shl` **0x14**). Bytes: `81 e6 00 00 10 00`.
- **XOR set-to-value:** same pattern as `Item_SetBroken` (`0x00513de0`):
  `flags ^= (((desired & 0xff) << 20) ^ flags) & 0x100000`

- **Dirty-on-change only:** if `((flags >> 20) & 1) != (desired & 0xff)` then **`FUN_00512670`** (`| 0x20000` self + `+0xac` chain).

void __thiscall Item_SetCustomized(int item /* ECX */, uint8_t desired)
{
  // load flags @ +0x17c
  uint32_t flags = *(uint32_t *)(item + 0x17c);
  uint32_t desired_byte = desired; // movzx from stack

  // compare bit20 vs full low byte

  return;
}
