## Machine-level notes

- Source: raw capture + live re-verify 2026-07-29.
- **Prefer bytes** when decompiler conflicts: `unaff_EBX` = entry **EBX**; `in_EAX` = entry **EAX** (ctx); decompiler call of `vtbl+0x10` on **`param_1`** in the properties path is **wrong** — bytes call **QI result** in the reused `param_4` stack slot.
- `push ecx` at entry is both saved-ECX and the 4-byte scratch used when `pcRowsAffected` is null.
- `param_4` stack slot is: (1) cPropertySets input (copied to EBP, 0→1), then (2) cleared and used as COM out for ICommandProperties QI.
- Callees: `FUN_00437cd0` = zero dword at `*EAX`; `FUN_0041d7b0` = Release `*EAX` if non-null.
