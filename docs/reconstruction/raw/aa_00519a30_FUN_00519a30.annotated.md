- **Payload:** `operator_new(0x10)` block stored at hash-node `+0x8`; key at node `+0x10`.

### Payload layout (`0x10` block at hash value)

| Off | Set by | Source field |
|---|---|---|
| `+0x00` | all insert paths | `intRGBColor` (Lookup returns `*payload`) |
| `+0x04` | phase-1 always-insert | `intWorth` from first-processed vector |
| `+0x08` | phase-2 insert or update | `intWorth` from second vector |
| `+0x0c` | phase-3 insert or update | `intWorth` from third vector |

Unset dwords on miss-only inserts are **uninitialized** (`operator_new` without zero).
