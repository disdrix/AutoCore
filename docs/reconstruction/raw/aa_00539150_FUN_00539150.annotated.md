## Machine-level notes

- **MSVC `_Tree` / `std::map` range erase** (`erase(first, last)` returning iterator via out-pointer).
- Map layout: `this+0x4` = header node*, `this+0x8` = size (dword).
- Node nil flag: **`byte node+0x49`**. Links: `node[0]` / `node[1]` / `node[2]` = left/parent/right (MSVC Dinkumware polarity Probable).
- Full-range fast path when `[first,last) == [leftmost, header]`: destroy subtree via `FUN_00537ef0(header[1])`, re-init header, size=0.
- Selective path: successor walk + `FUN_00538780` per node.
- ABI sealed by entry/epilogue bytes: ECX=map, three stack args, **`ret 0xc`**.
- Live re-decompile (2026-07-29) ≡ 2026-07-23 raw CF.
