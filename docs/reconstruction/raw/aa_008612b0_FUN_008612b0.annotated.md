## Machine-level notes

- **ABI:** **ECX = inventory window this\***; **two opaque stack formals** cleaned by **`RET 0x8`**; return **AL** bool.
- **Install:** single DATA xref at vtable slot **`0x00a64b00`** → pure virtual dispatch (no code callers).
- **Selection:** `window+0x4b8` soft-cast via MSVC RTTI **`CNDUIWindow` → `CWndInventoryItem`**.
- **Mode:** `mode = *(*(window+0x56c)+4)` discriminates **1 / 3 / 4** (cascade SUB).
- **Store path:** when `DAT_00d1bdfa` live → `Item_IsWantedByStore` gate → reject toast *“The store does not want that item.”* (chrome **`0x4e24`**) **or** C2S **`0x2027`** size **`0x40`** via `Client_SendSectorPacket`.
- **Non-store:** UseObject / special flag / use-by-coid / skill-target types **8** & **`0x32`** / equip leaf **`UI_InventoryWindow_TryEquipOrLockedToast_Inferred`**.
- **Close:** most success paths call `window->vtbl[+0x33c](0)` before return 1.
