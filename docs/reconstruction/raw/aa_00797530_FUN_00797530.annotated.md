## Machine-level notes

- **ABI:** EBX = layout object*; stack `char flag`; SEH `LAB_009add2c`; **`RET 4`** (`C2 04 00` @ `0x00797985`); void.
- **Role:** Finalize/flush a text-layout block: trim trailing spaces, apply alignment modes, materialize display runs (multi 0x60-source → 0x80-display, or single-run copy + `FUN_00427050`), mark ready, clear source text.
- **Not** a dtor — dualed `UiTextLayout_CompleteDtor_Inferred` (`0x00797d70`) calls this with flag **1** before free.
- **Constant:** `DAT_00a0f298` = **0.5f** (half-width / center factor for mode 1).
- Prefer assembly when decompiler shows `unaff_EBX` — machine uses EBX as this for the whole body.
- Scaffold parent-seed name tying this to Client_RecvBroadcast is **false** (UI layout only).

```c
// EBX = layout*; stack char flag
void UiTextLayout_Finalize_Inferred(char flag)
{
  // SEH LAB_009add2c
  wstring* text = (wstring*)(layout + 0x0C);

  // trim trailing spaces
  while (*text->end() == L' ') {
    text->resize(layout->size_at_0x20 - 1);
    layout->count_B0--;
  }

  if (layout->size_at_0x20 == 0 &&
      (layout->runs_begin_94 == 0 || run_count_60(layout) < 2)) {
    if (layout->mode_CC == 1)
      layout->x = (int)(layout->mA0 * 0.5f);
    else if (layout->mode_CC == 2)
      layout->x = (int)layout->mA0;
  } else {
    if (layout->mode_CC == 1)
      layout->x += (int)((layout->mA0 - layout->mA4) * 0.5f);
    else if (layout->mode_CC == 2)
      layout->x += (int)(layout->mA0 - layout->mA4);
    else if (layout->mode_CC == 3 && flag == 0)
      layout->lineH_08 = (layout->mA0 - layout->mA4) / (float)layout->count_B0;

    if (layout->runs_begin_94 && run_count_60(layout) > 1) {
      // multi-run: build display runs into vector @+0x80 (stride 0x80)
      // ... slice text per run, FUN_004275b0 / FUN_00427a40 ...
      goto epilogue;
    }
    if (layout->runs_begin_94 && run_count_60(layout) != 0) {
      FUN_00426ff0(/* run0+0x10 → layout+0x30 */);
      // copy 8 dwords run0+0x40 → layout+0x60
    }
    layout->i2C = layout->iC4;
    layout->i28 = layout->iC0;
    FUN_00427050(); // ECX=layout; ESI=layout+0x80
  }

epilogue:
  layout->y += (int)layout->dy_AC;
  layout->ready_B4 = 1;
  text->resize(0);
  FUN_00427210(0);
  // RET 4
}
```
