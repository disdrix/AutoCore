## Machine-level notes

- **Convention:** `__cdecl`, one stack arg (`mission` / mission-def pointer), bool in **AL**.
- **Not** `__thiscall` — body loads **local character** global `DAT_00d1b6d8` into **ECX**, then calls `FUN_0052b3b0` (`CVOGCharacter_IsMissionJournalReady`) as thiscall.
- Null global → `xor al,al; ret` (**return false**). Ghidra `in_EAX & 0xffffff00` is the same AL-clear pattern.
- Single consumer: `FUN_008a3510` mission-detail panel builder. When panel mode `this+0x50c == 0` and this returns true → append icon suffix `"_done"` and label `"  [Complete]"`.
- Sibling UI paths (`FUN_0082a050`, `FUN_00829b20`) call `0052b3b0` **directly** with the same global as this; this VA is the **thin null-safe wrapper** only.
