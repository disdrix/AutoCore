## Machine-level notes

- **thiscall** ECX = destination vector shell; one stack arg = source vector shell; **`RET 4`**.
- Vector shell fields used: `begin@+0x4`, `end@+0x8`, `capacity_end@+0xC` (capacity written only inside residual buy `FUN_0041c250`).
- Element stride **0x18**: count = `(src.end - src.begin) / 0x18` when `src.begin != 0`, else 0. Byte path uses signed mul-inverse `0x2AAAAAAB`.
- SEH frame: `LAB_009bce90` / FS:[0]; EH state −1 entry, 0 around Ucopy, restore on exit.
- Copy-ctor (not assign): buy helper **zeros** begin/end/cap then allocates; **no** free of prior dest buffer.
- Empty source: buy returns 0 after zeroing → skip Ucopy → empty vector (null triple).
- Non-empty: `FUN_00422580(src.begin, src.end, dest.begin, dest*, src*)` then `dest.end = EAX`. Extra two stack args (dest/src shells) unused by the 3-arg POD Ucopy body; caller cleans `ADD ESP,0x14`.
- Element copy is 6×dword POD (`param_3 += 6` dwords = +0x18). Null-dest guard inside Ucopy.
- Buynode `0041d860` constructs map value: char key @ node+0x0C, then this unit with **ECX = node+0x10** copies the trailing vector.
- Do **not** merge with SkillSet Ucopy `0040a600` (different ABI/role) or leaf Ucopy `00442b00`.
