## Purpose

Core **errReport dispatcher** called by `vog_LogMessage` (`0x00996dc0`) and other assert/log sites:

1. Map severity (EDI) → label string via table `@ 0x00afa2c0`.
2. Obtain Meyer singleton manager via `FUN_0076d140` → `&DAT_00d1f888`.
3. If **`mgr+0x8 == 0`**: call **default sink** `FUN_0076d020` (console/`fputs` + `FUN_0076c130` ODS-style; **ESI=sourceFile**).
4. Else: reverse-walk circular handler list at **`mgr+0x4`**; for each handler with `threshold <= severity`, invoke **`handler->vtbl+4`** with `(sourceFile, line, severity, label, message)` and keep **max** return.
5. Policy:
   - if `maxVote >= 2` → return `maxVote`
   - else if `severity > 4` (FATAL+) → return **3** (abort gate for `vog_LogMessage`)
   - else return `maxVote` (typically 0/1)

Sibling dual `vog_LogMessage`: return **exactly 3** → `c:\VOGCRASH.txt` + `raise(SIGABRT)` + `ExitProcess(3)`.
