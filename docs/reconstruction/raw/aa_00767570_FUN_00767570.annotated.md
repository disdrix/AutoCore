## Purpose

Leaf **test-and-pop** on the stoChunk reader soft-skip bitset (same bit math as `stoChunkReader_SoftSkipIfBitSet` @ `0x00767120`):

1. If bitset size (`*EDI`) is 0 → return false.
2. Else test bit `(size - 1)`.
3. Shrink size to `size - 1` via `FUN_004362c0` (pop the top bit).
4. Return whether the bit **was** set (captured before shrink).

Peer `SoftSkipIfBitSet` is **test-only** (ECX reader, leaf, no callee). This unit is **test + mutate** (EDI view, one callee).
