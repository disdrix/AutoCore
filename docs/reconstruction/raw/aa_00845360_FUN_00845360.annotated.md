## Machine-level notes (W23-J)

- **ABI:** item/template in **EAX** (`mov esi,eax`); stack `param_1` = UI text widget (`int*` with vfuncs); stack `param_2` = enable char; **plain `ret`** after `add esp,0x8c`.
- **Early outs → 0:**
  1. `param_2 == 0`
  2. `*( *(item+0xa8) + 0x38 ) == 0x1a`
  3. `DAT_00d1b6d8 == 0` (no local player)
  4. All requirement fields empty (level sum inactive, race -1, class -1, combat/tech/theory/perception ≤0)
- **Otherwise:** append localized `"Requires:"` header (`0xffbbbbbb`), then optional lines:
  - Level (player vfunc `+0x27c` vs item level via `FUN_0040f540`)
  - Race (`FUN_0051f8e0` + player race byte `@+0x532`)
  - Class (`FUN_0051f940` + player class byte `@+0x531`) when class id ≠ -1
  - Combat / Tech / Theory / Perception vs sealed getters
- **Return:** number of lines written (includes header as 1 when any content).
- **Decomp hazard:** Perception exit `return unaff_EBP+1` is line-count +1, not real EBP.

```c
{
    StringTable *st = FUN_007a69d0();

        return 0;
    if (all_requirements_empty(item))
        return 0;

    int lines = 1;
    text->AppendColored(L("Requires:"), 0xffbbbbbb);

    // Level / Race / Class / Combat / Tech / Theory / Perception …
    // met → white 0xffffffff or vfunc+0x250; fail → red 0xffff2020
    return lines;
}
```
