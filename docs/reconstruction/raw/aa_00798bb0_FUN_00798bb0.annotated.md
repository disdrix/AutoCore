## Machine-level notes

- **ABI:** `__cdecl` — three stack args; epilogue `add esp,0x14; ret` (locals only; **caller** cleans args).
- **Return:** `char`/`uint8` in **AL** — **1** on success (text copied), **0** on fail.
- **Ghidra gap:** decompiler shows 2 formals + `unaff_retaddr` / `unaff_EDI` / `unaff_ESI`. Callers prove **3 args**; `unaff_retaddr` is the **out wchar buffer**, `unaff_EDI` is the **attribute node*** from `getNamedItem`.

## Control-flow summary

1. SEH frame.
2. If `attrName == NULL` → `nameBstr = NULL`; else `nameBstr = SysAllocString(attrName)`; OOM → `FUN_004048e0(0x8007000e)` (noreturn `_com_raise_error`).
3. `hr = map->getNamedItem(nameBstr, &attrNode)`.
4. If `hr >= 0` **and** `attrNode != NULL`:
   - `hr2 = attrNode->get_text(&textBstr)`.
   - `attrNode->Release()`.
   - If `hr2 >= 0`: `wcscpy(outText, textBstr)`; free both BSTRs; **return 1**.
   - Else free `textBstr` (may be null/partial).
5. `SysFreeString(nameBstr)`; **return 0**.

## Pseudocode (annotated, ABI-corrected)

```c
char __cdecl MSXML_NamedNodeMap_GetNamedItemText(
    IXMLDOMNamedNodeMap *map,
    const OLECHAR *attrName,
    wchar_t *outText)
{
  BSTR nameBstr;
  BSTR textBstr;
  IXMLDOMNode *attrNode;   // local_14 in decomp (out of getNamedItem)
  HRESULT hr;

  // SEH
  if (attrName == NULL) {
    nameBstr = NULL;
  } else {
    nameBstr = SysAllocString(attrName);
    if (nameBstr == NULL)
      FUN_004048e0(0x8007000e);   // noreturn
  }

  attrNode = NULL;
  hr = map->lpVtbl->getNamedItem(map, nameBstr, &attrNode);  // vtbl+0x1c
  if (hr >= 0 && attrNode != NULL) {
    textBstr = NULL;
    hr = attrNode->lpVtbl->get_text(attrNode, &textBstr);    // vtbl+0x68
    attrNode->lpVtbl->Release(attrNode);                     // vtbl+0x08
    if (hr >= 0) {
      wcscpy(outText, textBstr);
      SysFreeString(textBstr);
      SysFreeString(nameBstr);
      return 1;
    }
    SysFreeString(textBstr);
  }
  SysFreeString(nameBstr);
  return 0;
}
```
