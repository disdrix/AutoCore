## Machine-level notes

- **ABI:** MSVC **thiscall** — `ECX = out buffer*`, stack args `(addr:u32, port:u16)`, epilogue **`ret 8`** (callee cleans 2 stack args).
- **Role:** Zero 16-byte buffer → set `AF_INET` → store IPv4 addr dword → `htons(port)` → store port → return buffer pointer.
- **No `htonl` on addr:** `param_2` is written raw at `+4`. Callers that need network-order addr must pre-convert (or pass host-form sentinel like `0xFFFFFFFF`).
- **Sibling:** `Net_SockaddrIn_InitInvalid` (`0x0046e280`) calls this with `(addr=0xFFFFFFFF, port=0xFFFF)`.
- Prefer bytes when decompiler drops `this` (e.g. incomplete `FUN_00681950` decompile still passes ECX).

## Annotated control flow

```c
// thiscall: ECX = sa (16-byte out), stack: addr, port
sockaddr_like * __thiscall Net_SockaddrIn_Init(sockaddr_like *sa, uint32_t addr, uint16_t port)
{
  // 1) zero full 16 B (four dwords)
  sa->dwords[0..3] = 0;

  // 2) family = AF_INET (2)  — overwrites low 16 of first dword
  sa->family = 2;

  // 3) sin_addr = addr (raw; no htonl)
  sa->addr = addr;

  // 4) sin_port = htons(port)
  sa->port = htons(port);

  return sa;
}
```
