## Machine-level notes

- Source: raw capture + live Ghidra re-seal (W19-A).
- **`__fastcall`/`thiscall`**: vehicle in **ECX** → ESI for body.
- Stack frame: 16-byte aligned (`and esp,-16`), large locals (`sub esp,0xe4`).
- Two phases:
  1. **Conditional fire-clear** of the 3 hardpoint slots at `this+0x260` when a lock/control object at MI-relative `+0xb0` has `*(u8*)(obj+0xb4) & 0x13 != 0`.
  2. **Per-slot aim/fire update** loop count **3** (`local_c4` / `local_e8` countdown).

### Phase 1 — fire flag clear (sealed via callee duals)

For `i = 0,1,2` (dword stride 4 over table at `this+0x260`):

| Step | Callee / write | Meaning |
|---|---|---|
| load slot | `slot = *(this+0x260)[i]` | hardpoint pointer |
| if non-null | `Weapon_SetFireFlagPair(slot, 0)` @ `0x0056a260` | clear +0xC7/+0xC8 |
| always on non-null | `*(u8*)(slot+0xC9) = 0` | clear third fire-related byte |

Gate: `obj = *(int*)(*(int*)(*(int*)(this+4)+4) + 0xb0 + this)` and `(obj[0xb4] & 0x13) != 0`.

### Phase 2 — three hardpoint slots

| Local / offset | Role |

| `local_e4` | byte offset into aim-vector array (`slotIdx * 0xc`) |

| clonebase | via `*( *( *(this+4)+4 ) + 0xac + this )` then `+0x3c` plant/def blob |

### Mode field (`plant+0x50c`)

- Three **3-bit** fields packed: shifts 0, 3, 6 (`7 << shift`).
- Values observed in CF:
  - `{0,1}` → yaw angle forced **0**
  - other (incl. **2**) → yaw = `this+0x158`
  - **2** + `this+0x3a0` non-null → extra vtbl+0x18/+0x14 apply on that interface

### Nested vs local vehicle (`this+8`)

| `this+8` | Orient / pos sources | FireHelper host |

| **non-0** | `*(this+8)+0x3c + 0x30` / `+0xb0` | `*(this+8)+0x3c + 0x40` |

### Graphics attachment path (gated)

When slot has `slot+8` iface **and** `this+0x105 != 0` **and** `slot+0xc0` chain non-null:

1. Compose matrices / basis via helpers above.
2. `Math_Matrix4x4_Set16` with Y-up identity middle column (`0, 1.0f, 0` as `0 / 0x3f800000 / 0`).
