## Machine-level notes

- **Class:** `CVOGObjectiveRequirement_Patrol` — vtable `PTR_FUN_009e0404`, this method at **`vtable+0x04`** (event-driven Action; same slot as Collect_Action).
- **Not** the dualed progress-fraction method `CVOGObjectiveRequirement_Patrol_Action` @ `0x0060e120` (`vtable+0x10`).
- **ABI:** `__thiscall`, ECX=req*, **7 stack args**, **`RET 0x1C`**, AL=0|1.
- **Events:** `0x0C` = AutoFail flag path (no distance); `0x0B` = pad-proximity AutoComplete / AutoFail-distance.
- **Fields** (sealed via dualed GetFlags `0x0060e260`):
  - `+0x08` slot index byte
  - `+0x10` AutoComplete (char)
  - `+0x14` AutoCompleteDistance (float)
  - `+0x18` AutoFail (char)
  - `+0x1c` AutoFailDistance (float)
  - `+0x24` Laps (int)
  - `+0x30` GenericTargetCOID pairs (i64-ish, step 8)
  - `+0xd0` target count
- **Constants:** `DAT_00aaa688 = 5.0f` slop; `g_flOne = 1.0f`.
- Prefer assembly when decompiler types event as `float*` or invents `in_stack_0000001c`.
