## Machine-level notes

- **ABI:** `__thiscall` — **ECX = Character\***; stack **tier** (uint 1..5); **`ret 4`** on every exit.
- **Level source:** `*(uint8_t*)(this + 0x599)` — same byte free-score dual uses as character level.
