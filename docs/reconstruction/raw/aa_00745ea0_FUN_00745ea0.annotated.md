## Role

**Soft-decrement the NDResource shell refcount** under the optional resource critical section.

| Step | Action |
|---|---|
| 1 | If `this+0x38 != 0`: `EnterCriticalSection(this+0x20)` |
| 2 | Default return `0xffffffff` |
| 3 | If `*(int*)(this+0x10) != 0`: `--refcount`; return becomes `0` |
| 4 | If flag still set (`CS+0x18` ≡ `this+0x38`): `LeaveCriticalSection` |
| 5 | Return status in EAX |

**Not** a full `Release` destructor path: no vtbl call, no free, no inner clear. Pair with `NDResource_AcquireInnerObject` (`0x00745ee0`) which increments the same `+0x10`.

## Annotated control flow

```c
uint32_t __thiscall NDResource_DecRef(void *self)
{
  /* ESI = self; EBX = &self->cs (+0x20); EDI = result */
  if (*(uint8_t *)((char *)self + 0x38) != 0)
    EnterCriticalSection((LPCRITICAL_SECTION)((char *)self + 0x20));

  uint32_t result = 0xffffffff;
  int *pRef = (int *)((char *)self + 0x10);
  if (*pRef != 0) {
    *pRef = *pRef - 1;
    result = 0;
  }

  /* leave uses flag at CS+0x18 == self+0x38 (same byte) */
  if (*(uint8_t *)((char *)self + 0x38) != 0)
    LeaveCriticalSection((LPCRITICAL_SECTION)((char *)self + 0x20));

  return result;
}
```
