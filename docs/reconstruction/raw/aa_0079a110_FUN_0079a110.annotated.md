## Purpose

Load the **float time** field at host offset **`+0x238`** and return it in ST0.

Heavy use as **game clock / anim sample time**: many callers do `MOV ECX, [DAT_00b04c74]; CALL FUN_0079a110` then feed the result into anim slot setup (`FUN_0074e910`) or other time consumers. Body is a pure field load — no side effects, no callees.
