## Purpose (sealed structural)

**In-place vertical flip** of an `NDAssetImage` / CxImage instance:

1. Gate on DIB owner pointer at `image+4` (null → return `0`).
2. Allocate a **temp** image `new(0x1b8)`, install vtbl `PTR_FUN_00a9bcac`, construct (`FUN_004320d0`), deep-copy from source with pixel-buffer flag (`FUN_00432260(src,0,0,1)`).
3. If temp DIB (`temp+4`) non-null:
   - **Row-reverse copy** of DIB bits: source last row → temp first row using pitch `@+0x30`, bits `@+0x34`, height `@+0x10`.
   - Call `NDAssetImage_FlipVertical` on temp (flips **info/alpha buffer** at `+0x1b0`).
   - `FUN_00432580(src)` — transfer fields/buffers **temp → source**, zero temp ownership.
   - Virtual dtor `(*temp->vtbl)(1)` — destroy temp.
   - return `1`.
4. Else return `0`.

**Caller:** BMP decode `FUN_00433dc0` when **top-down DIB** (`biHeight < 0` → `local_1f`), after pixels loaded — matches CxImage::Flip for top-down BMPs.

**Distinct from** `NDAssetImage_FlipVertical` (`0x004332e0`), which only flips the `+0x1b0` buffer in-place without DIB row reorder / temp object.

## Control flow map

```
if image+4 == 0: return 0
temp = new(0x1b8); if !temp: return 0
temp.vtbl = PTR_FUN_00a9bcac
NDAssetImage_Ctor(temp)                 // FUN_004320d0
NDAssetImage_CopyFrom(temp, image, 0,0,1) // FUN_00432260 — copy +0x1b0
if temp+4 == 0: return 0
// row reverse: src last row → dest first row
src = image.pBits + (height-1)*pitch
dst = temp.pBits
for row in 0..height-1:
  memcpy(dst, src, pitch)
  src -= pitch; dst += pitch
NDAssetImage_FlipVertical(temp)         // +0x1b0 flip, EBX=temp
NDAssetImage_TransferFields(image, temp) // FUN_00432580 — steal buffers
temp->vtbl dtor(1)
return 1
```

## Annotated pseudocode

```c
// NDAssetImage_Flip @ 0x0098ae80
// stack NDAssetImage* image; ret 4; AL 0/1

uint8_t NDAssetImage_Flip(NDAssetImage* image)
{
  if (*(int*)(image + 4) == 0)
    return 0;

  NDAssetImage* temp = (NDAssetImage*)operator_new(0x1b8);
  if (!temp)
    return 0;

  *(void**)temp = &PTR_FUN_00a9bcac;
  FUN_004320d0();                 // ctor; ESI/unaff = temp
  FUN_00432260(image, 0, 0, 1);   // copy into temp; EAX=temp residual

  if (*(int*)(temp + 4) == 0)
    return 0;

  int height = *(int*)(image + 0x10);
  int pitch  = *(int*)(image + 0x30);
  uint8_t* src = (uint8_t*)(*(int*)(image + 0x34) + (height - 1) * pitch);
  uint8_t* dst = (uint8_t*)*(int*)(temp + 0x34); // puVar3[0xd]

  for (int row = 0; row < height; row++) {
    // REP MOVSD + MOVSB of pitch bytes
    memcpy(dst, src, (size_t)pitch);
    src -= pitch;
    dst += pitch;
  }

  NDAssetImage_FlipVertical(); // EBX = temp; flips +0x1b0
  FUN_00432580(image);         // transfer temp → image; zero temp ownership
  (*(void(__thiscall**)(void*, int))*(void**)temp)(temp, 1); // dtor
  return 1;
}
```
