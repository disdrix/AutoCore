## Machine-level notes

- **Register contract** (not ECX-thiscall): **ESI** = primary UI object to close; **EDI** = secondary UI object to notify/reset.
- Prefer listing over decompiler: decompiler shows `unaff_ESI` / `unaff_EDI` (correct) but loses call-site host/chrome assignment.
- All edges are **virtual** (`vtbl+0x3d8`, `+0xcc`, `+0x440`, `+0xb0`, `+0x3bc`, `+0x3f4`) — static callee list empty / leaf.
- Shared visibility probe `vtbl+0x3d8` and dismiss `vtbl+0x440` match dualed UI patterns (`Client_DismissProgressBar`, mission Flush invoker, medal prep).
- Host detach/notify `vtbl+0xb0(child)` pattern matches dualed medal/progress paths — here `EDI->vtbl+0xb0(ESI)`.
- Global `DAT_00d1b978` also used on Tell pack `0x11176` inside dualed parent sibling `FUN_00830010` (chat/tell panel).
