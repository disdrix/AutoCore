## Purpose

**Deep-instantiate / clone** an `NDSpecialFX` host from a template:

1. `operator_new(0x240)` + **`FUN_004ba310(name)`** — host ctor (name `strncpy` to `+0xd5`, length `0x104`).
2. Copy scalar flags from template: `+0x28`, `+0xc`, `+7`, `+6`, `+4`.
3. If `filterId == -1`: `FUN_004a7e30(template+0x90)` (unfiltered path setup — residual).
4. Optional deep copy of `+0x60` blob (`0x30` bytes) with back-pointer at blob `+0x2c`.
5. Walk map at **`+0x228`**: clone each payload (`0x28` bytes) via `FUN_004a7580` (RB-tree successor walk).
6. Build empty RB sentinel (`FUN_00439770`) used later for parent remaps.
7. Walk list **`+0x204`**: filter by `payload+0x904 == filterId` (or all if −1); spawn count = `*(short*)(payload+700) * scale` (with flag `payload+0x90d & 1` starting at count−1); each via `FUN_00590800(cloneHost)`, stamp `inst[0x242] = stamp`, insert `FUN_004a7670`.
8. Post-touch clone’s `+0x204` with `FUN_0058f610`.
9. Walk **`+0x21c`**: if `node+0x178 != 0` and `FUN_0049a120()`: `FUN_004b92b0`.
10. Walk **`+0x1e0`** (primary FX graph nodes): filter `node+0x8c0`; replicate `count = short(node+0x8f8)` or `*(short*)(*(node+8)+700)` × scale; each `FUN_005bdcf0(cloneHost)`:
    - stamp `+0x8c4 = stamp`, parent host `+4 = cloneHost`, flags `+0x7fe/+0x7ff = 1`
    - clone linked lists at `+0x7dc`, `+0x1c`, chain at `+0x14/+0x308` (nodes `0x3e4` via `FUN_004a6c80`)
    - optional second chain when `node+0x7fc != 0` (`+0x3f8/+0x6ec`)
    - parent remap via `FUN_005b0990` / temp list / `FUN_004a7210`
    - insert into clone `+0x1e0` list (`FUN_006759b0` + `FUN_004a6be0`)
11. Walk **`+0x210`**: allocate `0x17c`, `FUN_005b94e0`, POD copy `0x5f` dwords; stamp `+0x28` (index 10); OR flags `+0x179 |= 0x18`; rewire lists; insert into clone `+0x210`.
12. Walk **`+0x1ec`**: POD clone `0x138` (`0x4e` dwords) into clone list.
13. Walk **`+0x1f8`**: POD clone `200` (`0x32` dwords) into clone list.
14. Tear down temporary list (`local_20` / `FUN_004397f0`).

**Caller seal** (`NDSpecialFX_LoadFromScriptName` @ `0x004a61b0`, dual-reviewed):

```c
FUN_004a0b90(fx, fx + 0xd5, /*scale*/ 1, /*filter*/ -1, stamp);
```

So: template host, name at `template+0xd5`, scale 1, no filter, stamp = load-path 3rd arg.

## Control-flow outline

```
SEH enter
host = new(0x240); if host: FUN_004ba310(host, name) else null
copy flags template → host
if filter == -1: FUN_004a7e30(template+0x90)
if template.blob60: host.blob60 = copy 0x30; blob.back = host
for each map node in template+0x228:
  clone payload 0x28; FUN_004a7580; tree-successor
sentinel = empty RB node
for each in template+0x204 matching filter:
  for i in scaled count range:
    inst = FUN_00590800(host); stamp; FUN_004a7670
for each in host+0x204: FUN_0058f610
tmpList = FUN_004397f0()
for each in template+0x21c: maybe FUN_004b92b0
for each in template+0x1e0 matching filter:
  for k in 1..count*scale:
    deep-clone node graph into host+0x1e0; parent remap; flush tmpList maps
for each in template+0x210 matching filter:
  clone 0x17c objects × scale into host+0x210
for each in template+0x1ec: POD 0x138 into host
for each in template+0x1f8: POD 200 into host
destroy tmpList
SEH leave
// return of host*: decompiler-modeled void — residual
```
