## Machine-level notes

- Source: raw capture + live `decompile_function` / `read_memory` (no `disassemble_bytes`).
- **ECX** = object; **no stack args**; returns **bool in AL** (`seta` / `sbb+neg` paths).
- Core flag: **`*(u8/u32*)(obj+0x184) & 0x08`** (bit **3**). Peer duals often write “bit 8” meaning the **mask**, not bit index 8.
- Parent chain field: **`obj+0xac`** (same link used by dirty helper `FUN_00512670`).
- When parent non-null: call **`parent->vtbl[+0x19c]()`** (related/owner resolve). If non-null result, test flag at **`result + *(*(result+4)+4) + 0x188`** (MSVC MI this-adjust + flag). Else test **`parent+0x184 & 8`**. Result is **OR** with self bit.

## Pseudocode (annotated)

```c
// ECX = Object* / CVOGClonedObject*
// return true if self has flag8, or (when +0xac linked) linked owner/related also has flag8
bool __fastcall Object_HasFlag8SelfOrLinked(int obj /* ECX */)
{
  int *parent = *(int **)(obj + 0xac);
  if (parent == NULL) {
    // no link: pure self
    return (*(uint *)(obj + 0x184) & 8) != 0;
  }

  // resolve related entity via parent vtbl +0x19c
  int related = (**(code **)(*parent + 0x19c))(); // thiscall parent
  bool selfFlag = (*(byte *)(obj + 0x184) & 8) != 0;

  if (related != 0) {
    // MI adjust: base = *(*(related+4)+4); test byte at related+base+0x188
    int adj = *(int *)(*(int *)(related + 4) + 4);
    bool relFlag = (*(byte *)(related + adj + 0x188) & 8) != 0;
    return selfFlag || relFlag;
  }

  // related null: fall back to parent object's own +0x184 bit
  return selfFlag || ((*(byte *)((int)parent + 0x184) & 8) != 0);
}
```
