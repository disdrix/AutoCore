## Purpose

**Lazy singleton getter** for the process-wide **`CVOGLootGenerator`** (loot/economy content manager) stored in **`DAT_00b037e8`**.

On first call when the global is null:

1. `operator_new(0xbc)` — object size **0xBC** (matches `CVOGSectorMap_InitGenerators` / `LootManager_ctor` duals).
2. `__thiscall FUN_0050c1b0(new, DAT_00b041fc)` — ctor (`LootManager_ctor_Inferred` / CVOGLootGenerator ctor) with table root.
3. Store result in `DAT_00b037e8`.
4. On OOM: store 0, return null.

Always returns the singleton pointer in **EAX** (null only if construction failed). Subsequent calls are a cheap load + SEH frame when non-null path short-circuits after the test (EAX still holds the loaded global).

This unit does **not** roll loot, walk tables, or take arguments — pure ensure/get.

## Annotated control flow

```c
// no args; returns CVOGLootGenerator* (or null)
CVOGLootGenerator* CVOGLootGenerator_GetOrCreate(void)
{
  // SEH frame (handler LAB_009a1f0c)
  if (DAT_00b037e8 != 0)
    return (CVOGLootGenerator*)DAT_00b037e8;   // EAX already loaded

  void* mem = operator_new(0xbc);
  if (mem == 0) {
    DAT_00b037e8 = 0;
    return 0;
  }
  // __thiscall: ECX = mem, arg0 = DAT_00b041fc (table root)
  DAT_00b037e8 = FUN_0050c1b0(mem, DAT_00b041fc);
  return (CVOGLootGenerator*)DAT_00b037e8;
}
```
