## Machine-level notes

- **ABI (sealed):** **EBX** = `CNDHash*`; bare `ret`. Decompiler `unaff_EBX` is the real formal — parent `FUN_00406fc0` does `mov ebx,eax` before the call.
- **Entry:** `push ebp/esi; xor ecx; push edi; xor ebp` (bucket index 0 in EBP); immediately `mov eax,[ebx+0x10]` (bucket table).
- **Exit:** `pop edi/esi/ebp; ret` (`5F 5E 5D C3`).
- **Callee:** `operator_delete` only for **payload** at `node+0x0C` — node itself is freelist-recycled, not freed.
- **Decompiler trap:** "Subroutine does not return" on `operator_delete` is **false** for this path; freelist link after delete is load-bearing.
