## Machine-level notes

- One-shot **QPC ↔ RDTSC** calibration that writes the 64-bit TSC frequency (ticks/sec) used by `Timer_GetTimeSeconds_Rdtsc` (`aa_0076c330`).
- Nullary cdecl/plain RET; all outputs are globals `DAT_00d1a538:53c` + ready flag `DAT_00d1a530`.
- Wait interval is `QueryPerformanceFrequency() >> 4` QPC counts ≈ **62.5 ms** (1/16 second), not a fixed iteration count.
- Spin samples `QueryPerformanceCounter` + `rdtsc` until QPC ≥ start + (freq>>4).
- Scale math uses MSVC helpers `__allmul` / `__aulldiv` for 64-bit:

```
Δtsc  = tsc_end - tsc_start
Δqpc  = qpc_end - qpc_start
scale = (Δtsc * freq) / Δqpc     // ≈ TSC Hz
```

- No lock around flag/scale (race on concurrent first use open).
- Image static zeros for all three globals (BSS / zero-init).

## Annotated control flow

```
Timer_CalibrateTscPerSec():
  QueryPerformanceFrequency(&freq)
  QueryPerformanceCounter(&qpc0)
  tsc0 = rdtsc()
  target = qpc0 + (freq >> 4)          // ~1/16 s later
  do {
    QueryPerformanceCounter(&qpc1)
    tsc1 = rdtsc()
  } while (qpc1 < target)
  scale = ((tsc1 - tsc0) * freq) / (qpc1 - qpc0)
  DAT_00d1a538 = (u32)scale
  DAT_00d1a53c = (u32)(scale >> 32)
  DAT_00d1a530 = 1
```

## Pseudocode (raw, with sealed names)

```c
void Timer_CalibrateTscPerSec(void)
{
  LARGE_INTEGER freq, qpc0, qpc1;
  uint64_t tsc0, tsc1, scale;

  QueryPerformanceFrequency(&freq);
  QueryPerformanceCounter(&qpc0);
  tsc0 = rdtsc();

  uint64_t target = (uint64_t)qpc0.QuadPart + ((uint64_t)freq.QuadPart >> 4);
  do {
    QueryPerformanceCounter(&qpc1);
    tsc1 = rdtsc();
  } while ((uint64_t)qpc1.QuadPart < target);

  scale = __aulldiv(__allmul(tsc1 - tsc0, freq.QuadPart),
                    (uint64_t)qpc1.QuadPart - (uint64_t)qpc0.QuadPart);
  DAT_00d1a538 = (int)scale;
  DAT_00d1a53c = (int)(scale >> 32);
  DAT_00d1a530 = 1;
}
```
