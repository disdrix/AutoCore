## Machine-level notes

- **cdecl leaf:** three stack pointer args; bare `RET`. Callers often push a **4th unused** dword and clean `0x10`.
- Inner primitive is **`rep movsd`** with **`ECX = 0x32`** (50 dwords = **200 / `0xC8` bytes**).
- Outer loop advances both src and dest by **`0xC8`** until src cursor equals exclusive end.
- Decompiler `for (iVar2 = 0x32; …)` is accurate; pointer math `param + 0x32` is dword-scaled (= +200 bytes).
- Prefer bytes + call sites over inventing a free/destructor role — this is **only a block move**.
