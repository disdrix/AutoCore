## Machine-level notes

- **Leaf** dword erase-range. Prefer bytes over decompiler for register formals.
- **EBX** = vector control block (`end` at `+8`); **EAX** = out-iterator pointer; stack **first/last**; **`RET 8`**.
- Twin `FUN_00410490` uses thiscall + `memmove` + `RET 0xC` — different ABI, same algorithm class.
- Sole consumer today: `FUN_0044a380` shrink arm (W37-Z sealed).

## Annotated CF

```c
// EBX = vec*; EAX = outIt*; stack first, last; RET 8
void StdVector_DwordEraseRange_EbxVec_Inferred(
    uint32_t* first /*stack*/,
    uint32_t* last  /*stack*/)
{
  // bytes: MOV ECX, [esp+8] (last); PUSH EDI; MOV EDI, [esp+8] (first)
  if (first != last) {
    uint32_t* end = *(uint32_t**)(ebx + 8);   // vec->end
    uint32_t* dest = first;
    for (; last != end; last++, dest++) {
      *dest = *last;                          // dword; +4/+4
    }
    *(uint32_t**)(ebx + 8) = dest;            // publish new end
  }
  *outIt /*EAX*/ = first;
}
```
