## Purpose

**Default UI message handler** used as fallthrough from dozens of dialog-specific switch cases. It:

1. **Swallows** message codes in **`[7, 15]`** (`0x07`–`0x0F`) by returning **1** (handled / no further work). Sibling duals treat **8** as activate; **7 / 0xD / 0xE** also appear as “already handled” event classes.
2. Otherwise calls **`this->vtbl+0xD8()`** (predicate, char/bool). If false → return **0**.
3. If predicate true **and** parent pointer **`this+0x2B0`** non-null → **forward** `(msg, controlId)` to **`parent->vtbl+0x338`** and return that result.
4. Else return **0** (unhandled / no parent).

Not a network builder. Not mission logic. Pure message-chain base.

## Signature (machine-sealed)

```c
// __thiscall — ECX = this (UI window/control)
// stack: [esp+4]=msg, [esp+8]=controlId
// epilogue: ret 8
unsigned __thiscall UI_DefaultMessageHandler(void *pThis, int msg, unsigned controlId);
```

## Offsets / vtables

| Site | Meaning | Conf |
|---|---|---|
| `this+0x2B0` | Parent window / host control pointer | **High** (bytes `[esi+0x2B0]`) |
| `this->vtbl+0xD8` | Predicate “may forward / is eligible” → `char` | **High** |
| `parent->vtbl+0x338` | Message virtual (widely used UI bubble slot) | **High** (peer duals) |
| msg range `7..15` | Auto-handled event band | **High** |

## Algorithm

```
if 7 <= msg <= 15: return 1
if !this->vtbl[0xD8/4](this): return 0
parent = *(this+0x2B0)
if parent == null: return 0
return parent->vtbl[0x338/4](parent, msg, controlId)
```
