## Control flow (annotated stages)

```

ensure alphabet container (FUN_00433c00 / FUN_00433ba0 0x100)
seed 256 leaves from DAT_00a1ea68
worklist[i] = { node*=0, leaf*=&alphabet[i] }
while count > 1:
  pick two lowest-weight entries (A,B)
  grow tree array if needed (malloc, copy, free old; cap rounded up to 16)
  parent.weight = wA + wB
  parent.left/right = encode(A/B) as leaf or internal short
  replace min-index slot with parent; shrink worklist (swap-from-end)
root = worklist[0]; copy into tree[0]
delete worklist
scratch BitStream(ctx); FUN_0077d440(ctx, rootIndex=0, depth=0)  // fill codes
destroy scratch
```
