## Machine-level notes

- **EDI** = bucket header* (chain head at **`+4`**). Custom register ABI — not ECX-thiscall.
- Bare **`ret`** (`c3`); pushes **EBX** + **ESI** as scratch.
- Walk marks **`node+0x08` = 1**; advances via **`node+0x10` (next)**.
- Healthy end-of-chain: second walk clears all marks to **0**.
- Cycle / re-touch: log severity **1** via `FUN_007a4480(1, str@0x00a64710)`; sever **`prev->next = 0`**; clear marks.
- No free, no key compare, no ordered-list (`+0x20/+0x24`) work.
- Always invoked after head-insert / bucket unlink in this family (not debug-gated).

## Recovered CF (annotated)

```c
// EDI = CNDHash bucket header*
// bare ret; void
void CNDHash_BucketChainTouchRepair(void /* EDI = bucket */)
{
    Node *cur = *(Node **)((char *)bucket + 4);  // head
    if (cur == 0)
        return;

    do {
        Node *prev = cur;
        *(uint8_t *)((char *)prev + 8) = 1;      // touch mark
        cur = *(Node **)((char *)prev + 0x10);   // next
        if (cur == 0) {
            // healthy: clear all marks
            for (cur = *(Node **)((char *)bucket + 4);
                 cur != 0;
                 cur = *(Node **)((char *)cur + 0x10))
            {
                *(uint8_t *)((char *)cur + 8) = 0;
            }
            return;
        }
    } while (*(char *)((char *)cur + 8) == 0);

    // already-touched next → cycle / corruption
    FUN_007a4480(1, "HashListError: Went to node we already touched! Attempting repair!");
    *(Node **)((char *)prev + 0x10) = 0;         // sever
    cur = *(Node **)((char *)bucket + 4);
    if (cur != 0) {
        do {
            *(uint8_t *)((char *)cur + 8) = 0;
            cur = *(Node **)((char *)cur + 0x10);
        } while (cur != 0);
    }
}
```
