## Machine-level notes

- **ABI:** EDI = widget; no stack args; EAX return (`0` / `-1`); plain `RET`.
- **Not** ECX thiscall. Decompiler `unaff_EDI` is the real formal (call sites `MOV EDI, tabCtrl`).
- Prefer disasm when decompiler collapses `FUN_00456960` arity — live setup is ECX=1, EDX=`group+0x90`, stack pos=`begin`, EAX=`&widget_local`.
- `FUN_00456960` is the known std::vector **InsertN** grow helper (not erase).
- Contrast true detach sibling `FUN_00756be0` (clears `widget+0x88`).

// returns 0 ok, 0xFFFFFFFF if no parent group
undefined4 UI_Widget_MoveToFrontInParentGroup_Inferred(void)
{
  int *group;      // ESI: widget[+0x88]
  int *begin;      // group[+0x94]
  int *end;        // group[+0x98]
  int *p;          // scan cursor
  int widget_local;

  group = *(int **)(unaff_EDI /*widget*/ + 0x88);
  if (group == 0) {
    return 0xffffffff;                 // no parent group
  }

  begin = *(int **)(group + 0x94);
  // size == (end - begin) >> 2
  if (begin != 0 &&
      ((*(int *)(group + 0x98) - (int)begin) >> 2) == 1) {
    return 0;                          // singleton group: leave order alone
  }

  // Erase self from pointer vector if present
  end = *(int **)(group + 0x98);
  for (p = begin; p != end; p = p + 1) {
    if (*p == unaff_EDI) {
      memmove(p, p + 1, ((int)end - (int)(p + 1)));  // byte count via SAR*4
      *(int *)(group + 0x98) = *(int *)(group + 0x98) - 4;
      break;
    }
  }

  // Insert self at front: InsertN(count=1) into vector at group+0x90
  // Live ABI into FUN_00456960:
  //   ECX = 1
  //   EDX = group + 0x90
  //   stack = current begin (insert position)
  //   EAX = &widget_local; widget_local = widget
  widget_local = unaff_EDI;
  FUN_00456960(/*count*/1, /*vec*/ (int)group + 0x90, /*pos*/ *(undefined4 *)(group + 0x94));
  return 0;
}
