## Machine-level notes

- **ABI:** `__cdecl` — three stack args, bare **`ret`**. Order: **dst, src, n**.
- **ISA:** classic MSVC memcpy shape: `rep movsd` for `n >> 2` dwords, then `rep movsb` for `n & 3` residual bytes. ESI=src, EDI=dst.
- **Leaf:** no callees; no IAT `memcpy` (inline string-ops path).
- **Semantics:** **forward-only** POD byte copy (**memcpy**, not `memmove`). Dest must not overlap src in the `memmove`-required direction.
- **Parents:** primary consumer of grow/realloc paths (`FUN_005b3300` HB grow, `FUN_005b3370` GrowableArray_DoubleGrow, many framework/string buffers). Call sites pass **byte counts** (`count * stride` or `len+1`).

## Pseudocode (annotated)

```c
// __cdecl
void Mem_CopyBytes(void* dst, const void* src, unsigned n)
{
  // dword phase
  unsigned dwords = n >> 2;
  while (dwords--) {
    *(uint32_t*)dst = *(const uint32_t*)src;
    dst = (char*)dst + 4;
    src = (const char*)src + 4;
  }
  // residual 0..3 bytes
  n &= 3;
  while (n--) {
    *(uint8_t*)dst = *(const uint8_t*)src;
    dst = (char*)dst + 1;
    src = (const char*)src + 1;
  }
}
```

Byte-equivalent retail body uses `rep movsd` / `rep movsb` with ESI/EDI.
