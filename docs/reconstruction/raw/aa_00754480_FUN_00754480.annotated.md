## Machine-level notes

- **ABI:** ECX = `Palantir*`. Bare `RET` (`C3`). EAX = `0` success / `0xFFFFFFFF` failure.
- **Prologue:** `PUSH ESI; MOV ESI,ECX; … PUSH EDI; LEA EDI,[ESI+8]`.
- **Nested device reset:** Before `CALL FUN_0075eff0`:
  - `MOV AL,[ESI+5]` → push as stack arg3
  - `MOV ECX,[ESI+0xB0]` → push as stack arg2
  - `MOV EDX,[ESI+0x28]` → push as stack arg1
  - `MOV EAX,EDI` → **EAX = this+8** (live-in for nested; decompiler under-reports)
- **Failure arm:** log `Palantir.cpp:0x184` + product string; `byte[this+6]=1`; `Sleep(1000)` IAT `@0x009c61a8`; `OR EAX,-1`; restore ESI/EDI; RET.
- **Success arm:** `byte[this+6]=0`; `ECX=*(this+0x2C)`; `PUSH EDI` (this+8); `CALL [vtbl+8]`; `XOR EAX,EAX`; RET.
- **Classification:** worker (calls device reset + log + Sleep + one virtual).
- **Callers:** direct `FUN_007a3c80`; vtbl[1] of `PTR_FUN_00a9f76c` (Palantir dtor-phase / live vtbl family — W34-K).
- **Decompile gap:** omits explicit `EAX=this+8` setup into `FUN_0075eff0`. **Bytes win.**
