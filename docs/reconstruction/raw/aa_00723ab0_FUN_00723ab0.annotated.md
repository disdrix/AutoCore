## Machine-level notes

- **ABI:** index in **EAX**, manager `this` in **ECX** (`__fastcall` / MSVC thiscall-with-index-in-EAX). No stack args. **`ret`** (not `ret N`). Return status in **AL** (`1` success, `0` fail).
- **Slot table:** `this+0x31c` is `SoundInstance*[48]` (index must be `< 0x30`).
- **Gate flags on instance:**
  - `+0x38` — “already stopped” (error log first `%d`); set to **1** on success stop.
  - `+0x3a` — “flagged to start playing” (error log second `%d`); cleared to **0** on success.
  - Success requires **both zero** before stop.
- **Fade/envelope write:** `FUN_007227e0(0.0f)` then `fstp [instance+0x1b0]`. With arg `0`, helper returns **`DAT_00aaa5d8 = -10000.0f`** (sentinel / instant-stop envelope; product meaning of field residual).
- Ghidra raw invents `uVar2` packing and `extraout_ECX` — **false**. Assembly keeps `ECX=this`, `EAX=index` across the float call; only ST0 is the float result. Prefer this annotated / asm CF over 2026-07-23 decompiler extras.
- Sibling `FUN_00723b20` (`CSoundManager_StopMatchingSounds`) walks the same `+0x31c` table and calls this unit per matching slot.

// returns AL: 1 = stop accepted, 0 = out of range / null / invalid flags

{

  int inst;

    return 0;

  if (inst == 0)
    return 0;

      0,
      "CSoundManager::_stopSound called with sound that was either already stopped(%d), or flagged to start playing(%d)",

  return 0;
