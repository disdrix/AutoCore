## Machine-level notes

- **ABI:** `__thiscall` — `ECX` = list host; stack arg = payload pointer; epilogue **`ret 4`**.
- **Null payload:** early-out with **AL = 0** (no alloc, no lock).
- **Node:** `operator_new(0xC)`; vtbl **`PTR_FUN_009cb340`** (`0x009cb340`); layout `{vtbl, payload*, next*}`.
- **Locks:** always `EnterCriticalSection(list+0x10)`; if **`count ≤ 3`** also outer `EnterCriticalSection(list+0x28)` (flag at frame `ebp-0x11`).
- **Link:** empty tail → head=tail=node; else `old_tail->next = node`, `tail = node` (singly-linked tail append).
- **Epilogue helper `FUN_00402598`:** Leave `+0x10` (and outer `+0x28` if taken); **`InterlockedIncrement(list+0xC)`**; restore SEH; return success byte (**1**).
- **Callers (sample):** `Object_EnqueueDeferredOnce` `0x004d0e90`, `Object_QueueDelete` `0x004d4790`, spawn/create paths, mission/reaction lists — all treat this as **CS-protected append**.
