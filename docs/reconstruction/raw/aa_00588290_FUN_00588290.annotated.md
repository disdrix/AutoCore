## Machine-level notes

- **ABI:** `__thiscall` — `ECX` = host with inventory grid at `+0x35c` (RTTI path: `CVOGStore*`); stack `item*`, `qty`; `RET 8`.
- **Body:** `0x00588290`–`0x00588440` (`0x1B1` B).
- **Sole code caller:** `FUN_00588450` @ `0x00588489` — dynamic_casts target to `CVOGStore`, then calls here with item + `GetQty(item)`.
- **Grid:** `*(this+0x35c)` — residual scratch `a_005714e0` seals asm `mov ecx,[ebp+0x35c]` at FindFree call site.
- **List walk:** same TraversalLock / Next / unlock family as grid list at `grid+0x2c` (helpers take list ECX = `grid+0x2c`).
- **Decompiler noise (preserve semantics, clean names):**
  - `unaff_EBX` / `unaff_retaddr` on Place call = **outX / outY** locals written by FindFree* (`&stack0xfffffff0` / `&stack0x00000000` in decompile).
  - `FUN_00513e70` / `FUN_00512670` are `__fastcall` with item in ECX (not visible as args in decompile).

## Control flow (sealed)

1. If `item == NULL` **or** `*(this+0x35c) == 0` → return **0**.
2. Begin list traversal on `grid+0x2c`.
3. For each existing item:
   - Null skip.
   - Match CBID: `*(item->typeHolder+0x34) == *(incoming->typeHolder+0x34)` where `typeHolder = item[0x2a]` (`item+0xa8`).
   - `Item_IsStackEligible(existing)` (`FUN_00513e70`) non-zero.
   - On hit: `SetQty(existing, GetQty(existing) + qty)`, unlock grid list, return **qty**.
     - **Odd / preserve:** **no** `Item_CanAcceptStackQty` / max-stack clamp on this merge path.
4. Unlock if still locked.
5. Free-path prep on **incoming** item:
   - `SetQty(item, qty)` (absolute assign of arg).
   - `item+0x17c |= 0x10` (`param_2[0x5f] |= 0x10`).
   - Dirty `FUN_00512670(item)`.
6. Placement search on grid:
   - If InvSizeX **and** InvSizeY both 0 at `cloneBlob+0x406/+0x407` → `FindFreeSlot(grid, 2, 2, &outX, &outY, page=-1)`.
   - Else → `FindFreeForItem(item, &outX, &outY, allowStack=1, page=-1)`.
7. If found: `PlaceItemFootprint(grid, item, outX, outY, GetQty(item))` → return **qty**.
8. Else return **0**.

```c
// CVOGStore_TryAddItemQty_Inferred
int __thiscall CVOGStore_TryAddItemQty_Inferred(void* store, Item* item, int qty)
{
  InventoryGrid* grid = *(InventoryGrid**)((char*)store + 0x35c);
  if (item == nullptr || grid == nullptr)
    return 0;

  int iterState = 0;
  Item* existing = nullptr;

  List_BeginTraversal_Inferred((char*)grid + 0x2c);          // FUN_004294f0
  int done = List_Next_Inferred((char*)grid + 0x2c, &iterState, &existing); // FUN_004022a0

  while (done == 0) {
    if (existing != nullptr
        && *(int*)(*(int*)((char*)existing + 0xa8) + 0x34)
           == *(int*)(*(int*)((char*)item + 0xa8) + 0x34)
        && Item_IsStackEligible(existing)) {                  // FUN_00513e70
      int cur = GetQty(existing);                             // vtbl+0x25c
      SetQty(existing, cur + qty);                            // vtbl+0x260 — NO capacity check
      GridList_UnlockIfHeld(grid);                            // +0x54 / LeaveCS(+0x30)
      return qty;
    }
    done = List_Next_Inferred((char*)grid + 0x2c, &iterState, &existing);
  }
  GridList_UnlockIfHeld(grid);

  SetQty(item, qty);
  *(uint*)((char*)item + 0x17c) |= 0x10;
  Object_MarkDirty_0x20000(item);                             // FUN_00512670

  uint8_t outX = 0, outY = 0;
  char found;
  int* holder = *(int**)((char*)item + 0xa8);
  char* blob = *(char**)((char*)holder + 0x3c);
  if (blob[0x406] == 0 && blob[0x407] == 0) {
    found = (char)InventoryGrid_FindFreeSlot(grid, 2, 2, &outX, &outY, (char)-1);
  } else {
    found = (char)InventoryGrid_FindFreeForItem(item, &outX, &outY, 1, (int)-1);
  }

  if (found != 0) {
    int q = GetQty(item);
    InventoryGrid_PlaceItemFootprint(grid, item, outX, outY, q); // FUN_00571620
    return qty;
  }
  return 0;
}
```
