## Machine-level notes

- **ABI (thiscall + stdcall cleanup):** container **`this` in ECX** (`MOV EBX,ECX` at entry); **`uint min_grow`** stack formal; **`RET 0x4`**.
- **Layout (matches GuardedVector family / push siblings `0043d670` / `0043e3d0`):**
  - `+0x04` — `void **slots` (heap block-pointer map)
  - `+0x08` — `uint capacity` (map slot count)
  - `+0x0C` — `uint begin` (element index; block = `begin >> 2`)
  - `+0x10` — `uint size` (not modified here)
- **Growth policy:** if `0x0FFFFFFF - capacity < min_grow` → `FUN_00436860` throws `"deque<T> too long"`. Else grow amount = `max(request, max(capacity/2, 8))` when that does not overflow.
- **Allocate:** `operator_new((capacity + grow) * 4)`.
- **Rearrange:** `memmove` linearizes the circular map into the new buffer preserving **block index** (`begin>>2`); zeros newly introduced slots (`STOSD`/`F3 AB` loops).
- **Commit:** if old `slots != NULL`, `operator_delete(old)`; then **`capacity += grow`**, **`slots = new`**. Decompiler marks `operator_delete` noreturn — **false**; bytes fall through to commit.
- **Callers (2):** `FUN_0043d670`, `FUN_0043e3d0` when map needs a new page; always `min_grow = 1`.
- **Twin:** same algorithm as `GuardedVector_GrowBlockMap` (`0x0043c9b0`, EBX-entry); this unit is the **ECX thiscall** clone.

## Byte-accurate pseudocode (role)

```c
/* GuardedVector_GrowBlockMap_Thiscall — grow circular block-pointer map.
   ABI: thiscall ECX=container; void Grow(uint min_grow) → ret 4 */

struct GuardedVectorHeader {
  /* +0x00 unknown / unused here */
  void **slots;      /* +0x04 */
  unsigned capacity; /* +0x08 */
  unsigned begin;    /* +0x0C — element index; block = begin>>2 */
  unsigned size;     /* +0x10 — untouched */
};

void __thiscall GuardedVector_GrowBlockMap_Thiscall(
    GuardedVectorHeader *self, unsigned min_grow)
{
  unsigned cap = self->capacity;
  if (0x0FFFFFFFu - cap < min_grow)
    FUN_00436860(); /* throw "deque<T> too long"; noreturn */

  unsigned chunk = cap >> 1;
  if (chunk < 8) chunk = 8;
  if (min_grow < chunk && cap <= 0x0FFFFFFFu - chunk)
    min_grow = chunk;

  unsigned begin_blk = self->begin >> 2;
  void **neu = (void **)operator_new((cap + min_grow) * 4);

  /* Circular linearization (decompiler CF + bytes):
     1) copy old[begin_blk .. cap) → neu[begin_blk ..]
     2) if min_grow < begin_blk: split-copy old[0..begin_blk) + zero
        else: copy old[0..begin_blk) after tail, zero (min_grow-begin_blk) gap,
              zero neu[0..begin_blk) */

  void *old = self->slots;
  if (old != 0)
    operator_delete(old);

  self->capacity = cap + min_grow;
  self->slots = neu;
}
```

## Ghidra raw CF caveats

1. Plate `if (slots==0) { commit; return; } else noreturn delete` is **inverted/truncated** — bytes always commit after optional delete.
2. `uVar2 = FUN_00436860()` — assignment dead; callee never returns on throw path.
3. `param_1` is ECX this (decompiler `__thiscall` correct for this unit; wrong for EBX sibling `0x0043c9b0`).
