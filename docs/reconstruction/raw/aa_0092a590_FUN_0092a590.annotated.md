## Machine-level notes

- **ABI:** ECX = MissionTracker*; EAX = missionId (0 = clear); AL = bool; bare RET.
- Prefer assembly when decompiler shows `void` / `undefined` return — live returns AL.
- Parent dualed binder `Client_TryBindActiveMissionTracker` (`0x0092fd00`) is sole caller; seeds ECX from `client+0x4d0`, EAX from saved mission id.
- Offsets sealed: tracker `+0x10` id, `+0xc` objective head, `+0x6` dirty, `+0x4` bind-ok; host via `*tracker` then `+0xe98` character, hash `+0x548`; node objective list head `+0x14c`.
- Clear helpers: `FUN_0092a3d0` expects **EDI**=tracker; `FUN_00929c00` expects **EAX**=tracker (custom, not pure thiscall).

    MissionTracker* tracker /*ECX*/,

  Character* ch = host ? host->character_e98 : 0; // +0xe98

  }

  Tracker_ClearObjectiveVector(tracker);
  Tracker_ResetDisplayFields(tracker);
  tracker->activeMissionId = 0;
  tracker->activeObjectiveHead = 0;
  return 0; // miss / no character
}
