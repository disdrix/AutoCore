## Purpose

Leaf **Euclidean length** of a contiguous 3-float vector pointed by **ECX**:

```text
||v|| = sqrt(v.x² + v.y² + v.z²)
```

No callees (hardware `FSQRT`). No writes. Return in x87 **ST0**.

## Machine-level notes

| Item | Note |
|---|---|
| Loads | `[ECX+8]`, `[ECX+4]`, `[ECX]` → z, y, x (push order; formula commutative) |
| Sum of squares | three `FMUL` self-products + two `FADDP` |
| Sqrt | `FSQRT` then stack cleanup (`FSTP`×3) leaving length in ST0 |
| Epilog | bare `RET` (`C3`) — zero stack args |
| Pad | `CC` filler to next function `FUN_00404c30` @ `0x00404c30` (float4 store helper; unrelated) |
| Decompiler | shows `__fastcall float *param_1`; ABI truth is **ECX pointer** |

## Pseudocode (annotated)

```c
// ECX = const float *v  (x,y,z contiguous)
// return ST0 = sqrt(v[0]^2 + v[1]^2 + v[2]^2)
float10 Math_Vec3_Length_Sqrt_Inferred(const float *v /* ECX */)
{
  // Machine order: load z,y,x then x*x + y*y + z*z
  return SQRT((float10)v[2] * (float10)v[2] +
              (float10)v[1] * (float10)v[1] +
              (float10)v[0] * (float10)v[0]);
}
```
