## Machine-level notes

- **stdcall** one arg: `void **slot` at `[esp+4]` after entry; epilogue **`C2 04 00`**.
- MSVC **SEH** frame (`FS:[0]`, state 0 then −1, handler `LAB_009bc278`).
- Intrusive refcount at **object+4**; destroy via **vtbl+8** when count hits 0.
- Phase1: if `*slot` non-null → `--refcount`, optional destroy, **`*slot = 0`**.
- Phase2: re-read `*slot` and same release without clear — **unreachable after phase1 clear**; null-slot also skips. Treat as **SEH/template dual residue**, not a second live release of a still-held pointer under normal CF.
- Leaf re: static callees (only indirect vtbl).
