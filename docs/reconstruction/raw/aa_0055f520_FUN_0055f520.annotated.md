## Machine-level notes

- **ABI:** thiscall; ECX = desc; stack = element count; returns desc; **`ret 4`**.
- **Global:** `DAT_00b05060` allocator (`int*`; vtable at `*[0]`).
- **Bytes:** `count*16` then `+0xF` / `AND AL,0xF0` (align16). Compare remaining `arena[3]` vs size.
- **Alloc:** if remaining < size → vcall `vtbl+0x24(size)`; else bump `arena[2]+=size`, `arena[3]-=size`.
- **Desc write:** `[0]=[3]=slab`, `[1]=0`, `[4]=count`, `[2]=count|0x80000000` (high bit = skip tag free on release).
- Init twin of `LocalWorklist16_Release_Inferred` (`0x0055f590`); stride-16 sibling of bind/unbind `LocalWorklist_Release` (*8 at `0x0055f4c0`).
