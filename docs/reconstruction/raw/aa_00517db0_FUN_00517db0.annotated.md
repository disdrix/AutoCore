## Machine-level notes

- Source: raw capture `aa_00517db0` + live Ghidra re-verify R10-032.
- **Bytes win** over decompiler for ABI: ECX = value dword; stack = list*; `RET 4`.
- Decompiler `local_4` is the stack slot created by `PUSH ECX` — value is **incoming ECX**, not garbage.
- `FUN_00404840(1)` is thiscall with **ECX reloaded to list** (`MOV ECX,EBX`).
- Prefer assembly when decompiler conflicts; full hex in raw R10-032 append.

## Callers (pattern)
