## Machine-level notes

- **ABI:** MSVC **`__thiscall`** — destination `float out[16]` in **ECX**; **16 float** args on stack (`[ebp+8]` … `[ebp+0x44]`); **`ret 0x40`** (0x40 = 16×4).
- **ISA:** 16× `movss` stack→aligned local, then **`rep movsd`** (ECX=16) local→dest. No arithmetic.
- **Leaf:** no callees, no globals, no FOV/aspect/near/far math.
- **Role vs sibling:** adjacent `FUN_0043f2e0` (`Math_MatrixOrthoOffCenterLH`) **computes** ortho projection elements. This unit only **stores** 16 precomputed floats — including when gfxView builds a **perspective** matrix and passes the finished diagonals/offs.
- Decompiler shows `undefined4` and a manual 16-iter loop; bytes use `movss` + `rep movsd` (same effect: 16 DWORD copy).
