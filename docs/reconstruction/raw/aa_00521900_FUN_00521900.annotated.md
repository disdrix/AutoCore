## Machine-level notes

- **thiscall** ECX = same character object family as race helper (`mov eax,[ecx+4]`).
- Same nested blob path; reads **class @ +0x531** and **race @ +0x532**.
- Class English comes from **unowned** leaf `FUN_0051f940(classId, raceId)` (cdecl, 2 args):
  - class 0: Commando / Champion / Terminator (by race)
  - class 1: Engineer / Shaman / Constructor
  - class 2: Lieutenant / Archon / MasterMind (else Officer)
  - class 3: Bounty Hunter / Avenger / Agent (else Ranger)
  - default: Unknown
- Then ring-buffer via `FUN_007a69d0` + `FUN_007a6de0(name, -1)`.
- Parent `FUN_005465c0` replaces token **`[$class]`** (len 8) with this return.
