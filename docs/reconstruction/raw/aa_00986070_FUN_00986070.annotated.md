## Machine-level notes

- **ABI:** no stack formals; **EBX = pool host\*** (sole caller: `mov ebx,[DAT_00d1f624]` then call); bare `C3`; **EAX = 0x40 object\*** or 0.
- **SEH:** `push -1; push LAB_009af9d3; fs:[0] chain`.
- **Empty freelist test:** `[ebx+0x14]==0` OR `(end-begin)>>2 == 0` where end=`[ebx+0x18]`.
- **Empty path:** `operator_new(0x40)` + `FUN_0074e380(raw)` (float bank + subobject via `FUN_0043fdf0` which installs `StdList_AllocSentinel_0xC` at sub+8). SEH state 0 during ctor.
- **Non-empty path:** `obj = *([ebx+0x18]-4)`; shrink freelist with `FUN_00456780(old_size-1, vec_host=ebx+0x10)` — decompiler shows `FUN_00456780(0)` (**wrong size**).
- **Always:** `lea esi, &result; mov eax, ebx; call FUN_004406e0` — push result ptr onto vector at **host+4/+8/+0xC** (tracked/issued).
- **Return:** EDI/EAX = acquired object.
