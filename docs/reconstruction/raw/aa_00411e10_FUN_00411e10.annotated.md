## Machine-level notes

- **ABI:** custom **ESI = CNDHash\***; no stack args; bare **`RET`** (`C3`). **Not** MSVC thiscall (ECX unused; body never loads ESI from ECX).
- **Flag:** `hash+0x1d` = TraversalLock byte (0 free / 1 locked). Shared with TraverseToNext checks (`HashError:TraverseToNext, not locked…` @ `0x00a27c9c`).
- **Odd behavior (preserve):** double-lock path **logs then still sets** flag=1 (does **not** early-return like `List_TraversalLock`).
- **Unlock:** not this function — callers store `*(hash+0x1d)=0` inline after walk.
- Prefer assembly when decompiler shows `unaff_ESI` — sealed as intentional ESI custom ABI.
