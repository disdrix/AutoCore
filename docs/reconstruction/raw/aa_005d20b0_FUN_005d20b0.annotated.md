## Control flow

1. SEH frame `LAB_009a7022`.
2. **Size guard:** if `map->size >= 0x1FFFFFFE` (`cmp [edi+8],0x1FFFFFFE` / `jb` past) → build `std::string("map/set<T> too long")`, length_error-style vfptrs `009c7628`/`009c7634`, `_CxxThrowException` (noreturn). Decompiler: `if (0x1ffffffd < size)`.
3. **Alloc/link node:** `FUN_006173a0(header, parent, header, value, color=0)` → `new(0x18)`, copy 2 dwords, color red, isnil 0.
4. `map->size++`.
5. **Attach under parent:**
   - parent == header → first element: root = leftmost = rightmost = new.
   - `insertLeft == 0` → `parent->right = new`; update rightmost if needed.
   - else → `parent->left = new`; update leftmost if needed.
6. **RB fixup** while parent color at `+0x14` is red (`==0`):
   - Uncle red → recolor parent/uncle black, grandparent red; climb.
   - Uncle black → rotate (`FUN_004e22d0` L / `FUN_006753b0` R) + recolor; one L-rotate path **inlined**.
7. Force root black: `header->parent (+4)` color `+0x14 = 1`.
8. `*outNode = newNode`; restore SEH; **`RET 0x10`**.
