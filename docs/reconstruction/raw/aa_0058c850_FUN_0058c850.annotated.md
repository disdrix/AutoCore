## Purpose

Apply skill damage across a **TFID target list**: resolve → temporary CS-guarded object list → per-target accuracy (skip first) → rolled damage → `Client_Combat_ApplySingleHitMaybeDefer` or combat floater on miss. Returns **summed damage**.
