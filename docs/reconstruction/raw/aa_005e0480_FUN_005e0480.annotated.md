## Purpose

**Pure switch remap:** sparse gear/item **type codes** → compact **table row index** `0..0xb`, or `0xffffffff` (−1) for unmapped codes.

Used by loot-catalog fill paths so multi-dimensional tables address a dense subtype axis of **12** rows (all-subtypes walk when −1).

---

## Machine-level notes

- **Stack formal:** `[esp+4]` = `typeCode` (int).
- **Dispatch:** `add eax, -6` then `cmp eax, 0x40` / `ja default` / jump table (compiler switch on codes 6..0x46).
- **Returns:** EAX = row index or −1; `ret 4`.
- **No callees, no globals, no side effects.**
- **Non-monotonic pairs (intentional table):**
  - `0x32 → 9`, `0x34 → 8` (swap relative to ascending keys)
  - `0x44 → 0xb`, `0x46 → 10` (swap)
- Prefer this annotated map over inventing product type names; codes match def-type cases elsewhere (e.g. item quality roll switch on 6/10/0xc/0xe/0x10/0x1c).
