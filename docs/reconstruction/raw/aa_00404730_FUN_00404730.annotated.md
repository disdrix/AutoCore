## Machine-level notes

- **Role:** Range POD copy / relocate worker for combat-floater elements of stride **`0x38`**.
- **Formals (used):** `srcBegin` (`[ebp+8]`), `srcEnd` (`[ebp+0xc]`), `dst` (`[ebp+0x10]`).
- **Extra stack:** loads `[ebp+0x14]` into `EBX`/`ECX` before each leaf call; **pod leaf ignores ECX** (`FUN_004046f0` is stdcall `(dst,src)` / `ret 8`). Caller trampoline `FUN_004044c0` pushes **5 dwords** (`add esp, 0x14`) — MSVC/thiscall noise; only 3 formals drive CF.
- **ABI of this VA:** **cdecl** (`ret` / `c3`); returns advanced `dst` in `EAX`.
- **SEH:** installs `LAB_009bd1d0`; scope cookie 0 during loop, −1 on exit.
- **Leaf per element:** `FUN_004046f0` = 14× dword (`0xe`) copy = **0x38 bytes**; null-checks **dst** only.
