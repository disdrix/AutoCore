## Machine-level notes

- **Decompile ≡ body bytes** (`read_memory` 2026-07-29). No `disassemble_bytes`.
- **ABI trap:** Ghidra shows plain `FUN_004bb010(undefined4 *param_1)` / no `this`. Image is **`RET 4`** + **ECX passthrough** into `CVOGReaction_ResolveObjectTarget` — same pattern as `Object_ResolveFromTFID` (`0x004bb950`). Callers load resolve ctx (often `MOV ECX,[host+0xe4e8]`) immediately before `CALL`.
- Blob layout (head only): `+0` coidLo, `+4` coidHi, `+8` bGlobal byte. Pad `+9..+15` unused.
- After resolve: if non-null, **thiscall** `obj->vtbl[+0x1d4]()` and return its result; else return `0`.
- **Not** resolve-only (`004bb950`); **not** vtbl+0x1d8 identity (`004bb070`); **not** vtbl+0x1dc (`004bb0a0`).
