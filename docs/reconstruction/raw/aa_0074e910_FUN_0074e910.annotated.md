## Machine-level notes

- Prologue: `movss xmm0,[esp+4]` (time) → `push esi; mov esi,ecx; cmp byte [esi+0x4c],0; push edi; lea edi,[esi+0x44]`.
- Stores: `+0x44 = time`, `+0x40 = param_3` (end/duration ref).
- **Mode branch on `+0x4c`:**
  - **0 (clamp):** if time < 0 → 0; else `time = min(time, +0x48)`.
  - **nonzero (wrap):** FPU `fld time; fld [esi+0x48]; call _CIfmod`; if result < `g_flZero` (`0x00a0f518` = 0.0) add `+0x48`.
- Shared tail: `+0x34 = param_3 - time / *(+0x3c)`; `+0x50=0`; `+0x68=0`; `+0x6c=time`; `pop edi/esi; ret 8`.
- Linear layout: wrap path first then epilogue, then clamp cold path that jumps back into shared tail (`eb bb` / `eb aa`) — MSVC layout; both paths real.
- Ctor default `+0x4c = 1` → wrap mode unless load path overwrites flag **after** this call.
