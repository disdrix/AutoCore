## Control-flow summary

1. SEH + construct local `std::string token`.
2. If `*(this+0x402c) < 0` → error path (already past-end / invalid).
3. If `*(this+0x4060) == 0`:
   - Clear token; scan stream bytes at `this+0x2c+cursor`:
     - Refill via `FUN_00435df0` when cursor would exceed avail.
     - Skip leading `isspace` until a non-space char arrives.
     - If `'` or `"` seen, enter quoted mode until matching closer.
     - Else accumulate until whitespace (token end).
     - EOF with empty token → set `+0x402c = -1`, error.
4. Else (`+0x4060 ≠ 0`): `token = *(string*)(this+0x404c)`; clear pushback.
5. If `token == "}"`:
   - Log *“Attempt to read past end of chunk…”* (`stoChunk.cpp:0x2a0`).
   - Sticky `+0x402c = -1`; re-stash `}` into `+0x404c`; fall through (no successful float).
6. Else: `sscanf(token.c_str(), "%f", out)`:
   - One conversion → **return 0**.
7. Error: format *“Expected float32 but got \"%s\" in chunk \"%s\"”* via `FUN_0076cec0` + `vog_LogMessage` (`stoChunk.cpp:0x434`); **return 0xffffffff**.
