## Machine-level notes

- **Leaf** color LUT: writes 4-byte little-endian D3DCOLOR (`AARRGGBB` as `[B,G,R,A]`) into buffer at **EAX**.
- **CL** = format index (caller often `*(u8*)(node+0x1c) - 0x0f` — see `UiHost_RefreshTrackedNodeWidgets`).
- Switch via index table `@0x007fda3c` + jump table `@0x007fda18` (no callees).
- Decompile ≡ raw ≡ bytes for all case constants. Decompiler may under-report **EAX**/**CL** at call sites.

### ABI (sealed)

| Register | Role |
|---|---|
| EAX | `uint8_t* outColor` / `D3DCOLOR*` (written; returned) |
| CL | format index `0..0x66` (values > `0x66` → default white) |
| return | EAX = out pointer (callers pass to UI draw or deref for DWORD) |

## Pseudocode (annotated)

```c
// EAX = outColor[4]; CL = formatIndex
void Ui_WriteFormatColorD3d(uint8_t formatIndex /*CL*/, uint8_t* out /*EAX*/)
{
  // switch(formatIndex) via JT @0x007fda18 / idx @0x007fda3c
  switch (formatIndex) {
  case 0:   out[0]=0xC1; out[1]=0xC1; out[2]=0xC1; out[3]=0xFF; return;
  case 1:   out[0]=0xFF; out[1]=0x8F; out[2]=0x00; out[3]=0xFF; return;
  case 2:   out[0]=0x2C; out[1]=0x4B; out[2]=0xFF; out[3]=0xFF; return;
  case 3:   out[0]=0x0B; out[1]=0xF4; out[2]=0x6C; out[3]=0xFF; return;
  case 4:   out[0]=0x00; out[1]=0xC9; out[2]=0xFF; out[3]=0xFF; return;
  case 100: out[0]=0x00; out[1]=0x00; out[2]=0xFF; out[3]=0xFF; return;
  case 0x65:out[0]=0x00; out[1]=0xFF; out[2]=0x00; out[3]=0xFF; return;
  case 0x66:out[0]=0xFF; out[1]=0x00; out[2]=0x00; out[3]=0xFF; return;
  default:  out[0]=0xFF; out[1]=0xFF; out[2]=0xFF; out[3]=0xFF; return;
  }
}
```
