## Machine-level notes

- **ABI sealed:** one stack arg = `list*`; **EAX** = `const uint32_t*` value source; epilogue **`RET 4`**. Not thiscall (list is not in ECX).
- **CF:** single basic block, cyclomatic 1; two callees; no branches in this unit.
- **Semantics:** MSVC **`std::list` push_front** for a **4-byte** element:
  1. `head = list->_Myhead` (`list+4`)
  2. `_Buynode(head, head->_Next, *eax)` via `FUN_00418700` (node size **0xC**)
  3. `_Incsize(1)` via `FUN_00418790` (ECX=1, EDX=list; may throw `length_error` / `"list<T> too long"`)
  4. Splice: `head->_Next = node`; `node->_Next->_Prev = node`
- Empty-list case is correct because sentinel is circular (`head->_Next == head` ⇒ `head->_Prev` updated via step 4).
- Distinct from sibling `FUN_00402d10` (thiscall + stack val ptr + `FUN_00404840` size path) and `FUN_00403120` (insert-before-node, `RET 8`).
