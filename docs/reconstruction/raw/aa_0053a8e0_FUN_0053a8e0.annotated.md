## Machine-level notes

- **thiscall**: `mov edi,ecx` — ECX = map (`+4` head sentinel, `+8` size).
- **ret 0x0c**: three stack formals — `outIt*`, `hint*`, `value*`.
- **Val12 node**: left@0 parent@4 right@8 value/key@+0x0c color@+0x18 **isnil@+0x19**.
- Fast paths call sealed `StdTree_InsertAndRebalance_Val12` (`FUN_00539210`, W27-Q) with `addLeft` 0/1.
- Neighbor path uses `FUN_005ae050` (Prevnode) / `FUN_005ae0b0` (Nextnode) — `__fastcall` ECX = `&nodeptr`.
- Fallthrough uses `FUN_0053a1a0` unique insert-or-find; only `*outIt` taken from result pair.
- Sole caller `FUN_0053af20`: lower-bound / insert-or-return-value @ `node+0x10`.

MapNode_Val12** __thiscall StdTree_InsertHint_Val12(
    MapShell_Val12* map,      // ECX
    MapNode_Val12** outIt,
    MapNode_Val12* hint,
    const Val12* value)       // key at *value / value[0]
// RET 0x0C
{
  MapNode_Val12* head = map->head;
  if (map->size == 0) {
    // insert as left of head (first node)
    InsertAndRebalance(map, outIt, /*addLeft*/1, head, value);
    return outIt;
  }
  if (hint == head->left /*leftmost*/) {
    if (*value < hint->key /*[3]*/) {
      InsertAndRebalance(map, outIt, 1, hint, value);
      return outIt;
    }
  } else if (hint == head) {
    // past-end: rightmost is head->right
    if (head->right->key < *value) {
      InsertAndRebalance(map, outIt, 0, head->right, value);
      return outIt;
    }
  } else {
    int key = *value;
    if (key < hint->key) {
      MapNode_Val12* pred = hint;
      Prevnode(&pred);                 // FUN_005ae050
      if (pred->key < key) {
        // key strictly between pred and hint
        if (pred->right->isnil)       // isnil @ +0x19
          InsertAndRebalance(map, outIt, 0, pred, value);
        else
          InsertAndRebalance(map, outIt, 1, hint, value);
        return outIt;
      }
    }
    if (hint->key < key) {            // decomp uses overflow-safe form
      MapNode_Val12* succ = hint;
      Nextnode(&succ);                 // FUN_005ae0b0
      if (hint == head || key < succ->key) {
        if (hint->right->isnil)
          InsertAndRebalance(map, outIt, 0, hint, value);
        else
          InsertAndRebalance(map, outIt, 1, succ /*via hint after step*/, value);
        return outIt;
      }
    }
  }
  // Hint unusable — full lower-bound insert-or-find

  InsertOrFind(map, &pair, value);    // FUN_0053a1a0
  *outIt = pair.node;
  return outIt;
}
