## Machine-level notes

- **ABI:** ECX = convoy/crew roster host (`char+0xCB0` at UI sites); no stack args; plain `RET` (`C3`); returns dword pointer in EAX (or 0).
- **Gate:** `*(uint8_t*)(this+0x1d8) == 0` → return 0. Sibling walkers treat `+0x1d8` as **member count** (e.g. `FUN_00574780`).
- **Load:** `slot = *(int*)(this+0x194)`; return `*(this + (slot + 0x1a) * 0x10)` = object* at `this+0x1a0 + slot*0x10`.
- **Same formula as** `ConvoyRoster_GetMemberBySlot_Inferred` but **without** 0..3 bounds; leader index stored at `+0x194` (byte-packed into convoy packet `0x800d` by `FUN_00574c30`).
- **Call-site role:** compare result to `DAT_00d1b6d8` (local player) — non-equal disables Invite/Kick and related convoy UI (leader gate). High/Inferred English "leader".
