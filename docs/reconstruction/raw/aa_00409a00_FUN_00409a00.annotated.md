## Machine-level notes

- **thiscall** ECX = `{ void* data; int size; int capacity }` (size unused here).
- Free only when `(int)capacity >= 0` (high bit clear → owned buffer; `0x80000000` sentinel skips free — same convention as dualed worklist / hkArray docs).
- Machine: `nbytes = (capacity & 0x7fffffff) * 8`; decompiler prints bare `capacity * 8` (mask omitted).
- Allocator: `DAT_00b05060` vtbl **`+0x14`**, tag **`0x12`**.
- SEH-only call sites: unwind tables JMP here with ECX = stack array — pure dtor/free helper.
- Sibling free half of `LocalWorklist_Release_Inferred` (`0x0055f4c0`) uses same tag free *8; that VA also does arena slab return. **This VA is free-only.**
