## Role

Unregister a world/link object from the manager's enrolled pointer list (`manager+0x120` / count `+0x124`), reverse its link-pair contribution via sorted diff walk, drop the short refcount at `object+6`, clear `object+0x8` owner slot, and scalar-destroy when the count hits zero.

**Twin:** `FUN_0055ff20` (enroll: vtbl+4 extract, refcount++, push list, `0062a4d0`).

## Stages

1. **Scope/lock** — `FUN_0062d960(*(manager+0x234))` with local work buffer (stack desc).
2. **Extract unbind pairs** — `(*(manager+0xc4))->vtbl+0xc(obj+0x1c or null, out_buf)`; out_buf yields `(pairs*, count)` used as `unaff_ESI`/`unaff_EBX` in decompiler.
3. **If count ≠ 0** — `LinkPair_CanonAndSort` (`006cad30`) then `LinkPair_SortedDiffWalk` (`006caaa0`) with empty left range `(0,0)` and right = extracted pairs; handler ECX = `manager+0x138`; 5th formal = `manager+0xd0 ? manager+0xd0+8 : 0`.
4. **Notify** — `FUN_0062a510(manager, obj)` (enroll twin `0062a4d0`).
5. **Release object** — `*(int16*)(obj+6)--`; `*(obj+0x8)=0`; if ref==0 then `obj->vtbl[0](obj,1)`.
6. **List remove** — linear search `manager+0x120[0..count)`; swap-remove; `count--`.
7. **Teardown worklist** — `LocalWorklist_Release` (`0055f4c0`).
