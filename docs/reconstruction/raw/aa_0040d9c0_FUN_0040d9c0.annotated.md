## Machine-level notes

- Source: raw capture + dual seal append for `aa_0040d9c0`.
- **This in ESI** (call sites `MOV ESI,ECX` / `LEA ESI,[obj+disp]`).
- Phase 1: spin `this[+0x10]` down to 0; when it hits 0, null `this[+0x0C]`.
- Phase 2: for i = count..1, `operator_delete` each non-null `base[i-1]`.
- Phase 3: `operator_delete` array base if non-null; zero `+0x08` and `+0x04`.
- Ghidra "does not return" on `operator_delete` is **false** — `ADD ESP,4` continues.
- Thunk `0x0040fd50` → JMP here. Wrapper `FUN_0040d910` adds SEH.

    int n = *(int *)(this + 0x10);
    if (n != 0) {
      n = n - 1;

  while (i != 0) {
    void *p = *(void **)(*(int *)(this + 4) + -4 + i * 4);

    if (p != 0)

  }

  *(int *)(this + 8) = 0;
  *(void **)(this + 4) = 0;
}
