## Purpose

Release one live pack allocation from a host that owns:

1. A **std map/tree** of live blocks (tree root plumbing @ host `+0x04`, element count @ `+0x0c`).
2. A sorted **free-range vector** of `(offset, size)` dwords (begin `@+0x14`, end `@+0x18`, element stride **8**).

On entry **ECX=host**, **EAX=block**:

1. **Lower-bound / find** map entry keyed by the block pointer (`FUN_00445750` on `host+4`).
2. **Erase** that map node (`FUN_004477a0` → ends in `operator_delete` of the tree node).
3. If **map size (`host+0xc`) becomes 0** → return **`1`** (AL). Caller may tear down outer container.
4. Else read **`block+0x18` = offset**, **`block+0x1c` = size**.
5. **Lower-bound** free-range vector for `offset` (`FUN_00460a60`, binary search on first dword of each pair).
6. **Coalesce next** if `cursor != end` and `*cursor == offset+size`: set `*cursor = offset`, add size into next length.
7. Else **coalesce prev** if `cursor != begin` and `prev.offset + prev.size == offset`: add size into prev length.
8. Else **insert** new `(offset, size)` at cursor (`FUN_00445c80`).
9. Return **`0`** (AL) after coalesce/insert.
