## Purpose

Apply **binary panel mode** on the car-tabs dialog host (`DAT_00d1b880` / `i_d_tabs_car_2d_*`):

| Mode (EAX) | Child chrome | Active tab panel |
|-----------:|-------------|------------------|
| **0** | show `+0x50c`, hide `+0x510` | layout **cargo** tab `+0x514` (`i_d_tabs_car_2d_tab_cargo.xml`); collapse mission `+0x518` |
| **1** | hide `+0x50c`, show `+0x510` | collapse cargo `+0x514`; layout **mission** tab `+0x518` (`i_d_tabs_car_2d_tab_mission.xml`) |

Host type evidence from init `FUN_0088a290` (not owned): loads cargo/mission tab XML into `[0x145]`/`[0x146]`, then tails into this apply with force=1.

## ABI (bytes-sealed)

```text
EAX      = panelMode {0, 1}   (other → store then no-op)
[ESP+4]  = host window*      (car-tabs dialog)
[ESP+8]  = force (char)      (non-zero → apply even if mode unchanged)
RET 8                        (stdcall 2 stack dwords)
return   = void
```

Gate: host `vtbl+0x3d8` must report visible/open. Then apply only if `force != 0` **or** `mode != host+0x528`.

// UI_CarTabs_ApplyPanelMode_Inferred
// EAX = mode; stack: (host*, force)
void UI_CarTabs_ApplyPanelMode_Inferred(int *host, int force /*char*/)
{
  int mode; // in_EAX
  char visible;

  visible = host->vtbl[0x3d8/4]();           // IsVisible
  if (visible == 0) return;
  if ((char)force == 0 && mode == host[0x14a]) return;

  host[0x14a] = mode;                        // +0x528

  if (mode == 0) {
    // Show chrome A, hide chrome B
    if (!child_visible(host[0x143])) { show(host[0x143]); setvis(host[0x143], 1); }
    if ( child_visible(host[0x144])) { setvis(host[0x144], 0); hide(host[0x144]); }
    // Expand cargo tab, layout it; collapse mission tab + detach list
    FUN_00822cb0(force); /* ESI=host[0x145], BL=1 */
    host[0x145]->vtbl[0x94/4]();
    FUN_00822cb0(force); /* ESI=host[0x146], BL=0 */
    FUN_00756c90();      /* EDI=host[0x146] */
  } else if (mode == 1) {
    // Hide chrome A, show chrome B
    if ( child_visible(host[0x143])) { setvis(host[0x143], 0); hide(host[0x143]); }
    if (!child_visible(host[0x144])) { show(host[0x144]); setvis(host[0x144], 1); }
    // Collapse cargo + detach; expand mission + layout
    FUN_00822cb0(force); /* ESI=host[0x145], BL=0 */
    FUN_00756c90();      /* EDI=host[0x145] */
    FUN_00822cb0(force); /* ESI=host[0x146], BL=1 */
    host[0x146]->vtbl[0x94/4]();
  }
  // mode ∉ {0,1}: mode stored, no child work
}
