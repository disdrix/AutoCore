## Machine-level notes

- **Role:** MSVC-style `std::copy_backward` for **0x18-byte POD** SkillSet entries (6 dwords).
- **Direction:** pointers walk **backward** (`SUB …,0x18`); decompiler negative indices `[-6]…[-1]` match that walk.
- **ABI (sealed):**
  - **EAX** = dest_end (in) → dest_begin (out / return)
  - **ECX** = src_end (exclusive)
  - **EDX** = src_begin (inclusive stop)
  - **RET 0** — no stack args
- **Empty range:** `CMP EDX,ECX` / `JZ ret` leaves EAX unchanged (dest_end == dest_begin when n==0).
- **No null-dest skip** (unlike forward twin `SkillSet_UninitializedCopy_0x18` @ `0x00442b00`).
- **Leaf:** no callees; no SEH; no globals.
- Prefer assembly when decompiler shows `void` + phantom `in_EAX`.

## Pseudocode (annotated; ABI-corrected)

```c
// EAX = dest_end, ECX = src_end, EDX = src_begin
// returns EAX = dest_begin
void *SkillSet_CopyBackward_0x18(void *dest_end /*EAX*/,
                                 void *src_end /*ECX*/,
                                 void *src_begin /*EDX*/)
{
  uint32_t *d = (uint32_t *)dest_end;
  uint32_t *s = (uint32_t *)src_end;
  uint32_t *b = (uint32_t *)src_begin;

  if (b == s)
    return d;                    // empty: dest_begin == dest_end

  do {
    s -= 6;                      // -0x18 bytes
    d -= 6;
    d[0] = s[0];
    d[1] = s[1];
    d[2] = s[2];
    d[3] = s[3];
    d[4] = s[4];
    d[5] = s[5];
  } while (s != b);

  return d;                      // dest_begin
}
```
