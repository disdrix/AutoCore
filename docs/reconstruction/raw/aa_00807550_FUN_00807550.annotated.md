## Machine-level notes

- **EAX** = client/host (register). **Stack** = object pointer. **`RET 4`**.
- Decompiler `in_EAX` is intentional register ABI (not phantom host).
- Manager: `host+0xc78` → vtbl call `+0x48` → manager object.
- Map shell at **`manager+0x244`**; head at **`map+4`** (= `manager+0x248`). Decompile compares hit to `*(manager+0x248)` — correct for head.
- Key: **`object+0x160`** (8-byte TFID; lo/hi dwords) — matches dualed find key layout.
- Find: dualed **`StdMap_Find_Tfid_Isnil29_Inferred`** (`0x004cba00`) with ECX=map, outIt on stack, pKey=object+0x160.
- On hit and **`payload[node+0x20]+0x5c == 0`**:
  1. Log `"Assigned a pending ghost to %I64d"` with TFID.
  2. Object vtbl **`+0x2b8`**(payload) — assign pending ghost.
  3. Dualed **`Map_EraseNode_B`** (`0x00409220`) removes the map node.
- Miss / end / already-assigned (`+0x5c != 0`) → no-op.
- Callers: vehicle object apply path (`Client_CreateVehicleObjectApply` ×3) and `FUN_0080af70` (EAX=host before call).
