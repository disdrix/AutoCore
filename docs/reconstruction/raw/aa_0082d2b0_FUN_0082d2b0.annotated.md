## Purpose

When the menu host is active (`this+0x4C0 ≠ 0`), **rebuild the popup shell**:

1. Call host `vtbl+0x450` (pre-clear / detach children).
2. Allocate + construct a **0x34-byte** owned object (peer dual tags **CNDHash** @ `+0x534`) with flag byte **2**, store at `this+0x534`.
3. Reset depth counters (`+0x68`, float `+0x74`, clamp `+0x70`, flag `+0x4A4`).
4. If prior popup dialog @ `+0x538` non-null, destroy via host `vtbl+0xbc`.
5. `new(0x488)` + `FUN_007b5dd0(alloc, 0)` → NDUI dialog; attach via host `vtbl+0xa8`.
6. Load **`i_d_pop_2d_wnd_blocker.xml`** (`dialog.vtbl+0x28`) and set layer **70000** (`dialog.vtbl+0x74`).
7. Bump depth counter, store dialog @ `+0x538`, write `-(float)count` @ `+0x74`, update max @ `+0x70`.
8. Host `vtbl+0x3f4(1)` post-rebuild notify.

Shared shell rebuild used by interaction-menu populate, skill menu, equip menu, and other `+0x4C0`-gated hosts — **not** a skill-cast residual.
