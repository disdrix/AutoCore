## Machine-level notes

- **ABI:** EAX = requested select index; stack host (shopveh list window); **`RET 4`**.
- **Host:**
  - `+0x4fc` — list length / max index exclusive bound (compare with `<=` on select, `<` on list_i).
  - `+0x500` — written with select index; center of the five-slot window.
  - `+0x50c[5]` — visible slot object pointers (window size **5**).
- **Slot map:** for list index `list_i` in `[select-2, select+2]`, `slot = list_i - select + 2` ∈ `[0,4]`.
- **Control id:** `vtbl+0x78` get id; `vtbl+0x74` set id. Product encoding `id = list_i + 0x9ca4` (40100). Clear = `-1`.
- **Match path:** if slot already carries `list_i` id → `FUN_0083a860` (has nested select content?) → refresh via `FUN_0083a880(0)` or rebind via `FUN_0083abf0`.
- **Mismatch path:** scan other slots for object whose id encodes `list_i`; if found, **`FUN_00833160`** (ESI/EDI swap — dualed WQ9J-D), copy id via set/get, `FUN_0083a880(0)`; if not found, `FUN_0083abf0`. Always ends by setting slot id to `list_i+0x9ca4`.
- **Leading/trailing clear:** when select near 0 or near end, unused window slots get optional `FUN_00833d50` (if `obj+0x508` non-null) then set id `-1`.
- **Decompiler quirk:** `in_EAX` is real (entry `TEST EAX`); register reuse makes some decompile vars noisy — assembly listing is authority for ESI/EDI load into swap.

## Control flow (assembly authority)

```text
if (select < 0 || select > host.count@+0x4fc) return;
host.select@+0x500 = select;
for list_i = select-2 .. select+2:
  slot = list_i - select + 2
  if list_i in [0,count) and slot in [0,5) and slots[slot] != null:
    cur_id = slots[slot]->vtbl[+0x78]()
    if cur_id - 0x9ca4 == list_i:
      if !FUN_0083a860(list_i): FUN_0083abf0(slot,list_i,host)
      else FUN_0083a880(slots[slot], 0)
    else:
      for j in 0..4, j!=slot:
        if slots[j] and slots[j]->getId()-0x9ca4 == list_i:
          ESI=slots[j]; EDI=slots[slot]; FUN_00833160()  // swap state
          slots[j]->setId( slots[slot]->getId() )
          FUN_0083a880(slots[slot], 0)
          if j > 4: FUN_0083abf0(...)  // dead (j<5); decompiler artifact
          goto assign
      FUN_0083abf0(slot,list_i,host)  // no donor found
    assign:
      slots[slot]->setId(list_i + 0x9ca4)
// clear prefix slots when select < 2
// clear suffix slots when (count-select+2) < 5
```
