## Machine-level notes

- **Convention:** custom register ABI — **ECX = mode**, **EAX = out byte\*** (BGRA). Bare `ret`.
- **Not** MSVC `__fastcall` stack form; second arg is not EDX. Mode only in ECX.
- Jump-table decode: `ecx = mode + 1`; if unsigned `ecx > 4` → default beige; else `jmp [table+ecx*4]`.
- Memory layout per channel: `out[0]=B`, `out[1]=G`, `out[2]=R`, `out[3]=A` → little-endian dword **AARRGGBB**.
- Callers load `*out` as `uint32` color after return (EAX still points at out).
- Sole caller dualed: `Ui_ResolveEntityNameColor_Inferred` (`0x00930fc0`).

## Pseudocode (annotated)

```c
// EAX = uint8_t outBgra[4]  (written as AARRGGBB dword when loaded LE)
// ECX = int mode
// returns EAX = out (implicit)
uint32_t* Ui_NameColorPalette_WriteArgb_Inferred(int mode /*ECX*/, uint8_t* out /*EAX*/)
{
  switch (mode) {
  case 0: // red
    out[2] = 0xC4; out[1] = 0x16; out[0] = 0x16; out[3] = 0xFF;
    return (uint32_t*)out; // 0xFFC41616
  case 2: // cyan
    out[2] = 0x66; out[1] = 0xD3; out[0] = 0xEA; out[3] = 0xFF;
    return (uint32_t*)out; // 0xFF66D3EA
  case 3: // green
    out[2] = 0x14; out[1] = 0xD3; out[0] = 0x14; out[3] = 0xFF;
    return (uint32_t*)out; // 0xFF14D314
  case -1: // white
    out[0] = out[1] = out[2] = out[3] = 0xFF;
    return (uint32_t*)out; // 0xFFFFFFFF
  default: // mode 1 and any other → beige
    out[2] = 0xDC; out[1] = 0xE0; out[0] = 0xC8; out[3] = 0xFF;
    return (uint32_t*)out; // 0xFFDCE0C8
  }
}
```
