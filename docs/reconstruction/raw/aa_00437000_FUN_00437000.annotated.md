- Decompiler labels `in_EAX` / `unaff_EDI` and invents `__fastcall param_1` from entry ECX spill — **reject** stack/fastcall formals; **EDI out** sealed by call sites.
- Internally: `mov esi,eax; …; add esi,0x14` → window at **reader+0x14** (identical remap to `stoChunkReader_ReadU32`).
- Ensure gate: if `available < cursor+1`, call `FUN_00435df0(window, base+cursor)`; fail if hr < 0 **or** `available < 1`.

- **Fail path writes `*out`:** `mov cl,[esp+7]; mov [edi],cl` — high byte of the entry-ECX push slot (prologue `push ecx`). **Not** a product default; callers must not rely on `*out` after −1. Sibling ReadU32 leaves `*out` untouched on fail.

// EDI = uint8_t* out
