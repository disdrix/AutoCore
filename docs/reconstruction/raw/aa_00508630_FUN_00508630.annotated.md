## Machine-level notes

- **ABI:** `__thiscall` — ECX = `CVOGHBBase*`; one stack formal `byte flags`; **`ret 4`**; EAX returns `this`.
- **Vtbl slot 0** of base `PTR_FUN_009cdab0` (`0x009cdab0`) — confirmed by `read_memory` on vtbl and by sealed `CVOGHBBase_ctor` dual.
- **Always** restores base vtbl imm `0x009cdab0` at `this+0` (even when owner is null).
- **Owner gate:** `this+0x18` (`pOwnerObject`); **list gate:** `*(owner+0xB0)`.
- **Unlink:** machine `push this; mov ecx, listMgr; call FUN_005085b0` — ECX is **list manager**, not HB. Decompiler often shows `FUN_005085b0(this)` incorrectly.
- **Scalar free:** if `(flags & 1)` → `operator_delete(this)` then fall through to return this (delete path may not return depending on CRT).
- **Sibling:** `CVOGHBBase_dtor` @ `0x00508390` is the complete body **without** free / without flags formal.
