## Role

Virtual **OnHeartBeat** (`vtbl+0x0c`) for **`CVOGHBMoveVehicle`** (also shared by **`CVOGHBMoveVehicleToMouse`**).

Each pulse (when `TryFire` decides the period is due):

1. If bound vehicle entity (`this+0x24`) is **null** → write out-status **1** and return.
2. Else call **`CVOGVehicle::MoveToTarget3DPoint`** on that entity with HB-stored accept/cruise/aim fields and **allowReverse=1**.
3. If MoveTo returns **false** (arrived / disabled / no phys) → **`CVOGHBBase_Stop(this)`** which may run dualed **OnEnd** (steer-park).
4. Always (entity present path) write out-status **0** (Continue) — HB stays live unless Stop removed it.

## Annotated control flow

```c
// Machine-correct reconstruction (not raw decompiler arg bind)

void __thiscall CVOGHBMoveVehicle_OnHeartBeat(CVOGHBMoveVehicle *self, uint32_t *pOut)
{
  VehicleEntity *entity = self->entity; // +0x24

  if (entity == nullptr) {
    *pOut = DAT_00af4f84; // 1
    return;               // RET 4; EAX = pOut
  }

  // ECX still = entity (not reloaded)
  char ok = MoveToTarget3DPoint(
      entity,
      self->acceptDist,   // +0x2c
      self->cruiseScale,  // +0x30
      self->aimUnused,    // +0x34  (pushed; unused inside MoveTo)
      /*allowReverse=*/1);

  if (ok == 0) {
    CVOGHBBase_Stop(self); // may OnEnd: SetSteer(0)+Push
  }

  *pOut = DAT_00d02c60; // 0 = Continue
  return;               // RET 4; EAX = pOut
}
```

### Why decompiler lied about MoveToTarget this

After `mov ecx,[esi+0x24]; test ecx,ecx; jnz armed`, ECX still holds the entity. The four `push`es are pure stack args; `call 004fc650` is thiscall with **ECX=entity**. Ghidra folded the first stack push into `this`, shifting accept/cruise/aim and dropping the entity bind.
