# Annotated low-level: FUN_0052c700 (mission staging map store)

| Field | Value |
|---|---|
| Stable ID | `aa_0052c700` |
| VA | `0x0052c700` |
| System | `missions-progression` |
| Date | 2026-07-23 scaffold; **2026-07-29 dual seal** |

## Machine-level notes

- **Map this** = `character + 0x508` (`LEA EBX,[ESI+0x508]`), not raw character.
- End sentinel compare uses `character + 0x50c`.
- `MOV ECX,0xC` + `REP MOVSD` = **exactly 12 dwords**.
- Hit: dest `LEA EDI,[node+0x18]`.
- Miss: stack pair `{key, payload[12]}` → `FUN_00539cb0` insert.
- Epilogue: re-find → `EAX = node+0x18` → `MOV [EAX+0x28], key` → **return payload***.
- `RET 8`: two stack formals (key, payload*).

## Sealed payload (12 dwords @ `node+0x18`)

| i | off | meaning |
|--:|----:|---|
| 0..7 | +0x00 | item COID slots **or** `−1` |
| 8 | +0x20 | NPC (`Mission.NPC`) on award path; else often `−1` |
| 9 | +0x24 | AutoAssign on award path; else often `−1` |
| 10 | +0x28 | **forced mission key** by this function |
| 11 | +0x2C | `0` / consumer flag byte |

## Pseudocode (annotated; asm-corrected return + map this)

// returns payload* (node+0x18)

{
  int map = character + 0x508;          // asm LEA
  int out_it[2];
  uint32_t insert_pair_key;
  uint32_t insert_value[12];
  int node;

  FUN_00538a40(/*this=*/map, out_it, &key);   // lower_bound
  node = out_it[0];

  if (node == *(int *)(character + 0x50c)) {
    // miss → insert {key, payload12[12]}
    insert_pair_key = key;
    for (int i = 0; i < 12; i++)
      insert_value[i] = payload12[i];
    FUN_00539cb0(/*this=*/map, /*out*/out_it, &insert_pair_key);
  } else {
    // hit → overwrite payload
    uint32_t *dst = (uint32_t *)(node + 0x18);
    for (int i = 0; i < 12; i++)
      dst[i] = payload12[i];
  }

  FUN_00538a40(/*this=*/map, out_it, &key);
  node = out_it[0];
  uint32_t *payload = (uint32_t *)(node + 0x18);
  payload[10] = key;                    // +0x28; asm MOV [EAX+0x28],EBP
  return payload;
}
