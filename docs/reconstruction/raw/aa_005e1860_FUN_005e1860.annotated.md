## Machine-level notes

- **Role:** Classic **sorted merge** of two half-open `int32` ranges into an output cursor (MSVC `std::merge`-style on dwords). Stores the **advanced write cursor** to `*pOutEndSlot`.
- **ABI:** `__cdecl`; 6 stack pointer args; bare `ret` (caller cleans 0x18).
- **Compare:** signed `int` (`*b < *a` → take from B, else take from A — equal prefers A).
- **Empty A range:** degenerates to pure copy of `[beginB, endB)` — how `FUN_005e0cd0` always calls it (passes `0,0` for range A).
- **No callees** (leaf). No globals.
- Prefer this CF over scaffold auto-names (`Named_CalleeOf_…_005e1860`).

| Slot | Role |

## Pseudocode (annotated)

```c
// __cdecl leaf — sorted merge of two int ranges; *pOutEndSlot = advanced out
void IntRange_MergeSorted_WriteEndPtr(
    int **pOutEndSlot,  // param_1
    int  *beginA,       // param_2
    int  *endA,         // param_3
    int  *beginB,       // param_4
    int  *endB,         // param_5
    int  *out)          // param_6
{
  if (beginA != endA) {
    do {
      if (beginB == endB) break;
      if (*beginB < *beginA) {   // signed compare
        *out++ = *beginB++;
      } else {
        *out++ = *beginA++;
      }
    } while (beginA != endA);
    // drain remainder of A (B exhausted mid-merge)
    for (; beginA != endA; ++beginA)
      *out++ = *beginA;
  }
  // drain remainder of B (A empty or exhausted)
  for (; beginB != endB; ++beginB)
    *out++ = *beginB;

  *pOutEndSlot = out;
}
```
