## Machine-level notes

- Leaf **right rotate** for MSVC-style map/set trees with **isnil @ +0x49** (staging 0x50-node family and siblings).
- Twin of sealed `Tree_RotateLeft` (`FUN_00568b70` @ `0x00568b70`).
- Pivot child is **left** (`*node` / `+0`), not right (`+8`) — polarity opposite of L-rotate.
- Root stored at `head->parent` (`map+4` → head; head `+4` = root).
- Parent slot detection: if `x == parent->right` (`parent+8`) attach as right; else attach as left (`*parent`).
- **No** color touch (`+0x48`); pure structural rewires; no alloc/free; no callees.
- Used by insert rebalance (`FUN_00538ea0`, `FUN_005690a0`, …) and erase rebalance (`FUN_00538780`, `FUN_00568c60`).

```c
void __thiscall Tree_RotateRight(int map, int *x)
{
  int y = *x;                         // y = x->left
  *x = *(int *)(y + 8);               // x->left = y->right
  if (*(char *)(*(int *)(y + 8) + 0x49) == 0) {
    *(int **)(*(int *)(y + 8) + 4) = x;  // y->right->parent = x  (if !isnil)
  }
  *(int *)(y + 4) = x[1];             // y->parent = x->parent

  if (x == *(int **)(*(int *)(map + 4) + 4)) {
    // x was root
    *(int *)(*(int *)(map + 4) + 4) = y;
    *(int **)(y + 8) = x;             // y->right = x
    x[1] = y;                         // x->parent = y
    return;
  }
  int *p = (int *)x[1];
  if (x == (int *)p[2]) {
    // x was right child
    p[2] = y;
    *(int **)(y + 8) = x;
    x[1] = y;
    return;
  }
  // x was left child
  *p = y;
  *(int **)(y + 8) = x;
  x[1] = y;
}
```
