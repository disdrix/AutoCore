## Machine-level notes

- Leaf **16-byte store** into **`this+0x90..0x9c`** (4 dwords).
- ABI: **ECX** = destination object; stack `const uint32_t src[4]*`; void; **`RET 4`**.
- Twin (dualed MEGA-053): `Object_Store16At80_Inferred` @ `0x00404c60` stores **`+0x80..0x8c`**.
- Callers often pair both as a contiguous 32-byte field write `this+0x80..0x9f`.
- Direction is **into this** (setter), not TFID-style out-copy.
- Product field English (position / orientation / generic blob) residual → `_Inferred`.
- Caller decompiles frequently drop stack arity; body + call-site assembly seals ABI.
