## Machine-level notes

- **`thiscall`**: ECX = vector shell (`begin@+4`, `end@+8`, `capEnd@+0xC`); stack `insertPos`, `count`, `fillSrc*`; **`ret 0xC`**.
- **Fill value** is **one dword** loaded from `*fillSrc` once at entry (MSVC insert-n of POD `uint32_t` / pointer-sized cell).
- **Element stride 4** sealed by `>> 2` size math and `operator_new(cap * 4)`.
- **Max length** compare uses imm **`0x3FFFFFFF`** (signed max dword count for 32-bit MSVC vector).
- **Growth:** geometric `cap + (cap>>1)`, clamped; if still short use `size + count`.
- **Three insert strategies:**
  1. **Realloc** when `capacity < size + count`: new buffer, copy `[begin,pos)`, fill n, copy `[pos,end)`, delete old, rebind pointers.
  2. **End-room shortfall** (`(end-pos)>>2 < count`): move tail up, fill remainder at old end, fill hole at pos.
  3. **In-place room:** copy-backward tail, fill n slots at pos, bump end.
- **count == 0** is a no-op (outer `if (param_3 != 0)`).
- Primary grow consumer: `FUN_004367f0` / `StdVector_DwordResize` (insert at end). Sibling insert-N family also exists at `FUN_004073a0` (not owned this dual).

## Control flow

```
begin = this[+4]; cap = begin? (capEnd-begin)>>2 : 0; size = begin? (end-begin)>>2 : 0
fill = *fillSrc
if count == 0: return
if size + count > 0x3FFFFFFF: FUN_004540b0()  # length_error style
if capacity < size + count:
  newCap = cap + (cap>>1); if overflow-ish newCap=0
  if newCap < size+count: newCap = size+count
  p = new(newCap*4)
  mid = copy [begin, insertPos) → p
  mid = fill_n(mid, count, fill)
  copy [insertPos, end) → mid
  delete begin if non-null
  rebind begin/end/capEnd; return
end = this[+8]; nbytes = count*4
if (end - insertPos)>>2 < count:
  # not enough tail room in absolute sense for pure backward — hybrid
  copy [insertPos, end) → insertPos+nbytes
  fill_n(end, count - (end-insertPos)>>2, fill)
  end += nbytes
  fill [insertPos, end-count) with fill
  return
# pure room at end for backward move
newEnd = copy [end-count, end) → end   # grow end first
end = newEnd
copy_backward [insertPos, end-count) → ...
fill [insertPos, insertPos+nbytes) with fill
```
