## Purpose

**thiscall** method on a small host/context object:

1. If `*(this+0x40)` (map) is null → return **0**.
2. Read integer screen pixel `(x,y)` from `this+0x38` / `this+0x3c`.
3. Unproject through the map’s gfxView at `*(map+0xe890)` → world near point + direction (`GfxView_UnprojectScreenToWorldRay_Inferred`).
4. Pack origin/dir as **float4** (xyz from unproject, **w=0**).
5. March along dir against the map heightfield with **maxSteps=400** (`CVOGMap_MarchDirToTerrain_Inferred`).
6. On hit: call virtual **`vtbl+0x5c`** on `*(this+0x24)` with the hit buffer; return **1**.
7. Miss / no map → return **0**.

Virtual method (DATA slot `@0x009d55bc`); no direct code xrefs.

### Decompiler gap (bytes win)

Ghidra surface shows:

```c

FUN_004cff70(&origin, &dir, hit, 400); // drops this
```

Bytes:

```text
mov eax, [esi+0x40]           ; map
…
mov ecx, [eax+0xe890]         ; gfxView = *(map+0xe890)
call FUN_0075c340             ; thiscall view
…
mov ecx, [esi+0x40]           ; map
call FUN_004cff70             ; thiscall map; RET 0x10 (callee cleans 4 stack args)
```

## Pack after unproject (sealed CF)

Unproject writes **vec3** near + **vec3** dir. Body copies into two **float4** with **w cleared** (`xorps` / store 0):

| float4 slot | Source |
|---|---|
| origin.xyz | near.xyz |
| origin.w | **0** |
| dir.xyz | dir.xyz |
| dir.w | **0** |

Then `MarchDirToTerrain(map, &origin, &dir, hitBuf, 400)`.

## Hit notify

```text
mov ecx, [esi+0x24]     ; target
mov edx, [ecx]          ; vtbl
lea eax, [hitBuf]
push eax
call [edx+0x5c]         ; thiscall target; stack = hit*
mov al, 1
```

Hit buffer is a stack object sized **28** B in decompiler (`local_20[28]`); MarchDir dual treats outHit as **float4** — extra bytes are stack pad / residual layout.
