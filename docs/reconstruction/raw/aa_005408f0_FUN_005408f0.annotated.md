## Machine-level notes

- **ABI:** `__thiscall`, **`ret 0x0c`** (3 stack dwords). ECX host; hash at **`this+0xf0c`**.
- **Body:** `005408f0`–`005409b1` (**193 B**).
- **Hash node:** key@`+0x10`, next@`+0x0c`, value@`+0x08`; value flag@`+0x0a` (0 → need master load).
- **SkillDef path:** `SkillDefMap_GetGlobal` is leaf (decompiler fake args are for ExactFind setup); end sentinel `*(map+4)`.
- **FUN_00540090:** materializes skill script base name into 0x400 buf from map node `+0x10` (skill-def string block).
- **FUN_004a6390:** `FxMaster_LoadMasterFromXML` — always appends `_nfx.xml` itself.
- **FUN_004a16d0 this:** bytes `lea ecx,[esi+4]` with ESI=hash value → **cache entry +4** is FxMaster host; decompiler first-arg this is wrong.
- Prefer assembly when decompiler conflicts on this/arg mapping.
