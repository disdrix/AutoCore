## Algorithm (phases)

1. **Decode flags**; optional race base-stat seed (`FUN_00521230`) when bit0.
2. **Zero** selected pools; research path sets dirty flags.
3. Capture `levelChanged` / `leveledUp`; store **`nLevel = newLevel`**.
4. **For L = 2 .. newLevel**: ensure XP table; lower_bound(L); if hit:
   - bit0: skill += row+0x16; bump four base-stat helpers (+1 each)
   - bit2 (`0x4`): attrib += row+0x14
   - bit6 (`0x40`): research += row+0x18
   - if level changed: clamp total XP (`+0x730`) from row+0x10 at boundary
5. **If bit `0x4`**: traverse skill HB (lock/unlock + HashError strings); `Skill_SetRankAndReevaluate`; hash-lookup one more skill; wipe `+0x74c`×100 to −1.
6. **Always (tail):** `Vehicle_RecalcCombatPools` if vehicle; vtable `+0x5c`; copy `+0x12e→+0x12c`; `+0x4f2=1`; optional `SearchAutoMissions`.
7. **Vehicle equip rebind** when vehicle present + extra condition (`this[0x32f]`): weapons 0..2, special slots (armor/power/race/etc.) via `FUN_005714e0` / `FUN_00571620` / `FUN_004d0e90` + attach helpers.
8. **Buff/item list** walk (`this[0x14e]`): add skill/attrib/research from item defs when corresponding flags set.
