## Machine-level notes

- MSVC SEH frame: `push ebp; mov ebp,esp; push -1; push LAB_009bc590; …`
- `mov esi, ecx` → **this** = list*; **no stack formals**; epilogue **`ret`** (`C3`).
- Outer CS always at **`list+0x28`**; nested CS at **`list+0x10`** only when **`count < 2`**.
- Head at **`list+4`**, tail at **`list+8`**, count at **`list+0xC`** (`InterlockedDecrement` after leave).
- Node: vtbl@0, payload@+4 (returned), next@+8; destroy via `(*vtbl)(node, 1)`.
- Empty list → return **0** (no CS enter).
- Push twin `FUN_004024d0` allocates **0xC** node (`PTR_FUN_009cb340`), appends to tail.
- Dtor twin `FUN_004bcbf0` drains with this pop then `DeleteCriticalSection` on both CS.
- Heavy use as **object-list iterator** (skill multi-target `FUN_0058c850`, mission notify, combat).

## Pseudocode (annotated)

```c
// __fastcall / __thiscall  ECX = ThreadSafeObjectList*
// returns payload* (object) from former head, or NULL if empty
void *ThreadSafeObjectList_PopFront(ThreadSafeObjectList *list)
{
  // SEH frame omitted
  if (list->head == NULL)          // +4
    return NULL;

  EnterCriticalSection(&list->csOuter);   // +0x28
  Node *node = list->head;
  bool takeInner = (list->count < 2);     // +0xC
  if (takeInner)
    EnterCriticalSection(&list->csInner); // +0x10

  void *payload = node->payload;          // node+4
  Node *next = node->next;                // node+8
  list->head = next;
  if (next == NULL)
    list->tail = NULL;                    // +8

  node->payload = NULL;
  node->vtbl->destroy(node, 1);           // (*vtbl)(1)

  if (takeInner)
    LeaveCriticalSection(&list->csInner);
  LeaveCriticalSection(&list->csOuter);
  InterlockedDecrement(&list->count);
  return payload;
}
```

## Control-flow diagram

```

EnterCS(outer +0x28)
node = head; takeInner = (count < 2)
if takeInner: EnterCS(inner +0x10)
payload = node[+4]
head = node[+8]; if !head: tail=0
node[+4]=0; node.dtor(1)
if takeInner: LeaveCS(inner)
LeaveCS(outer)
InterlockedDecrement(count +0xC)
return payload
```
