## Machine-level notes

- **stdcall** one stack formal: destination image object.
- **EBX** = source image object (caller must set; decompiler `unaff_EBX`).
- Entry loads dest into EBP and ESI, then calls `FUN_004321b0` (dest pre-clear: free existing owned buffers at +4 / +0x1ac / +0x1b0 / +0x1b4 and related).
- Fail: AL=0 → `pop esi; pop ebp; ret 4`.
- Success: bulk **move** owned fields src→dest via `rep movsd`, then **zero** src ownership so temp dtor is safe.
- Block sizes sealed: **10 dwords** from +8 (40 B), **0x5F dwords** from +0x30 (380 B), plus scalars +4 / +0x1ac / +0x1b0 / +0x1b4.
- Return **1** in AL; epilogue **ret 4**.
- Callers: decode-by-format success commit, flip helpers, other NDAssetImage load paths (4 xrefs).
