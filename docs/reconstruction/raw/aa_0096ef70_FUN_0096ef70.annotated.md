## Machine-level notes

- **9-byte** body: `mov eax,ecx` / `mov dword [eax],0` / `ret`.
- **ECX** = address of handle (this / fastcall single ptr). **No stack formals.**
- Returns **this** in EAX (ctor idiom); decompiler lists `void`.
- Zeroes **only** the first dword — the payload pointer.
- Role sealed by peer **dtor** `FUN_0096efd0` (not OWN): decrements refcount at `obj+8`, may call release vfunc at `*(obj+4)+8`, nulls handle. Therefore this is **default-null construction** of that handle type.
- ~**62** unconditional call xrefs across UI/graphics/TacArc/paint/assets.
