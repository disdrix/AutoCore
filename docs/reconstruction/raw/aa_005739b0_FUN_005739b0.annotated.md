## Machine-level notes

- **ABI:** `__cdecl`, three stack pointers:
  - `[esp+4]` = `first` (mutable cursor, dword*)
  - `[esp+8]` = `last` (exclusive end, dword*)
  - `[esp+0xC]` = `value` (const dword* — template source)
  - bare **`ret`** (callee does not clean args)
- **Stride:** `add eax, 4` — **exactly 4-byte** elements. Not a byte fill, not a struct construct-N.
- **Leaf:** no `call` / no SEH.
- **Semantics:** half-open range fill `[first, last)` with `*value`. Equivalent to:

  ```c
  for (; first != last; ++first) *first = *value;
  ```

- ESI used only as load temporary inside the loop; value pointer stays in EDX.
- Parent `FUN_004507a0` (vector insert-N dword) uses this to paint template dwords into a hole after memmove/grow — confirms **assign fill**, not ctor/dtor.

/* StdFill_DwordRange — fill [first, last) with *value (4-byte POD). */

void __cdecl StdFill_DwordRange(uint32_t *first, uint32_t *last, uint32_t const *value)
{
  for (; first != last; first = first + 1) {

  }

}
