## Machine-level notes

- **ABI:** two stack args `game*`, `packet*`; frame `SUB ESP,8` + EBX/EBP/EDI; **`RET 8`** (stdcall-like). Not thiscall.
- **Role:** **create** path used when resolve-misses (`FUN_008122e0` / `0x201C` handlers). Twin **update** is `FUN_00811e00` ("ProcessSectorUpdate").
- **Factory:** `CVOGReaction_GiveItemByCbid(*(packet+4))`. Fail logs plate string with programmer callout.
- **Init sequence:** `vtbl+8(cbid, *(game+0xe04), 0)` then `vtbl+0x1cc`, flag fusion into object dword `+0x184` (`[0x61]`), then `vtbl+0xc4(..., mode=2, ...)`.
- **Post flags:** `+0xa1` → table create helper `008024d0` with globals `DAT_00d1d86c`/`DAT_00d1d870`; `+0xc0` → `007fb2b0` id pair.
- **Residual:** `FUN_0092a3b0` call present in bytes under flag gate; decompiler may drop as unreachable — keep as open residual for ports.
