## Purpose

Given a **bound motion/status controller** (`this`) and a **skill id**, walk a tree-of-lists of `0x18`-byte table entries keyed by skill id. On match: schedule end-time on `this+0x30`, optionally apply vehicle/phys status motion (flags, impulse, handbrake, heading/rotation), then dispatch entity `vtbl+0x64` by mode byte.

Sole direct caller: thin gate `Skill_ApplyBoundStatusMotionIfPresent_Inferred` (`FUN_004c2f20`) which tail-JMPs here when `boundObj+0x1FC != 0`.
