## Purpose (annotated)

Integrate one motion step for a **motion slot** bound to a host CVOG-like object:

1. Snapshot current position `this[0x5e..0x60]` (`+0x178..+0x180`).
2. Branch on host path pointer `*(*this)`:
   - **null path** — free integrate:
     - optional nested basis / quat prep (`+0x1e8 bit7`, host `+0x98a bit5`, slot flag `+0x90`) using `Math_QuatInverseRotateDelta` + peer `FUN_004e8320`
     - if attach gate `(def+0x3e3 & 8)` and host`+0xc` non-zero: chase attach sample `FUN_005c4e30` toward host`+0x880`
     - else flag-gated force helpers on `def+0x1e4` bits 3/4/5/6 → `FUN_005c36f0` / `005c4040` / `005c2de0` / `005c2030` (+ local orientation rebuild with factor **2.0**)
     - optional heightfield snap `FUN_004cd220` when `param_2≠0` and host`+0x98c bit5`
   - **non-null path** — sample path point by index `this[0x6a]`, transform via `FUN_004b49a0`, optional ahead-bias with `0.5` / `6.0` constants
3. Post-modes on host`+0x984`:
   - **2**: store unit delta of this step into orientation slots `this[0x61..]`
   - **4**: copy host facing `+0x844..+0x84c`
4. Optional linear velocity accumulate from host `+0x217..` when flag combo allows.
