## Machine-level notes

- **ABI:** `__thiscall` — **ECX** = list*; stack = `const dword*` (pointer to payload value); void; **`RET 4`**.
- **Layout (MSVC list):**
  - list `+4` = `_Myhead` sentinel
  - list `+8` = `_Mysize`
  - node `+0` = `_Next`, `+4` = `_Prev`, `+8` = dword `_Myval`
- **Callees:**
  - `FUN_00418700` — buy 0xC node (`Next=head`, `Prev=head->Prev`, `Myval=*pValue`); stdcall/thiscall-member shape **`RET 0xC`**
  - `FUN_00404840` — `_Incsize(1)` with `"list<T> too long"` overflow; **thiscall `RET 4`**
- **CF:** buy node → incsize → rewire `head->Prev` and `old_prev->Next` (insert before sentinel = **push_back**).
- Prefer assembly when decompiler drops ECX on Incsize (`FUN_00404840(1)` still has `MOV ECX,ESI` live).
