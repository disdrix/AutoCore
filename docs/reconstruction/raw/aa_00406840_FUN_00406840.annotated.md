## Machine-level notes

- **ABI (non-obvious):** ECX=queue*; **EAX=newCount**; stack **0x138-byte value by-value**; void; **`RET 0x138`**.
- **Stride:** `0x138` via magic `0xD20D20D3` reciprocal divide (same family as `LogicUiEventQueue_InsertN`).
- **Queue layout:** begin `@+4`, end `@+8`, cap_end `@+0xC` (cap unused here).
- **CF:**
  1. `size = begin ? (end-begin)/0x138 : 0`
  2. if `newCount <= size`: if `newCount < size` → `FUN_00407640` erase `[begin+new*0x138, end)`; return
  3. else → `LogicUiEventQueue_InsertN(queue, end, newCount-size, &value)` grow/fill
- **Decomp caveat:** `FUN_004076a0` call shown without ECX=queue; image thiscall supplies it. Grow path passes `end` as insertAt.
- **Callers:** both live sites set `EAX=0` (clear queue) — `FUN_00801c50` @ `0x00801e8b`, `FUN_00946c00` @ `0x009470a0`.
