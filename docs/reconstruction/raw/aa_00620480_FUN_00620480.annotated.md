## Purpose (sealed structural)

Skill handler (installed as **DATA** function pointer at `0x009d1598`) that:

1. Gates on world/map flag `ctx+0x7e`, non-null caster/source `param_1`, and related object from `vtbl+0x214`.
2. Samples pose (quat/pos) from related object (`FUN_00404c90` / `FUN_00404a20`).
3. Spawns a template entity either:
   - **Direct:** `operator_new(0x690)` + `FUN_004c9aa0(1)` when `skillDef+0x22 == 0`, then vcall init with template id `skillDef+0x14c`; or
   - **Template path:** `FUN_0058bf50(templateId, skillDef, source)` — on null log `"Skill %d had invalid template %d."` and **return 0**; else resolve transform and spawn via related vtbls.
4. Snaps Z via `CVOGMap_CastTerrainHeight` using `pos.z + DAT_00aaa7ac` (**100.0f**).
5. Ensures skill tree entries at `skillDef+0x154/+0x158/+0x15c`.
6. Constructs HB action `operator_new(0x6c0)` + `FUN_006202f0(...)`; if owner null → vtbl dtor; else `CVOGHBList_Enqueue(ctx+0xe4ec)` + `CVOGHBBase_Start`.
7. Optional `Skill_ApplyEffectsOnTarget_Inferred` when `skillDef+0x150 != 0`.
8. Returns **1** on outer success path (or fall-through when gate fails without work).
