- `__thiscall`/`__fastcall`: ECX = skill-bearing owner (`this`); ESI holds `this` for duration.
- First action: `push 1; call Object_CreateOrRecreateSkillHash_Inferred` (`0x00518e30`) — **wipes/creates** skill CNDHash at `this+0x70` with log2 bucket exp **1**.

- Rank sources: virtual methods **`vtbl+0x264 / +0x268 / +0x26c`** — return byte zero-extended (`movzx ax/cx, al`) → short rank for `Skill_EnsureLoadedInTree`.
- Call convention to ensure: push rank, push skillId, ECX=this; callee cleans 8 B (`ret 8` sealed on Ensure dual).
