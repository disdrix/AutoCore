## Machine-level notes

- **ABI (bytes):** **EAX** = container; **0** stack formals; plain **`RET`**; void (no value returned).
- **Leaf:** no callees; no CS; no page free; no element read/write.
- **Semantics:** header-only pop_front for POD ring: if `size!=0`, advance `begin` with wrap at `capacity*4`, decrement `size`, force `begin=0` when emptied.
- **Layout family:** `+0x08` page capacity, `+0x0c` begin, `+0x10` size (same slots as PushFront/PushBack/Resize).
- **Xrefs (6):** `0x0043cc4a`, `0x0043d0e2` (insert/grow workers + Catch paths), `0x008c41f1`, `0x0090c2da`, `0x008dd784`, `0x008dd902`.
- **Polarity vs PushFront (W29-B):** PushFront decrements begin and may allocate page; this advances begin and never touches map.

## Pseudocode (annotated)

```c
// EAX=container; void; plain RET
void GuardedVector_PopFront(GuardedVectorHeader* container /*EAX*/)
{
  if (container->size == 0)
    return;

  container->begin += 1;
  // wrap when begin reaches total element slots (capacity pages * 4)
  if ((uint32_t)(container->capacity * 4) <= (uint32_t)container->begin)
    container->begin = 0;

  container->size -= 1;
  if (container->size == 0)
    container->begin = 0;
}
```
