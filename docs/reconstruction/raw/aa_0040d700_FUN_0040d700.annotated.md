## Control flow (bytes + decompile)

### Full-range fast path

If `first == head->left` **and** `last == head` (erase `[begin, end)` = entire tree):

1. `StdTree_FreeSubtree_Val12(this, head->parent)` — free all real nodes (`FUN_0040d630`).
2. Reset sentinel: `parent = left = right = head`; `size = 0`.
3. `*out_it = head->left` (= head).
4. `RET 0x0C`.

**Note:** free path does **not** run value vtbl dtors (same shape as peer `StdMap_EraseRange_Val12` full free); value destroy lives in clear (`StdTree_Clear_PtrVal_Vtbl0C`) when required.

### Partial range

While `first != last`:

1. If `first->isnil == 0`, compute **in-order successor** (right-min else parent-climb) using isnil@`+0x19`.
2. `FUN_004188e0(this, &first_slot, first)` — single-node erase + RB rebalance + `operator_delete(node)`.
3. `first = successor`.

Then `*out_it = first` (= `last`); `RET 0x0C`.
