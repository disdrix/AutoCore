## Machine-level notes

- **Role:** Fill a 16-byte `sockaddr_in`-layout buffer with **AF_INET + INADDR_NONE + port 0xFFFF** via shared helper `FUN_0067b0a0`, then return the pointer.
- **Semantics:** “Invalid / unspecified endpoint” placeholder used when no real peer address is available (auth client path, many net helpers).
- **ABI:** `__cdecl`, one stack arg (`void*` / `sockaddr_in*`), returns same pointer in EAX (`ret` without n).
- **Decompiler gap:** Ghidra shows `FUN_0067b0a0(0xffffffff,0xffffffff)` without ECX; bytes seal `mov ecx, esi` with `esi = param_1`.
- Callee `FUN_0067b0a0` is **out of OWN VA** — dual only seals the call and constants here.
