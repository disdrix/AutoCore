## Purpose

**POD range copy** of **0x18-byte (6-dword) elements** from half-open `[begin, end)` into a destination buffer starting at `dest`.

Used by SkillSet `std::vector`-style insert / reallocate (`FUN_00440f80`, `FUN_00442760`) after `operator_new(n * 0x18)`. MSVC max-size constant at parents: `0xaaaaaaa` = `INT_MAX / 0x18`.

**Not** a string copy. **Not** a typed ctor loop (no per-element constructor calls — pure loads/stores).

## Signature (byte-sealed ABI)

```c
// Custom register ABI (decompiler: __fastcall begin/end + phantom in_EAX)
// EAX = dest begin (cursor; advanced by 0x18 each element)
// ECX = src begin
// EDX = src end (exclusive)
// returns EAX = dest end (dest + n*0x18); empty range leaves EAX = dest begin

```

## Pseudocode (annotated ≡ raw ≡ bytes)

```c
void *SkillSet_UninitializedCopy_0x18(void *dest /*EAX*/,
                                      void *begin /*ECX*/,
                                      void *end /*EDX*/)
{
    uint32_t *d = (uint32_t *)dest;
    uint32_t *s = (uint32_t *)begin;
    uint32_t *e = (uint32_t *)end;

    if (s == e)
        return d; // empty: no push/pop

    for (; s != e; s += 6, d += 6) {
        if (d != nullptr) {
            d[0] = s[0];
            d[1] = s[1];
            d[2] = s[2];
            d[3] = s[3];
            d[4] = s[4];
            d[5] = s[5];
        }
        // d still advanced even if null (retail behavior)
    }
    return d;
}
```

## Machine notes

- Leaf: no callees.
- Empty range: `cmp ecx,edx; jz` straight to `ret` (no push).
- Null dest cursor: skip 6-dword stores, still `add eax,0x18` — only safe for empty range if dest starts null; parents pass real buffers.
- Sibling body at `0x00442b40` uses stack args — separate unit, not sealed here.
- 8 call sites across 2 SkillSet insert helpers.
