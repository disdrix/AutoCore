## Machine-level notes

- Source: raw capture + live `decompile_function` / `read_memory` (no `disassemble_bytes`).
- **ECX = reader** (`mov esi, ecx`); SEH frame + `sub esp,0x1c`; plain `RET`.
- Sticky error `this+0x402c`: **cleared to 0** at entry; binary/text failures **OR** `0xffffffff`.
- Mode `this+0x4044`: **0 binary** seek; **non-zero text** brace balance.
- Ring top index: wrap `(write + base - 1)` with capacity `+0x4038`; entry ptrs at `+0x4034`.
- Ring entry field **`+0x10`**: absolute **end position** used to reposition stream window (`+0x18` cursor / `+0x1c` base / `+0x20` remaining).
- Bound check against `this+0x28` (stream limit) and sign of end.
- Text path: nest depth starts at **1**; token reader `FUN_00767840(this,1)`; `{` depth++; `}` depth--; exit when depth 0; log on sticky < 0.
- Shared epilogue: if `write(+0x4040) != 0` then `--write`; if write becomes 0 clear `base(+0x403c)`.
- Pairing leave thunk `0x00437120`: `if (scope.okFlag) LeaveChunk(scope.reader)` via tail JMP (not owned).

      this->stickyError |= 0xffffffff; // bytes: or [esi+0x402c], -1
