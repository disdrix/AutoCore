## Machine-level notes

- Source: raw capture + live `decompile_function` / `read_memory` (2026-07-29).
- **SSE `movss`** four-wide component copy — **not** normalize, quat, or matrix.
- **Sibling** `0x004e9530` (`Math_CopyFloat3ToFloat4_Inferred`) copies xyz and leaves **W dirty** from stack local; **this unit copies W from `src+0xC`**.
- Calling convention: **cdecl** stack args; epilogue bare **`C3`**.
- **EAX at RET = dst*** (last `mov eax, [ebp+8]` before stores) — callers treat return as `float*`.
- `and esp, -16` is transient alignment only; frame restored before ret.
