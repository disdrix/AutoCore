### Control-flow skeleton

1. If `client+0x13 == 0`: fall through to restore ExceptionList, **return 1**.
2. Else install SEH, bump timer nested A, `FUN_0094b3a0`, profile 5.
3. If `client+0xf40 == 0`: skip inner work.
4. Else bump nested B, **`FUN_0093a5c0(0)`** focus/UI poll gate; **if non-zero: skip rest of frame body**.
5. Else run ordered subsystem sequence (see clean plate), optional frametime log, `Sleep(0)`, end profile 0, `FUN_0079a9f0`, `FUN_0092cd20`.
6. Restore ExceptionList; **return 1**.
