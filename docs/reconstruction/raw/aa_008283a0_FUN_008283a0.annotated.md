## Machine-level notes

- **Button** arrives in **EAX** → ESI; **item id** in **ECX** (signed); hi half via `cdq`.
- **Plain `ret`** after `add esp,0x104` — ABI differs from skill twin (`ret 4`).
- `payloadKind @ +0x548 = 2` forces item mode; `pSkill @ +0x558 = 0`.
- Exclusive slot: `SetQuickBarItem(id)` then `SetQuickBarSkill(-1)`.
- Icon path comes from temporary clonebase via `CVOGReaction_GiveItemByCbid`, not skill stem strings.
- `DAT_00afdf0c` is a color constant block (white/modulate), not a path string.

## Annotated control flow

```
UI_QuickBarSlotButton_AssignItem_Inferred(button=EAX, itemId=ECX) -> 1
  if itemId == -1:
      QuickBar_ClearActiveSlot_INFERRED()
      return 1

  bChanged = !(kind==2 && idLo==itemId && idHi==(itemId>>31))
  idLo/idHi = cdq(itemId)
  flatSlot  = page*10 + column
  kind = 2; pSkill = 0

  CVOGCharacter_SetQuickBarItem(g_localChar, flatSlot, idLo, idHi)
  CVOGCharacter_SetQuickBarSkill(g_localChar, flatSlot, -1)

  if bChanged && fSelected:
      UI_QuickBarSlotButton_SetSelected(button, 0)

  iconState = 0
  if pOwnedChild: destroy (vtbl+4)

  if pIconWidget:
      tmp = GiveItemByCbid(idLo)
      if tmp == null:
          QuickBar_ClearActiveSlot_INFERRED(); return 1
      tmp->vtbl+8(idLo, DAT_00d1b644)
      FUN_0085d970(tmp, pathBuf)
      tmp->dtor(1)
      icon set-texture / color / invalidate (vtbl +0x2c8,+0x50,+0x15c,+0x34c)

  chromeA/B optional refresh (vtbl +0x1d8,+0x34c)
  button->vtbl+0x448()
  return 1
```
