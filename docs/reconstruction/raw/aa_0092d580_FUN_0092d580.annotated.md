## Machine-level notes

- **Convention:** **ECX = host**, **EDX = signed levelDiff**, **EAX = out float4\*** (16 B). Bare `ret`.
- Leaf: pure band select + four dword loads/stores.
- Band table is a **contiguous array of 8 × 16-byte slots** starting at `host+0xBE4`.
- Thresholds are **signed** (`cmp`/`jl`/`jg`); zero uses unsigned trick in decompiler (`param_2 < 0x80000000`) matching `cmp edx,-1; jg → +0xC14`.
- Parent `Ui_ResolveEntityNameColor` multiplies first three floats by **255.0f** and packs A=`0xFF`. Fourth dword copied but may be unused padding/alpha float — not sealed as product alpha.
- Also used by mission dialog / journal UI for title or list tinting.

## Pseudocode (annotated)

```c
// Copies host.bandTable[bandIndex(levelDiff)] (16 B) → out
// EAX preserved as out return
float* Ui_NameColorLevelBand_CopyFloat4_Inferred(
    void* host /*ECX*/,
    int levelDiff /*EDX*/,
    float out[4] /*EAX*/)
{
  const float* slot;
  if      (levelDiff >= 7)  slot = (float*)((char*)host + 0xC54);
  else if (levelDiff >= 5)  slot = (float*)((char*)host + 0xC44);
  else if (levelDiff >= 3)  slot = (float*)((char*)host + 0xC34);
  else if (levelDiff >= 1)  slot = (float*)((char*)host + 0xC24);
  else if (levelDiff <= -5) slot = (float*)((char*)host + 0xBE4);
  else if (levelDiff <= -3) slot = (float*)((char*)host + 0xBF4); // -4,-3
  else if (levelDiff <= -1) slot = (float*)((char*)host + 0xC04); // -2,-1
  else                      slot = (float*)((char*)host + 0xC14); // 0
  out[0] = slot[0];
  out[1] = slot[1];
  out[2] = slot[2];
  out[3] = slot[3];
  return out;
}
```
