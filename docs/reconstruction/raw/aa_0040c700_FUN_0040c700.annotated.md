## Machine-level notes

- **Exact inverse** of `List_TraversalLock` (`0x004294f0`):
  - Lock: if `+0x28==0` → `EnterCriticalSection(+4)` then `+0x28=1`; if already set → debug log, no re-enter.
  - Unlock (this unit): if `+0x28!=0` → `+0x28=0` then `LeaveCriticalSection(+4)`; if clear → no-op.
- Safe on unlocked list (flag already 0): does **not** LeaveCS.
- Does **not** walk nodes, free, or throw `0x80070005`.
- Sibling walkers (`List_IterateNext`) re-enter via `TryEnterCriticalSection(+4)` while flag held; this unlocks after the walk window.
- Distinct from InventoryGrid-local unlock helpers that use different CS offsets (`grid+0x30` / flag `+0x54`).
