## Machine-level notes

- **Merge two physics hosts/islands** under a world/sim object: absorb `src` into `dest`, rebind owned lists, remove `src` from the world host table, destroy `src`.
- Sole static consumer: `PhysSim_FlushPendingBodyPairs_Inferred` (`0x00561320`) when a pending body pair has distinct `body+0x44` hosts.
- Decompiler shows `FUN_00560a30(hostA, hostB)` without this — **bytes seal ECX=world** (`mov ecx,esi` at call site; prologue `mov ebx,ecx`).
- Capacity high-bit (`& 0x7fffffff`) is the same grow pattern as `Host_ActionList_Push` / other phys vectors.
- `FUN_0055eb80` = `PhysSim_ActivateHost` (already dual-sealed).
- `FUN_00560750` merges the **+0x68** list (decomp call `param_3+0x1a` = dword 0x1a → byte **+0x68**); product English open (constraint/contact family Tentative).
- Destroy path: `(*vtbl)(1)` — MSVC scalar deleting destructor convention.

// __thiscall; RET 0x8
Host *PhysSim_MergeHosts_Inferred(World *world, Host *dest, Host *src)
{
  if (dest == src)
    return dest;

  if (dest->activated_flag_0x29 == 0) PhysSim_ActivateHost(dest);
  if (src->activated_flag_0x29 == 0)  PhysSim_ActivateHost(src);

  MergeListAt0x68(dest, src); // FUN_00560750

  // Append vector A @ +0x3c (bodies*): rebind item+0x44=host, item+0x58=index
  // Append vector B @ +0x4c: rebind item+0x10=host
  // Append vector C @ +0x58: rebind item+0x14=host
  // Max/add scalars @ +0x08..+0x18
  // Append 8-byte vector @ +0x74 (no per-item host rewrite)

  // World host table swap-remove src by src->index@+0x24
  world->hosts[src->index] = world->hosts[world->hostCount - 1];
  world->hosts[src->index]->index = src->index;
  world->hostCount--;

  dest->dirty_0x28 = (dest->dirty_0x28 == 0 && src->dirty_0x28 == 0) ? 0 : 1;
  src->vtbl->dtor(src, /*delete*/1);
  return dest;
}
