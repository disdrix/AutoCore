## Machine-level notes

- **No stack formals.** Caller places the image object in **ESI** (decompiler `unaff_ESI`). Plain **`ret`**.
- Return is **AL** boolean: **0** = busy/locked (`*(ESI+0x38) != 0`), **1** = owned buffers released.
- Free path uses CRT **`free`** via IAT slot **`0x009C6524`** (loaded into EBP once; `call ebp` + `add esp,4`).
- Pointer array at **`+0x1b4`**: for `i in [0, +0x1a4)`, if entry non-null call **`vtbl[0](entry, 1)`** (deleting dtor / release with flag 1), then free the array itself and null the field.
- Then free-and-null **`+0x1ac`**, **`+0x1b0`**, **`+4`** if non-null.
- Same ownership slots that `NDAssetImage_TransferFields_Inferred` (`0x00432580`) moves / zeros — sealed field family.
- Callers: create (`004323e0`), transfer (`00432580`), decode (`00432cb0` many sites), helper (`00432b30`). **13** xrefs.

## Control flow (sealed)

```
obj = ESI
if *(obj+0x38) != 0: return 0          // busy gate — no frees
if *(obj+0x1b4) != 0:
  for i = 0 .. *(obj+0x1a4)-1:
    p = *( *(obj+0x1b4) + 4*i )
    if p: (*p)[0](p, 1)                // vtbl[0] with arg 1
  free(*(obj+0x1b4)); *(obj+0x1b4) = 0
if *(obj+0x1ac): free; null
if *(obj+0x1b0): free; null
if *(obj+4):     free; null
return 1
```
