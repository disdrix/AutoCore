## Purpose

CNDUIDialog **child-hash teardown leaf** invoked from complete dtor `CNDUIDialog_CompleteDtor` (`0x00792c20`) before owned-pointer scalar deletes. If `this+0x4c0` (hash*) is non-null: clear selection, walk the hash under traversal lock, tear down each child entry, remove children from the dialog's pointer vector, unlock, clear the list shell at `+0x4dc`, **recreate** the empty hash (BL=5), and set flag `this+0x4c4 = 1`. Does **not** free the hash object or `this` — parent complete dtor scalar-deletes `+0x4c0` afterward.
