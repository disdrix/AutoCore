## Machine-level notes

- **Register ABI:** stream **window** in **ESI**, destination **header** (`u32[4]` / 16 bytes) in **EDI**.
- **Return:** `0` on success; `0xffffffff` (−1) if ensure fails or still &lt; 16 available bytes.
- **Purpose:** binary-mode **16-byte chunk header** read used by `stoChunkReader_OpenChunk` (only caller).
- On short buffer: call `FUN_00435df0(window, base+cursor)` as `__thiscall` (ECX=window, stack arg=absolute pos) to refill/realign the window; re-check available ≥ 16.
- Copy 4 little-endian dwords from `window+0x18+cursor` → `*EDI`, then `cursor += 0x10`.
