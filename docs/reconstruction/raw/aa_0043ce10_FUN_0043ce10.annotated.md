## Machine-level notes

- Source: raw capture + live re-verify append for `aa_0043ce10`.
- Prefer bytes when decompiler omits register ABI (container is **EAX** → **EBX**, not a stack this).
- GrowBlockMap (`FUN_0043c9b0`) requires **EBX=container**; entry `MOV EBX,EAX` seals that contract.
- Element is dword copy from `*param_1` into page-mapped slot (4 dwords / 0x10-byte page).
- `begin` absolute index wraps: when `begin==0`, treat as `capacity*4` then decrement.
