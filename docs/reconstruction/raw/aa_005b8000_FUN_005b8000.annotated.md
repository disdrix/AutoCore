## Machine-level notes

- **Not** a vtbl entry; used as the element dtor callback for `_eh_vector_destructor_iterator_` (and ctor EH counterpart on `FUN_004941b0`).
- Element size sealed by all registration sites: push `0x28` / `6A 28` before vector iter (see Class_009c7a1c_CompleteDtor W28-M; FUN_00494170 entry loads array @+0x28).
- `FUN_004be2a0` is the **complete dtor body** of the heap object stored at element+0x24 (called with ECX=owned, then `operator_delete(owned)`). Type product name for that object open.
- Vector at +0x14 holds pointers to list hosts; each list uses head pointer @ +8 and size @ +0xC (StdList-like sentinel pattern: head self-links when emptied).
- Scaffold alias `Named_CalleeOf_Named_VOG_DEBUG_STOP_005b8000` is **rejected** — wrong role (not VOG debug).
