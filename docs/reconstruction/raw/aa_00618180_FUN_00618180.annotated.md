## Purpose

Intermediate **constructor** for the shared skill-heartbeat class `CVOGHBSkill_Common`:

1. Run `CVOGHBSkillBase_ctor` (blob copy, ValidateTarget, attach, base period).
2. Install Common vtbl.
3. Seed Common-tail fields (`+0x6c0` byte, `+0x6c4` float scale, `+0x6c8` zero).
4. Optionally clamp / rescale remaining HB period when target-side gate holds and remaining UI time exceeds **30.0 s**.

Used as intermediate base by many subclass ctors (e.g. `CVOGHBSkill_Virus_Ctor` passes `0, 1.0f` then overrides vtbl).

## Decompiler pitfalls

1. **`param_9` is float** — body uses `movss` to `+0x6c4`; Ghidra overlays `nPeriodSentinel` int.
2. **`param_1[0x2b].…` overlay** — `sizeof(CVOGHBBase)==0x28` → `0x2b*0x28+0x08=0x6c0` etc.; prefer absolute offsets.
3. **`iVar1 = param_1[1].nUnusedOrFlags`** — machine is **byte** `this+0x44`, not a full int field name.
4. Base callee display may say `FUN_005788d0` or `CVOGHBSkillBase_ctor` (same VA).
