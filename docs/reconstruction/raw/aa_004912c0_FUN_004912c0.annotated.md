## Machine-level notes

- **ABI:** MSVC **`__thiscall`**: ECX = env host; one stack dword (caller frame float / dt — **unread** in body); **`ret 4`**.
- **Prologue:** `sub esp,0xC; push esi; mov esi,ecx` — host in ESI for body.
- **Clock path:** `env+0xB8` → object with clock at `+0x78`. If clock null **or** `env+0x180 == 0`, sky blend amount defaults to **1.0** (`g_flOne`).
- **Sky blend:** dualed `WorldClock_GetSkyBlendAmount_Inferred` (`fld [clock+0x15c]`) → `fBlendAmount` for sky materials.
- **Quarter phase:** dualed `WorldClock_GetQuarterPhase01_Inferred`; remapped by **mode** dword at **`clock+0x154`** (0..3) into a full-day phase using **1/3** and **2/3** constants, then fed to light helpers `FUN_0079a110` / `FUN_0074e690` / `FUN_0074e910`.
- **Optional audio/light object** at `env+0x188` when flag `env+0x87` set — vtbl `+8` float apply.
- **Sky materials:** when dirty flag `env+0x90` and material bank `env+0x94` non-null → `FUN_00490af0(blend,1,cloudFlag,skyFlag)` (`SkyBox*` / `fBlendAmount`). If blend ≥ 1.0 → `FUN_00490820` texture bind + clear dirty.
- **Flags:** short fields `+0x98/+0xa0/+0xa8` < 0 encode bools (decomp shows `1.4013e-45` = float bit-pattern **1** for cloud path).
- Prefer bytes for `ret 4` and float constants; decompiler `__fastcall` plate omits dead stack arg.
