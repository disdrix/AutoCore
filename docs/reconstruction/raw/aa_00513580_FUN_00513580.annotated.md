## Machine-level notes

- **ABI:** MSVC **thiscall** — **ECX** = item; plain **`ret`**; **EAX** = int sum. Decompiler may show `__fastcall`.
- **Gate:** `FUN_004ce940()` returns game-data / catalog singleton (or 0). Null → **return 0**. Result kept in EBP and used as **ECX** for per-type lookup helpers.
- **Loop:** `i = 0 .. vtbl[+0x60]()-1` — slot count via virtual. Per slot: `slotId = vtbl[+0x5c](i)` (uint16).
- **Type switch:** host `clonebase = item[0x2a]` (`item+0xa8`); switch on `*(clonebase+0x38)` (item class enum). Only types **10, 0xc, 0xe, 0x1c, 0x44, 0x46** resolve a component object; others skip.
- **Lookup family** (thiscall on catalog, arg = slot id):

| Type | Lookup | Role (inferred) |
|-----:|--------|-----------------|
| `10` | `FUN_00508b60` | linear find in catalog list `+0x4c` by key `+0x6c` |
| `0xc` | `FUN_00508ac0` | sibling list |
| `0xe` | `FUN_00508bb0` | sibling list |
| `0x1c` | `FUN_00508b10` | sibling list |
| `0x44` | `FUN_00508c50` | sibling list |
| `0x46` | `FUN_00508c00` | sibling list |

- **Sum:** if lookup ≠ 0, **`sum += *(int32*)(component + 0x94)`**. Double lookup in decompile is real (null-check then re-fetch) — preserve in clean.
- **Return:** accumulated sum (0 if no manager, no slots, or no resolved components).
- **Callers:** store sell price `0x005142a0` adds `item+0xC4` then scales; sibling `0x00514250` same sum helper.

## Pseudocode (annotated)

```c
// ECX = Item*; returns int sum of component value fields
int __thiscall Item_SumEquippedComponentValues(int *item)
{
  int sum = 0;
  int *catalog = (int *)FUN_004ce940(); // singleton; may construct
  if (catalog == 0)
    return 0;

  uint32_t n = item->vtbl[+0x60](); // slot count
  if (n == 0)
    return 0;

  int clonebase = item[0x2a]; // +0xa8
  int itemType = *(int *)(clonebase + 0x38);

  for (uint32_t i = 0; i < n; ++i) {
    uint16_t slotId = (uint16_t)item->vtbl[+0x5c](i);
    int *comp = 0;
    switch (itemType) {
      case 10:   comp = FUN_00508b60(catalog, slotId); break;
      case 0xc:  comp = FUN_00508ac0(catalog, slotId); break;
      case 0xe:  comp = FUN_00508bb0(catalog, slotId); break;
      case 0x1c: comp = FUN_00508b10(catalog, slotId); break;
      case 0x44: comp = FUN_00508c50(catalog, slotId); break;
      case 0x46: comp = FUN_00508c00(catalog, slotId); break;
      default: break;
    }
    // compiler re-fetches slotId + lookup when non-null (see raw double call)
    if (comp != 0)
      sum += *(int *)((int)comp + 0x94);
  }
  return sum;
}
```

## Jump-table encoding (bytes)

Switch lowers `type` by 10 (`add eax, -10`), rejects `> 0x3c`, then:

```
movzx edx, byte [eax + 0x00513730]   ; case → index 0..6
jmp [edx*4 + 0x00513714]
```

Index byte table maps only the six live cases above; other offsets → index 6 (default).
