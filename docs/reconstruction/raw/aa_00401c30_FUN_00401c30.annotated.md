## Machine-level notes

- **ABI:** container pointer in **EAX** (MSVC register-arg size helper; **not** ECX thiscall). Bare `RET` (`C3`). Size returned in **EAX**.
- **Layout:** `begin` @ `+0x4`, `end` @ `+0x8`. Capacity not read.
- **Null-safe:** if `begin == 0` → return `0` (avoids null deref on empty/uninitialized vector).
- **Size formula:** `(end - begin) >> 2` ≡ element count for **4-byte** elements (`uint32_t` / `T*`).
- **Leaf:** no CALLs.
- **Twin:** dualed `StdVector_DwordSize` @ `0x004024b0` is identical CF with **ECX** = vec instead of EAX.
