## Purpose

Compute **surface-to-surface 3D Euclidean distance** between two game objects:

1. Resolve **world position XYZ** for each object (same dual path as `Object_GetWorldPositionPtr` / `FUN_00404c90`).
2. `dist = sqrt(dx² + dy² + dz²)`.
3. Subtract **both** object radii at **`+0x34`**.
4. Return `dist - rA - rB` as `float10` / x87 ST0.

Used by AI pursue, fire-weapons range, interact-objective proximity, and related gates.

## Annotated CF

```c
// __thiscall: ECX = objectA, stack[0] = objectB*
// Returns float10; ret 4
float10 __thiscall Object_SurfaceDistance3D_Inferred(int objA, int objB)
{
  float *posA;
  float *posB;

  // --- world position A (identical shape to FUN_00404c90) ---
  if (*(int *)(objA + 8) == 0) {
    // entity-embedded pose: *(*(obj+4)+4) + obj + 0x84
    posA = (float *)(*(int *)(*(int *)(objA + 4) + 4) + 0x84 + objA);
  } else {
    // physics path: rigid body world pos at rb+0xb0
    posA = (float *)(*(int *)(*(int *)(objA + 8) + 0x3c) + 0xb0);
  }

  // --- world position B (same) ---
  if (*(int *)(objB + 8) == 0) {
    posB = (float *)(*(int *)(*(int *)(objB + 4) + 4) + 0x84 + objB);
  } else {
    posB = (float *)(*(int *)(*(int *)(objB + 8) + 0x3c) + 0xb0);
  }

  // center-center Euclidean then surface adjust
  // MACHINE: fsqrt; fsub [ecx+0x34]; fsub [edx+0x34]
  return SQRT(
           (posA[0]-posB[0])*(posA[0]-posB[0]) +
           (posA[1]-posB[1])*(posA[1]-posB[1]) +
           (posA[2]-posB[2])*(posA[2]-posB[2])
         )
         - *(float *)(objA + 0x34)
         - *(float *)(objB + 0x34);
}
```
