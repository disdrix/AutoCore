## Machine-level notes

- **ABI:** EAX = host context; EDX = parameter name (C string); stack arg0 = data pointer; **`RET 4`**.
- Host layout: `host[+4]` → object with service pointer at **`+0xc`**.
- Service vtbl:
  - **`+0x24`**: lookup handle `(service, 0, name)` → handle (0 if service null).
  - **`+0x50`**: write `(service, handle, data, 0xFFFFFFFF)`.
- Call sites in `FUN_00942840` always pass name `"gWorldFogCenter"` (`0x00a2cf30`) and a float3 buffer; then copy floats into `*(…+0xe898)+0x8c`.

- **Odd:** null service only skips lookup; write reloads service without a second null check (can fault).
