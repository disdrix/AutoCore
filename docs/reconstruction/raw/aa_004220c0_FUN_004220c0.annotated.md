## Machine-level notes

- **Leaf:** no callees, no SEH, bare `ret`.
- **ABI:** **ECX** = count, **EAX** = dst start, **EBX** = src prototype (fixed across iterations).
- **Stride:** `rep movsd` of **`0x24d` dwords** = **`0x934` bytes** per element; dest advances by **`0x934`**.
- **Semantics:** MSVC-like **`uninitialized_fill_n`** for POD / trivial-copy elements — stamp the same prototype into `count` consecutive slots.
- **Null dst:** skips `rep movsd` but still advances EAX by `0x934` per remaining count (callers use non-null end/base in practice).
- **Count 0 / negative:** `test ecx; jbe` treats signed-negative as huge unsigned — callers pass non-negative counts.

## Annotated algorithm

```c
/* SkillRow_UninitializedFillN_0x934
   Register ABI (not stack):
     ECX = count
     EAX = dst
     EBX = src prototype (0x934-byte element)
*/

void SkillRow_UninitializedFillN_0x934(void /*ECX*/ *count_as_ecx,
                                       void /*EAX*/ *dst_as_eax,
                                       const void /*EBX*/ *src_as_ebx)
{
  uint32_t count = (uint32_t)(uintptr_t)count_as_ecx; /* actually ECX */
  uint32_t *dst  = (uint32_t *)dst_as_eax;
  const uint32_t *src = (const uint32_t *)src_as_ebx;

  if (count == 0)
    return;

  for (; count != 0; --count) {
    if (dst != 0) {
      /* rep movsd: 0x24d dwords from src → dst */
      for (int i = 0; i < 0x24d; ++i)
        dst[i] = src[i];
    }
    dst += 0x24d;   /* +0x934 bytes */
  }
}
```

## Call-site ABI proofs

1. **Emplace fast path** (`0x0041af46`): `mov ecx,1` / `mov eax,esi` (end) / call — inserts one copy at vector end.
2. **Grow path** (`0x0041f884`): `lea ebx,[ebp-0x948]` local prototype / `mov ecx,esi` count — fills N new slots from template.
3. **Wrapper** (`0x0041c9a0`): calls this then returns `base + n*0x934`.
