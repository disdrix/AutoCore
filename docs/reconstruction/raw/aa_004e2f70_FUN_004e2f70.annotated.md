## Machine-level notes

- Source: raw capture for `aa_004e2f70` + live `decompile_function` / `read_memory` (2026-07-29).
- **Leaf** dword **fill-n**: write `*value` into `count` consecutive dwords at `dst`; return **end** pointer `dst + count*4`.
- **Not** memcpy / uninitialized_copy: `param_3` is **not** advanced — same source dword is replicated.
- Free helper: ECX unused; **`ret 0x0C`** (three stack args).
- Used by many MSVC-style `vector` insert/grow paths (fill hole with `*value`); scaffold alias seeds from `CVOGSectorMap_AddCharacter` callee chain — **not** map-exclusive.

## Pseudocode (annotated copy of raw)

undefined4 * FUN_004e2f70(undefined4 *dst, int count, undefined4 *pValue)
{
  undefined4 *p;
  int n;

  p = dst;
  for (n = count; n != 0; n = n + -1) {
    *p = *pValue;          /* pValue NOT advanced */
    p = p + 1;             /* +4 bytes */

## Early-out
