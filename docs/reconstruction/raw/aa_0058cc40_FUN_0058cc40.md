### Semantics (sealed math)

1. Resolve short-host `ESI` via vtbl **+0x214**: if `target==null && source!=null` use source, else use target.
2. If host non-null:
   - `deltaInt = trunc(amount)`; if `amount in [-1.0, 1.0]` then `deltaInt = trunc(maxShort * amount)` where `maxShort = *(short*)(host+0x12e)`.
   - `old = *(short*)(host+0x12c)`; call vtbl **+0xAC** with `old + deltaInt`.
   - `applied = newShort - old` (re-read word at +0x12c).
3. Always build combat floater blob (type **2**):
   - source color 16 B from `source+0x160` or default `DAT_009d4d28`.
   - target color 16 B from `target+0x160`.
   - delta field = applied; flag bytes 0; type dword = 2.
4. Enqueue via **thiscall** `Client_EnqueueCombatFloater_INFERRED`: `ECX = *(target+0xA4) + 0xE8A4`.
5. Return applied short delta (0 if host unresolved).
