## Machine-level notes

- **Cdecl** composer: caller `ADD ESP, 0x14` (five stack dwords).
- **EAX / ECX** optional `float3*` translation pairs; each non-null builds **+T and −T** mat4s from identity base `DAT_00afdf70`.
- **Stack formals** (see raw append): dest, R_outer quat*, scale float3*, R_inner quat*, T float3*.
- Quat→matrix: `FUN_0076eb00`. Quat inverse: `FUN_0076e6b0` then `eb00` again.
- Scale: identity copy then diagonal `m00/m11/m22` from xyz.
- Multiply: `FUN_00412d80(dest, A, dest)` → `dest = A * dest` (left-multiply chain).
- Returns **dest** pointer in EAX.
