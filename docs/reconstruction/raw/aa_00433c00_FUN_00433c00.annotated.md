## Machine-level notes

- **ABI:** ECX = container*; EAX = requested capacity (`in_EAX` in decompiler). Void return.
- **Exclusive caller:** `BitStream_HuffmanBuildTables` (`FUN_0077d520`) @ `0x0077d53d`:
  - `mov eax, 0x100`
  - `mov ecx, 0x00d1eab4`  → container is the global triple at `DAT_00d1eab4`
- **Layout** (stride-0xC vector):

| Off | Global | Role |
|---|---|---|
| +0 | `DAT_00d1eab4` | live size |
| +4 | `DAT_00d1eab8` | capacity |
| +8 | `DAT_00d1eabc` | data pointer (alphabet entries, 12 B each) |

- **Grow policy:** if `capacity < need`:
  1. `newCap = need + (0x10 − (need & 0xF))`  (round-up slab; for need=0x100 → 0x110)
  2. `malloc(newCap * 0xC)`
  3. Temporarily install new ptr; `FUN_00433ca0` copies live `size` elements (0xC each) from old buffer
  4. Restore old, `free(old)`, commit new ptr + capacity
- **No-op** when already capacious (`jbe` after `cmp need, capacity`).

## Pseudocode (annotated)

```c
// ECX = container, EAX = need
// container: { uint32_t size; uint32_t capacity; uint8_t *data; } elem=12
void __fastcall BitStream_HuffmanAlphabetEnsureCapacity(HuffmanAlphaContainer *c /*ecx*/)
{
  uint32_t need = /* EAX */;
  if (c->capacity < need) {
    uint32_t newCap = need + (0x10u - (need & 0xFu));
    void *neu = malloc(newCap * 0xCu);
    void *old = c->data;
    c->data = neu;
    FUN_00433ca0(/* copy size elems old→neu; EAX=size, EDX=0, ESI=old, EDI=c */);
    c->data = old;
    free(old);
    c->data = neu;
    c->capacity = (int)newCap;
  }
}
```
