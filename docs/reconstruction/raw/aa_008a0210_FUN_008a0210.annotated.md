## Machine-level notes

- **ABI:** **EBX = CDlgQuickBar host***; stack **`char direction`** (`0` = prev / wrap-down, non-zero = next / wrap-up); **`ret 4`**. Frame uses EBP as column-array base (`lea ebp,[ebx+0x63c]`).
- **Return:** always **AL = 0** (`xor al,al`) on every exit. Callers treat this as fire-and-forget UI work, not a success flag.
- **Decompiler gap:** at `LAB_008a02ad`, raw shows two `FUN_00826780` calls with identical this. Live bytes set **different ECX**: first call ECX = **current** selected column (`[ebx+edi*4+0x63c]`), second ECX = **target** (`[ebx+esi*4+0x63c]`). Annotated/clean restore that.
- **Callee role:** `FUN_00826780` is sealed `UI_QuickBarSlotButton_SetSelected` (thiscall column + `fSelected` 0|1).
- **Fill gate:** column payload/kind at `+0x548` must be **non-null and ≠ 6** (empty sentinel shared with SetSelected).
- **Bootstrap path** (`iVar6 == 10`, no column has `+0x4fc`): linear scan first filled column; inline select (RTTI → peer clear `FUN_0089fef0` → highlight `+0x56c vtbl+4(1)` → stamp `DAT_00d1da38[page]=column` → set `+0x4fc=1`). Same select tail as `UI_QuickBarSlotButton_SetSelected(1)`.
