## Machine-level notes

- **ABI:** `__thiscall` — `ECX = StoStreamWindow*`, stack arg0 = **absolute stream position** to place at window base; epilogue **`ret 4`**.
- **Return:** last source **Read** (`vtbl+0x14`) result in **EAX** (callers test `< 0`); decompiler flattens to `void`.
- **Callees:** CRT `memmove` (IAT `0x009c652c`); virtual Seek (`*pSource.vtbl+4`); virtual Read (`*pSource.vtbl+0x14`).
- Prefer assembly/`read_memory` when decompiler conflicts (path-C `stack0xfffffffc` is min-select temp).

## Window layout

```
+0x00 pSource*
+0x04 cursor
+0x08 base
+0x0c available
+0x10 capacity
+0x14 streamEnd   // used as abs limit for available clamp
+0x18 buffer[]
```

## Algorithm (three arms)

**Input:** `absPos` (callers pass `base + cursor` to re-anchor at current logical pos).

### Arm A — seek forward inside current window (`base <= absPos < base+available`)

1. `keep = available - (absPos - base)`
2. `memmove(buf, buf + (absPos - base), keep)` — discard prefix, retain suffix
3. `base = absPos`; `cursor = 0`
4. `available = min(capacity, streamEnd - absPos)`
5. Seek(`absPos + keep`, 0) — source cursor after retained span
6. Read(`buf + keep`, `available - keep`) — fill tail; **return Read status**

### Arm B — seek backward within capacity (`absPos < base` and `base <= capacity + absPos`)

1. `slide = capacity - base + absPos`  (decompiler temp; used as memmove size bound)
2. `memmove(buf + (base - absPos), buf, min(available, slide-bound))` — shift retained data right
3. `base = absPos`; `cursor = 0`
4. `available = min(capacity, streamEnd - absPos)`
5. Seek(`absPos`, 0)
6. Read(`buf`, `oldBase - absPos`) — fill front gap; **return Read status**

### Arm C — full reposition (`LAB_00435ee4`)

1. `base = absPos`; `cursor = 0`
2. Seek(`absPos`, 0)
3. `available = min(capacity, streamEnd - absPos)`
4. Read(`buf`, `available`); **return Read status**

## Pseudocode (annotated; faithful CF)

```c
// Returns Read status in EAX (callers: hr < 0 → fail). Epilogue ret 4.
int __thiscall stoChunkStreamWindow_Ensure(StoStreamWindow *win, int absPos)
{
  int oldBase = win->base;          // [2]
  int target  = absPos;

  if (oldBase <= target) {
    if (target < win->available + oldBase) {
      // Arm A: forward slide inside window
      int keep = win->available - (target - oldBase);
      memmove(win->buf, win->buf + (target - oldBase), keep);
      win->base = target;
      {
        int rem = win->streamEnd - target;
        win->available = (rem <= win->capacity) ? rem : win->capacity;
      }
      win->cursor = 0;
      Source_Seek(win->pSource, keep + target, 0);           // vtbl+4
      return Source_Read(win->pSource, win->buf + keep,
                         win->available - keep);             // vtbl+0x14
    }
    if (oldBase <= target) goto full_reposition;
  }

  if (oldBase <= win->capacity + target) {
    // Arm B: backward slide within capacity
    int bound = (win->capacity - oldBase) + target;
    int *psz = &win->available;
    if (bound < win->available) psz = &bound;
    memmove(win->buf + (oldBase - target), win->buf, *psz);
    win->base = target;
    {
      int rem = win->streamEnd - target;
      win->available = (rem <= win->capacity) ? rem : win->capacity;
    }
    win->cursor = 0;
    Source_Seek(win->pSource, target, 0);
    return Source_Read(win->pSource, win->buf, oldBase - target);
  }

full_reposition:
  win->base = target;
  win->cursor = 0;
  Source_Seek(win->pSource, target, 0);
  {
    int rem = win->streamEnd - win->base;
    win->available = (rem <= win->capacity) ? rem : win->capacity;
  }
  return Source_Read(win->pSource, win->buf, win->available);
}
```
