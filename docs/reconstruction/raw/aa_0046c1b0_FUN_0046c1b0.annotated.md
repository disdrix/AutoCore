## Role

**Find a node by u32 key** in a NestedHash0x10 bag and write an iterator (node pointer or end sentinel) through register out-parameter **EAX**.

Observed consumers:

- Sto factory insert paths `FUN_004449b0` / `FUN_00444a40` (maps from once-gets `00438c40` / `00438ca0`)
- Operator[] shell `FUN_0046bf40` (find → insert-on-miss sibling `0046bf90`)
- GfxMesh edge bag `FUN_0098fef0` (W35-F)
- Multiple other NestedHash0x10 tables (~13 live callers)

**Not** insert, erase, or rehash — find only. Sibling insert is `NestedHash0x10_Insert_Inferred` (`0x0046bf90`).

**Not** the string-hash twin `HashMap_FindIterator_Inferred` (`0x0044e8c0`) which calls `FUN_0043b870` and uses EDI/EBX/`ret 4`.

| Offset | Width | Role |
|---|---|---|

## Node layout (body-backed; size **0x10** via insert twin)

| Offset | Width | Role |
|---|---|---|
| `node+0x00` | ptr | **next** in ordered bucket chain |
| `node+0x04` | ptr | prev (not read here; used by insert) |
| `node+0x08` | u32 | **key dword** (compared to `*key`) |
| `node+0x0c` | u32 | value payload (not read by find) |

## Algorithm

```
mask = map->mask (+0x20)
idx = (*key) & mask          // identity hash — no string hash leaf
if (idx >= map->bucket_count (+0x24)):
  idx += -1 - (mask >> 1)

start = table[idx]
end   = table[idx + 1]        // adjacent slot
for node = start; node != end; node = node->next:
  if node->key (+8) < *key: continue
  if node->key > *key:  *out = map->end (+8); return
  // equal:
  *out = node; return
*out = map->end; return
```

Bucket chains are **key-ordered** (early exit on greater key).

## Annotated pseudocode

```c
void NestedHash0x10_FindIterator_Inferred(
    NestedHash0x10* map /*ESI*/,
    uint32_t* key /*ECX*/,
    void** out_it /*EAX*/)
{
  uint32_t mask = *(uint32_t *)((char *)map + 0x20);
  uint32_t keyv = *key;
  uint32_t idx = keyv & mask;
  if (*(uint32_t *)((char *)map + 0x24) <= idx)
    idx = idx + (uint32_t)(-1 - (mask >> 1));

  int *bucket = (int *)(*(int *)((char *)map + 0x14) + idx * 4);
  int *node = (int *)*bucket;
  int *end  = (int *)bucket[1];

  if (node != end) {
    do {
      if (keyv <= (uint32_t)node[2]) {     /* *key <= node.key */
        if ((uint32_t)node[2] <= keyv) {   /* equal */
          *out_it = node;
          return;
        }
        *out_it = *(void **)((char *)map + 8);
        return;
      }
      node = (int *)*node;                 /* next */
    } while (node != end);
  }
  *out_it = *(void **)((char *)map + 8);
  return;
}
```
