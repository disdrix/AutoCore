## Purpose

**Idempotent deferred-work enqueue** for a world object onto a CS-protected linked list owned by the reaction/world host.

1. If object flags `+0x17c` **bit 0** already set → return (already queued).
2. Else call `FUN_004e15a0` on host queue at `this+0xe5fc` with the object — if list already contains object → return.
3. Else `FUN_004024d0` appends a 0xC list node pointing at the object, then **OR** flags bit0 (`| 1`).

Sticky bit0 = **`ObjectFlag_DeferredQueued`** (mask `0x1` at `object+0x17c`). Prevents double-enqueue without scanning the list when the bit is hot.

## Annotated control flow

```c
// ECX = host*; stack = Object*
void Object_EnqueueDeferredOnce(Host* host, Object* obj)
{
  if ((*(uint8_t*)(obj + 0x17c) & 1) != 0)
    return;                              // already sticky-queued

  Queue* q = *(Queue**)(host + 0xe5fc);
  if (FUN_004e15a0(q, obj) != 0)
    return;                              // already on list (bit may lag)

  FUN_004024d0(q, obj);                  // append node
  *(uint32_t*)(obj + 0x17c) |= 1;        // ObjectFlag_DeferredQueued
}
```
