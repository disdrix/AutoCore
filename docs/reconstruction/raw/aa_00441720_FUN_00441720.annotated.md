## Purpose

MSVC-style **`_Tree::erase(first, last)`** for the **isnil@+0x1d** node family with **0x10-byte value shell** (color@+0x1c ⇒ value `[+0x0c,+0x1c)`):

1. **Full clear** when `[first,last) == [begin,end)` i.e. `first == head->left && last == head`: free entire tree via `FUN_00440c90(head->parent)`, reset head extremities, `size = 0`, write begin to `*outIt`.
2. **Partial range**: for each node, compute in-order successor (isnil@+0x1d), then single-erase via `FUN_00442000(tree, outTemp, node)`.

Both static call sites only exercise the full-clear path (gfxUIWindow tree-shell teardown).

## Pseudocode (annotated ≡ raw ≡ live)

```c
// EDI = MapShell_Shell10*
// stack: node** outIt, node* first, node* last
// RET 0xC; returns outIt in EAX
node **StdTree_EraseAll_Shell10_Inferred(node **outIt, node *first, node *last /* EDI=tree */)
{
  node *head = tree->head;           // [EDI+4]

  // Full clear: [begin, end)
  if (first == head->left && last == head) {
    FUN_00440c90(/*ECX=tree,*/ head->parent);  // free-subtree isnil@+0x1d
    head->parent = head;
    tree->size = 0;                  // [EDI+8]
    head->left = head;
    head->right = head;
    *outIt = head->left;
    return outIt;
  }

  while (first != last) {
    node *victim = first;
    if (first->isnil /* +0x1d */ == 0) {
      // classic in-order successor → first
      node *r = first->right;
      if (r->isnil == 0) {
        first = r;
        node *l = r->left;
        while (l->isnil == 0) {
          first = l;
          l = l->left;
        }
      } else {
        node *p = first->parent;
        node *cur = first;
        while (p->isnil == 0 && cur == p->right) {
          cur = p;
          p = p->parent;
        }
        first = p;
      }
    }
    FUN_00442000(tree, &tmp, victim);  // single erase + rebalance
  }
  *outIt = first;  // == last
  return outIt;
}
```
