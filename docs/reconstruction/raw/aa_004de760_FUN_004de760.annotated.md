## Machine-level notes

- Source: raw capture + W23-M `decompile_function` / `read_memory` re-verify.
- **Not** an RTTI type descriptor (false coverage alias). Executable worker that *uses* Deliver RTTI for dynamic cast.
- Locks `character+0x55c` pending-objectives CNDHash (`hash+0x1d` TraversalLock), walks bucket chain (`hash+0x14` start, node `+0x14` next, payload `node+0x8`).
- For each pending objective `*payload`: iterate evaluator vector `obj+0x158..+0x15c` (pointer count via `>>2`).
- Gate: vcall evaluator `+0x50` == **3** (Deliver requirement type) → `__RTDynamicCast` to `CVOGObjectiveRequirement_Deliver`.
- Match: `deliver+0x1c` (`[7]`) == `host+0xfc`.
- Object filter:
  - `optionalObject == 0`: enumerate host list at `*(char_mi+0xa8)+0xe4e8` vector `+0x2c/+0x30`, resolve via vcall `+0x1d8`.
  - else: single optional object.
- Object CBID/key match: MI field `+0x34` via object `+0xac` chain == `deliver+0x18` (`[6]`).
- Predicate: deliver vcall `+0xc`(character, hash_entry) → false ⇒ register mode **5**, true ⇒ mode **8**.
- Register: `FUN_004dbef0` / `CVOGReaction_RegisterObjectHashEntry_Inferred` with links `-1,-1` and objective id from `*(hash_entry)+0x10`.
- Always unlocks hash on fall-through end; early unlock when chain exhausted.

  h->traversalLock = 1;

  Node *cursor = 0;
  for (;;) {
    if (!h->traversalLock) log("HashError:TraverseToNext...");
    // first: cursor = h->head(+0x14); else cursor = cursor->next(+0x14)
    Entry *entry = cursor ? *(Entry**)(cursor + 8) : 0;
