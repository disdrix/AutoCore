## Control flow

```
head = *(map+4)
cand = head
node = head->parent            // root
if (!isnil(node)):
  key = *ebx
  while !isnil(node):
    if node->key < key: node = node->right
    else: cand = node; node = node->left
if cand != head && cand->key <= key:  // equality after lower_bound
  *eax = cand
else:
  *eax = head                  // end
```
