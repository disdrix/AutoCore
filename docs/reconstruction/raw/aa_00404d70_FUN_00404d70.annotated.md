## Machine-level notes

- Source: raw capture + live `decompile_function` / `read_memory`.
- **10-byte tail-call thunk** — not a CALL/return wrapper:
  1. `MOV ECX, [ECX+0xF10]` — replace this with hash*
  2. `JMP CNDHash_LookupByKey` — keep stack key; inherit Lookup's `RET 4` + EAX value
- Decompiler printed `void` + `call; return` — **behaviorally wrong on return** (tail JMP preserves Lookup EAX).
- Host at call sites: always **`DAT_00b041fc`** loaded into ECX before CALL (GiveItemByCbid `0x0051a176`, CreateCreature `0x00564f88`, …).
- Callee sealed: `CNDHash_LookupByKey` `aa_005b0920` (mask-AND bucket + chain; return node value or NULL).
- Role: **CBID → clonebase definition\*** used by item factory, creature spawn, mission collect UI, vehicle/item equip paths, etc.
