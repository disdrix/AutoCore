## Machine-level notes

- SEH-framed stdcall: `push -1` / `push LAB_009bc010` / install `fs:[0]`.
- Ghidra splits the status epilogue as `FUN_004228d1` (fall-through via `jmp` after store).
- Decompiler reports `void`; retail returns **HRESULT** in EAX (`S_OK` / `E_OUTOFMEMORY`).
- Sole live caller `OleDb_BuildBindingsAllocRow_Inferred` @ `0x00421604`: `push 1; push ebx`.
