## Purpose

Stamp **one** mission-dialog **response-button slot**:

1. Bounds-check `slotIndex` against `dialog+0x510` (active response count).
2. If widget at `dialog+0x708 + slot*4` is non-null:
   - `widget->vtbl+0x1d8(caption, 1, 1)` — set caption text.
   - `widget->vtbl+0x34c()` — refresh/invalidate.
3. Write TFID pair `(tfidLo, tfidHi)` into `dialog+0x518 + slot*8` / `+0x51c`.

Inverse of dualed wipe `MissionDialog_ClearResponseButtonSlots_Inferred` (`0x008aa560`), which clears **all 8** TFID pairs to (−1,−1) and destroys widgets.

Does **not** create widgets (caller `FUN_008ac110` rebuilds from XML). Does **not** send packets. Does **not** handle clicks.
