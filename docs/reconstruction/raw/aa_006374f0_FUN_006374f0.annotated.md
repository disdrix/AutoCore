## Purpose

Unpack inbound TNL special-message payload for opcode **`0x206C` (GroupReactionCall)** into a heap **ByteBuffer** object. Wire is bit-packed; rebuilt data is a stack image (`opcode tag 0x206c` + count + per-entry records stride **`0x28`**) memcpy'd into `malloc`'d buffer owned by the ByteBuffer.

Sole caller: `Client_UnpackSpecialMessage` when `param_2 == 0x206c`.

## Wire codec (sealed)

```
FUN_0042b3a0(in+0xc, in+0x10)          // bind BitStream
count = readBits(8)                    // u8
for i in 0..count-1:                   // entry stride 0x28
  type = readBits(8)
  if type == 1:
    u16  = readBits(16)
    f32  = readBits(32) as float       // movss store (bytes)
  else:
    id19 = readInt(0x13)               // 19-bit
    pad  = 0
    tfid = readBits(0x40)              // u64
    flag0 = readFlag()                 // inlined bit test
    flag1 = readFlag()                 // inlined bit test
```

### Type branch notes

| Type | Fields | Conf |
|---|---|---|
| `1` | u16 + float32 (`movss` @ store) | **High** (bytes) |
| other | 19-bit int + zero dword + u64 + 2 flags | **High** |

Flags match sibling pattern: inlined BitStream bit tests (not a `BitStream_readFlag` call).

### Rebuild size

`size = count * 0x28 + 1` — sealed from `lea ebp,[eax+eax*4]; lea ebp,[ebp*8+1]`.

Stack source of memcpy starts at `local_27ec` which is pre-stored with **`0x206c`**. Consumer layout semantics beyond "ByteBuffer holds this blob" remain partially open (see gaps).

## Control flow (annotated)

```
SEH setup; tag = 0x206c
bind BitStream from in
count = readBits(8)
for each entry: decode type-1 or reaction-style into stack image (stride 0x28)
bb = new(0x18); LinkedListHead_Ctor; vtbl=009d7b00; malloc(size); owns=1
memcpy(&tag, bb->data, size)
*out = bb; bb->ref++
teardown BitStream; in->ref--; if 0: in->Release()
return out
```
