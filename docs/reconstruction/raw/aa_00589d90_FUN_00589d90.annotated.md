## Machine-level notes

- **ABI (sealed):** cdecl; three stack args; bare `RET`; EAX = applied delta (or 0).
  - `param_1` = fallback host object* (often return of packaging helper `FUN_00578270`)
  - `param_2` = preferred target object* (skill HB host object, e.g. `this+0x18`)
  - `param_3` = float amount (signed absolute **or** fraction of max when in `[-1,1]`)
- **Resolve path:** prefer `param_2` → `vtbl+0x19c` → MI component `*( *(obj+4)+4 ) + obj + 4`; on fail use `param_2+0xAC` as new host, else `param_1` same chain. Then `vtbl+0x1d4` → combat pool with shield ints.
- **Apply:** `delta = in[-1,1] ? (int)(max * amount) : (int)amount`; `new = clamp(cur+delta, 0, max)`; store `+0x144`; return `new-cur` if changed else 0.
- **Sibling family (not OWN):** heat `0x00589bc0` (RTTI+AddHeat); HP `0x00589c70` (vtbl 0x23c/0x244 + damage helper); short/floater `0x0058cc40`; multi-arg `0x0058d8e0`. Parent tick `0x0061b6f0` / peer `0x00618270`.
