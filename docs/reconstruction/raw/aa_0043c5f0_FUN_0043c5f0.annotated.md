## Machine-level notes

- **ABI:** `__thiscall`-style. **ECX** = source guarded container*; stack `dest*`; epilogue **`RET 4`**. Void return.
- **SEH:** standard MSVC frame (`push -1` / handler `LAB_009be0c8` / `fs:[0]`). `local_4` state `-1` → `0` around the assign body so unwind can leave CS if locked.
- **Optional lock:**
  - Gate: `source+0x2c` as `char` nonzero → use critical section.
  - CS object: `source+0x14` (`LPCRITICAL_SECTION`).
  - Enter before work; Leave after (same gate). Leave compares via `esi+0x18` ≡ `source+0x2c` (esi = &CS).
