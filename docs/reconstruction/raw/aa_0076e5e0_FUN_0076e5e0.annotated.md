## Machine-level notes

- **cdecl** `float *out, float *in` (4-float quat); returns `out` in **EAX**.
- `lenSq` from **`in`**: `x²+y²+z²+w²` (SSE `mulss`/`addss` path).
- **Near-zero band** (`read_memory`): if `−1e-6 < lenSq < +1e-6` (`DAT_00aaa640` / `_DAT_00a240ec` bits `0xB58637BD` / `0x358637BD`) → return `out` unchanged (no normalize, no copy).
- **Near-unit skip:** `Math_FloatNearlyEqual_AbsRel(lenSq, 1.0f, 1e-6, 1e-6)` (`FUN_0040d450`). Imm pushes `0x358637BD`, `0x3F800000`.
  - If **equal** and `out != in`: copy 4 floats `in → out`.
  - If **equal** and same pointer: no-op.
  - If **not equal**: `scale = g_flOne / sqrt(lenSq)` then scale **`out[0..3]`** (FPU `fsqrt` + `fdivr [g_flOne@0x00a0f2a0]`). Call sites typically pass identical pointers.
- Leaf-ish worker: sole function callee is `FUN_0040d450`.

## Pseudocode (annotated)

```c
// cdecl; EAX = out
float * Math_QuatNormalize(float *out, float *in)
{
  float lenSq = in[0]*in[0] + in[1]*in[1] + in[2]*in[2] + in[3]*in[3];

  // near-zero: avoid div-by-near-zero; leave out alone
  if (lenSq < 1e-6f && -1e-6f < lenSq)
    return out;

  if (!Math_FloatNearlyEqual_AbsRel(lenSq, 1.0f, 1e-6f, 1e-6f)) {
    float scale = 1.0f / sqrtf(lenSq);  // g_flOne / SQRT
    out[0] *= scale;
    out[1] *= scale;
    out[2] *= scale;
    out[3] *= scale;
  } else if (out != in) {
    out[0] = in[0]; out[1] = in[1]; out[2] = in[2]; out[3] = in[3];
  }
  return out;
}
```
