## Purpose

Convert a **32-bit FourCC / type tag dword** into a **null-terminated 4-character C string in big-endian byte order**, then construct a **`std::string`** into the caller-supplied out object.

Used for:

1. **phyBoundingVolumeFactory** invalid-tag log: `"Invalid tag [ %s ] for phyBoundingVolume"` (caller `FUN_00467690`).
2. **stoChunkWriter_BeginChunk** — emit / format chunk FourCC as text.
3. Thin wrapper `FUN_00436250`.

Tag `0` → buffer `{0,0,0,0,0}` → **empty** `std::string` (first byte is NUL).

Example: tag `0x42565350` → bytes `'B','V','S','P',0` → `"BVSP"` (matches phy BV factory magic compares in `FUN_00467690`).

{

  std::string tmp;      // local_28 (MSVC SSO footprint ~28 bytes in decomp)
  // SEH scope object (local_c / puStack_8 / local_4)

}
