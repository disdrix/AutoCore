## Machine-level notes

- **ABI:** MSVC `__thiscall`. `ECX` = skill HB this; stack `uint32_t *pOutStatus`; returns `EAX = pOutStatus`; **`RET 4`**.
- Decompiler shows `__fastcall` with phantom `param_2` (EDX) — **reject**. Assembly: only stack out-param; EDX is residual after creature virtual.
- Ghidra types `this` as `CVOGHBBase*` with array overlay (`param_1[1]`, `param_1[0x28]`) — **layout mis-type**. Use absolute offsets from assembly.
- Prefer assembly over decompiler for TFID push order and fail-path status write.
