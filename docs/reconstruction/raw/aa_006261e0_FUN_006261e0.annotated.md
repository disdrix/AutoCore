## Machine-level notes

- **ABI:** **`__thiscall`** ECX = activate-player HB; stack `(flag_onEnd, flag_hard)`; epilogue **`ret 8`** (`C2 08 00`); void.
- **Install:** DATA vtbl `0x009e3168` slot **`+0x18`** (`0x009e3180`) — same slot as shared base `CVOGHBBase_EndOrDestroy` (`0x005083f0`) on many other HB types; this subclass **overrides**.
- **CF (relative to base EndOrDestroy):**
  1. if `(char)flag_onEnd == 0`: call own **OnEnd** via `(*this)->vtbl+0x14` (= `FUN_00626210` on this class).
  2. always `CVOGHBBase_EndOrDestroy(this, flag_onEnd, flag_hard)`.
- **Why pre-call when flag_onEnd==0:** base EndOrDestroy **skips** OnEnd when flag0==0 (clears owner link only). Subclass still needs host notify (`host+0x6c8` / host vfunc) on soft/abort paths → force OnEnd once, then base with flag0=0 (no second OnEnd).
- **When flag_onEnd≠0:** skip pre-call; base will invoke `vtbl+0x14` OnEnd once.
- **Does not:** implement hard/soft teardown itself (base SEH tail owns that).
