## Role

Merge **src** host's sorted **stride-16 pair list** at `host+0x68` into **dest**'s same list: snapshot dest, dual-key ordered merge, on equal keys invoke absorb/destroy virtuals, rewrite dest array, release temp worklist.

Sole static caller: `PhysSim_MergeHosts_Inferred` (`0x00560a30`) when two body hosts collapse.

## ABI

| Formal | Source | Conf |
|---|---|---|
| dest list | **EAX** (`MOV ESI,EAX` prologue) | **High** |
| src list | **Stack[0x4]** | **High** |
| cleanup | plain `ret`; caller `ADD ESP,4` | **High** |

## Pair list @ host+0x68

Vector-like: `data*`, `count`, `capacity|flags`. Element = 16 bytes: two keyed pointers + payload object + dword.

## Equal-key side effect

On dual-key match: call `record[+8]->vtbl+0x14` then `*(*(record[+8])+8)->vtbl+0x10` — absorb constraint/contact into survivor; equal entries not both emitted (count reduced by equals).
