## Purpose

**Try to concatenate / merge a peer item into `this`** when both share the same CBID.

Mutating success path:
1. Optionally combine ushort field at `item+0x180` under def limit `+0x4BC` (full absorb if sum fits; else remainder-wrap).
2. On the non-early path, **add peer quantity into this** via vtbl get `+0x25C` / set `+0x260`.
3. Mark dirty via `FUN_00512670` (flag `0x20000` @ `+0x17C`).

Returns **1** on successful same-CBID merge, **0** if peer is null or CBID differs.

**Not** a capacity-only predicate (`Item_CanAcceptStackQty` `0x0040abf0`).  
**Not** eligibility-only (`Item_IsStackEligible` `0x00513e70`).

## Machine-level notes

- Prefer assembly when decompiler conflicts (none observed 2026-08-05).
- Decompiler `param_1[0x2a]` ≡ item `+0xA8`; `param_1+0x60` as `int*` ≡ `+0x180`.
- `IDIV` path uses `CDQ; IDIV EDI` → remainder in **EDX**; if EDX==0 substitute full limit (not zero).
- Early fit path **skips** vfunc qty merge — sealed oddity; preserve bit-exact.
- Limit field is def **`+0x4BC`**, not capacity max **`+0x4BA`** used by `Item_CanAcceptStackQty`.

## Pseudocode (annotated)

```c
// thiscall: ECX = dest item*, stack = peer item*
// returns 1 on concat success, 0 on null peer / CBID mismatch
uint32_t __thiscall Item_TryConcatStackWithPeer(int *this_item, int *peer)
{
  ushort limit;
  int vtbl;
  uint sum;
  int peerQty;
  int thisQty;
  ushort rem;

  // Gate: peer non-null and same CBID at clonebase+0x34
  if ((peer != 0) &&
      (*(int *)(peer[0x2a] + 0x34) == *(int *)(this_item[0x2a] + 0x34)))
  {
    // def blob via clonebase+0x3C; u16 limit @ +0x4BC
    limit = *(ushort *)(*(int *)(this_item[0x2a] + 0x3c) + 0x4bc);

    if ((limit != 0) && (limit != 0xffff)) {
      // sum ushort field at item+0x180 (NOT vfunc qty)
      sum = (uint)*(ushort *)(peer + 0x60) + (uint)*(ushort *)(this_item + 0x60);
      if (sum <= limit) {
        *(short *)(this_item + 0x60) = (short)sum;
        FUN_00512670();           // this dirty | 0x20000 (+ linked +0xAC chain)
        return 1;                 // EARLY: no vfunc qty merge
      }
      // overflow: store sum % limit, or limit if exact multiple
      rem = (ushort)(sum % (uint)limit);
      if ((int)(sum % (uint)limit) == 0) {
        rem = limit;
      }
      *(ushort *)(this_item + 0x60) = rem;
    }

    // Merge authoritative quantity: this.qty = peer.qty + this.qty
    vtbl = *this_item;
    peerQty = (**(code **)(*peer + 0x25c))();       // peer GetQty
    thisQty = (**(code **)(*this_item + 0x25c))();  // this GetQty
    (**(code **)(vtbl + 0x260))(peerQty + thisQty); // this SetQty(sum)
    FUN_00512670();
    return 1;
  }
  return 0;
}
```
