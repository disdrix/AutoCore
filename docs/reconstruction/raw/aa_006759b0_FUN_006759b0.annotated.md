## Machine-level notes

- **`operator_new(0xC)`** then fill three dwords if non-null.
- Node layout (MSVC list node for pointer/dword `T`):
  - `+0x00` = link0 (callers pass head / prev)
  - `+0x04` = link1 (callers pass head→next)
  - `+0x08` = value = `*param_3` (one dword)
- **ABI:** `__stdcall`, `ret 0xc` (3 stack args). **Return:** node* in **EAX** (Ghidra typed `void`; all list insert callers assign the result).
- Null `operator_new` → fall through without stores; EAX remains 0.
- No freelist; always heap allocate.
- Extremely hot leaf — 40+ CALL xrefs (auth lists, sound queue, map UI, etc.).
