## Phase breakdown (CF)

### A. Orbit aim + optional yaw nudge

1. `c = cos(cam+0xcc8)`, `s = sin(cam+0xcc8)`.
2. Aim:
   - `ax = focus.x + c * range_a * cam+0x5ac`
   - `az = focus.z + c * range_a * cam+0x5b4`
   - `ay = focus.y + s * range_b`
3. Gate flags (`map+0xf5`, `DAT_00d1b212`, `cam+0xa86`, `cam+0x493`, `cam+0xa83`): if disabled, skip yaw nudge block.
4. Else: sample orientation via vtable `+0x1a4` on `DAT_00d1b6d8` chain; extract basis (`FUN_004e8a40`, `FUN_004e8ad0`, `FUN_004e88e0`); normalize; dot with camera look xz; scale by `DAT_00afe264` and `1.5`/`3.5`; accumulate ± into `cam+0x538`.

### B. Look basis construction

1. `delta = focus - aim` (and secondary vectors).
2. Repeated `FUN_0076f5f0` normalize.
3. Cross products with world-up globals `DAT_00afdfc8/cc/d0` to form right/up/forward triad; re-normalize.

### C. Collision pull-in (8 probes × multi-pass)

1. Seed eye candidate from `cam+0x530` scaled by cos/sin yaw + basis.
2. Outer `while(true)`:
   - Inner `i = 0..7`: `FUN_00915ad0(cam, …, i)` then `FUN_00916090(start→end)` → distance.
   - If distance `> 0.2`, project hit normal-ish vs look basis; keep best pull amount in `local_c4/local_c8`.
   - If no hit improved, break; else step eye along look by `(dist - 0.05)` and repeat (with floor).
3. Publish pull distance into `cam+0x52c` / `cam+0xcdc` (or clear path flags when no pull).

### D. Commit camera eye

1. Vector from current eye (`DAT_00d17944+0x228..`) to aim; normalize if length outside tiny band.
2. If `DAT_00d1f0a0 == 0`: integrate eye along unit dir by prior length; else snap eye to aim.

### E. Optional ground / gamepad / look writeback

1. Special ground token path may bias `focus.y` via `fStack_dc` blend.
2. If gamepad gate (`DAT_00d1b20f` + `DAT_00d1b618`): sample axes via `DAT_00d1b620`, rotate by map orientation block `+0xe890`, write look XYZ to `*(DAT_00d1b6d8+0x250)+0x170..0x17c`.
3. Else if `cam+0x493==0` and a UI/mode field is 0: write scaled basis `cam+0x5ac..` * `-1.0`.
4. Else copy globals `DAT_00d1a640..4c` into look slot.
