## Machine-level notes

- **Decompiler hazard:** plate marks `operator_delete` noreturn and drops post-delete **size--** + **`*outIt = successor`** + **`ret 8`**. Bytes seal fall-through (same as dualed `Map_EraseNode` / `Map_EraseNode_B`).
- **Two-child path:** Ghidra flags blocks around `0x0051cf20`–`0x0051cf77` as "unreachable"; image implements successor transplant + color@+0x14 swap.
- **isnil gate:** `cmp byte [EAX+0x15],0` immediately after SEH frame setup; non-zero throws `"invalid map/set<T> iterator"` @ `0x00a152f0`.
- **ABI:** `__thiscall` ECX=map (saved in EBP); stack `(outIt**, pNode*)` loaded as `[ESP+0x14]` before frame; **RET 8** (`C2 08 00`).
- Prefer assembly / `read_memory` when decompiler conflicts on epilogue and two-child path.
