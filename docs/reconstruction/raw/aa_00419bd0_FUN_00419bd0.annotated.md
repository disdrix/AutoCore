## Machine-level notes

- **Custom ABI:** freelist head pointer in **EDI** (`Node **pHead`). Decompiler `unaff_EDI`.
- **Return:** decompiler prints `void`; machine leaves **EAX = popped node*** (insert callers assign: `puVar2 = FUN_00419bd0()`).
- **Grow path:** if `*pHead == NULL` **or** `*(*pHead) == 0` (empty / exhausted chain landing on null terminator):
  1. `slab = _aligned_malloc(1000, 0x10)`
  2. `CVOGReaction_FailMissionNotify` @ `0x004149d0` with **ECX = EDI+4**, stack `&slab` — dual seals as **Vector_PushDword** (slab tracking vector; **not** mission fail)
  3. `*pHead = slab`
  4. Chain **0x18** links at stride **+0x28**: `*node = node + 0x28`
  5. `[slab + 0x3c0] = 0` — null terminator after 24 usable nodes
- **Pop path (always, including after grow):** `EAX = *pHead; *pHead = *EAX` (advance freelist).
- Twin of mission-family `CNDHash_FreelistPop_Node0x1c` (`0x0053ada0`) and audio `AlignedFreelist_PopSlot_0x160` (`0x00480460`) — same lazy-slab pattern, different stride/size.
- Callers: `CNDHash_Insert_u64` `0x00413920`, `FUN_00419620` — both pass **EDI = hash+0x20**.
