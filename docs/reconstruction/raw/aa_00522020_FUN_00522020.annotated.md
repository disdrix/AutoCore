## Machine-level notes

- Source: raw capture + MEGA-045 live re-verify (`decompile` / `disassemble_function` / `read_memory` / callers/xrefs).
- **Leaf selector:** returns one of three Character-owned `InventoryGrid*` slots by integer **mode**, else **0**.
- **ABI sealed:** `__thiscall` ECX=Character*; stack `int mode`; EAX=grid*; **`RET 4`**.
- Mode cascade is **subtract-chain** (not cmp-table): `mode-1` / `-2` / `-2` → cases 1 / 3 / 5.
- Mode **1** alone null-checks mid `*(this+0x250)` before load of cargo grid at mid`+0x2B0`.
- Modes **3** / **5** return `*(this+0xCBC)` / `*(this+0xCE0)` directly (null pointer is a valid return).
- Sole caller `FUN_00941b20` @ `0x00941bc7` uses result as destination grid for equip/customize space check.
- Cross-dual invType map (DropResponse / GrabApply): **1**=cargo, **3**=locker, **5**=trade — English labels **Inferred** here.

// returns InventoryGrid* (or 0)
InventoryGrid* Character_SelectInventoryGridByMode_Inferred(Character* ch, int mode)
{
  if (mode == 1) {
    // cargo host mid*
    void* mid = *(void**)((char*)ch + 0x250);
    if (mid != nullptr) {
      return *(InventoryGrid**)((char*)mid + 0x2B0); // invType 1 cargo grid

    // fall through → 0

      return *(InventoryGrid**)((char*)ch + 0xCBC); // invType 3 locker grid

    if (mode == 5) {
      return *(InventoryGrid**)((char*)ch + 0xCE0); // invType 5 trade grid
    }
  }
  return nullptr; // modes 0/2/4/… and mode1 with null mid
}
