## Machine-level notes

- Sibling of sealed `CVOGRegionMissions_ctor` @ `0x0060b870` (same `VOGRegionMissions.cpp` product path).
- `this` = `CVOGRegionMissions*` (0x10 wrapper): `*this` = primary mission-id hash; `this+4` = objective-id hash.
- Early exit: null hash or lookup miss → AL=0, `ret 4`.
- DB cold-load helpers shared with ctor; decompiler marks row array as `unaff_EBX` and loses count into `iStack_c` — **treat as catalog row vector**.
- Mission def objective table: count byte `+0x130`, ptr table `+0x13c`.
- Catalog row: count at dword `+0x4c` (= byte `+0x130`), ptrs at `+0x4d` / free path uses `+0x134`.
- Mismatch → remove objective hash nodes (key `obj+0x10`) then re-insert via `CNDHash_Insert` / `FUN_0053c460` with soft=0.
- Node freelist install writes vtbl `0x009cf02c` (method0 `0x00537d10` per `read_memory`).
- `"VOG_DEBUG_STOP"` is generic; **do not** name this function after it.
