## Purpose

Client **mission-tracker HUD refresh**. With UI host in **ECX**, recompute objective title / instruction text / icon material / optional range string and push them into host widgets. Pure chrome — **no sector packet builders**.

Prior string-only alias `Mission_Look_in_your_Mission_Inventory` is **one branch** of the instruction-text chooser, not the whole unit.

## Control flow (sealed stages)

```
1. Gates:
   - no DAT_00d1b6d8 → return
   - byte[client+0x4f1] != 0 → return
   - missing host widgets [0x1a2]/[0x1a5]/[0x1a4] → return
   - install SEH frame; local_298 = FUN_007a69d0()

2. Title arm (DAT_00d1ad10+9 == 0):
   a. key = tracker+0x10
      key==0 → FUN_008a8660() or set title "No Objective", clear instruction, hide icon, set dirty+4
   b. mission = CNDHash_LookupByKey(client+0x548, key)
      null → FUN_008a8660(); return
   c. "No Objective" + hide chrome if mission prerequisites fail (hash 0x55c lookups + vector size)
   d. optional FUN_00547920(0) if mission+0x14c child flag @+0x168 clear
   e. if tracker+7 == 0: title = mission+4 string
      else: scan mission objective list (+0x158) for type 3/6; else contact string via FUN_008a8040
   else (tracker+9 != 0): title = "Next mission"

3. Common post-title:
   title.layout; host.vtbl+0x450(0)
   cVar5 cleared if tracker+8 or (DAT_00d1b217 && FUN_00411220())

4. Instruction arm if FUN_0092c810() < 1:
   - rebuild cStack_124 instruction buffer
   - optional mission inventory / journal / "Go to <name>" via objective walk + CVOGCharacter_IsMissionTurnInReady (FUN_0052b420)
   - strings: "Look in your Mission Inventory", "Read mission journal for details", "Go to %s"
   - set instruction widget text; hide icon; return

5. Range / minimap arm if FUN_0092c810() >= 1:
   - physics cast gate via __RTDynamicCast to CVOGPhysicsBase
   - Client_EvalAutoPatrolWaypoint → TFID; invalid → clear instruction / optional dirty
   - distance via FUN_00404c00 after vec subtract + UI Y bias
   - if cVar5==0: minimap hint strings (Gold Targets / Large Blue Dots)
   - else metric (m/km) or imperial (ft/yds/mi) with caps ">1.20km" / ">0.75 mi"
   - material tint MatDiffuse/Ambient/Emissive; set instruction text to distance string; 3D icon placement helpers

6. SEH teardown FUN_00403430; restore ExceptionList; return
```
