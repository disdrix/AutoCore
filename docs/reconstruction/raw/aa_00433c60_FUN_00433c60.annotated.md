## Register / ABI contract

```
// Custom register; no stack formals; plain RET
// EBX = Cont8* container   (+0 count, +4 capacity, +8 buf*)
// ESI = const void* src    (old buffer)
// EDI = uint32_t endIdx    (exclusive)
// EDX = uint32_t startIdx  (inclusive; typically 0)
void BitStream_HuffmanTree_CopyRange(void);
```

| Formal (logical) | Source | Conf |
|---|---|---|
| container | EBX | **High** (parent `mov ebx,eax`; body `[ebx+8]`) |
| src | ESI | **High** (parent saves old buf in ESI) |
| endIdx | EDI | **High** (parent `mov edi,[ebx]` count) |
| startIdx | EDX | **High** (parent `xor edx,edx`; loop `add edx,1`) |
| return | void | **High** |

## Pseudocode (annotated)

```c
// for (i = start; i < end; ++i) {
//   dest = container->buf + i*8;
//   if (dest != NULL) {
//     *(uint32_t*)dest       = *(uint32_t*)(src + i*8);
//     *(uint32_t*)(dest+4)   = *(uint32_t*)(src + i*8 + 4);
//   }
// }
void BitStream_HuffmanTree_CopyRange(/*EBX*/ Cont8* container,
                                     /*ESI*/ const uint8_t* src,
                                     /*EDI*/ uint32_t endIdx,
                                     /*EDX*/ uint32_t startIdx)
{
  for (; startIdx < endIdx; startIdx++) {
    uint32_t off = startIdx * 8;
    uint32_t* dest = (uint32_t*)(*(uint8_t**)((uint8_t*)container + 8) + off);
    if (dest != 0) {
      dest[0] = *(uint32_t*)(src + off);
      dest[1] = *(uint32_t*)(src + off + 4);
    }
  }
}
```
