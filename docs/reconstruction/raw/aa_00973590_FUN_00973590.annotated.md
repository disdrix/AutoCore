## Machine-level notes (W29-I)

- **Bytes authority** over decompiler for clamp-pointer selection on mid channels.
- **EAX** = destination `uint8_t[4]` (not in Ghidra signature).
- **`ret 0x10`**: stdcall-style clean of 4×float stack args.
- **Leaf**: FPU `fld`/`fistp` ROUND only; no callees.
- Channel order is **BGRA memory** when stack args are **RGBA** (f0=R→[2], f1=G→[1], f2=B→[0], f3=A→[3]).
- Consumers (W28-E/F): `Color_PackFloat4_Scale255_Inferred` (`00973820`), `Color_LerpPackedARGB_Inferred` (`00973690`).

## Algorithm (sealed)

```
// EAX = dest
// stack: float f0,f1,f2,f3   (often R,G,B,A already scaled 0..255)
// ret 0x10; void

auto clamp_u8 = [](float f) -> uint8_t {
  int v = ROUND(f);           // fistp
  if (v < 0) return 0;
  if (v > 0xFF) return 0xFF;
  return (uint8_t)v;
};

dest[2] = clamp_u8(f0);
dest[1] = clamp_u8(f1);
dest[0] = clamp_u8(f2);
dest[3] = clamp_u8(f3);
```
