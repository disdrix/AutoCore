## Machine-level notes

- **ABI:** `__fastcall` — **ECX** = `count`, **EDX** = `list*`; plain **`RET`**.
- **`_Mysize`** at `list+8` (load then `size + count` store).
- **Max:** immediate **`0x1fffffff`** (not `0x3fffffff` twin @ `0x0043fe60`).
- Gate: if `(max - size) < count` → construct `"list<T> too long"` → `FUN_00401a40` → `_CxxThrowException(..., DAT_00acc388)` noreturn.
- Else `_Mysize += count`.

- SEH frame present (`LAB_009bc919`); not required for port semantics.
