### Successor (inline, Val12)

Same shape as peer `StdTree_EraseRange_Val12` @ `0x0040d700`:

1. If `node->isnil != 0`: stay (nil is end).
2. Else if `node->right` non-nil: leftmost of right subtree (`isnil@+0x19`).
3. Else walk parents while coming from right child; return parent.

## Machine-level notes

- **Peer clone:** body hex identical to `0x0040d700` except relative CALL targets (`005731c0` free, `00573250` erase).
- **Decompiler quirk:** `FUN_00573250` shown as 2-arg; assembly is thiscall `ECX=map` + two stack formals (matches dualed erase ABI `RET 8`).
- **Free-subtree quirk:** `FUN_005731c0` decompile drops left-walk after false noreturn on `operator_delete`; live disasm seals right-recurse + left-advance + delete loop, **RET 4**.
- Prefer assembly / `read_memory` when decompiler conflicts.
