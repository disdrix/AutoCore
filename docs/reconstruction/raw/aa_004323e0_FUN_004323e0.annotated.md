## Machine-level notes

- **ABI:** custom register + stdcall stack. Entry: **EBX** = `CxImage* this`, **EAX** = height; stack `(width, bpp, type)`; epilogue **`ret 12`**.
- **Precheck:** `FUN_004321b0()` — non-zero required; zero → return null without setting lastError in this unit (destroy/create gate).
- **bpp quantization → effective bit depth `bits`:**
  - `bpp < 2` → `bits = 1`
  - `bpp < 5` → `bits = 4`
  - else → `bits = 8 + ((bpp > 8) ? 0x10 : 0)` → **8 or 24**
- **MAX_MEMORY gate:** `(width * height * bits) >> 8 > 256000000` → copy `"CXIMAGE_MAX_MEMORY exceeded"` into `this+0x44`, return 0.
- **Palette count `this+0x28`:** 1→2, 4→0x10, 8→0x100, 24→0.
- **Stride `this+0x30`:** `((width * bits + 31) >> 5) * 4` (DWORD-aligned row bytes).
- **Image byte size `this+0x1c`:** `stride * height`.
- **BITMAPINFOHEADER-ish block @ `this+8`:** `biSize=0x28`, biWidth=width, biHeight=height, biPlanes=1, biBitCount=bits, biCompression=0, biSizeImage=imageBytes, clrUsed=0; type stored @ `this+0x40`.
- **Alloc:** `malloc(imageBytes + 0x28 + paletteCount*4)` → `this+4`.
- **Zero palette:** `FUN_00433490()` then dword-fill palette entries.
- **Optional:** if `this+0x1b0` non-zero → `FUN_004331d0()` (not owned).
- **Install header:** copy 10 dwords from `this+8` into allocated block; `this+0x34 = block + *block + paletteCount*4` (bits pointer).
- **Returns:** allocated block pointer (or null). Caller often checks `image+4` / bits separately.

## Pseudocode (annotated)

```c
// EBX = this, EAX = height, stack: width, bpp, type; ret 12
int* CxImage_Create(/*EBX*/ CxImage* self,
                    /*EAX*/ int height,
                    /*stack*/ int width,
                    /*stack*/ uint bpp,
                    /*stack*/ uint32_t type)
{
  if (!FUN_004321b0()) return NULL;

  if (width == 0 || height == 0) {
    // memcpy lastError: "CxImage::Create : width and height must be greater than zero"
    return NULL;
  }

  int bits;
  if (bpp < 2) bits = 1;
  else if (bpp < 5) bits = 4;
  else bits = 8 + ((bpp > 8) ? 0x10 : 0); // 8 or 24

  if (((uint)(width * height * bits) >> 8) > 256000000) {
    // lastError = "CXIMAGE_MAX_MEMORY exceeded"
    return NULL;
  }

  // palette count from bits
  self->paletteCount /*+0x28*/ =
      (bits == 1) ? 2 :
      (bits == 4) ? 0x10 :
      (bits == 8) ? 0x100 : 0;

  int stride = ((width * bits + 31) >> 5) * 4;
  self->stride /*+0x30*/ = stride;
  int imageBytes = stride * height;
  self->bitCount /*+0x16*/ = (short)bits;
  self->width /*+0x0c*/ = width;
  self->type /*+0x40*/ = type;
  self->biSize /*+0x08*/ = 0x28;
  self->height /*+0x10*/ = height;
  self->planes /*+0x14*/ = 1;
  self->compression /*+0x18*/ = 0;
  self->imageBytes /*+0x1c*/ = imageBytes;
  self->field_2c /*+0x2c*/ = 0;

  void* block = malloc(imageBytes + 0x28 + self->paletteCount * 4);
  self->block /*+0x04*/ = block;
  if (!block) {
    // lastError = "CxImage::Create can't allocate memory"
    return NULL;
  }

  uint32_t* pal = (uint32_t*)FUN_00433490(); // palette base in block
  if (pal) {
    // zero paletteCount dwords (and 0 trailing bytes)
    for (uint n = self->paletteCount & 0x3fffffff; n; --n) *pal++ = 0;
  }

  if (self->extra /*+0x1b0*/) FUN_004331d0();

  // copy 10 dwords header this+8 → block
  uint32_t* src = (uint32_t*)(self + 0x08);
  uint32_t* dst = (uint32_t*)self->block;
  for (int i = 10; i; --i) *dst++ = *src++;

  int* hdr = (int*)self->block;
  if (hdr)
    self->bits /*+0x34*/ = (int)hdr + *hdr + self->paletteCount * 4;
  else
    self->bits = 0;
  return hdr;
}
```
