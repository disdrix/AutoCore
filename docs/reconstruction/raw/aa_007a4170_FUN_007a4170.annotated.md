## Machine-level notes

- **Role:** Leaf **unit float sample** from the global RNG ushort table (same host as `Rng_CopyUnitTableWindow_Inferred` / `Rng_CloneSeededTable_Inferred`).
- **ABI:** `__thiscall`; ECX = `RngHost*`; stack `uint index`; **`ret 4`**; return **float in ST0** (`float10` decomp).
- **Sequential mode** (`(int)index < 0`):
  - If `cursor > 0xFFFFF`, reset cursor to 0.
  - Read `table[cursor]` as `ushort`, `cursor++`, return `u16 * DAT_00aaa638`.
- **Indexed mode** (`index >= 0`):
  - `index &= 0x800FFFFF`; if still signed-negative apply MSVC power-of-two wrap `(index-1|0xFFF00000)+1`.
  - Read `table[index]` **without** advancing cursor; same scale.
- **Scale:** `DAT_00aaa638` = `0x37800080` ≈ **1/65535** (not exactly 1/65536=`0x37800000`). Maps ushort domain → ~[0, 1].
- **Not:** window bulk-copy (`0x0051b720`), heap clone (`0x0058ab60`), or the getter `CVOGReaction_RandomUnitScalar` (`0x007a4330` → `&DAT_00d20c1c`).

## Pseudocode (annotated)

```c
// __thiscall  RET 4  // ST0 = unit float
float Rng_SampleUnitFloat_Inferred(RngHost* self, uint32_t index)
{
  // DAT_00aaa638 ≈ 1/65535
  const float kUnitScale = DAT_00aaa638;

  if ((int32_t)index < 0) {
    // Sequential: wrap cursor, advance by 1
    if (self->cursor > 0xFFFFF)
      self->cursor = 0;
    uint16_t w = *(uint16_t*)(self->tableBase + self->cursor * 2);
    self->cursor = self->cursor + 1;
    return (float)w * kUnitScale;
  }

  // Indexed: mask + signed power-of-two reduce; no cursor write
  index &= 0x800FFFFFu;
  if ((int32_t)index < 0)
    index = (index - 1u | 0xFFF00000u) + 1u;
  uint16_t w = *(uint16_t*)(self->tableBase + index * 2);
  return (float)w * kUnitScale;
}
```
