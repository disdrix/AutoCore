## Machine-level notes

- **Role:** text-mode peer of binary `stoChunkReader_ReadU32` (`0x00437050`). Reads one **uint32** token from a text stoChunk stream into caller `out*`.
- **ABI:** **EDI** = `stoChunkReader*`; stack = `uint32_t* out`; epilogue **`ret 4`**. Dispatcher `FUN_00436900` does `mov edi,eax` then call when `reader+0x4044 != 0`.
- **Sticky status:** `reader+0x402c` — early exit if already negative; set to `−1` on EOF-without-token and on past-end-of-chunk (`}`).
- **Pushback path:** if `reader+0x4060 != 0`, consume cached string at `reader+0x404c` (then clear cache) instead of scanning.
- **Scan path (`+0x4060 == 0`):**
  1. Ensure ≥1 byte via window fields (`cursor@+0x18`, `base@+0x1c`, `available@+0x20`, buffer `@+0x2c`) and `FUN_00435df0` when short.
  2. Skip leading whitespace (`isspace`) until content; whitespace after content ends token.
  3. Quote mode: `'` or `"` opens; matching closer ends quoted region (quote chars appended to token).
  4. Outer loop structure has only `goto` exits to parse/error labels (decompiler shows `while(true)`).
- **Parse:** `FUN_00767600(out, 4, 0)` — convert token string → uint32 (size 4). Success if return `≥ 0` → return **0**.
- **Past end:** token `== "}"` → log `"Attempt to read past end of chunk..."` (`stoChunk.cpp:0x2a0`), sticky `−1`, push token into `+0x404c` pushback, clear local.
- **Type error:** format `"Expected uint32 but got \"%s\" in chunk \"%s\""` via `FUN_0076cec0` + `vog_LogMessage` (`stoChunk.cpp:0x40b`) → return **`0xffffffff`**.
- **Chunk name helper:** `FUN_00436250()` then SSO/heap c_str select (`size < 0x10` → inline +4 else heap +4).
