## Machine-level notes

- Prefer **machine** over decompiler: Ghidra omits stack flag, type 1/6 rewrite, `RET 4`, and shows bare `FUN_005d4440()`.
- **ECX in** = entity; after first load **ECX** = phys for tail.
- Soft-ready predicate mirrors network apply soft path (`aa_0053eec0` / `fn_0053eec0_networkApply`): `(phys+0x40==0) || (phys+0x08==0)`.
- Flag is **boolean selector**, not a type id: `0→1`, `≠0→6`.
- Tail `JMP 0x005d4440` preserves caller return address; early outs use `RET 4`.
