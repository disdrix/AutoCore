## Machine-level notes

- **ABI:** MSVC `__thiscall`, `ret 12` — ECX = character; stack0 = type-`0x1a` object*; stack1 = craft qty (`int`, must be `>0`); stack2 = **mode** (`char`/`int`, compared to `1` and `2`).
- **Return:** **1** success (including “no materials / nothing to craft” early), **0** hard fail (missing grids, no space, insufficient materials for requested qty, null blob after load attempt).
- Sibling of `aa_00531570` but multi-bank ingredients + mode mask; uses `FUN_00522060` as craftable-count helper.

if (cargoHolder == NULL) return 0;
cargo  = *(cargoHolder + 0x2b0);
if (cargo == NULL) return 0;

    FUN_004f1e20(pObj, /*param_2*/0, /*param_3*/1);
    if (*(pObj + 0x3c) == NULL) return 0;

if (!FUN_00522060(this, pObj, &available, mode, /*simple4c0=*/0))
    return 1;   // no craftable batches → soft success / no-op

if (qty > available) return 0;   // hard fail: cannot satisfy request

// Find free cargo footprint for product InvSize (page = -1 whole grid)
if (!FindFreeSlot(cargo, blob[0x406], blob[0x407], &ox, &oy, -1))
    return 0;

// mode != 1 and blob+0x4d4 > 0 → primary ingredient bank

    cost = (int)*(char*)(blob + 0x4d4);          // units of primary CBID per batch
    primaryCbid = *(blob + 0x4d0);

    if (have < cost * qty) {
        craftedFromPrimary = have / cost;
        secondaryNeed = qty - craftedFromPrimary;  // remainder batches from secondary bank
        qtyPrimary = craftedFromPrimary;
    } else {
        secondaryNeed = 0;
        qtyPrimary = qty;

    removeTotal = cost * qtyPrimary;
    removed = Remove(cargo, primaryCbid, removeTotal);
    if (removeTotal - removed > 0)
        Remove(locker, primaryCbid, removeTotal - removed);
    totalOut = qtyPrimary;
} else {
    secondaryNeed = qty;   // decompiler: iVar4 starts as full qty when primary skipped
    // when primary taken fully, secondaryNeed was set 0; when mode==1 path, iVar4=qty
}

// mode != 2 → consume secondary ingredient list (up to 5 CBIDs)

    for (i = 0; i < n; i++) {
        cbid = *(int*)(blob + 0x498 + 4*i);
        if (cbid == -1) continue;
        removed = Remove(cargo, cbid, secondaryNeed);
        if (secondaryNeed - removed > 0)
            Remove(locker, cbid, secondaryNeed - removed);
    }
    totalOut += secondaryNeed;
}

// Product CBID at blob+4 (not object+0x34 — differs from simple exchange unit)

## Mode semantics (sealed CF)

| `mode` | Primary bank `+0x4d0/+0x4d4` | Secondary list `+0x498…` |
|--------|------------------------------|---------------------------|
| `!= 1` and cost `+0x4d4 > 0` | counted + removed | — |
| `== 1` | **skipped** | — |
| `!= 2` | — | removed (each non-`-1` slot) |
| `== 2` | — | **skipped** |

`FUN_00522060` uses the same mode flags when computing `available` (plus optional simple `+0x4c0` path when its 5th arg ≠ 0 — **not** used by this craft unit).

## Soft-success edge
