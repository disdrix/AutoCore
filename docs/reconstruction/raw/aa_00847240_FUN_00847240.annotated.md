## Machine-level notes

- Prefer assembly when decompiler conflicts. **CF matches** live decompile ≡ raw.
- **ABI:** cdecl stack `(Item* item, char showMeta)`; caller `ADD ESP,8`. **EDI** is a live register from callers — UI text host with vfuncs:
  - `+0x250` plain append (localized / sprintf buffer)
  - `+0x224` colored append `(text, color)`
  - `+0x22c` colored append with secondary color word (rarity)
- Prologue: `sub esp,0x18c`; push ebx/ebp/esi; ESI = item*.
- Epilogue: plain `ret` (`C3`); return value = approximate **line-count contribution** for layout (1–2+).
- `unaff_EBX` in decompile on the restriction return path is a **decompiler artifact**; asm is `ADD EAX,2` on the existing accumulator in EAX / stack slot.
