## Purpose

Split an input path into drive/dir/fname/ext, **fill a missing extension** from **ESI**, then recompose into an output buffer.

Classic ensure-extension pipeline:

1. `FUN_0076af70` — splitpath-style into three 256-byte locals + drive (EAX out).
2. If **extension buffer empty** → copy C-string from **ESI** into it.
3. `FUN_0076aba0` — makepath-style recompose to **out**.

Does **not** overwrite a non-empty extension. Call sites pass ESI=`"glm"` (`0x00aa61bc`) when building `.glm` pack paths.
