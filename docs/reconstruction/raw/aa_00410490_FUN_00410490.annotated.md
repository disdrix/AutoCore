## Machine-level notes

- **`__thiscall`**: `ECX` = vector control block; stack args = `(outIt*, first, last)`.
- **`ret 0xC`** — three stack dwords cleaned by callee.
- Vector layout used here: **end @ `this+8`** (begin typically `@+4`, used by callers to form `first`/`last`).
- If `first != last`:
  1. `_Size = ((end - last) >> 2) * 4` — byte length of **tail** `[last, end)` as dword-aligned count×4.
  2. `memmove(first, last, _Size)` — slide tail down onto the erased hole.
  3. `end = memmove_return + _Size` — new logical end (also equals `first + _Size`).
- Always `*outIt = first` (iterator to erase position / new sequence start of tail).
- **No** element destructors (POD dword); **no** capacity shrink; **no** `operator_delete`.
- Multi-domain: resize-shrink (`00410420`, `004367f0`), bitset-like trim (`004365e0`), other dword vectors (`00449000`).

## Pseudocode (annotated)

```c
// __thiscall; ret 0xC
// Erase [first, last) from dword vector; shift [last, end) → first; set end; *outIt = first
void __thiscall StdVector_EraseRange_Dword(
    int this,              // ECX — end at +(8)
    void **outIt,          // stack
    void *first,           // erase begin
    void *last)            // erase end (exclusive)
{
  if (first != last) {
    // tail_bytes = ((end - last) / 4) * 4   — equivalent to end-last for dword-aligned ptrs
    size_t size = ((*(int *)(this + 8) - (int)last) >> 2) * 4;
    void *moved = memmove(first, last, size);
    *(void **)(this + 8) = (void *)((int)moved + size);
  }
  *outIt = first;
}
```
