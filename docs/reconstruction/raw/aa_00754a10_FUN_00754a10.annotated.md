## Machine-level notes

- **Worker** — opens a GDI face into an existing **GlyphCache** (`0xB8`) host: LOGFONT, metrics, atlas dims, 32bpp DIB section.
- **ESI = this** (not ECX). **ECX = style flags**. Stack: face name, height. **`RET 8`**. EAX `0` / `-1`.
- Product path string seals Palantir `graphics\gfxFontImpl.cpp`.
- Sole caller: get-or-create factory tries requested face then **`"Arial"`** fallback.
- Sibling: `GlyphCache_PlacementCtor` (`0x00754ee0`, W35-H) zeroes host before this unit runs.

## Style flags (param ECX)

| Bit | Tag | Effect |
|-----|-----|--------|
| 0 | `\|Bold` | `lfWeight = 700` (else 400) |
| 1 | `\|Italic` | `lfItalic = 1` |
| 2 | `\|Shadow` | cellH+1, maxW+2 |
| 3 | `\|Outline` | cellH+2, maxW+3 |

Empty tag set → display style `"Normal"`.
