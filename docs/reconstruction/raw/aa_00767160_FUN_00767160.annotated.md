## Purpose

**Printf-style text emit** on a **stoChunkWriter**:

1. `_vsnprintf` format + varargs into a **1024-byte** stack buffer.
2. Optional **line wrap** when `textCol > 0` and `textCol + 1 + len > 0x78` (120): reset column, write `"\r\n"` via stream `vt+0x18`.
3. If column is **0** (line start): call indent helper `FUN_00767070` (writes `indentDepth*4` spaces — residual of that VA).
4. Else: write a single **space** (`DAT_00a2a000`) and `textCol++`.
5. Write formatted bytes `(buf, len)`; `textCol += len`.
6. Return accumulated **status** dword at `writer+0x04` (OR of all stream results).

**ABI (sealed by asm):**

| Slot | Role |

| Return | `writer->status` (`+0x04`) |

## Pseudocode (annotated, faithful)

```c
// EAX = stoChunkWriter* writer
// stack: format, ...
uint32_t stoChunkWriter_WriteFormatted(const char *format, ...)
{
  char local_400[0x400];
  stoChunkWriter *writer = (stoChunkWriter *)in_EAX; // ESI after prologue
  int len = _vsnprintf(local_400, 0x400, format, &va_after_format);

  // Soft wrap: if already mid-line and next token would exceed 0x78
  if ((int)writer->textCol > 0 && (writer->textCol + 1 + len) > 0x78) {
    writer->textCol = 0;
    writer->status |= stream_write(writer->stream, &DAT_00a97b84 /* "\r\n" */, 2);
  }

  if (writer->textCol == 0) {
    // Line start: emit indent (FUN_00767070; uses ESI = writer)
    writer->status |= FUN_00767070();
  } else {
    // Mid-line: single space separator, advance column by 1
    writer->status |= stream_write(writer->stream, &DAT_00a2a000 /* " " */, 1);
    writer->textCol += 1;
  }

  writer->status |= stream_write(writer->stream, local_400, len);
  writer->textCol += len;
  return writer->status;
}
```

**Note on wrap predicate:** decompiler `0x78 < in_EAX[8] + 1 + iVar1` ≡ asm `lea eax,[col+len+1]; cmp eax,0x78; jle skip` — wrap when **greater than** 0x78.

**Note on `len`:** `_vsnprintf` return is pushed as write length without clamping; negative/truncated returns are residual risk (not handled in body).
