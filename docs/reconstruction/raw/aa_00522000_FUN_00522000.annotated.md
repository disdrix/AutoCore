## Purpose

Return the **active equip-slot TFID table length** for a Character:

```text
count = min(8, (*(uint8_t*)(this + 0x59a) >> 1) + 3)
```

Callers iterate `this+0x5a0` as an array of **8-byte TFID pairs** (`lo`,`hi`) with this count as the exclusive upper bound. Leaf — no callees.

## ABI

| Item | Seal |
|---|---|
| Convention | `__thiscall` / `__fastcall` — **ECX = Character\*** |
| Stack | none |
| Return | **EAX** = count (`uint8` / int in EAX, range 3..8 under normal field values) |
| Epilogue | bare **RET** |

Call sites reload ECX from global local-character `DAT_00d1b6d8` before the call. UI sites that see a null character substitute **literal 8** without calling.

## Annotated pseudocode

```c
// __thiscall: ECX = Character*
// returns equip TFID table count in EAX, clamped to [3..8] for field 0..inf
unsigned char __fastcall Character_GetEquipTfidTableCount_Inferred(int character /*ECX*/)
{
  unsigned char count;

  // field +0x59a: compact slot-budget byte (also written by level/flag paths e.g. SetLevelWithFlags)
  count = (*(unsigned char *)(character + 0x59a) >> 1) + 3;
  if (count > 7) {          // decompiler form; asm: cmp 8 / jl
    count = 8;
  }
  return count;
}
```
