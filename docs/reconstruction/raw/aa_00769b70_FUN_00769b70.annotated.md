## Machine-level notes

- Hybrid ABI: **EDI** = out `std::string*`; stack `reader*`; **`ret 4`**; SEH `LAB_009affaf`.
- Same scan/pushback/quote loop as `ReadTextToken`, then **strict success filter**: only double-quoted tokens with `size>1`, stripped via `substr(1, size-2)`.
- Used by OpenChunk text path and PeekChunkTag / expected-string helper.
- `}` always past-end fails (no allowEndBrace param).
- Live re-verify 2026-07-29 ≡ raw 2026-07-23 CF; strip count confirmed in bytes (`add esi,-2` / `push 1`).
