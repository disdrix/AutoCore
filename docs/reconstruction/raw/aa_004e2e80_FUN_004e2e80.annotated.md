## Machine-level notes

- **ABI sealed:** `__stdcall`, three stack args, `ret 0xC`.
- **Size:** `((end - begin) >> 2) * 4` — floor to whole dwords; not a pure byte memcpy of raw span when span not multiple of 4.
- **memmove** allows overlapping ranges (vector grow/relocate use).
- **Return** is end-of-write pointer (`dest + size`), classic STL uninitialized_copy / relocate idiom.
- Prefer assembly when decompiler conflicts — here decompile ≡ bytes.

## Pseudocode (annotated)

```c
// __stdcall  ret 0xC
// Move dword-aligned POD range [srcBegin, srcEnd) → dest; return dest+byteCount.
void *Mem_MoveDwordRange_ReturnEnd(void *srcBegin, int srcEnd, void *dest)
{
  size_t size = ((srcEnd - (int)srcBegin) >> 2) * 4;
  void *p = memmove(dest, srcBegin, size);
  return (void *)((int)p + size);
}
```
