## Machine-level notes

- Hybrid ABI: **EDI** = out `std::string*`; stack `reader*`, `char allowEndBrace`; **`ret 8`**.
- Shared text token core with typed readers (`readF32`, TextReadU32) and with `ReadQuotedTag` scan loop.
- `allowEndBrace!=0` used by LeaveChunk brace walk so `}` is a normal token (not past-end sticky).
- Pushback: non-empty test at `reader+0x4060` (size of string at `+0x404c`); consume by assign+clear.
- Prefer assembly when decompiler conflicts; live re-verify 2026-07-29 ≡ raw 2026-07-23 CF.

## Pseudocode (annotated)

```c
// EDI = std::string *out
// stack: stoChunkReader *reader, char allowEndBrace
// stdcall ret 8; EAX = 0 / 0xffffffff

uint32_t stoChunkReader_ReadTextToken(stoChunkReader *reader, char allowEndBrace)
{
  // Early: if not allowing end-brace and sticky already failed → -1
  if (allowEndBrace == 0 && *(int*)(reader + 0x402c) < 0)
    return 0xffffffff;

  if (*(int*)(reader + 0x4060) != 0) {
    // consume pushback string at +0x404c
    *out = *(string*)(reader + 0x404c);
    *(string*)(reader + 0x404c) = "";
    goto finish;
  }

  out->resize(0);
  bool have = false;
  char quote = '\"';   // default closer (overwritten on open quote)
  for (;;) {
    bool in_quote = false;
    for (;;) {
      // need at least 1 byte; refill via FUN_00435df0(base+cursor)
      if (remain(+0x20) < cursor(+0x18) + 1) {
        if (FUN_00435df0(*(int*)(reader+0x1c) + *(int*)(reader+0x18)) < 0
            || *(int*)(reader+0x20) < 1) {
          if (!have) { sticky = -1; return -1; }
          goto finish;   // partial token ends at EOF
        }
      }
      char c = *(char*)(*(int*)(reader+0x18) + reader + 0x2c);
      *(int*)(reader+0x18) += 1;

      if (!in_quote) {
        if (c == '\'' || c == '\"') {
          in_quote = true;
          quote = c;
        } else if (isspace((int)c)) {
          if (have) goto finish;   // end unquoted token
          continue;                // skip leading whitespace
        }
        have = true;
        *out += c;                 // includes opening quote char
        continue;
      }
      // inside quotes: append until matching closer (also appended)
      *out += c;
      if (c == quote) break;       // then outer loop restarts (in_quote cleared)
    }
  }

finish:
  if (*out == "}" && allowEndBrace == 0) {
    vog_LogMessage(stoChunk.cpp, 0x2a0, 3,
      "Attempt to read past end of chunk. Ignoring reads until chunk exit");
    sticky = -1;
    *(string*)(reader+0x404c) = *out;  // re-stash
    *out = "";
    return 0xffffffff;
  }
  return 0;
}
```
