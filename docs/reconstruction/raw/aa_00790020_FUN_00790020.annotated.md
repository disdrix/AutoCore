## Purpose

Client/UI-host **key-down virtual method**: gate on `vtbl+0x3d8`, optionally forward `(key,lParam)` to focused UI at `this+0x4BC`, then handle **ESC (`0x1B`)** via UI cancel (`vtbl+0x3BC(0)`) or secondary-modal dispatch (`vtbl+0x338(8, this+0x49C)`). Returns **0** if gated off, else **1** (or modal dispatch result).

Not a DIK remapper — parent `Client_Input_OnKeyDown_MatchAction` consumes the return as a **continue/gate byte**.
