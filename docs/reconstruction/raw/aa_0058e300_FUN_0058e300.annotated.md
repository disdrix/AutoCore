## Machine-level notes

- **ABI:** thiscall; ECX = object*; stack `want_start`, `want_stop` (non-null = act); `RET 8`.
- **Sibling:** `FUN_0058e270` — same start/stop body but gate is `(slot_filter==-1 || slot==filter) && slot!=-1`.
- **This unit:** gate **`*(this+0x25c) < 0` only** (negative slot / unslotted path used when dispatcher `use_slot_filter==0`).
- **Stop path:** if `want_stop != 0`: `FUN_0096d550(this=want_stop, key=*(this+0x914))` — remove matching phys-link entry.
- **Start path:** if `want_start != 0`: lookup `FUN_0096d460(this=want_start, key=*(this+0x258))`; if missing (0), `FUN_0096dc80(this=want_start, keyA, keyB@+0x914, paramC@+0x254)` then **set** `+0x90f` bit0.
- **Else (gate open, start missing or lookup hit):** **clear** `+0x90f` bit0.
- **Callers:** `NDSpecialFX_ForEachOwnedBit7_ApplyFxToggle` (`004b7030`) when no slot filter; `NDSpecialFX_DeactivateClear` (`004b7150`) as `FUN_0058e300(0, phys)` stop-only.
