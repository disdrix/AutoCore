## Role

**Insert a key/value pair** into NestedHash0x10 (or return existing equal key). Returns a small pair `{ node*, inserted_bool }` through a stack out-parameter.

Phases:

1. **Load / rehash gate** — if `maxidx(+0x24) <= list_size(+0xc) >> 2`, grow mask (`*2+1`) or rebuild bucket table via `FUN_0044a380(sentinel)` and redistribute nodes.
2. **Bucket find** — identity hash `key & mask`, fold vs `bucket_count`, walk ordered chain (backward via `prev` from end marker).
3. **Hit** — write `{node, inserted=0}`; `RET 8`.
4. **Miss** — `FUN_0046c2a0` buynode `new(0x10)` copying key/value from `kv*`; `FUN_0046c230(1, map+4)` bump list size (throws `"list<T> too long"` on overflow); splice into doubly-linked list + fix bucket starts; write `{node, inserted=1}`; `RET 8`.

Observed consumers:

- Sto factory `FUN_004449b0` / `FUN_00444a40` (after find; sets `node+0xc = creator`)
- Operator[] shell `FUN_0046bf40` (find miss → insert default)
- GfxMesh edge bag `FUN_0098fef0` (W35-F)

Sibling find: `NestedHash0x10_FindIterator_Inferred` (`0x0046c1b0`).

## Algorithm (structural)

```
if maxidx <= list_size/4:
  if maxidx < bucket_capacity-1:
    if mask < maxidx: mask = mask*2+1
  else:
    mask = capacity*2 - 3
    FUN_0044a380(sentinel)   // rebuild
  redistribute / advance maxidx

idx = key & mask; fold if needed
walk bucket end→prev looking for key:
  if equal: *out = {node, 0}; ret 8
  if ordered insert point found: break

node = buynode(hint_next, hint_prev)  // copies *kv
list_size += 1
splice node into list; fix bucket start pointers downward
*out = {node, 1}; ret 8
```
