## Machine-level notes

- **ABI:** ECX = descriptor; plain `ret`; void.
- **Global:** `DAT_00b05060` — same arena as init / `LocalWorklist_Release` (*8).
- **Slab path:** aligned size `(count*0x10+0xf)&~0xf`; if size==0 OR (slab ≠ arena[5] AND arena[5]≠0) → bump `arena[2]-=size`, `arena[3]+=size`; else vcall `vtbl+0x28(slab,size)`.
- **Tag free:** if `(int)desc[+8] >= 0` → vcall `vtbl+0x14(*desc, (count&0x7fffffff)<<4, 0x12)`.
- Decompiler drops align16 and `0x7fffffff` mask — keep both in clean.
- Release twin of `LocalWorklist16_Init_Inferred`; stride-16 sibling of `LocalWorklist_Release_Inferred` (`0x0055f4c0`, *8).
