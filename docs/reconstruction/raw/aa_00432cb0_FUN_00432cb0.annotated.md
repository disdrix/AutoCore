## Machine-level notes

- **Format mode in EAX** (`in_EAX`) is a real register formal — callers load it before `CALL` (`get_assembly_context` on `0x00432c16` / `0x00432c72`).
- **ECX = stream** with read/seek vtable (`+0x10`, `+0x14` used here; LoadTGA also uses `+8`/`+0x20`).
- Stack arg `param_2` = outer decode/context object: `+0x30` seed blob (0x5F dwords), `+0x44` error C-string sink (32 bytes = 8 dwords).
- Stack temporary image at `local_378` uses vtable **`PTR_FUN_00a9bcac`** (same family as other NDAssetImage ctors/dtors: `FUN_004320d0` / `FUN_004321b0`).
- Fail paths either copy loader error from stack (`local_334` strcpy into `param_2+0x44`) or stamp fixed `"Decode: Unknown or wrong format"`.

## Auto-cascade (mode 0) detail

1. `pos = stream.vtbl+0x14()` — save start.
2. Construct stack `NDAssetImage`; optional copy `context+0x30` → image body when `local_374==0`.
3. `NDAssetImage_LoadTGA(&stack_img, stream)`; on success → fall through to commit.
4. Else `stream.vtbl+0x10(pos,0)` rewind; dtor; reconstruct; try PNG.
5. Else rewind; dtor; reconstruct; try BMP.
6. Else rewind; dtor; `FUN_00432b10` prep; try `FUN_0098b5b0`.
7. If all fail: stamp unknown-format string; return 0.
8. On any success: `FUN_00432580(context)` move/commit; dtor; return 1.
