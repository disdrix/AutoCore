## Machine-level notes

- **ABI:** thiscall; `RET`; ECX = object; **EAX** = mode **0xB** or **10**.
- **Leaf:** no CALL, no store — pure classify of stored TFID at `this+0x108`.
- **Invalid TFID → 0xB; else → 10.** Same predicate as mode write in `FUN_004c4880` / `Object_SetTFID_ApplyPhysMode_Rebind`.
- **Xrefs:** DATA only at vtable `0x009cbe8c` (no static CALL sites found).
- Body is tiny; decompile ≡ bytes for CF with no residual.
