## Machine-level notes

- **Role:** Select active tab on the **Cs2d** dual-tab host window (`i_d_tabs_cs_2d_*` family): tab **0** = R&D (`tab_randd.xml` / cmd **0x9c43**), tab **1** = Memorization (`tab_memorization.xml` / cmd **0x9c44**). Swaps content-panel visibility, expands/collapses tab chrome via `FUN_00822cb0` + `FUN_00756c90`, and vcalls `+0x94` on the newly active tab control.
- **ABI (sealed):** **not** ECX thiscall.
  - **EAX** = `tabIndex` (0 or 1)
  - stack arg0 = window `this`
  - stack arg1 = `force` (char; non-zero forces re-apply even if same tab)
  - **`RET 8`**
- **Body:** `0x00888b00`–`0x00888c7c` (125 B). Entry: `MOV EBP,[ESP+8]`; `MOV ESI,EAX`.
- **Gate:** window must be visible (`this.vtbl+0x3d8`); then `(force || tabIndex != this+0x534)`.
- **State write:** always `*(this+0x534) = tabIndex` when gate passes (even if tabIndex ∉ {0,1}).
- **Layout:**
  - `+0x510` / `[0x144]` panel0 (shown on tab 0)
  - `+0x514` / `[0x145]` panel1 (shown on tab 1)
  - `+0x51c` / `[0x147]` R&D tab control
  - `+0x520` / `[0x148]` Memorization tab control
  - `+0x534` / `[0x14d]` selected tab
- **Panel ops:** show = `vtbl+0x43c` then enable `vtbl+4(1)`; hide = disable `vtbl+4(0)` then `vtbl+0x440`.
- **Tab chrome (disasm — decompiler incomplete):**
  - Active tab: `ESI=tab`, `BL=1`, `FUN_00822cb0(force)`, then `tab.vtbl+0x94()`
  - Inactive tab: `ESI=tab`, `BL=0`, `FUN_00822cb0(force)`, then `EDI=tab`, `FUN_00756c90()`
- **Ctor evidence:** `FUN_00888e50` loads XML names + sets tab cmd ids **0x9c43/0x9c44**, then `FUN_00888b00(window,1)` with EAX from caller context (init path).
- **Global host:** `DAT_00d1b870` is the live instance used by input poll, memorize-success UI, and parent `UI_Window_OnCommand_Class8_Inferred` case 5.
- **Sibling pattern:** same shape as residual `FUN_00889410` (3-tab) / `FUN_00889fb0` (2-tab other host) — **not dualled here**.
- **Not** inventory grab/drop/equip wire; pure client UI tab selection.

// INFERRED — product class name open; XML family + cmd ids sealed.
// ABI: EAX=tabIndex; stack (window*, force); RET 8.

                                    int tabIndex /*EAX*/)
{

  if (!force && tabIndex == window->selected_0x534) return;

  window->selected_0x534 = tabIndex;

  if (tabIndex == 0) {                           // R&D
    int* panel0 = window->panel0_0x510;
    int* panel1 = window->panel1_0x514;
    if (!panel0->vtbl[+0x3d8]()) {
      panel0->vtbl[+0x43c](); panel0->vtbl[+4](1);
    }
    if (panel1->vtbl[+0x3d8]()) {
      panel1->vtbl[+4](0); panel1->vtbl[+0x440]();
    }
    // expand R&D tab, collapse Mem tab
    FUN_00822cb0(/*ESI=*/window->tabRandD_0x51c, /*BL=*/1, force);
    window->tabRandD_0x51c->vtbl[+0x94]();
    FUN_00822cb0(/*ESI=*/window->tabMem_0x520, /*BL=*/0, force);
    FUN_00756c90(/*EDI=*/window->tabMem_0x520);
  } else if (tabIndex == 1) {                    // Memorization
    int* panel0 = window->panel0_0x510;
    int* panel1 = window->panel1_0x514;
    if (panel0->vtbl[+0x3d8]()) {
      panel0->vtbl[+4](0); panel0->vtbl[+0x440]();
    }
    if (!panel1->vtbl[+0x3d8]()) {
      panel1->vtbl[+0x43c](); panel1->vtbl[+4](1);
    }
    FUN_00822cb0(/*ESI=*/window->tabRandD_0x51c, /*BL=*/0, force);
    FUN_00756c90(/*EDI=*/window->tabRandD_0x51c);
    FUN_00822cb0(/*ESI=*/window->tabMem_0x520, /*BL=*/1, force);
    window->tabMem_0x520->vtbl[+0x94]();
  }
  // else: index stored only
}
