## Purpose

MSVC-style red-black **tree tidy** on a Val12 facade (`head@+4`, `size@+8`) **without** an SEH frame:

1. Full-range erase `[begin, end) = [*head, head)` via dualed InventoryGrid range erase `FUN_00573700`.
2. `operator_delete` the header sentinel.
3. Null `head` and `size`.

SEH-unwind twin role of peer `StdTree_Tidy_FreeHead_Bare_Val12` @ `0x0040d6d0` (erase leaf `0040d700`); this instance binds the InventoryGrid erase leaf `00573700`.

