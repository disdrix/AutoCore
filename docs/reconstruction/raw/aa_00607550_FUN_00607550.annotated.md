## Machine-level notes

- Pure lookup: **no writes** to outpost host; returns dword or 0.
- Bank select via `this+0x220`: non-zero → `DAT_00d029e0`, zero → `DAT_00d029f0` (same dual banks as `Outpost_GetPulseXpPercent` / CaptureOutpost schedule notes).
