## Machine-level notes

- Source: raw capture + live `decompile_function` / `read_memory` (2026-07-29).
- **thiscall/fastcall**: `this` in **ECX** (saved to ESI); bare `ret` (no stack args).
- **Score path:** `min( min(*(i16*)(this+0x13e), 200) + *(i16*)(this+0x146), 250 )`.
- **Vehicle probe:** multi-inheritance this-adjust then **`call [vtbl+0x1DC]`**. Nonzero ⇒ thr **1**, zero ⇒ thr **-100** via `neg/sbb/and 0x65/add -100`.
- **Return:** `max(score, thr)` (if thr < score return score else thr). Non-vehicle thr=-100 nearly always yields score; vehicle floors at 1 when score ≤ 1.
- Second `vtbl+0x1DC` only on thr-return path (not CSE'd).
- **Product label:** `Client_DebugDumpEntityCombatStats` uses return as base for **`"TargetAccuracy:"`** after a separate level formula (outside this unit).

   Returns capped accuracy-base used by TargetAccuracy display / combat paths.
   Does NOT apply level band (DebugDump does that outside). */

int __fastcall Object_GetTargetAccuracyBase_Inferred(void *self)
{
  int base = *(short *)((char *)self + 0x13e);
  if (base > 200) base = 200;
  int score = base + *(short *)((char *)self + 0x146);
  if (score > 250) score = 250;

  /* MI this-adjust → primary object; vtbl+0x1DC returns vehicle* or null */
  void *probe = Object_GetVehicleOrNull_MI(self); /* INFERRED role */
  int thr = (probe != 0) ? 1 : -100;

  if (thr < score)
    return score;   /* recompute same clamp in asm */
  return thr;       /* second probe call in asm */
}
