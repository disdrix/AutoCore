## Machine-level notes

- **ABI:** 5 stack formals `(start_c, start_i, end_c, end_i, fill*)`; plain `RET` (caller cleans `0x14`); saves EBX/EBP/ESI/EDI.
- **Leaf:** no callees.
- **Ring map addressing** (MSVC deque-like map of 4-slot pages):
  - `page = idx >> 2`
  - `sub  = idx - page*4` (via `idx + page*-4`)
  - if `page >= capacity_pages` (`[container+0x08]`) then `page -= capacity_pages`
  - `page_ptr = ([container+0x04])[page]`; store `*fill` at `page_ptr[sub]`
- **Self-guard:** skip store when dest element address equals fill pointer (alias-safe fill).
- **Range:** half-open dual-iterator form; addressing always uses **start** container (`param_1`); end pair is stop identity only.
- **Exclusive parent pattern:** `FUN_0043e080` / `GuardedVector_InsertN_Thiscall` (3 call sites — fill residual after push_front/push_back arms).
- **Twin:** sealed `GuardedVector_RingFillRange` (`0x0043cef0`) uses **EBX** fill and **no** self-guard / 4 stack args.

## Pseudocode (annotated)

```c
// 5 stack args; plain RET
void GuardedVector_RingFillFromPtr(
    GuardedVectorHeader* start_c, uint32_t start_i,
    GuardedVectorHeader* end_c,   uint32_t end_i,
    const uint32_t* fill)
{
  for (; start_c != end_c || start_i != end_i; ++start_i) {
    uint32_t page = start_i >> 2;
    int32_t  lane_base = static_cast<int32_t>(page) * -4;
    if (start_c->capacity <= page)
      page -= start_c->capacity;
    uint32_t* dest = reinterpret_cast<uint32_t*>(
        reinterpret_cast<int*>(start_c->slots)[page]
        + (static_cast<int>(start_i) + lane_base) * 4);
    if (dest != fill)
      *dest = *fill;
  }
}
```
