## Role

Per-slot **outer tick** for an object-motion / reaction entity:

1. Early abort on host state bits.
2. Optional **radius pull** when slot leaves host sphere (`host+0x980`).
3. Duration countdown (`slot[0x5c]`) and optional secondary timer (`slot[0x5b]`).
4. Nested integrate via sealed `FUN_004b1100` (`ObjectMotion_IntegrateStep_Inferred`).
5. Return **1** keep / **0** remove.
