## Machine-level notes

- **ABI:** `__thiscall` host in **ECX** + one stack material* + **`RET 4`**.
- **Host layout (span ≥ 0x0C):** `+4` begin, `+8` end of **0x14-stride** key buckets.
- **Bucket entry 0x14:** `+0` key (== material `+8`); `+8` / `+0xC` begin/end of material* vector.
- **Material:** non-null; `+8` effect/key non-null; compatibility via `FUN_00752590` (EAX=candidate, EDX=probe).
- **Not a refcount op:** returns alternate pointer or 0; callers AddRef(+4 first-use vfunc+4) / Release old (vfunc+8) / store.
- **Global host:** callers pass `*(MatRegistry**)DAT_00d1f61c` in ECX (BSS zero in static image).

## Pseudocode (annotated)

```c
// ECX = MatRegistry* host (often *DAT_00d1f61c)
// stack = Material* probe
// returns Material* alternate or NULL; RET 4
int __thiscall MatRegistry_FindCompatibleMaterial_Inferred(int host, int probe)
{
  int candidate;
  char ok;
  int *bucket;
  int *it;
  int *end;

  if (probe == 0 || *(int *)(probe + 8) == 0) {
    return 0;
  }

  // table [host+4, host+8) stride 5 dwords (0x14)
  for (bucket = *(int **)(host + 4);
       bucket != *(int **)(host + 8);
       bucket = bucket + 5) {
    if (*bucket == *(int *)(probe + 8)) {
      it  = (int *)bucket[2]; // entry+8
      end = (int *)bucket[3]; // entry+0xC
      if (it == end) {
        return 0;
      }
      // skip self; skip incompatible (FUN_00752590 == 0)
      while ((candidate = *it,
              candidate == probe ||
              (ok = FUN_00752590(/*EAX*/candidate, /*EDX*/probe), ok == 0))) {
        it = it + 1;
        if (it == end) {
          return 0;
        }
      }
      return candidate;
    }
  }
  return 0;
}
```

## Compatibility predicate (`FUN_00752590`, unowned)

Same key at `+8`, same shorts `+0x1c`/`+0x1e`, same int `+0x20`, then byte-compare buffers at `+0xC` for length derived from key object. Returns 1 if match, 0 otherwise.
