## Machine-level notes

- **EDI** = input path C-string (register argument; not stack).
- Two `strrchr` via IAT `0x009c662c`: first `'\\'` (0x5C), then `'/'` (0x2F).
- Picks the **later** of the two separator positions (pointer compare); if only one exists, uses it; if neither, returns **EDI unchanged**.
- When a separator is found, returns **separator + 1** (leaf name / basename pointer **into** original string — no copy).
- Does **not** strip extension (not PathRemoveExtension).
- Sibling `FUN_007b6450` uses return value as filename suffix after copying search-root prefixes — confirms basename role.
- EBX preserved; ESI clobbered as temp; EAX return.

## Pseudocode (annotated)

```c
// Register ABI: EDI = path; return EAX = basename pointer into path
char * Path_GetFileName(void /* path in EDI */)
{
  char *path = /* EDI */;
  char *bs = strrchr(path, '\\');
  char *sl = strrchr(path, '/');
  if (bs == NULL) {
    if (sl == NULL) return path;
    return sl + 1;
  }
  if (sl == NULL || sl < bs)
    return bs + 1;
  return sl + 1;
}
```

Equivalent rule: return pointer past max(last `\`, last `/`), or path if none.
