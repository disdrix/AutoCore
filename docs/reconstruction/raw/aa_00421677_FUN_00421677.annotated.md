## Purpose

Epilogue of the OLE DB binding-setup path: after parent `FUN_0042139b` allocates a row buffer at `ctx+8`, this unit:

1. Fails with **E_OUTOFMEMORY** if the row buffer is null (allocation failed).
2. Otherwise **zero-fills** the row buffer for the computed byte size.
3. Calls **`FUN_00422830`** (`OleDb_IAccessor_CreateAccessor_FreeBindings_Inferred`) to create the accessor and free temporary binding heap slots.
4. Frees the temporary bindings array; on CreateAccessor failure, frees `ctx+0x10`.
5. Tears down SEH / releases a COM iface held at `[ebp-0x18]`, returns **HRESULT**.

## Control flow (annotated)

```
// Ghidra entry @ 0x00421677 (EBX = ctx*, EBP = parent frame)
edi = ctx->rowBuf (+8)
esi = [ebp-0x1c]           // temp bindings
if (edi == NULL) {
  operator_delete[](esi)
  operator_delete[](ctx->auxBuf +0x10)
  [ebp-4] = -1
  ctx->auxBuf = NULL
  if (iface = [ebp-0x18]) iface->Release()  // vtbl+8
  ExceptionList = [ebp-0xc]
  return E_OUTOFMEMORY     // 0x8007000E
}

// Zero-fill row buffer
size = [ebp-0x24]
rep stosd (size>>2); rep stosb (size&3)   // EDI = rowBuf, AL=0

// CreateAccessor + free binding heap slots (custom ABI; see aa_00422830)
hr = FUN_00422830( /* EAX=[ebp-0x18], ECX=ctx+0xc, EDX=bindings,
                      stack: [ctx+0], size */ )

operator_delete[](esi)     // free temp bindings
if (hr < 0) {
  operator_delete[](ctx->auxBuf)
  ctx->auxBuf = NULL
}
[ebp-4] = -1
if (iface = [ebp-0x18]) iface->Release()
ExceptionList = [ebp-0xc]
return hr                  // ret 4
```
