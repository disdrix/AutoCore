## Machine-level notes

- **ABI:** `__thiscall` Character `this` in ECX; two stack dwords; **`ret 8`**. First stack arg is **dead** (callers pass tier or row index).
- **Grid path:** `grid = *(*(this + 0x250) + 0x2B0)` — same cargo-grid pattern as DropResponse inventoryType **1**.
- **Callee:** `InventoryGrid_FindItemByCoid` (`FUN_00571010`, dualed) with COID lo/hi on stack.
- **Type gate:** `*(item->def + 0x38) == 0x1A` → `CloneBaseObjectType.Commodity` (26). Non-commodity or missing item **stops** the walk and returns current accum.
- **Null TFID:** `(lo & hi) == 0xFFFFFFFF` ⇔ both halves are `0xFFFFFFFF` → skip slot, continue.
- **Cost formula (exact):**

```
accum = 1
for i in 0..4:
  if not null(tfid[i]):
    item = FindItemByCoid(grid, lo, hi)
    if item == null OR type != Commodity: return accum
    accum += *(uint8_t*)(*(def + 0x3C) + 0x4C8) + i
return accum
```

- Byte at `*(def+0x3C)+0x4C8` is a **subblob** field (not the same as refine-panel `def+0x4C8` tier without proof of identity). Product English open.
- Callers: `FUN_00522780` (tier score vs max capacity `FUN_00520340`); `FUN_005244e0` (sum over 5 TFID rows × 40 B stride).

// stack: unused_arg (dead), TFID row[5]  // ret 8

                                               uint32_t unused_arg,
                                               const uint32_t* tfidRow /* 5×{lo,hi} */)
{

  InventoryGrid* grid = *(InventoryGrid**)(*(uint8_t**)(self + 0x250) + 0x2B0);

      return accum;

    void* sub = *(void**)((uint8_t*)def + 0x3C);
    uint8_t w = *(uint8_t*)((uint8_t*)sub + 0x4C8);
    accum += (int)w + i;
  }
  return accum;
}
