- **ABI:** `__thiscall` ECX=grid; stack0=`relatedGrid*`; stack1=`char doRemove`; **`RET 8`**.
- Walks std-map-like placement tree at `grid+0x60` (head sentinel; isnil `@node+0x19`; item `@node+0x10`; originX `@+0x14`; originY `@+0x15`).
