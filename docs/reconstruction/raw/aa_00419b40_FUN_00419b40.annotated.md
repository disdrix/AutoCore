## Purpose

**Bucket-chain find** for the **u64-key CNDHash** node layout (keyLo@`+0x18`, keyHi@`+0x1c`, next@`+0x10`).

Walks the singly-linked chain starting at `bucketHeader+4`. On each non-match, records the current node into `*predOut` so callers (especially unlink `FUN_00419b80`) can splice without a second walk.

Returns the **matched node pointer** (not the payload) in **EAX**, or **NULL**.

---

## ABI (machine-sealed)

| Slot | Role |
|---|---|
| **EAX** (in) | Bucket header* — reads `*(header + 4)` as chain head |
| **EDI** (in) | `Node **predOut` — written 0, then predecessor of current as walk advances |
| **[esp+4]** | `keyLo` (u32) |
| **[esp+8]** | `keyHi` (u32) |
| **EAX** (out) | Matched `Node*` or `NULL` |
| **Epilogue** | `ret 8` → **`__stdcall`** 8 stack bytes |

Decompiler shows `void` / loses return and invents `in_EAX` / `unaff_EDI` — those registers are intentional custom ABI used by the CNDHash u64 family (same pattern as insert/remove sealed duals).

---

## Control flow

```
*predOut = 0
node = header->head (+4)
if node == 0: return 0

loop:
  if node->keyLo(+0x18) == keyLo && node->keyHi(+0x1c) == keyHi:
    return node          // *predOut is predecessor (0 if head match)
  *predOut = node
  node = node->bucketNext(+0x10)
  if node: goto loop
return 0                 // miss; *predOut = last node in chain
```

Compare polarity: match requires **both** dwords equal (AND). Mismatch on either → advance.

## Node / header offsets used

| Off | Role |
|---|---|
| header `+0x04` | chain head `Node*` |
| node `+0x10` | bucket next |
| node `+0x18` | keyLo |
| node `+0x1c` | keyHi |

Cross-check (sibling insert `aa_00413920`): new node sets `puVar2[6]=keyLo`, `puVar2[7]=keyHi`, `puVar2[4]=oldHead` — same offsets. Value payload at `+0xc` is **not** read here (callers like `FUN_00413b30` load it after return).

## Pseudocode (annotated, machine-faithful)

```c
// Custom ABI: EAX=bucketHeader, EDI=predOut; stdcall keyLo,keyHi; ret 8
// Returns matched Node* in EAX (decompiler shows void — ignore)
Node *CNDHash_BucketFindNodeByU64Key(BucketHeader *header /*eax*/,
                                     uint32_t keyLo, uint32_t keyHi,
                                     Node **predOut /*edi*/)
{
  Node *node = header->head; /* *(header+4) */
  *predOut = 0;
  if (node == 0)
    return 0;

  for (; node != 0; node = node->bucketNext /* +0x10 */) {
    if (keyLo == node->keyLo /* +0x18 */ && keyHi == node->keyHi /* +0x1c */)
      return node;
    *predOut = node;
  }
  return 0;
}
```
