## Machine-level notes

- **ECX** = `stoChunkReader*` (all 4 call sites set ECX from the reader register used for EnterChunkScope).
- **Leaf.** No stack frame. Plain `RET`.
- **Return:** boolean 0/1 in EAX; callers `TEST AL,AL`.
- **reader[+0]:** unsigned id / index used as 1-based bit selector. If **0** → return **false** (`XOR AL,AL`).
- **reader[+8]:** base address of a uint32 bitset (pointer value treated as `uint*`).
- Bit formula (when id ≠ 0):
  - `base' = reader[+8] + (id >> 5) * 4`
  - `low = id & 0x1f`
  - `idx = low - 1`  (i.e. tests bit **(id & 0x1f) − 1** relative to `base'`, with further word stride if idx underflows)
  - return `( *dword & (1u << (idx & 31)) ) != 0`
- Plate comment + unserialize callers: **nonzero → soft-success skip** (return 0 from Unserialize without reading body); **zero → continue** deserialize. Distinct from hard fail (−1).
- Edge: when `id & 0x1f == 0` (id multiple of 32), `low-1` underflows to `0xFFFFFFFF` — bit 31 of a far word. **No retail proof** that such ids are used. Document as residual.

## Pseudocode (annotated)

```c
// __fastcall / this-style: ECX = stoChunkReader*
// Return: 0 = continue deserialize; 1 = soft-skip (caller returns 0)

uint __fastcall stoChunkReader_SoftSkipIfBitSet(uint *reader /* ECX */)
{
  uint id = reader[0];           // +0
  if (id == 0) {
    return 0;                    // XOR AL,AL (upper EAX preserved; callers only TEST AL)
  }
  uint base = reader[2];         // +8 bitset base
  uint low = id & 0x1f;
  base += (id >> 5) * 4;
  uint idx = low - 1;
  uint word = *(uint *)(base + ((idx >> 5) * 4));
  uint mask = 1u << (idx & 0x1f);
  return (word & mask) != 0;
}
```
