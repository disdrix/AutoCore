## Machine-level notes

- **EBX** = bucket header* (chain head at `+4`).
- **Stack** `keyLo`, `keyHi`; **`ret 8`** (stdcall).
- Find callee writes predecessor into the **keyLo stack slot** (predOut); after return that slot is **Node*** pred, not keyLo.
- Unlink is **singly-linked** on `node+0x10` only (ordered list `+0x20/+0x24` is parent remove's job).
- Always runs `FUN_00419ad0` with **EDI = bucket** (touch-bit walk / cycle cut) before return — hit or miss.
