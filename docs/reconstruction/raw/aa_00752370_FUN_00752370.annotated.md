## Machine-level notes

- Source: raw capture for `aa_00752370` + W38-Q `read_memory` body seal.
- Prefer body bytes when decompiler conflicts (`ret 8`).
- ECX = effect shell; `+8` → inner resource with param table.
- Indirect `vtbl+0x24` on `inner+0xc` resolves name → handle; linear scan table stride 8.
- Callers bind MatDiffuse / MatAmbient / DiffuseTexture / WireColor etc. via this index + `FUN_0096fff0` set-param.

// ECX = EffEffect*; stack: int* outIndex, const char* nameOrToken
void __thiscall EffEffect_FindParamIndexByName_Inferred(
    int effect, int *outIndex, undefined4 nameOrToken)
{
  int inner = *(int *)(effect + 8);
  int idx = -1;
  if (inner != 0 && *(int *)(inner + 0xc) != 0) {
    int *iface = *(int **)(inner + 0xc);
    // GetParameter-by-name (arg0=0, arg1=name)
    int handle = (**(code **)(*iface + 0x24))(iface, 0, nameOrToken);
    if (handle != 0) {
      int count = *(int *)(inner + 0x18);
      int *table = *(int **)(inner + 0x10); // entries: {handle, ...} stride 8
      int i = 0;
      if (count > 0) {
        while (1) {
          idx = i;
          if (table[i * 2] == handle) break; // dword0 of entry i
          i++;
          if (i >= count) { *outIndex = -1; return; }
        }
      }
    }
  }
  *outIndex = idx;
}
