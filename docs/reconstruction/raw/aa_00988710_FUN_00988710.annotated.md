## Machine-level notes

- **ABI:** ECX = owned-block `this` (`MOV EDI,ECX`). Void. **Bare `RET`** (`C3`). Not stdcall.
- **Role:** complete destructor of a heap-owned block that holds a tree map + refcounted iface. Callers always `operator_delete` the host after return — hence **CompleteBeforeDelete**.
- **False-noreturn:** Ghidra truncates after `operator_delete(head)`; epilogue nulls head/size and returns. Prefer assembly + `read_memory`.
- **Tree family:** isnil flag @ node `+0x25` (same as ctor twin `FUN_009886d0` / erase helper `FUN_0044f3c0`).
- **Does not free host.** Only frees the tree **sentinel head**.
