## Machine-level notes

- Source: raw capture + live decompile/`read_memory` 2026-07-29.
- Same Val12 map family as `CVOGCharacter_SetMissionCounter` (`0x005305b0`, W30-I) / `AddMissionCounter` (`0x00530610`) / `GetResourceBalanceByType` (`0x0052ada0`).
- Map object = `char+0x584`; ordered-map find `FUN_00418b80`; head/end sentinel `char+0x588`.
- **Gate:** hit **and** mapped second dword `node+0x14 > 0`. Else return 0.
- **On success:** re-find; if still hit: force `node+0x10 = 0` (GetResourceBalance field); if `node+0x14 < 0` copy into `+0x10` (defensive; outer gate had `> 0`); dirty `char+0x634 |= 0x40`. Then **always** `SetMissionCounter(key, 0)` (zeros `+0x14`), dirty `|= 0x40` again, return 1.
- ABI: `__thiscall`; ECX=character; one stack formal (key); **`ret 4`**; BOOL in AL.
- Sole caller `FUN_00809dd0` (from `Client_PacketDispatch`): on success flag at packet `+4`, clears counter key at packet `+8`; else toast `"FAILED: Server reports failure."`.
