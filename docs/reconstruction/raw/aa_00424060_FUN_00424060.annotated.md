## Machine-level notes

- **ECX** = CS-list object (`ObjectCsList` family layout).
- SEH `LAB_009bd790` + `__chkstk 0x1004` (throw-path frame).
- Product SEH string: **`"List Error!  DestroyAll Call Stack:\n%s\n"`** — method English **DestroyAll**.
- Throw `0x80070005` (`E_ACCESSDENIED`) if traversal flag `+0x28` set while locked.
- Drain head `@+0x1C`, next `@node+8`, scalar-delete each node `vtbl[0](1)`.
- **Does not** clear `node+4` (twin of `ObjectCsList_ClearDestroyNoNode4_Inferred` @ `0x0051bc90`; opposite of `0x0051b8a0`).
- Does **not** free list object or call `DeleteCriticalSection` — complete/scalar dtors do that after.
- Used by CNDUIWindow nested member `@+0x1E8` (`CNDDoubleList`/`CNDDoubleListPtr` of `STextMarkup`) and many other list types sharing this layout.
