## Machine-level notes

- Source: raw capture `aa_00571b80` + live `decompile_function` (≡ raw) + `read_memory` prologue / unstamp loop / epilogue.
- Prefer assembly when decompiler elides `this` (`FUN_00415c00`, `FUN_005085b0` both take `this = grid+0x2c`).
