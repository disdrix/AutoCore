## Machine-level notes

- `__thiscall`: `push esi; mov esi,ecx`; plain `ret`.
- Does **not** free freelist slab at `this+0x20` (dtor `FUN_0051dfe0` calls `FUN_0059c8a0` after this).

## Behavioral summary

| Step | Action |
|---|---|
| 1 | `this->count (+0xC) = 0` |
| 2 | `FUN_0051bfb0(this)` — walk buckets `0…mask`, destroy values, push nodes to freelist `+0x20`, null bucket heads |
| 3 | If `this->buckets (+0x10) != NULL`: `free(*buckets)` (sentinel slab), `operator_delete[](buckets)`, `buckets = NULL` |

### Why `free(*buckets)` then `delete[] buckets`

Alloc twin `FUN_0051ba40` (Recreate path):

- `operator_new[](N*4)` → pointer table at `+0x10`
- `malloc(N*0xC)` → contiguous sentinel slab (vtbl `009ce090`)
- `buckets[i] = &slab[i*0xC]` so `*buckets == slab base`

Clear frees slab via first entry, then deletes the pointer table — matches alloc.
