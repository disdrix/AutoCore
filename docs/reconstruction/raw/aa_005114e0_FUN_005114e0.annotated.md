## Machine-level notes

- **ABI:** `__thiscall` — `ECX` = dest vector (`ESI`); stack arg0 = const src vector (`EBX` from `[EBP+8]`); **`RET 4`**; returns dest in `EAX`.
- **Vector triad:** dest `+4` begin, `+8` end, `+0xC` capEnd; `+0` allocator/proxy untouched.
- **Element stride:** `SAR 4` / `SHL 4` → **0x10** B POD (4 dwords). Max elements **`0x0FFFFFFF`**.
- **Empty path:** if `src.begin == 0` or `n == 0`, zero triad and return (no alloc).
- **Throw path:** `n > 0x0FFFFFFF` → `CALL FUN_004540b0` (noreturn length_error; decomp may fake-assign).
- **Copy:** `FUN_005dd920(begin, end, buf)` writes 4 dwords per element; result → dest end.
- **SEH:** frame `LAB_009a34a0`; state 0 after successful alloc before range-copy.
- Prefer assembly when decompiler conflicts (throw return assignment, extra stack args on `FUN_005dd920` call).

    const StdVector_Elem0x10* src) // [EBP+8]

    n = 0;

  return dest;
}
