## Machine-level notes

- Live `read_memory` seals full body; epilogue **`C2 04 00`** (one stack formal).
- **`__thiscall`**: `8B F9` → EDI = this (`StringVecShell*`).
- Capacity gate: `begin != 0` **and** `(end-begin)/0x1c < (capEnd-begin)/0x1c` using signed-div magic **`0x92492493`** (same family as W32-A/B string vector).
- **Fast path:** cdecl `FUN_00431700(end, 1, value)` constructs one `basic_string` in place; `end += 0x1c`. Caller pushes five dwords; callee decompile consumes three (dest/count/value) — extras are unused stack residue.
- **Slow path:** thiscall `FUN_00430310(this, &out_scratch, end, value)` = `StringVec_InsertOne` at **end** (W32-A), which may grow via `FUN_004306b0` (W32-B). Out-iterator written to a discarded stack slot (push_back does not return an iterator to the caller).
- Null / unallocated begin forces slow path (size forced 0 then capacity miss).
- Closes residual named by W32-A (“push_back gate `FUN_004301f0`”) and W32-D leaf push path.
