## Machine-level notes

- **ABI:** **EAX = `Mt19937State*`** on entry. First two insns: `push esi; mov esi, eax`. Not ECX-thiscall. Bare **`ret`** (`c3`).
- **Return:** tempered `uint32` in **EAX**.
- **Layout (shared with twist/seed siblings):**
  | Off | Field |
  |---:|---|
  | +0x000 | `uint32 mt[624]` |
  | +0x9c0 | `uint32* cursor` |
  | +0x9c4 | `int remaining` |
  | size | **0x9c8** |
- **Refill:** if `remaining == 0` → `call Rng_Mt19937_Twist` (`0x004248c0`). Twist uses **ESI** state — already set by entry `mov esi,eax`.
- **Extract:** `--remaining`; load `*cursor`; `cursor += 4` (one dword); temper; return.
- **Decompiler `in_EAX`:** real ABI (phantom local), not junk. Clean docs EAX explicitly (same style as seed dual).
- **Not ESI entry** unlike twist — callers leave state in EAX (or set EAX then call).

## Annotated control flow

```
uint32 Rng_Mt19937_Extract(Mt19937State* st /*EAX*/)
{
  // body: ESI = st
  if (st->remaining == 0)
    Rng_Mt19937_Twist(st);   // ESI ABI sibling; resets remaining=624, cursor=&mt[0]

  st->remaining -= 1;
  uint32 y = *st->cursor;
  st->cursor += 1;

  y ^= y >> 11;
  y ^= (y & 0xff3a58ad) << 7;
  y ^= (y & 0xffffdf8c) << 15;
  return (y >> 18) ^ y;
}
```

## Temper vs textbook MT19937

| Step | Body form | Textbook |
|---|---|---|
| 1 | `y ^= y >> 11` | same |
| 2 | `y ^= (y & 0xff3a58ad) << 7` | `y ^= (y << 7) & 0x9d2c5680` |
| 3 | `y ^= (y & 0xffffdf8c) << 15` | `y ^= (y << 15) & 0xefc60000` |
| 4 | `return (y >> 18) ^ y` | same |

Mask rewrite is bit-equivalent (bits that would shift out of 32-bit are don't-care in the AND mask).
