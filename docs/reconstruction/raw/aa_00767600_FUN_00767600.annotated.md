## Machine-level notes

- **ABI:** **EAX** = `const std::string*` token (MSVC SSO layout); stack `(void* out, uint byteLen, int signedMode)`; epilogue **`RET 12`**. Returns **0** ok, **−1** fail.
- **SSO string (MSVC):** if `str+0x18 < 0x10` → chars at `str+4`; else chars at `*(char**)(str+4)`.
- **Empty token** (`*pc == 0`) → −1.
- **Leading `-`:** only if `signedMode == 1`; else −1. Sets negative flag and advances past `-`.
- **Parse:** for each char, `isdigit`; fail if not. Accumulate `u64 = u64 * 10 + (c - '0')` via `__allmul(lo,hi,10,0)` then add digit with carry. Loop until NUL.
- **No hex / base prefix** — decimal digits only.
- **Unsigned range (`signedMode==0`)** by `byteLen`:
  | len | reject if |
  |---|---|
  | 1 | `(val & 0xffffff00) \|\| hi != 0` |
  | 2 | `(val & 0xffff0000) \|\| hi != 0` |
  | 4 | `hi != 0` |
  | 8 | never (full u64) |
  | other | log line **0x3ab** + −1 |
- **Signed range (`signedMode==1`)** — check **absolute** value before negate:
  | len | reject if |
  |---|---|
  | 1 | `(val & 0xffffff80) \|\| hi != 0`  (max 127; **no −128**) |
  | 2 | `(val & 0xffff8000) \|\| hi != 0`  (max 32767) |
  | 4 | `(val & 0x80000000) \|\| hi != 0`  (max INT_MAX) |
  | 8 | `(val & 0x8000000000000000) != 0`  (max LLONG_MAX) |
  | other | log line **0x3c3** + −1 |
- **Negate:** if signed and had `-`, two's-complement on 64-bit local (`neg lo; adc; neg hi`).
- **Store:** copy `byteLen` bytes from little-endian local u64 to `out` (dword loop `len>>2`, then byte tail `len&3`).
- **Log:** `vog_LogMessage(path, line, level=3, "Invalid integer length in ConvertToInteger()")`.

## Pseudocode (annotated)

```c
// EAX = const std::string* text; stack out, byteLen, signedMode; RET 12
int32_t stoChunk_ConvertToInteger(
    /*EAX*/ const MsvcString* text,
    /*stack*/ void* out,
    /*stack*/ uint32_t byteLen,   // 1,2,4,8
    /*stack*/ int32_t signedMode) // 0=unsigned, 1=signed
{
  const char* pc = (text->cap_or_size < 16) ? text->inline_buf : text->ptr;
  if (*pc == 0) return -1;

  bool neg = false;
  if (*pc == '-') {
    if (signedMode == 0) return -1;
    neg = true;
    pc++;
  }

  uint64_t val = 0;
  if (*pc != 0) {
    do {
      if (!isdigit((unsigned char)*pc)) return -1;
      val = val * 10 + (uint64_t)(*pc - '0');
      pc++;
    } while (*pc != 0);
  }

  if (signedMode == 0) {
    switch (byteLen) {
    case 1: if (val > 0xFFull) return -1; break;
    case 2: if (val > 0xFFFFull) return -1; break;
    case 4: if (val > 0xFFFFFFFFull) return -1; break;
    case 8: break;
    default:
      vog_LogMessage(STOCHUNK_CPP, 0x3ab, 3, "Invalid integer length in ConvertToInteger()");
      return -1;
    }
  } else if (signedMode == 1) {
    switch (byteLen) {
    case 1: if (val > 0x7Full) return -1; break;
    case 2: if (val > 0x7FFFull) return -1; break;
    case 4: if (val > 0x7FFFFFFFull) return -1; break;
    case 8: if (val > 0x7FFFFFFFFFFFFFFFull) return -1; break;
    default:
      vog_LogMessage(STOCHUNK_CPP, 0x3c3, 3, "Invalid integer length in ConvertToInteger()");
      return -1;
    }
    if (neg) val = (uint64_t)(-(int64_t)val); // two's complement as in retail
  }

  // memcpy out <- &val for byteLen bytes (dword then byte)
  memcpy(out, &val, byteLen);
  return 0;
}
```
