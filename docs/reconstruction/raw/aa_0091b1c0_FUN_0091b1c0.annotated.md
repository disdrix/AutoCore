## Machine-level notes

- **Epilog** `C2 14 00` seals five stack dwords (focus xyz + two ranges).
- **EDI** is not free noise: sole caller `FUN_0091ce80` does `mov edi, esi` with ESI = cam this before `call 0x0091b1c0`.
- Quat→forward uses factor **2.0** (`0x00a10e74`, decompiler misname `g_flLevelUpUiBase_Inferred`).
- Collision is a **single** vertical segment via dualed `Client_Map_RaySegmentHitDistance_Inferred` (`0x00916090`), not the 8-probe multipass of default mode `009168d0`.
- `VOG_DEBUG_STOP` string is **only** the null-`DAT_00d1b6d8+0x48` abort path — reject naming the function after it.
- Debug `sprintf`/`OutputDebugStringA` of look-dot is live in retail body (side channel).
