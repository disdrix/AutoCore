## Machine-level notes

- **`__thiscall`**: ECX = vector shell; three stack formals; **`RET 0x0C`**.
- Computes **stable element index** before insert so the out-iterator survives reallocation inside `FUN_004306b0`.
- Empty or null-begin → index forced to **0** (insert at “start” of empty container).
- Always inserts **exactly one** element (`push 1`).
- Stride **0x1c** matches MSVC `basic_string` size used by path-list / AssManager helpers.
