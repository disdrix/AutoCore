## Purpose

Write a **signed quantized integer** into a TNL-style BitStream:

1. Write **1 sign flag** via `BitStream_writeFlag(value < 0)`.
2. If negative, take **absolute value**.
3. Write **`bitCount - 1`** magnitude bits via `BitStream_writeBits`.

This is the integer packing stage for `BitStream_writeQuantizedFloat` (`0x0042b910`), which multiplies the float by `(1<<(bitCount-1))-1` and truncates before calling here.

**Not** a float writer. **Not** an unsigned-only packer.

## Pseudocode (annotated ≡ raw ≡ bytes)

```c
void BitStream_writeQuantizedSignedInt(BitStream *stream /*EDI*/,
                                       int value /*ECX*/,
                                       uint8_t bitCount /*AL*/)
{
    int local = value;
    uint8_t magBits = bitCount - 1;
    char flag = BitStream_writeFlag(stream, value < 0); // thiscall ECX=stream
    if (flag != 0) {
        local = -value; // NEG ESI; INT_MIN edge = retail 2's complement wrap
        BitStream_writeBits(stream, magBits, &local);
        return;
    }
    local = value;
    BitStream_writeBits(stream, magBits, &local);
}
```

## Machine notes

- Callees: `BitStream_writeFlag` @ `0x0042b770`, `BitStream_writeBits` @ `0x0042b4a0` (relative calls sealed).
- **No magnitude mask** on write (unlike read sibling `0x0042b9d0`, which masks with `(1<<magBits)-1` when width ≠ 32).
- `writeFlag` return is tested; TNL pattern returns the flag written (same as input).
- Sole caller prepares `EDI`/`ECX`/`AL` after float quantize.
