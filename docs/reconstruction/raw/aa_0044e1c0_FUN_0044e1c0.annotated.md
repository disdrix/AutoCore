- **Bytes win** on cleanup: every epilogue is **`RET 0x18`** (6 stack dwords). Decompiler lists 5 live formals; sole caller `FUN_00971700` pushes **6**.


```
suffix = size - prefix
N      = (last - first) >> 2

    push_front each of the old prefix elements (page-mapped) via 0043e3d0
```
