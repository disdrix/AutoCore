- **ABI:** `__cdecl` — host pointer and `char bReloadSkillDef` on stack; epilogue bare **`c3`**.

- **Optional def reload (`param_2≠0`):** `FUN_007e26e0(skillId, buf)` then `FUN_0054a290` / `SkillDef_InstallLoadedRecord` path.
- **Always:** `Skill_ReevaluateForCurrentRank(skill)`; convert wide name → MB; `FUN_0054f430(skill, mb)` copies into **`skill+0x1a5`**.
- **End of chain:** unlock hash; if `vtbl+0x210(0)` or `vtbl+0x214()` → `FUN_00516a00(0)` (re-fire cast HBs for active skills).
- Sole caller: `FUN_00517df0` (map/zone skill refresh orchestration).
