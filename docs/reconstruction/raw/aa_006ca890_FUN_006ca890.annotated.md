## Machine-level notes

- **Stack:** `AND ESP,0xFFFFFFF0` + `SUB ESP,0x2C` — 16-byte-aligned query packet for vcall.

- Soft-desc dword @ **+0x24** → entry **+0x40** when flag ≠ 0.
- Related object `param_4`: links entry `+8 = obj+0x14`, `+0x44 = obj+0x10` (null-safe).
- Sole direct caller: thin wrapper `FUN_0055e1e0` (builds local entry, vtbl `0x009d27a8`).
- Grandparent hub: after `FUN_0040c410` init; before `SoftCastHitList_SortIfCountGt1` (`0x0048a060`).
