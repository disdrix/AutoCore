## Machine-level notes

- **ABI:** ECX = clock host (`mov esi,ecx`); **bare `ret`** (`C3`); result on **x87 ST0** (`float10` in decompiler).
- **Cache fast-path:** `ucomiss` `this+0x24` vs `DAT_00aaa668` (**-1.0**); unequal → return cached `+0x24`.
- **Live path:** CRT `_time64` / `_localtime64`; int64 subtract at `+0x160/+0x164`.
- **Quarter map:** seconds-within-hour (`tm_min*60+tm_sec`) minus {0,900,1800,2700} by mode `this+0x154`, then × **1/900**.
- **Sub-second blend:** globals `DAT_00b04750` (last secOfHour) + `DAT_00b0474c` (last `g_dwClientTickMs`); add `Δms * 0.001 * 1/900` when same second.
- **Clamp:** `[0, g_flOne]`.

## Control-flow map

```
if this+0x24 != -1.0:
    return this+0x24
now = time64()
adj = now - *(int64*)(this+0x160)
tm = localtime64(adj)
secOfHour = tm_sec + tm_min*60
switch this+0x154:
  0: phase = secOfHour
  1: phase = secOfHour - 900
  2: phase = secOfHour - 1800
  3: phase = secOfHour - 2700
  default: phase = 0; skip scale
if mode in 0..3:
  phase *= 1/900
if DAT_00b04750 == secOfHour:
  phase += wrap(tick - DAT_00b0474c) * 0.001 * 1/900
else:
  stamp tick + secOfHour
return clamp(phase, 0, 1)
```
