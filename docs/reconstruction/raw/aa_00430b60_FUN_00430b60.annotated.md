## Algorithm

1. If `map->size > 0x7FFFFFD` → build `"map/set<T> too long"` → `FUN_00401a40` → `_CxxThrowException(..., DAT_00acc388)`.
2. `FUN_0042a890(key, left=head, parent=where, right=head, color=0)` → `new(0x30)`, red node, isnil=0.
3. `map->size++`.
4. Link under `where`:
   - `where == head` → root = leftmost = rightmost = new.
   - `addLeft != 0` → `where.left = new`; if `where == leftmost`, update head.left.
   - else → `where.right = new`; if `where == rightmost`, update head.right.
5. RB fixup while parent color is red (`+0x2C == 0`):
   - uncle red → recolor parent/uncle black, grandparent red, climb.
   - uncle black + inner child → rotate at parent (`FUN_0044e010` L / `FUN_0042a840` R).
   - then recolor + rotate at grandparent.
6. Root color forced black; `*outIt = newNode`; restore SEH; `ret 0x0C`.
