## Machine-level notes

- Source: live `batch_decompile` + `read_memory` (W37-D). Scaffold raw body 2026-07-23 unchanged.
- **ABI:** ECX = `XformBlock*` (0xC0); returns **this** in EAX (`MOV EAX,ECX` preserved through body); plain `RET`.
- **Leaf** — no callees. Uses SSE: `MOVSS` / `XORPS` / `REP MOVSD`.
- **Globals:**
  - `g_flOne` @ `0x00a0f2a0` = `00 00 80 3F` (1.0f)
  - `DAT_00afdf70` = row-major 4×4 **identity** (16 floats / 64 B)
- **Written layout (0xC0):**

| Off | Init | Role (family-inferred) |
|-----|------|------------------------|
| `+0x00` | copy identity | basis / world mat4 |
| `+0x40` | copy identity | secondary / local mat4 |
| `+0x80` | `(0,0,0,1)` | rotation quat (identity) |
| `+0x90` | `(0,0,0)` | translation xyz |
| `+0x9c` | `(1,1,1)` | scale xyz (see `FUN_0044b440`) |
| `+0xa8` | `(1,1,1)` | additional unit triple |
| `+0xb4` | `0` | version / dirty counter |

- Consumers allocate with `_aligned_malloc(0xC0, 0x10)` then call this (e.g. GfxView `+0x08`). Also used as `eh_vector_constructor_iterator` element ctor.
- Decompiler shows `void`; bytes keep **EAX = this**.

## Pseudocode (annotated)

XformBlock* __fastcall Xform_Ctor_Inferred(XformBlock* this /*ECX*/)
{
  float one = g_flOne;          // 1.0f
  // zero via XORPS used for float 0 stores

  // two identity 4x4 copies (REP MOVSD ×16 dwords each)
  memcpy(this + 0x00, &DAT_00afdf70, 0x40);
  memcpy(this + 0x40, &DAT_00afdf70, 0x40);

  // quat identity (0,0,0,1)
  this->f80 = 0; this->f84 = 0; this->f88 = 0; this->f8c = one;
  // translation 0 + scale 1,1,1  (+0x90..+0xa4)
  this->f90 = 0; this->f94 = 0; this->f98 = 0;
  this->f9c = one; this->fa0 = one; this->fa4 = one;
  // extra unit triple +0xa8..+0xb0
  this->fa8 = one; this->fac = one; this->fb0 = one;
  // version / flag / dirty
  this->u_b4 = 0;
  this->b_b8 = 0;
  this->u_bc = 0;
  return this;
}
