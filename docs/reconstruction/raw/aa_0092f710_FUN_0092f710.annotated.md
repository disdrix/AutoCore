## Purpose

Load user key bindings from **`keymap.ini`** into the client ActionMap at **`client+0x116c`**.

- If the file is missing: write a default keymap via `FUN_007f9480` (path `"keymap.ini"` in EAX, ActionMap on stack) and return.
- If present: line-parse `Description=primary;alt` (comments `//`, field seps `=;` ), resolve description → (mode, slot) via `FUN_007f9230`, parse key tokens via `FUN_0092db30`, apply primary then alt binds via dualed `ActionMap_TrySetSlotBind` (`BL=0` then `BL=1`).

Called once from dualed **`Client_InitInstance`** (`0x0094a6a0`) in the CoInitialize / Version / Ini / **Keymap** / colors boot block.

## Pseudocode (annotated; CF ≡ raw ≡ live)

```c
// Client_LoadKeymapIni — aa_0092f710 @ 0x0092f710
// RET 4; ActionMap at client+0x116c
void Client_LoadKeymapIni(void *client)
{
  FILE *file;
  char line[2048];
  char primary[512];
  char alt[512];
  char comment_delim[3]; /* "//" from DAT_00a152dc */
  char field_delim[3];   /* "=;" from DAT_00a152e0 */
  uint32_t key_out;
  uint32_t mod_out;      /* via FUN_0092db30 outs — register-mediated */
  int mode;
  unsigned slot;
  char *tok;
  char *p;
  size_t n;

  file = fopen("keymap.ini", "r");
  if (file == NULL) {
    /* EAX = "keymap.ini"; stack = client+0x116c */
    FUN_007f9480((int)((char *)client + 0x116c));
    return;
  }

  /* load stack copies of "//" and "=;" */
  comment_delim[0] = '/'; comment_delim[1] = '/'; comment_delim[2] = 0;
  field_delim[0] = '='; field_delim[1] = ';'; field_delim[2] = 0;

  tok = fgets(line, 0x800, file);
  while (tok != NULL) {
    p = strstr(line, comment_delim);
    if (p != NULL) *p = '\0';

    key_out = 0;
    tok = strtok(line, field_delim);
    if (tok != NULL) {
      n = strlen(tok);
      if (n >= 2) {
        void *map = (char *)client + 0x116c;
        mode = 0;
        do {
          /* EAX=mode, ECX=map, stack=tok */
          slot = FUN_007f9230(tok) & 0xff;
          if (slot != 0) break;
          mode++;
        } while (mode < 4);

        if (mode != 4 && slot != 0) {
          tok = strtok(NULL, field_delim);
          if (tok != NULL) {
            strncpy(primary, tok, 0x1ff);
            alt[0] = '\0';
            tok = strtok(NULL, field_delim);
            if (tok != NULL) strncpy(alt, tok, 0x1ff);

            /* parse primary; BL=0 lane */
            FUN_0092db30(&key_out /* + EBX mod out; EAX=primary */);
            FUN_007f72e0(/* AL=slot BL=0 SI=key DX=mod stack map,mode */);

            /* parse alt; BL=1 lane */
            FUN_0092db30(&key_out /* EAX=alt */);
            FUN_007f72e0(/* AL=slot BL=1 ... */);
          }
        }
      }
    }
    tok = fgets(line, 0x800, file);
  }
  fclose(file);
}
```
