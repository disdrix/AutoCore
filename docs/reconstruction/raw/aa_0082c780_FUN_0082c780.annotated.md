## Machine-level notes

- Source: raw capture + R11-027 live re-verify (`decompile` ≡ raw CF; `disassemble_function` + `read_memory` seal ABI/immediates).
- Prefer assembly when decompiler conflicts (EDI load for `FUN_0090d400`; AL-only false returns).
- **ABI:** `__thiscall` ECX=`this`; stack `(cmdClass, cmdId)`; **`RET 8`**.
- **cmdId 70000** (`0x11170`) with **cmdClass ∈ {8, 0xb, 0xe}** → load child `@+0x2b0` into EDI, call dismiss helper `FUN_0090d400` (ESI=self, EDI=child), return 1.

- **Else:** return 0.
- **DATA entry:** vtable dword `@0x00a732a4` = this VA.
- Dualed Class8 specialization `FUN_0082f510` calls this as base on dead-vehicle divert and non-class-8 / unhandled fallback (when cmdId≠70000). Sibling `FUN_00830aa0` handles 0x11171..0x11173 class-8 then falls through here.
