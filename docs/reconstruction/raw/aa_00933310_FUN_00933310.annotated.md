## Machine-level notes

- **Disasm authority.** Decompiler collapses the body to a single `FUN_00402b30(&stack…)` with `void` formals — false ABI.
- Custom register + stack ABI: **EAX** = item/object* (key seed), **CL** = u8 flag, **5 stack args**, **`RET 0x14`**.
- Sole callee: dualed `StdMap_InsertOrFind_UintKey_Isnil31_EaxEbx_Inferred` (`0x00402b30`) — EAX=map, EBX=value*, stack out, RET 4.
- Map shell: **`client + 0xF14`** (same offset used by `Client_NotifyActiveMissionChanged`).
- Prefer assembly when decompiler conflicts (this unit is a textbook conflict).

## ABI (sealed)

```text
// entry:
//   EAX = ItemObject* (or related object*)  — becomes value.key dword0
//   CL  = u8 flag (callers XOR CL,CL → 0)
//   [ESP+4]  = ClientHost* client
//   [ESP+8]  = int a1        // all sites: 1
//   [ESP+C]  = int a2        // all sites: 0

```

## Control flow (annotated)

```text
SUB ESP, 0x38
// pack value on locals:
//   value+0x00 = EAX            // uint key (item*)
//   value+0x08 = EAX            // mirrored
//   pack a1 byte + CL into mid fields
//   fold a2,a3,a4 into trailing value dwords
//   (also folds uninit local [ESP_sub+0xc] — odd, preserved)

out   = &stack_pair

// discard out
```
