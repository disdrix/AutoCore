## Machine-level notes

- **thiscall** large constructor: ECX → ESI (`8B F1`); returns `this` in EAX (`8B C6`); bare `ret` after local stack cleanup (`83 C4 08 C3`).
- Installs vtbl **`PTR_FUN_009cc770`** at `*this` — same vtbl family as `CVOGSectorMap::StepTo` string plate (`0x009cc79c`).
- Called once from **`Client_InitInstance`** after debug string **`"@@new CVOGSectorMap"`** and `operator_new(0xE920)`.
- Initializes embedded rb-tree headers via dual-sealed `FUN_004e7450` / `FUN_004e7420`, many critical sections, heap subsystem objects, default floats (`g_flOne`), tick stamp, and global **`_DAT_00b03600 = this`**.
