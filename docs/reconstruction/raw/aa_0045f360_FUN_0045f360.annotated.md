## Machine-level notes

- **ABI (register-heavy, MSVC helper):**
  - **EAX** = destination begin (in) / destination end (out)
  - **ECX** = source begin → moved to ESI
  - **EDI** = source end (live-in; not pushed/popped)
  - bare **`RET`** (`C3`); saves/restores ESI and EBX
- **Stride:** each element advances by **`0x1c`** (`ADD reg, 0x1C` ×4 on ESI/EAX/ECX/EDX mid-cursors).
- **Copy body:** when EAX ≠ 0, stores **7 dwords** from src to dst using mid-pointers at `+0x14` (`LEA ECX,[EAX+0x14]`, `LEA EDX,[ESI+0x14]`).
- **Null dest:** `TEST EAX,EAX; JE` skip stores but still advance all cursors (counting / dry-run style).
- **Empty range:** `CMP ESI,EDI; JE` early out — EAX unchanged.
- **Classification:** leaf (no CALL).
- **Callers:** only `StdVector_InsertN_Pod28` (`0x0045cd30`) — grow path relocate head/tail + in-place arms (4 sites).
- **Decompile gap:** void / single formal; omits EAX/EDI contract and EAX-as-end return. **Bytes + parent sites win.**

## Pseudocode (bytes authority)

```c
// EAX=dst, ECX=src_begin, EDI=src_end; bare RET; EAX = dst + n*0x1c
void* StdUninitCopy_Pod28(void* dst, const void* src_begin, const void* src_end)
{
  if (src_begin == src_end)
    return dst;

  do {
    if (dst != nullptr) {
      uint32_t* d = (uint32_t*)dst;
      const uint32_t* s = (const uint32_t*)src_begin;
      d[0] = s[0]; d[1] = s[1]; d[2] = s[2]; d[3] = s[3];
      d[4] = s[4]; d[5] = s[5]; d[6] = s[6];
    }
    src_begin = (const char*)src_begin + 0x1c;
    dst       = (char*)dst + 0x1c;
  } while (src_begin != src_end);

  return dst;
}
```
