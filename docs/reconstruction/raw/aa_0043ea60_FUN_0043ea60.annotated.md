## Machine-level notes

- **ABI (custom register this):** container **`this` in EBX** (entry `MOV EAX,[EBX+8]`; no `MOV EBX,ECX`); **`uint min_grow`** stack formal; **`RET 0x4`**. Not `__thiscall`.
- **Layout (matches push siblings `0043e970` / `0043e9e0`):**
  - `+0x04` — `void **slots` (heap block-pointer map)
  - `+0x08` — `uint capacity`
  - `+0x0C` — `uint begin` (element index; block = `begin >> 1`)

- **Allocate / rebalance / zero / commit:** same structure as family; only **head extract is `>>1`** (`D1 ED` vs `C1 ED 02`).
- **Commit:** optional `operator_delete` then `capacity += grow`, `slots = neu` (bytes; decompiler plate wrong).
