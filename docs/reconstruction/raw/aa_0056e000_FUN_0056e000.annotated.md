## Purpose (structural)

**Apply per-target damage for a resolved hit list** (vtable worker; sibling of `Weapon_TryFireResolveHits_Inferred` / `0x0056c860`).

Requires non-null weapon source id at adjustor **`+0xB0`**. Loops `i = 0 .. count-1` over `targets[i]` pointer array:

1. Optional **distance falloff** when `this+0xE0 != 0`: first target anchors world pos; subsequent scale  
   `local_84 = 1.05f - dist(pos_i, pos_0) / *(float*)(this+0xE0)`.
2. Call target **`vtbl+0x4C`** with attacker adjustor base, weapon fields `+0x124` / `+0x130`, and out-flags → base damage int.
3. Scaled damage `iStack_90 = (int)(base * local_84)`.
4. If damage **&lt; 1**: maybe still report residual flags via `FUN_0056ff00` (miss / shield tick style).
5. Else: roll critical via `CVOGReaction_RandomUnitScalar` + `FUN_004cf080`; if mult &gt; 1, scale damage; if host `+0xA8` present: status tweak via `FUN_0056add0` (types 1/5 → target `+0xCC = 4`), hit feedback `FUN_0056ff00`, optional `CVOGHBBase` action (`FUN_006335b0` duration 500, def field `+0x52c`) enqueued and started.

Returns **0** if no source `+0xB0`; else **1** after the loop (even when `count==0`).

### Falloff formula

```
// only for i > 0 when this+0xE0 != 0 and body resolve ok
scale = 1.05f - length(pos_i - pos_0) / *(float*)(this + 0xE0)
damage = (int)(baseDamage * scale)
```

First target (`i==0`) stores anchor position; scale stays `g_flOne` (1.0).

### Critical path

```
rng = CVOGReaction_RandomUnitScalar();  // table + wrap at 0x100000
f   = FUN_004cf080(sourceId, target, rngWord);
crit = (f > 1.0f);
if (crit) damage = ROUND(damage * f);
```
