## Purpose

MSVC-style **red-black map/set range erase** for the large-node family (`isnil@+0x29`, same as `Map_EraseNode` / `Map_ExactFindByIntKey`).

Two paths:

1. **Full clear** — `[first, last) == [begin, end)` detected as `first == *head && last == head`: free entire tree via `FUN_0051bbc0(head->parent)`, reset head self-links, `size=0`, `*out = *head`.
2. **Partial range** — while `first != last`: compute in-order successor (inline, isnil@+0x29), call `Map_EraseNode(this, &first, node)`, advance to successor; finally `*out = first`.

## Control flow (annotated)

```c
void __thiscall Map_EraseRange(map, out_it, first, last)
{
  head = map->head;                 // *(map+4)

  // Full-range fast path: erase [begin, end)
  if (first == *head && last == head) {
    FUN_0051bbc0(head->parent);     // free subtree from root (isnil@+0x29)
    head->parent = head;
    map->size = 0;
    *head = head;                   // left = head
    head->right = head;
    *out_it = *head;                // begin after clear
    return;                         // ret 0x0c
  }

  // Partial: erase each node in [first, last)
  while (first != last) {
    succ = first;
    if (!first->isnil) {
      // standard tree successor (right-min or parent climb); isnil@+0x29
      …
    }
    Map_EraseNode(map, &first, first);  // ECX=map; may also write succ to &first
    first = succ;
  }
  *out_it = first;
  return;                           // ret 0x0c
}
```

## Notes / traps

1. Decompiler plate on `FUN_0051cb40(&param_3, node)` **omits ECX** — bytes restore `ECX = map` before call.
2. Free-subtree decompile may show false **noreturn** on `operator_delete` (same trap as `Map_EraseNode`).
3. Distinct from `StdMap_EraseRange_Inferred` (`isnil@+0x15`) and `FUN_0051d700` (`isnil@+0x1d`).
4. Twin `Map_EraseRange_B` (`0x0051d880`) differs only by free-subtree `FUN_0051be90`.
