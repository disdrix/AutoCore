## Purpose (structural)

**Weapon fire attempt + hit resolve + damage/effect dispatch** (vtable worker).

Gates on owner presence, heat/power cost, and owner status flags; zero-fills a hit work buffer; default-fills missing target from owner selected-target slot; calls weapon **`vtbl+0x50`** to resolve the shot; optionally dispatches damage via `FUN_004d7e30` (null-list) or `FUN_004da2e0` (list); post-resolves via **`vtbl+0x48`**. Returns **1** if the gated fire path ran, **0** if any gate failed.

Not a product name — string `"VOG_DEBUG_STOP"` is a **null-host debug assert** only.

## Machine-level notes

- Prefer live decompile CF; large stack locals are decompiler overlays of one resolve buffer.
- Owner fetch pattern is MSVC multi-inheritance adjustor:  
  `owner = (*(code**)(adjThis + 0x214))()` where  
  `adjThis = this + *( *(this+4) + 4 )` (i.e. `param_1[1]` chain).
- Owner flag byte at **`owner_adj + 0xB8`**: reject if **`& 0x10`** or **`& 0x02`**.

- Host pointer at **`weapon + *(weapon+4) + 0xA8`**: null → `FUN_007a4480(0,"VOG_DEBUG_STOP")`.
- Damage source identity at weapon-adjusted **`+0xB0`**; vec4-like args at **`+0x164..+0x170`**.
- Vtable cluster: slot `@0x009d3320` next to `FUN_0056e000` `@0x009d331c` on same table.
