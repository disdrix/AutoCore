## Control-flow map

```
i = 0
loop:
  if i >= width: return rle_state
  if rle_state == 0xFF: read 1 packet byte → pkt
  else: pkt = rle_state; rle_state = 0xFF

  if pkt has high bit (RLE run):
    run = pkt - 0x7F                    // == (pkt & 0x7F) + 1
    if i + run > width:
      rle_state = encode_leftover_RLE   // high-bit form for next row
      pos = stream.vtbl+0x14()          // mark before color sample
      run = width - i
    switch bpp:
      8:  read 1 B; replicate run times (1 B/px)
      15/16: read 2 B; expand to 24-bit RGB; replicate (3 B/px write)
      24: read 3 B; replicate (3 B/px)
      32: read 4 B; write RGB (3 B) + FUN_00433280(A) per pixel
    if rle_state != 0xFF: stream.vtbl+0x10(pos, 0); // rewind color for resume
  else:  // raw packet
    run = pkt + 1
    if i + run > width:
      rle_state = encode_leftover_raw
      run = width - i
    FUN_00434dd0(image, bpp_holder, run, param_6, i)  // uncompressed pixels

  if *(short*)(image+0x16) == 0x18: dest += run * 3
  else: dest += run
  i += run
  goto loop
```
