## Machine-level notes

- **Body (6 bytes):** `8B 41 04 C2 04 00`
  - `mov eax, dword ptr [ecx+4]`
  - `ret 4` — cleans **one** stack dword (the zone name pointer)
- Decompiler shows only ECX/`param_1` load; **does not surface** the unused stack name or `ret 4`.
- Callers universally:
  1. Load **`ECX = *(DAT_00d1f040)`** (global current profiler context / zone).
  2. **`push` string literal** zone name (`"CVOGSectorMap::StepTo"`, `"LoadMasterFromXML"`, …).
  3. `call FUN_0076cf00`.
- Name argument is **ABI-compatible dead weight** in this retail image — body never reads it (stripped / disabled instrumentation body).
- Return value = **`*(ctx+4)`**. Sibling zone ctor (`Profiler_Zone_Ctor` `0x00786280`) stores `Profiler_TimerBlock*` at **zone+4** after `new(0x30)` + `Profiler_TimerBlock_Ctor`.
- Paired leave **`FUN_0076cef0`** @ `0x0076cef0` is pure **`ret`** (`c3`) — no stack cleanup (leave takes no args in this build).
- **Not** gameplay logic; ignore for physics/server ports (matches existing drive/step notes).
