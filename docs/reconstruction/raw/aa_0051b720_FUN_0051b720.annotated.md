## Machine-level notes

- **Leaf** thiscall on RNG singleton (`DAT_00d20c1c` via `CVOGReaction_RandomUnitScalar`).
- Layout (shared with `Rng_CloneSeededTable_Inferred` / `FUN_007a4170`):
  - `this+0x08` = `uint8_t*` / ushort table base (2 MiB after init)
  - `this+0x0C` = int cursor (ushort index)
- Wrap: if `cursor + nWords > 0xFFFFF` → `cursor = 0` (headroom for `nWords` ushorts in 0x100000-entry table).
- Copy: `nWords * 2` bytes via `rep movsd` + residual `rep movsb` from `table + cursor*2` → `dst`.
- Advance: `cursor += 1` (not `+= nWords`) — **preserve** sliding-window side effect.
- **Return EAX = pre-increment cursor** (decompiler void is wrong). Used as `lDiceSeed` (`packet+0x3C`) under world sim flag `world+0x7e`.
- Sibling: `Rng_CloneSeededTable_Inferred` (`0x0058ab60`) = alloc 0x4B0 + force seed + fixed-600 inline copy of same algorithm.
- Single-word unit draw: `FUN_007a4170` (u16 * 1/65536).

// Returns pre-increment cursor (uint32) in EAX
uint32_t Rng_CopyUnitTableWindow_Inferred(
    RngHost* this,       // ECX — typically &DAT_00d20c1c
    int nWords,          // stack+4 — ushort count to copy (callers use 600)
    void* dst)           // stack+8 — destination buffer (nWords*2 bytes)
{
  if ((this->cursor + nWords) > 0xFFFFF) {
    this->cursor = 0;
  }
  uint8_t* src = this->tableBase + this->cursor * 2;
  // bulk: (nWords*2)/4 dwords + (nWords*2)%4 bytes
  memcpy(dst, src, (size_t)nWords * 2);
  uint32_t oldCursor = (uint32_t)this->cursor;
  this->cursor = this->cursor + 1;
  return oldCursor;
}
