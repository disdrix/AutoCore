## Machine-level notes

- **ABI:** `__thiscall` — ECX = list host; stack **four** dwords (`unused, unused, tfid_lo, tfid_hi`); **`RET 0x10`**; EAX = **0** always.
- **Mutator:** linear scan of pointer vector at `this+0x38` / `this+0x3c`; on TFID match free entry heap object, zero slot, `memmove` compact, `end -= 4`, **do not advance cursor** (re-examine slid-in element → multi-match erase).
- **Key:** exact int equality of `entry+0x08` / `entry+0x0c` vs stack TFID pair (args 3–4).
- **Unused stack args 1–2:** still cleaned by callee (`RET 0x10`); body never reads them. Caller `FUN_0080eeb0` still pushes a nested +0x164/+0x168 pair before the TFID.
- **False noreturn:** decompiler marks `operator_delete` as noreturn; assembly has `ADD ESP,4` and continues — **delete returns**.
- Prefer assembly when decompiler conflicts — CF matches; ABI width sealed only by `disassemble_function` + `read_memory`.
