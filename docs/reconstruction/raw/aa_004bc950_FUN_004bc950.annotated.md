## Machine-level notes

- Source: raw capture + R10-028 re-verify (decompile + read_memory; no `disassemble_bytes`).
- **ABI:** ECX = list host; bare **`RET`** (`C3`). Decompiler `__fastcall` matches ECX formal.
- Layout (family with `List_TraversalLock` / `List_IterateNext` / `List_RemoveAll`):
  - `+0x04` — `CRITICAL_SECTION`
  - `+0x1c` — head pointer
  - `+0x20`, `+0x24` — companion heads / cleared with head
  - `+0x28` — traversal-lock flag (non-zero blocks DestroyAll)
- Node: vtbl @ `+0`, next @ `+8`. **No** `node[+4]=0` clear (unlike `List_RemoveAll`).
- Product string seals name: `"List Error!  DestroyAll Call Stack:\n%s\n"` @ `0x00a33af0`.
- Mid-body SEH landing (chkstk `0x1004`, stack walk, `VOG_DEBUG_STOP` @ `0x00a15844`) is **not** main CF — decompiler correctly omits from primary path.
- Throw `0x80070005` when locked (same HRESULT as `List_RemoveAll` / `List_IterateNext` lock fail).
- Used primarily from list-host **dtors** (vtbl switch + DestroyAll + DeleteCS) and inventory grid sort teardown of stack-local hosts.
