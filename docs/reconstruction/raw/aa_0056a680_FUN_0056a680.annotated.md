## Machine-level notes

- **thiscall**, stack `char bSkipScale` @ `[esp+8]` after push; epilogue **`ret 4`**.
- Base value: **`this+0xD0`** (int ms). Sibling setter `FUN_0056a1b0` writes same offset (clamp min 1).
- Related object: MI-style load `*(this + *( *(this+4) + 4 ) + 0xB0)`.
- Scale source: related `vtbl+0x214` thrice (null check / read float / multiply) → float at **`blob+0x1E8`**.
- Identity scale short-circuit: `ucomiss` vs **`g_flOne` @ `0x00a0f2a0`** (= 1.0f).
- Round bias for floor test: **`g_flMissionXpRoundBias` @ `0x00aaa6d0`** (≈0.5001f); return path uses `FUN_0040dab0` (same ±bias then trunc).
- Scaled floor: if rounded product **≤ 500**, return **500**; else return rounded product.
- Callers treat result as **milliseconds** (`* g_flMsToSeconds` for DPS / arc timing).
