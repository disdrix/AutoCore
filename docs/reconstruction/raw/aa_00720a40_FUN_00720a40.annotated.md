## Purpose

**In-place constructor / field initializer** for the process-wide sound manager object.

Sole caller: `CSoundManager_GetInstance` (`0x00720d40`) which invokes  
`FUN_00720a40(&DAT_00d20070)` once under once-flag `DAT_00d20200` bit0, then registers atexit teardown.

Product family sealed by sibling string at `FUN_00723ab0`:  
`"CSoundManager::_stopSound called with sound that was either already stopped(%d), or flagged to start playing(%d)"`.
