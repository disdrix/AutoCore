## Machine-level notes

- **ABI:** thiscall — **ECX** = character*, stack item*, **ST0** float return, **`RET 4`**.
- **CBID slots are ints**, not floats. Sentinel is **`-1`** (`0xFFFFFFFF`). Decompiler `float`/`-NAN` is a type error; assembly `CMP reg,-1`.
- **Type `0x1a`** = crafting materials (matches dualed parent string "You cannot Reverse Engineer crafting materials").
- **Skill field** `character+0x598` is a **byte** scaled by tier multipliers (3.5 / …).
- **Free flag** `character+0x6b4 >= 1` short-circuits to **1.0** (100% after caller ×100).
- **Object map** `*(DAT_00b041fc + 0xf10)` hash: mask at `+8`, buckets at `+10`, chain `+0xc`, key `+0x10`, payload `+8`.
- **CloneBase path:** live object `+0x3c` may be null → `FUN_004f1e20(1,1)`; type at object/`clone` `+0x38`; material rank byte at clone def `+0x4c8`.
- **Score formula** ends with `×0.01` and cap **0.95**; UI multiplies by **100** and clamps to **100** then prints `%.01f%%`.
