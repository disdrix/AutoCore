## Machine-level notes

- **Role:** MSVC-style `list::_Buynode` for **dword/pointer** payload nodes (size **0xC**).
- **SEH:** Full FS:[0] frame (`LAB_009bc331`); twin `StdList_BuyNode_Dword` @ `0x006759b0` is the **non-SEH** 39 B clone of the same fill CF.
- **ABI:** `__stdcall` three stack args; **`RET 0xC`**. Return **EAX** = node* (0 if `operator_new` fails). Decompiler `void` is wrong — call sites capture EAX.
- **Layout written:**
  - `node+0x00` = link0 (arg1) — insert callers treat as **prev**
  - `node+0x04` = link1 (arg2) — insert callers treat as **next**
  - `node+0x08` = `*pValue` (arg3 dereference) — single dword value
- **Does not** increment list size or rewire links; callers do Incsize (`FUN_00404840` / peers) + `head[+4]=node; *node[+4]=node`.
- Prefer assembly when decompiler conflicts (return type; EH locals).
