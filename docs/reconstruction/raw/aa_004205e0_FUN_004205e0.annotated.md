## Machine-level notes

- **No stack formals.** Context is **`ESI`** (`unaff_ESI` in Ghidra) — register convention shared with rebind/bind helpers.
- Sole caller: `FUN_0041c000` (`OleDb_RebindAccessor_Inferred`). Used as post-bind gate: if return `< 0` and accessor handle still set → ReleaseAccessor again.
- Layout of ESI context (decompiler-derived):
  - `ESI[0]` → iface pointer (vtable host)
  - `ESI[2]` → binding table object
  - `ESI[3]` → third arg to vtbl method (row/bind context)
- Binding table (`ESI[2]`):
  - `table[0]` / `*table` → entry base
  - `table[1]` / `*(table+4)` → entry count
  - `table[2]` → fourth arg to vtbl method
- Each entry stride **8**:
  - `entry+0` dword passed to vtbl+0x10
  - `entry+4` byte flag; **non-zero** ⇒ active, invoke method
- Call shape: `hr = (**(iface->vtbl + 0x10))(iface, ESI[3], entry_dword, table[2])`
  - On standard `IAccessor`, slot `+0x10` is **CreateAccessor** (see dual of `aa_004231d0`). Exact product method name remains inferred if custom vtbl.
- Returns first negative HRESULT, else last `hr` (0 if no active entries / all ≥0).
