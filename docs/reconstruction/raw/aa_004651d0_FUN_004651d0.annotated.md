## Machine-level notes

- **Leaf** fill of **N dwords** at dest with `*value`.
- Custom register ABI: **EDI=dest, ESI=count, EDX=value\***; bare `ret`.
- Value is **re-read each iteration** from `[edx]` (not hoisted) — matches `StdFill_DwordRange`.
- **Does not advance EDX** — same fill word for every slot.
- Early-out when ESI==0 still returns `lea eax,[edi+esi*4]` (= dest).
- Sibling of range-iterator fill `StdFill_DwordRange` (`0x005739b0`); this is **count-based** + returns write end for chaining after realloc prefix.

## Pseudocode (annotated)

```c
// Custom: EDI=dest, ESI=count, EDX=&fill
// Returns dest + count (as uint32_t* end / byte end edi+4*esi)
uint32_t *Mem_FillDwordN_ReturnEnd(/*edi*/ uint32_t *dest,
                                   /*esi*/ int count,
                                   /*edx*/ uint32_t const *value)
{
  uint32_t *p = dest;
  for (int i = count; i != 0; --i) {
    *p = *value;   // re-read [edx] each iter
    ++p;
  }
  return dest + count;  // lea eax,[edi+esi*4]
}
```
