## Fallthrough semantics (sealed)

If the mapped type's table misses, control **falls into subsequent case bodies** in the compiler's case layout order (not sorted numeric). A miss on type 0xC will attempt 0x1C helper, then 0xA, … before default. Clean must preserve fallthrough — not insert `break` on miss.
