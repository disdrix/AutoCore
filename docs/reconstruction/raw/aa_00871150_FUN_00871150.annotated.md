## Purpose

Refresh a bank of optional child widgets on a UI host from a **tracked node** (id pair + small fields). Early-out if host is not visible (`vtbl+0x3d8`) or node is null. Optionally re-highlight widgets when the node's id pair matches the global selection (`DAT_00d1b6d8`).

---

## ABI (bytes-sealed)

```
// this in EAX (caller: mov eax, esi before call)
// arg0 = node (ret 4)
void UiHost_RefreshTrackedNodeWidgets_Inferred(UiHost* host /*EAX*/, TrackedNode* node /*stack*/);
```

Prologue: `sub esp,0x108`; load node into EBP; `mov esi, eax` (host).
Epilogue: `add esp,0x108; ret 4`.

## Annotated control flow

```c
void UiHost_RefreshTrackedNodeWidgets_Inferred(UiHost* host /*EAX*/, int* node /*stack*/)
{
  // 1. Gate: host visible?
  if (!host->vtbl[0x3d8/4](host)) return;
  if (node == NULL) return;

  // 2. Format helper from node+0x1c (bytes: CL = *(u8*)(node+0x1c) - 0x0f)
  FUN_007fd970((uint8_t)((*(uint8_t*)(node + 0x1c/4 /*byte*/) ) - 0x0f)); // see bytes

  int idA = node[2]; // +0x08
  int idB = node[3]; // +0x0c

  // 3. Optional widgets (host dword indices)
  // +0x5e8 [0x17a]: sprintf "%d"; vtbl+0x45c/460/464/34c with idA/idB
  // +0x5ec [0x17b]: flag=1 path; vtbl+0x45c/464/34c
  // +0x5f0 [0x17c]: FUN_0051fa10; FUN_0051f910; sprintf "%d/%s/%s"; bind
  // +0x5f4 [0x17d]: if present:
  //     if host+0x50c == -1: always set text path
  //     else if host+0x50c == (short)node[+0x1c]: match text path
  //     else: alternate text path (same vtbl+0x45c call in decomp — residual arg loss)
  //     then vtbl+0x464 + 0x34c
  // +0x600 [0x180]: FUN_008705c0; bind like 0x17a
  // +0x5fc [0x17f]: sprintf "%d/%d"; bind; second 0x460 with -*(u16*)(node+0x14)
  // +0x5f8 [0x17e]: sprintf "%d"; bind

  // 4. If DAT_00d1b6d8 selected id pair == (idA,idB):
  //    for each non-null widget in bank: vtbl+0x464()  // re-select / highlight
}
```

### Widget bank map

| Host dword idx | Byte | Format / notes |
|---|---|---|
| `0x17a` | `+0x5e8` | `"%d"` + full bind (45c/460/464/34c) |

| `0x17c` | `+0x5f0` | `"%d/%s/%s"` via 0051fa10/0051f910 |
| `0x17d` | `+0x5f4` | gated by `host+0x50c` vs `short(node+0x1c)` |
| `0x180` | `+0x600` | via FUN_008705c0 |
| `0x17f` | `+0x5fc` | `"%d/%d"` + ushort@node+0x14 |
