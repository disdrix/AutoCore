## Purpose

When the skill panel is in mode `*(panel+0x51c) == 1` and a local session host exists, refresh the two **shared skill-column** UI widgets (`panel+0x744`, `panel+0x748`) with a localized hint:

> `"This column of skills is shared by the <ClassName> class."`

Class names come from dualed `LookupClassDisplayName_Inferred` (`0x0051f940`) using a **hard-coded 12-pair class-share table** indexed by the local character's `(classId@+0x531, raceId@+0x532)`.

## Control flow

```
Locale_GetInstance → ESI
if DAT_00d1b6d8 == 0: return
build 24-dword share table on stack
if *(EDI+0x51c) != 1: return
if *(EDI+0x744) != 0:
    resolve local char blob via d1b6d8 chain → +0x3c
    classId = blob+0x531; raceId = blob+0x532
    sharedA = table[(classId + raceId*4)*2]
    name = LookupClassDisplayName(sharedA, raceId)
    ring-localize name + "class" + prefix
    sprintf "%s %s %s." → "This column of skills is shared by the <Name> class."
    widget(+0x744)->vtbl[+0x308](buf)
if *(EDI+0x748) != 0:
    same with table[... *2 + 1] → widget +0x748
return
```

## Share table (product constants)

Index `i = classId + raceId * 4` (class 0..3, race 0..2 → i 0..11).

| i | A (col +0x744) | B (col +0x748) | Class-line reading (via 0051f940 families) |
|--:|---:|---:|---|
| even 0,2,4,6,8 | 1 | 3 | Engineer-line ↔ Ranger-line |
| odd 1,3,5,7,9 | 0 | 2 | Commando-line ↔ Officer-line |
| 10 | 3 | 1 | Ranger ↔ Engineer (swapped) |
| 11 | 2 | 0 | Officer ↔ Commando (swapped) |
