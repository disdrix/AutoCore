## Algorithm

1. If `map->size > 0x4444442` → `"map/set<T> too long"` length_error path (inlined exception + vftables) → `_CxxThrowException(..., DAT_00acc388)`.
2. `FUN_00568f60(head, where, head, value, color=0)` → `new(0x4C)`, copy 15 dwords, red, isnil=0.
3. `map->size++`.
4. Link under `where` (empty / left / right + extremum updates) — same shape as string-key insert.
5. RB fixup while parent color red (`+0x48 == 0`):
   - uncle red → recolor + climb.
   - uncle black: `FUN_00568b70` left rotate / `FUN_005681a0` right rotate as needed.
   - parent-is-right outer path: grandparent left-rotate **inlined** (isnil checks at `+0x49`).
6. Root black; `*outIt = newNode`; `ret 0x10`.
