## Purpose

**Boolean prerequisite gate for tinker-kit use:** does the candidate item’s type match the kit’s host type family (or the type-6 subtype remap pair `0x44`/`0x46` ↔ subtypes 10/11)?

Sole static caller: `FUN_00513c10` (partition residual `Item_ValidateTinkerKitUse`). Fail → parent returns status `3` (prereq fail). Pass → parent continues skill/level/charge checks.
