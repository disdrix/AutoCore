## Purpose

Call **IAccessor::CreateAccessor** (`vtbl+0x10`) on the COM interface in **EAX**, then free per-binding heap pointers at offset **`+0x14`** for `cBindings` entries (stride **`0x48`**). Returns the CreateAccessor **HRESULT**.

Used from DB bind / mission-db load plumbing (`FUN_00421677`, `FUN_004229e0` QI-extract path).

## Signature (byte-sealed ABI)

```c
// Custom multi-register + stack convention (decompiler understates)
// EAX = IAccessor* iface          (phantom in_EAX)
// ECX = DBCOUNTITEM cBindings
// EDX = DBBINDING* / binding-row base (stride 0x48)
// [esp+4] = HACCESSOR* phAccessor
// [esp+8] = DBLENGTH cbRowSize     (inferred labels)
// returns HRESULT in EAX
HRESULT OleDb_IAccessor_CreateAccessor_FreeBindings(
    /*EAX*/ IAccessor *iface,
    /*ECX*/ uint32_t cBindings,
    /*EDX*/ uint8_t *bindings,
    /*stack*/ void *phAccessor,
    /*stack*/ uint32_t cbRowSize);
```

| Formal | Location | Conf |
|---|---|---|
| iface | **EAX** | **High** (vtbl load `MOV EDX,[EAX]`) |
| cBindings | **ECX → ESI** | **High** (loop counter) |
| bindings | **EDX → EDI** | **High** |

## Pseudocode (annotated, image-faithful)

```c
// Prefer this over raw decompiler (which collapses args + free loop)
HRESULT __regcall CreateAccessor_FreeBindings(
    IAccessor *iface /*EAX*/,
    uint32_t cBindings /*ECX*/,
    uint8_t *bindings /*EDX*/,
    HACCESSOR *phAccessor /*stack1*/,
    DBLENGTH cbRowSize /*stack2*/)
{
    void **vtbl = *(void ***)iface;
    uint32_t flags = 2; // DBACCESSOR_ROWDATA
    if (*(int32_t *)(bindings + 0x24) != 0)
        flags = 3; // ROWDATA | PASSBYREF (0x1) — inferred OLE DB names

    HRESULT hr = ((CreateAccessor_fn)vtbl[0x10/4])(
        iface,
        flags,
        cBindings,
        bindings,
        cbRowSize,
        phAccessor,
        /*rgStatus*/ NULL);

    // Always attempt free when cBindings != 0 (independent of hr)
    uint8_t *p = bindings;
    uint32_t n = cBindings;
    while (n != 0) {
        operator_delete(*(void **)(p + 0x14));
        p += 0x48; // 0x14 + 0x34
        --n;
    }
    return hr;
}
```

## Machine notes

- Prologue saves EBX/ESI/EDI; epilogue restores; plain **`RET`** (caller cleans stack args).
- Free loop uses **cdecl** `operator_delete` (`ADD ESP,4`).
- Decompiler `WARNING: Subroutine does not return` on `operator_delete` is **false**.
- Binding stride **0x48** may wrap/pad beyond bare MS `DBBINDING` (often ~0x34) — layout is image-defined.
