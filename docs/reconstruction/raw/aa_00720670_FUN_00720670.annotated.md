## Machine-level notes

- **Prologue:** MSVC SEH (`push -1` / `push LAB_009abd9c` / `fs:[0]`), save `ESI=ECX` (this), `EDI = this+0x170` (critical section).
- **Lock:** `EnterCriticalSection(this+0x170)` — same CS as `CSoundManager_Ctor` dual (`aa_00720a40`).
- **Mode / flag** (Ghidra `in_stack_000000bc` / `in_stack_000000c0`):
  - Relative to **entry ESP**: mode dword @ `+0xBC`, flag byte @ `+0xC0`.
  - Inside the **0xC8** request blob starting at entry `ESP+4`: mode @ **+0xB8**, flag @ **+0xBC**.
  - Flag @ request `+0xBC` matches compact-scan field in `FUN_00720090` (dword index `0x2F` in 0x32-dword elements).
- **When `compactFlag != 0`:**
  - mode `1` → `FUN_00720090(this)` then `this+0x13 = 1`; goto join
  - mode `2` → compact then `this+0x14 = 1`; goto join
  - other modes: fall through to non-flag branch
- **When flag is 0 (or non-1/2 under flag):**
  - mode `1` → `this+0x13 = 1`
  - mode `2` → `this+0x14 = 1`
  - mode `5` → `this+0x15 = 1`
  - else: no sticky-byte write
- **Always (join `LAB_007206f4`):**
  - `FUN_004804d0(this+0x70, &request)` — push-copy **200-byte** element into growable vector at `this+0x70` (callee divides spans by 200).
  - `LeaveCriticalSection(this+0x170)`
  - SEH teardown; **`ret 0xC8`**
- **IAT:** EnterCS `[0x009c61bc]`, LeaveCS `[0x009c61b8]` (body absolute indirs).
- **Not** stop path — deactivate sibling uses `FUN_007203b0` (MarkStopByName family). Activate FX list `FUN_004b6fc0` copies 0x32 dwords then GetInstance + this.
