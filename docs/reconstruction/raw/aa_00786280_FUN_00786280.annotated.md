## Machine-level notes

- **ABI:** **ECX = parent Zone\*** (nullable), **stack0 = self Zone\*** (pre-`new(0x5c)`), **stack1 = const char\* name**, **`ret 8`**, returns **self in EAX**.
- Ghidra labels this `__thiscall` with `param_1=ECX` (parent), `param_2=self`, `param_3=name` — parent is **not** the constructed object.
- Alloc size for zone: **0x5c** (both callers).
- Child name map: MSVC-like tree header via `FUN_0044e100` → node `0x30`; circular left/parent/right; nil byte `+0x2d=1`; size at zone `+0x24=0`. Insert API used elsewhere: `FUN_004309c0(zone+0x1c)`.
- Child pointer vector zeroed at `+0x10/+0x14/+0x18` (begin/end/cap pattern).
- Timer: `operator_new(0x30)` + `FUN_00780730` (ESI) → `zone+4`; OOM → `zone+4=0`.
- Byte `+0x58 = 1` (active/valid flag — exact English open).
- **`+0x0c` not written** by ctor (gap dword between parent and vector).
- SEH: handler `LAB_009ac29c`; state 0 during map header, state 1 during timer new+ctor.
