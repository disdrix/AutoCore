## Machine-level notes

- Source: raw + live Ghidra `decompile_function` / `read_memory` (no `disassemble_bytes`).
- **ABI sealed:** **this in ESI** (callers `mov esi, <reader>`); zero stack args; plain `ret`; EAX = FOURCC or 0.
- **Not** the same thiscall-as-ECX convention as `stoChunkReader_OpenChunk` (`0x0076a2c0`).
- Saves absolute stream cursor `this+0x1c + this+0x18` before any read; restores after — **peek**, not consume.
- Also snapshots/restores pending token string at `this+0x404c`.
- Binary (`+0x4044 == 0`): call `OpenChunk`, read ring tag via `FUN_00436220`, **decrement nest** `+0x4040` (undo open bookkeeping).
- Text (`+0x4044 == 1`): require keyword `"CHUNK"`, parse tag token, require length 4, pack big-endian FOURCC (matches decomp CONCAT byte reverse).
- Other mode values: return 0 after restore.
- Callers treat EAX as tag: e.g. `cmp eax, 'PARM'` in `effEffect_Unserialize`.

## Control flow (condensed)

```
tag = 0
pending_copy = this->pending(+0x404c)

if (mode(+0x4044) == 0) {                    // binary

    tag = *RingTopTagSlot(this)              // FUN_00436220
    if (--nest(+0x4040) == 0) active(+0x403c) = 0
  }
} else if (mode == 1) {                      // text
  tok = ReadToken(this, 1)                   // FUN_00767840
  if (ok && tok == "CHUNK") {
    if (ReadTagToken(this) ok                 // FUN_00769b70

  }
}

SeekTo(save_cursor)                          // rewrite +0x18/+0x1c/+0x20 if in range
this->pending = pending_copy
return tag
```
