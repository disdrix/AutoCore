1. **Resolve** `Object_ResolveFromTFID(node+0x10)`.
2. **Dead entry** (resolve → 0):
   - If node TFID matches current selected target at MI-adjusted `+0x44/+0x48/+0x4c`, call host `vtbl+0x258` with null TFID (`DAT_009cb8c0..`).
   - In-order successor (isnil@+0x29); erase node via `StdTree_EraseAndRebalance_Isnil29`.
3. **Live entry**:
   - If `obj->vtbl+0x210(0) != 0` → **return obj**.
   - Else if `obj->vtbl+0x214()` yields a related object, copy TFID blob `@+0x228..+0x234`, run `Object_ResolveTfIdVtbl1dc`; non-zero → **return obj**.
   - Else successor only (keep node).
4. Exhaust map → **return 0**.
