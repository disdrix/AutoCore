## Machine-level notes

- Source: raw capture for `aa_00403450` reconfirmed live 2026-07-29.
- **ABI (sealed):** `__thiscall` — ECX = string object (`char**` data pointer at `+0`); stack `LPCWSTR wide`, `UINT codePage`; **`ret 8`**.
- **SSO / heap gate:** convert size `_Size = (lstrlenW(wide)+1)*2`. If `_Size > 0x80`, `malloc(_Size)` into `*this`; if ≤ `0x80`, **does not** rebind `*this` (caller must already point at inline buffer, typically `this+4` via `FUN_00402d50`).
- **Null wide:** `*this = 0`; return (no convert).
- **OOM:** `FUN_004048e0(0x8007000E)` → `_CxxThrowException` (E_OUTOFMEMORY).
- **Convert fail:** `WideCharToMultiByte == 0` → `FUN_004048c0` → `GetLastError` as HRESULT → throw.
- **Does not free** a prior heap `*this` before rebinding on large path (init/fresh-object pattern; sibling `00402d50` always rebinds to inline first).
