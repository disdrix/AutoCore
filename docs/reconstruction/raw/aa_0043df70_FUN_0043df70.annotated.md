## Machine-level notes

- **ECX = container** (`MOV EAX,[ECX+0x10]` entry). Not EAX (unlike PushFront/PushBack).
- `size` at `+0x10`, `begin` at `+0x0c`.
- Pure bookkeeping pop_back: decrement size; if empty, zero begin.
- Does **not** destroy the logical back element or free pages — callers (SEH catch / insert undo) handle object lifetime separately.
- Sibling pop_front bookkeeping: `FUN_0040d980` (EAX container; begin++ with wrap).
- Used from InsertN / related SEH cleanup as named in W29-A (`pop_back FUN_0043df70`).

## Pseudocode (sealed)

```c
// ECX = GuardedVectorHeader*
void GuardedVector_PopBack(GuardedVectorHeader* container /*ECX*/)
{
  int size = container->size;           // [ECX+0x10]
  if (size == 0) return;
  size -= 1;
  container->size = size;
  if (size == 0)
    container->begin = 0;               // [ECX+0x0c]
}
```
