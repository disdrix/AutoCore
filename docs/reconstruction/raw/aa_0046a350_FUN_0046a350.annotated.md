## Machine-level notes

- **ABI (register-only leaf):**
  - **EAX** = destination begin (in) / destination end (out)
  - **EDX** = source begin
  - **EBX** = source end (half-open)
  - bare **`RET`** (`C3`); saves/restores ESI, EDI
- **Stride:** each element advances by **`0x1C`** on both EDX and EAX.
- **Copy body:** when EAX ≠ 0: `MOV ECX,7; MOV ESI,EDX; MOV EDI,EAX; REP MOVSD` (7 dwords = 0x1c).
- **Null dest:** `TEST EAX,EAX; JE` skip stores but still advance cursors.
- **Empty range:** `CMP EDX,EBX; JE` early out — EAX unchanged.
- **Classification:** leaf (no CALL).
- **Callers:** only `FUN_00469f50` (`StdVector_InsertN_Elem28_ValueEdx_Inferred`, W34-Q) — 4 sites on grow relocate + in-place arms.
- **Decompile gap:** invents unused `__fastcall param_1`; marks `in_EAX` phantom. **Bytes + parent sites win** (parents publish `MOV [EDI+8],EAX` from return).
- **Peers:** `StdVector_UninitializedCopy_Elem28_Inferred` (`0x004673b0`, ECX first / stack last); `StdUninitCopy_Pod28` (`0x0045f360`, ECX first / EDI end).
- **Reject** scaffold long `Named_CalleeOf_…_0046a350`.
