## Machine-level notes

- **Role:** allocate a **0x28-byte** node and install **circular next/prev** (`*node = node`, `*(node+4) = node`). Return node* in **EAX**.
- **ABI:** no formals; bare **`C3`**; cdecl `operator_new` cleaned with `add esp,4`.
- **Bytes ≡ decompile CF** for stores; decompiler `void` return is **wrong** (EAX preserved through stores).
- **Family:** identical control flow to `StdList_AllocSentinel_0xC_Inferred` (`0x004933f0`, also 26 B) with size **0x28** instead of **0xC**. Non-SEH (contrast SEH `0x0040fb90` 0xC factory).

## Control flow (annotated)

```
push 0x28
call operator_new          ; EAX = node or null
add esp, 4
test eax, eax
jz  skip_next
  mov [eax], eax           ; next = self
skip_next:
lea ecx, [eax+4]
test ecx, ecx              ; null+4 → 4 (non-null); only nulls if EAX null and path hit
jz  skip_prev
  mov [ecx], eax           ; prev = self
skip_prev:
ret                        ; EAX = node*
```
