## Machine-level notes

- **ABI (bytes):** **`ESI` = client\*** (not ECX thiscall); stack **`short size`**, **`void* buffer`**; epilogue **`ret 8`**.
- **Connection slot:** `client+0xc7c` — global/net companion to sector `client+0xc78` used by `Client_SendSectorPacket`.
- **Ready gate:** `conn->vtbl[+0x08]()` must return non-zero; else **`E_FAIL` (`0x80004005`)**.
- **Null conn:** also **`E_FAIL`** (unlike sector silent drop).
- **Send:** `conn->vtbl[+0x18](0xFFFFFFFF, buffer, (int)size, 0)` — reliability flags **hardcoded 0** (GuaranteedOrdered in TNL domain used by sector sibling).
- **Success:** **`xor eax,eax` → 0**.
- **Callers:** chat global `0x8000` (`Client_SendChatOrMacro`), dismiss modal `0x8006`, force-quit dialog, many UI/global C2S builders (50+ xrefs).

{

  if (conn != 0) {
    char ready = (*(char (**)(void))(*conn + 8))(); // vtbl+0x08

    }
  }
  return 0x80004005;
}
