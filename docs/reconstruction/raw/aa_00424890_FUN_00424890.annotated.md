## Machine-level notes

- Source: raw capture for `aa_00424890` + live Ghidra re-seal (W19-A).
- **Leaf** MT19937 **seed / state-fill** (not twist, not temper/extract).
- Multiplier **`0x6c078965`** (= 1812433253) is the standard MT19937 initialization constant.
- Loop bound **`0x270`** = N = 624 words.
- Right-shift **`0x1e`** = 30 bits — classic `mt[i-1] ^ (mt[i-1] >> 30)`.
- Does **not** write cursor (`+0x9c0`) or remaining (`+0x9c4`); those are set by twist sibling `Rng_Mt19937_Twist` (`0x004248c0`).
- Callers (`FUN_007a4200` table fill, `FUN_007a42d0` ctor) typically chain seed → twist after this returns.

### ABI (byte-sealed)

```
EAX = uint32* mt          ; state array base
EDX = uint32 seed         ; mt[0] = seed
ECX = i (1..623)          ; scratch counter
RET near (C3); 0 stack args
```

### Formula (exact)

```
mt[0] = seed
for i = 1 .. 623:
    mt[i] = 0x6c078965 * (mt[i-1] ^ (mt[i-1] >> 30)) + i
```

## Pseudocode (annotated; types recovered)

```c
// Structural: Rng_Mt19937_Seed
// Ghidra shows unused param_1; real ABI is EAX=mt, EDX=seed.
void Rng_Mt19937_Seed(uint32_t *mt /*EAX*/, uint32_t seed /*EDX*/)
{
  int i;

  i = 1;
  *mt = seed;                         // mt[0]
  do {
    // mt[i] = f(mt[i-1], i)  with pointer walk: write mt[i] via [eax+4], then eax += 4
    mt[1] = (*mt >> 0x1e ^ *mt) * 0x6c078965u + (uint32_t)i;
    i = i + 1;
    mt = mt + 1;
  } while (i < 0x270);                // 624
  return;
}
```
