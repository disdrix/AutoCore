## Machine-level notes

- Source: raw capture + live `decompile_function` + `read_memory` (no `disassemble_bytes`).
- **EDI = BitStream\*** (decompiler `unaff_EDI`); **ECX = extra bits** needed beyond current bit capacity.
- NewSize formula uses **byte-sealed** grouping: `((extra + bitCap + 7) >> 3) + 0x5DC`. Decompiler C text misses parens around the shift.
- Success is **only** the owned-buffer `realloc` path (`AL=1`). Fail sets `+0x1c=1` and `AL=0`.
- `realloc` NULL result is **not** checked (stores NULL, still returns 1) — port hazard.
- IAT `[0x009C650C]` resolves to `realloc` (decompiler + cdecl stack args match).

## BitStream offsets used

| Off | Role | Confidence |
|---|---|---|
| +0x0c | `void*` buffer base | High |
| +0x10 | allocated / tracked size in **bytes** | High |
| +0x14 | owns-heap flag (`char`); must be non-zero to realloc | High |
| +0x1c | error flag set on grow fail | High |
| +0x2c | bit capacity mirror (set = NewSize*8 on success) | High |
| +0x30 | bit capacity (write limit; input to formula) | High |

## Pseudocode (annotated; CF ≡ bytes)

```c
// EDI = BitStream* this; ECX = extraBits (int)
// returns bool in AL
uint BitStream_GrowForBits(int extraBits /*ECX*/, BitStream* this /*EDI*/)
{
  // CORRECT grouping (bytes):
  uint NewSize = ((extraBits + this->bitCap_0x30 + 7) >> 3) + 0x5DC;

  if (this->byteSize_0x10 < NewSize) {
    if (this->ownsBuffer_0x14 != 0) {
      this->byteSize_0x10 = NewSize;
      this->buffer_0x0c = realloc(this->buffer_0x0c, NewSize); // no NULL check
      int bits = NewSize * 8;
      this->bitCapMirror_0x2c = bits;
      this->bitCap_0x30 = bits;
      return 1; // AL=1
    }
    // !owns → fail (also stamps byteSize)
  } else {
    // already byteSize >= NewSize → still fail path
    this->byteSize_0x10 = NewSize;
  }
  // shared fail (also reached from !owns via jump to stamp):
  this->byteSize_0x10 = NewSize; // when coming from !owns
  this->errorFlag_0x1c = 1;
  return 0; // AL=0
}
```
