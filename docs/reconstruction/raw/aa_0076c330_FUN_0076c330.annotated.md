## Machine-level notes

- **Role:** Return **monotonic-ish wall time in seconds** as x87 `float80` (`float10` in Ghidra), computed as `rdtsc / calibrated_ticks_per_second`.
- **Lazy init:** If `DAT_00d1a530 == 0`, call `FUN_0076c270` which pairs `QueryPerformanceFrequency/Counter` with `rdtsc` to store 64-bit **TSC ticks per second** into `DAT_00d1a538:DAT_00d1a53c`, then sets the flag to 1.
- **Divide:** MSVC `__aulldiv` — 64-bit unsigned divide of TSC by scale → integer **seconds** quotient.
- **Fraction:** Low remainder reconstructed as `tsc_lo - quot_lo * scale_lo` (32-bit imul path; decompiler expression matches MSVC u64→f80 convert of full scale for the divisor).
- **Return:** ST0 = `(float80)quot + (float80)rem / (float80)(u64)scale`. Callers typically `fstp dword [...]` (e.g. `NDResource_AcquireInnerObject` → `this+0x1c`).
- **ABI:** No stack args; `RET` only. Not `__thiscall`.
- **Sibling:** `FUN_0076c3c0` is a *different* zone-timer helper (object-relative rdtsc delta × scale) — do not merge.

## Pseudocode (annotated)

```c
// Returns seconds since arbitrary TSC epoch (scale-calibrated).
// float10 == x87 ST0; retail callers often store as float32.
float10 Timer_GetTimeSeconds_Rdtsc(void)
{
  uint64_t tsc;
  uint32_t scale_lo, scale_hi;
  int64_t  quot;   // actually u64 from __aulldiv; used as signed in fild path

  if (DAT_00d1a530 == 0) {
    FUN_0076c270();  // calibrate DAT_00d1a538:53c; set DAT_00d1a530 = 1
  }

  scale_hi = DAT_00d1a53c;
  scale_lo = DAT_00d1a538;
  tsc = rdtsc();

  // quot = tsc / scale  (u64 / u64)
  quot = __aulldiv((uint32_t)tsc, (uint32_t)(tsc >> 32),
                   DAT_00d1a538, DAT_00d1a53c);

  // frac = rem / scale   with rem ≈ low32(tsc) - quot_lo * scale_lo
  // scale u64→f80 uses MSVC sign-bit split on high dword (see raw decompile)
  return (float10)quot
       + (float10)((int32_t)tsc - (int32_t)scale_lo * (int32_t)quot)
         / unsigned64_to_float80(scale_lo, scale_hi);
}
```
