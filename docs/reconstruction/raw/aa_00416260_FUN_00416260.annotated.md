## Machine-level notes

- Same ABI family as vec3 helper: ESI/EDI float pointers + stack rel/abs + `RET 8`.
- Quat layout assumed **xyzw** contiguous floats: index 0=x,1=y,2=z,3=w.
- Positive path compares components in order **w, x, y, z**.
- Negative path builds `-a[i]` via SSE: `XORPS xmm0,xmm0; SUBSS xmm0,[esi+off]; MOVSS [esp],xmm0` then passes that stack slot as second formal to the leaf (leaf formals: a=b_comp, b=negated_a_comp).
- Double-cover: unit quaternions `q` and `-q` represent the same rotation; accepting either is correct SO(3) equality under the dual-gate eps.
