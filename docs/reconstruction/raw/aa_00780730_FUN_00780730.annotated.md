## Machine-level notes

- **Register ABI:** pre-allocated timer block in **`ESI`**; **returns `ESI` in `EAX`**; `ret` (no stack formals).
- Sole caller `FUN_00786280` @ `0x00786313`: after `operator_new(0x30)` success → `mov esi, eax` → `call` → `mov [edi+4], eax` (zone.timer = constructed block).
- Object size **0x30** (alloc at caller). Divisor lives at **`+0x10/+0x14`**.
- Zeroes all sample fields **except** it never zeroes `+0x10/+0x14` before QPF (those dwords receive QPF then the scaled divisor).
- `QueryPerformanceFrequency` via IAT `[0x009c61b4]`; divide via `__alldiv(qpf64, 1000000)`.
- Scaled unit for later accumulate/start paths: **microseconds** (QPF / 1e6 = ticks per µs).
