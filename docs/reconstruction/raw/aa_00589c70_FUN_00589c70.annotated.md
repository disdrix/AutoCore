## Machine-level notes

- **ABI:** `__cdecl`, four stack args, bare `RET` (`C3`). Callers always `ADD ESP, 0x10`.
- **Stack layout after `PUSH EBX/EBP/ESI/EDI`:**
  - `[ESP+0x14]` = `param_1` source / fallback entity
  - `[ESP+0x18]` = `param_2` preferred target object
  - `[ESP+0x1c]` = `param_3` float amount
  - `[ESP+0x20]` = `param_4` char allowKill
- **Entity resolve:** vtbl slot **+0x19C** then MSVC complete-object adjust  
  `LEA ESI, [*( *(*(ret+4)+4) ) + ret + 4]`; fallback field **`+0xAC`** (`param_2[0x2b]`).
- **HP vtbl (on resolved ESI):**
  - **+0x23C** — GetCurrentHp (inferred; matches `FUN_004d78e0` usage)
  - **+0x244** — GetMaxHp (inferred; same)
- **Apply path:** `ECX = [ESI+0xA4]`; `CALL FUN_004d7e30` with signed integer delta. Downstream treats **positive delta as damage** (`HP' = HP - delta`).
- **Percent window:** `amount ∈ [DAT_00aaa668, g_flOne]` = **[-1.0f, 1.0f]**.
- **Floor oddity:** when `!allowKill && projected < 1`, `deltaInt` is rewritten to `cur-1`, but return still uses **pre-floor** `projected - cur`.
- Prefer this annotated note + assembly when decompiler collapses `FUN_004d7e30` thiscall / color-by-value args.

## Pseudocode (annotated)

```c
// __cdecl; returns projected HP delta (heal +, damage −); 0 on fail / no-op
int Skill_HB_ApplyHpDelta_Inferred(
    void *sourceOrNull,   // param_1 — attacker/source forwarded to floater path
    void *targetObj,      // param_2 — preferred resolve root (skill target)
    float amount,         // param_3 — signed: +heal / −damage; |x|<=1 → % max HP
    char allowKill)       // param_4 — 0 = clamp so at least 1 HP remains
{
  void *entity = sourceOrNull;

  if (targetObj != NULL) {
    void *iface = targetObj->vtbl[0x19C/4](targetObj);   // thiscall
    if (iface != NULL) {
      entity = AdjustCompleteObject(iface);              // LEA [edx+eax+4]
      if (entity != NULL)
        goto apply;
    }
    entity = *(void **)((char *)targetObj + 0xAC);       // fallback field
  }

  if (entity == NULL)
    return 0;

  {
    void *iface = entity->vtbl[0x19C/4](entity);
    if (iface == NULL)
      return 0;
    entity = AdjustCompleteObject(iface);
    if (entity == NULL)
      return 0;
  }

apply:
  // Sign flip: float+ → int− (heal into apply pipeline); float− → int+ (damage)
  int deltaInt = -(int)amount;                           // CVTTSS2SI + NEG
  if (amount >= -1.0f && amount <= 1.0f) {
    int maxHp = entity->vtbl[0x244/4](entity);
    deltaInt = -(int)((float)maxHp * amount);
  }

  int curHp = entity->vtbl[0x23C/4](entity);
  int projected = curHp - deltaInt;                      // apply is HP -= deltaInt

  if (allowKill == 0 && projected < 1)
    deltaInt = curHp - 1;                                // leave 1 HP; return unclamped

  // thiscall: ECX = *(entity + 0xA4)
  // stack: mode0, deltaInt, source, entity, flags1, flags1, 0, color4x, 0
  FUN_004d7e30(/*this=*/entity->combatCtrl_0xA4,
               0, deltaInt, sourceOrNull, entity,
               1, 1, 0,
               DAT_009d4d28, DAT_009d4d2c, DAT_009d4d30, DAT_009d4d34,
               0);

  if (curHp == projected)
    return 0;
  return projected - curHp;                              // == -deltaInt (pre-floor)
}
```
