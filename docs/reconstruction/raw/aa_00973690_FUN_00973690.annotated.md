## Machine-level notes

- **ABI:** ECX = dest `uint32_t*` / `uint8_t[4]`; stack `float t`, `uint32_t c0`, `uint32_t c1`; **`ret 0x0C`**.
- **Clamp:** `t` forced into **[0, 1]** using `0.0` and `g_flOne` (`0x00a0f2a0` = `1.0f`).
- **Packing:** dword **`0xAARRGGBB`** (memory B,G,R,A). Lerp integer channel deltas then float.
- **Out path:** `mov eax,ecx` → `FUN_00973590(R,G,B,A)` writes clamped bytes to dest.
- Prefer call-site `LEA ECX,dest` over decompiler surface (surface omits ECX).

## Pseudocode (annotated)

```c
// void __fastcall Color_LerpPackedARGB(uint32_t *dest, float t, uint32_t c0, uint32_t c1)
// ECX=dest; stack t,c0,c1; RET 0x0C
void Color_LerpPackedARGB_Inferred(uint32_t *dest /*ECX*/, float t, uint32_t c0, uint32_t c1)
{
  float clamped;
  float *p;

  // clamp t to [0,1]
  p = &/*0.0 local*/;
  /* local_one = g_flOne */
  if (0.0f <= t) {
    p = &/*local_one*/;
    if (t <= g_flOne)
      p = &t;
  }
  clamped = *p;

  // c0/c1 are 0xAARRGGBB
  uint32_t b0 = c0 & 0xff, g0 = (c0 >> 8) & 0xff, r0 = (c0 >> 16) & 0xff, a0 = c0 >> 24;
  uint32_t b1 = c1 & 0xff, g1 = (c1 >> 8) & 0xff, r1 = (c1 >> 16) & 0xff, a1 = c1 >> 24;

  // FUN_00973590 writes *dest as BGRA bytes (0..255 clamp inside)
  FUN_00973590(
    (float)(int)(r1 - r0) * clamped + (float)r0,
    (float)(int)(g1 - g0) * clamped + (float)g0,
    (float)(int)(b1 - b0) * clamped + (float)b0,
    (float)(int)(a1 - a0) * clamped + (float)a0);
  // EAX was set from ECX before call
}
```
