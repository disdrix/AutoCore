## Machine-level notes

- Frame: `push ebp; mov ebp,esp; and esp,-16; sub esp,0x94` — 16-byte aligned locals.
- **ECX = dest bounds\*** saved early; restored for writeback (`mov edi,[esp+…]` before sphere stores).
- **Three stack args**, **`ret 12`**.
- Early gate: `cmp byte [localBounds+0x2c], 0` / `jnz` skip-all.
- `DAT_00a0f298 = 0.5f` for merged-sphere radius formula `(r1 + dist + r2) * 0.5`.

## Algorithm (annotated CF)

```
if (local[+0x2c] != 0) return;

matrix = FUN_0044b5c0(xformRef, local_matrix_buf);  // also sees scaleSrc in EDI

worldCenter = Mat4TransformPoint3_Project(local.center, matrix);

if (scaleSrc[+0xb8]==0 && xformRef[+0xb8]==0)
  worldR = (scaleSrc.sx / xformRef.sx) * local.radius;
else
  worldR = len(scaleSrc.s) * (local.radius / len(xformRef.s));

// Merge sphere into dest (ECX):
if (dest.radius == 0) dest.center,radius = worldCenter,worldR;
else {
  d = dist(worldCenter, dest.center);
  rMerge = (dest.radius + d + worldR) * 0.5f;
  if (dest.radius < rMerge) {
    if (worldR < rMerge) {
      // expand dest center toward world along segment
      t = (rMerge - dest.radius) / d;  // if d>0
      dest.center += t * (worldCenter - dest.center);
      dest.radius = rMerge;
    } else {
      dest.center,radius = worldCenter,worldR;  // world fully contains
    }
  }
}

// Build expanded AABB: for corner index 0..7, mix local AABB min(+0x14) / max(+0x20)
// components via bit selects; transform each corner; clamp-expand dest AABB min/max.

dest[+0x2c] = 0;
dest[+0x10] = abs(sqrt( (dest.maxX - dest.cx)^2 + (dest.maxZ - dest.cz)^2 ));
return;  // ret 12
```
