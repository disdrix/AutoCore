## Machine-level notes

- Nested character blob path identical to `Character_GetClassDisplayName_Inferred` / race helper.
- Virtual level getter = vtbl slot **`+0x27c`** (same as mission token `[$level]`).

## Purpose

Format a **class ± level display label** into a caller-provided `char*` buffer:

| Level vcall (`+0x27c`) | Output |
|---|---|
| `>= 0` | `sprintf(out, "%s, %s %i", className, "Level", level)` → e.g. `"Commando, Level 12"` |
| `< 0` | `sprintf(out, "%s", className)` → class name only |

Class English comes from dualed leaf `FUN_0051f940(classId@+0x531, raceId@+0x532)` then TLS ring (`007a69d0` / `007a6de0`).
