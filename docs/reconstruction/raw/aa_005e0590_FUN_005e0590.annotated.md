## Purpose

**Random quality/band index bias (mostly downward).** Draws a unit float `U16 * (1/65536)` from the global reaction RNG table, then returns `maxBand`, `maxBand-1`, or `maxBand-2` depending on thresholds.

Sole live consumer: `FUN_005e0cd0` (quality/type-band catalog fill) — result is added to `typeRow * 0x32` to form the band-table linear index.

---

## Machine-level notes

### ABI

- **Input:** **ESI** = max band / quality index (`unaff_ESI` in decompiler — not a stack formal).
- **Output:** EAX = biased index (int; caller often treats as `short`).
- **Convention:** bare `ret`; no stack cleanup. Caller must leave desired max in ESI before `call`.
- **No `this`.**

### RNG object (`CVOGReaction_RandomUnitScalar` → `&DAT_00d20c1c`)

| Off | Role |
|---|---|
| `+0x8` | `uint16_t *` table base |
| `+0xc` | int cursor/index; wrap when `>= 0x100000` (1 048 576) |

Sequence:

1. `rng = CVOGReaction_RandomUnitScalar()`  // actually returns **object pointer**, not a float
2. if `rng->index >= 0x100000`: `rng->index = 0`
3. `u16 = rng->table[rng->index]`
4. `rng->index++`
5. `f = (float)u16 * DAT_00aaa638`

### Constants (`read_memory`)

| Symbol | Bytes (LE) | Float | Role |
|---|---|---|---|
| `DAT_00aaa638` | `80 00 80 37` | **~1.5259e-5** (≈ **1/65536**) | U16 → unit scale |
| `DAT_00a0f298` | `00 00 00 3f` | **0.5** | n==2 split |
| `DAT_009dbf08` | `9f aa aa 3e` | **~0.333333** (≈ **1/3**) | n>2 keep / drop gate |
| `DAT_009dbf04` | `9f aa 2a 3f` | **~0.666666** (≈ **2/3**) | n>2 drop-2 gate |

### Decision table (input = ESI = `n`)

| Condition | Return |
|---|---|
| `n <= 1` | `n` (unchanged) |
| `n == 2` and `f < 0.5` | **2** (keep) |
| `n == 2` and `f >= 0.5` | **1** (drop 1) |
| `n > 2` and `f < ~1/3` | `n` (keep) |
| `n > 2` and `~1/3 <= f < ~2/3` | `n - 1` |
| `n > 2` and `f >= ~2/3` | `n - 2` |

Approx distribution for `n > 2` (unit uniform): **1/3 keep**, **1/3 drop-1**, **1/3 drop-2**. For `n == 2`: **50% keep**, **50% drop-1**. Never increases `n`.

## Pseudocode (annotated)

```c
// ESI = maxBand (register param; decompiler: unaff_ESI)
// returns biased band index in EAX
int LootCatalog_RandomBiasBandIndex_Inferred(/* ESI */ int maxBand)
{
  void *rng = CVOGReaction_RandomUnitScalar(); // &DAT_00d20c1c
  int *pIndex = (int *)((char *)rng + 0xc);
  if (*pIndex >= 0x100000) {
    *pIndex = 0;
  }
  uint16_t *table = *(uint16_t **)((char *)rng + 8);
  uint16_t u = table[*pIndex];
  *pIndex = *pIndex + 1;
  float f = (float)u * DAT_00aaa638; // ~1/65536

  if (maxBand > 1) {
    if (maxBand == 2) {
      if (f < DAT_00a0f298) { // 0.5
        return 2;
      }
      return 1;
    }
    // maxBand >= 3
    if (DAT_009dbf08 <= f) { // ~1/3
      int out = maxBand - 1;
      if (DAT_009dbf04 <= f) { // ~2/3
        out = maxBand - 2;
      }
      return out;
    }
  }
  return maxBand;
}
```
