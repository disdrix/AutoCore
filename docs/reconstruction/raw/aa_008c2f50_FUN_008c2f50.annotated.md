## Machine-level notes

- **EDI-based host**, not ECX thiscall. Sole caller `FUN_008c3ca0` is `__thiscall` with host in EDI for the duration of the switch; call site `CMP ESI,8` / `CALL 008c2f50` leaves EDI live.
- Busy gate `DAT_00d1a8f6` is the same client pending-op flag used by grab/drop paths (`aa_00860e20` family) — when set, this unit returns 0 without merging.
- Host layout (relative to EDI):
  - `+0x50c` — index (used as table index and packet byte)
  - `+0x580` — inventory host pointer
  - host `+0x56c` — InventoryGrid*
  - host `+0x564` — written from `DAT_00d17768[index]` on dirty path
- Core merge is **not** reimplemented here: `FUN_00572ab0` / `InventoryGrid_AutoMergePartialStacks_Inferred` (W29-E).
- `FUN_00860700` (ESI=host): reaction/target walk + vtbl `+0x34c` notify — ownership out of W30-N.
- Sector packet **0x204a**, size **8**:
  ```
  +0 u32  0x204a
  +4 u8   *(EDI+0x50c)
  +5 u8   0xFF
  +6 u8   0x00
  +7      (frame pad / unused in decompile locals)
  ```
- Success path saves ESI across refresh+send (`push esi` before table write path). Fail path never pushes ESI.
