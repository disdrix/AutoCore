## Purpose

Roll a **critical-hit damage multiplier** for combat:

1. Null attacker → return **1.0** (no crit).
2. Read attacker **level** via `vtbl+0x27c` (int → float; product English Probable "GetLevel" from other duals).
3. Compute crit **chance** via `FUN_004cef70(attacker, target)`.
4. Compare `(roll % 100)` against `chance * 100.0`.
5. On hit: return `level * 0.01 + ~1.2`; else **1.0**.

Callers treat return `> 1.0` as crit and scale damage with `ROUND(dmg * mult)`.
