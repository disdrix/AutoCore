## Machine-level notes

- Source: raw capture + W24-Q live Ghidra seal.
- **Custom dispatch ABI** (not a clean stdcall): **EDI** = packet body*, **EBX** = game/client ctx*.
- Resolve via `CVOGReaction_ResolveObjectTarget(type@+0x98, coid@+0x90, coid@+0x94)` with **this** = `*(ebx+0xD34)`.
- Miss → `FUN_008120d0(ebx, edi)` allocate/create; hit → `FUN_00811e00` sector-update (object remains in **EAX** as `in_EAX`; ECX=packet).
- If object non-null: `weapon = obj->vtbl[+0x1E0]()`; if weapon: clear fire pair(0), `Weapon_FireHelper(weapon, &DAT_00d1a680, 1)`.
- FireHelper **param_3=1** is the **suppress-fire** early path (sealed dual `aa_0056d160`) — does **not** emit primary fire packets.
- Parent: `Client_PacketDispatch` case `0x201C` only (1 xref).
