## Machine-level notes

- Source: raw capture + live `read_memory` body + call-site `get_assembly_context` (2026-07-29).
- **Decompiler incomplete on ABI:** Ghidra types pure `__stdcall(pTfid)` and drops ECX. Image preserves ECX into `CVOGReaction_ResolveObjectTarget` (`0x004bae70`); callers load resolve ctx (often `base+0xe4e8` or `+0xd34`) before the call.
- TFID layout used here matches `TFID_EqualsObjectId` head: dword `+0`, dword `+4`, byte `+8`.
- `MOV AL,[tfid+8]` only writes AL; upper 24 bits of the pushed “bGlobal” dword are residual pointer bits. Callee reads **byte** `[esp+4]` only — safe.
- Side effects: **none** in this body (pure unpack + tail call). Mutation / hash work lives in `FUN_004e3260` via Resolve.

   Thin TFID unwrap → CVOGReaction_ResolveObjectTarget(ctx, bGlobal, coidLo, coidHi).

void * __thiscall Object_ResolveFromTFID(void *ctx /*ECX*/, TFID_16 *pTfid /*stack*/)
{
  /* stack after entry: [esp]=ret, [esp+4]=pTfid */
  unsigned int coidHi = *(unsigned int *)((char *)pTfid + 4);
  unsigned int coidLo = *(unsigned int *)pTfid;

## Control flow

```
load pTfid from [esp+4]
push *(pTfid+4)          ; coidHi
push *(pTfid+0)          ; coidLo
push (AL=*(pTfid+8))     ; bGlobal low byte
call CVOGReaction_ResolveObjectTarget  ; ECX = caller-supplied ctx
ret 4                    ; EAX = object* or NULL
```

No branches. No null gate on `pTfid` (null → fault).
