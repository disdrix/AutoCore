## Machine-level notes

- **thiscall** vehicle entity (`ECX`); stack **mask** (`char`/`u8` promoted); **`RET 4`**.
- Walks **3** hardpoint slots under **`vehicle+0x260`** (same table as `Weapon_SetFireFlagPair` / fire-all).
- Per slot: bit `mask & (1<<i)` decides want-fire vs clear path.
- Fire path gates: `weapon+0xCB == 0` and world readiness byte `+0x7E != 0`.
- On fire path: weapon **vtbl+0x4C(0)** → can-fire char; `Weapon_SetFireFlagPair(canFire)`; if true → `Weapon_FireHelper`, optional **LogicUi 0x31** when local player matches, `new(0x24)` + `CVOGHBWeaponFire_ctor` + enqueue on world+0xE4EC + `CVOGHBBase_Start`.
- Else (null-gated out of fire triple): `Weapon_SetFireFlagPair(wantFireBit)` only.
- Null weapon slot: skip entirely (no flag write).
