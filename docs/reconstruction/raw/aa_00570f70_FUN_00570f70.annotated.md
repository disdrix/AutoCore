## Machine-level notes

- **ABI:** `ECX` = `InventoryGrid*`; void; bare `RET` (`C3`). No stack args.
- **EDI** = `this+0x2c` = embedded **List** host for grid items (not the cell buffer).
- Decompiler drops ECX on List helpers; assembly seals `MOV ECX,EDI` before each List call and `MOV ECX,EBP` before Allocate.
- Prefer assembly for list/grid split; decompile CF order is correct.
- `List_RemoveAll` throws `E_ACCESSDENIED` if TraversalLock still held → inline unlock **must** run first (it does).
