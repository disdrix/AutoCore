## Purpose

**Client-side fan-out cleanup** when a world/UI object is going away: clear every client/UI slot that still points at `obj`, refresh related panels, drop inventory/mission/select chrome bindings, clear selection targets that reference `obj`, and notify a COID-keyed helper with the object's COID.

Not the full `VOGClient_CompletelyDestroyObject` path (that is `0x009440e0`). This unit is a **reference scrubber** used by special-event ship teardown and related helpers.

## High-level stages (CF order) — SEALED

1. **Null reject** if `obj == NULL`.
2. **Clear sticky slot** `client+0x3bf8` if it equals `obj`.
3. **Optional map/gfx notify** when `*( *(client+0xe04)+0xe5fc ) +0xc` non-zero:
   - `FUN_00405920(LAB_0092d8e0, obj)` then try parent via vfunc `+0x1d4` / cargo via `+0x1d8` → second `FUN_00405920` with related pointer.
4. **Tree erase by COID** if vfunc `+0x210` non-zero: walk map rooted at `client+0xd24/+0xd28` keyed by `obj[0x58]/[0x59]` (COID lo/hi), destroy node payloads, `FUN_00402850` erase.
5. **UI vfunc notify** `*(client+0xf40)` → `vtbl+0x444(obj)` if present.
6. **Selection / chrome:**
   - if `client+0x3048 == obj` → `FUN_0093e120(0)`
   - select panels at `+0x10a4/+0x520/+0x518` and `+0x10b4/+0x54c/+0x518` → `FUN_00837d50` (UiSelectWidget_ApplySelectChrome)
   - clear `+0x1088+0x50c` if matches
   - if `+0x1068+0x7cc == obj` → `FUN_007fca10` then null
7. **Misc UI:** `+0x10cc` path → vfunc `+0x1dc` + `FUN_008719d0`; visible panel `+0x1098` → `FUN_008bf020`.
8. **Inventory / equip presence** via `InventoryGrid_ContainsItem` (`FUN_00571b60`) / `Vehicle_HasEquippedTFID` (`FUN_004f70f0`):
   - if present: vfunc `+0x25c(1)` + `FUN_00571b80` then **`Client_RefreshOpenMissionUiWindows`**
   - else skip mission refresh (goto LAB_00945097)
9. **Inventory sheet windows** at `client+0x105c` and `+0x1060` (visibility vfunc `+0x3d8`): if grid contains item → `FUN_00571b80` + `FUN_0085fd20` (RemoveByItem); `+0x1060` may also vfunc `+0x448` if selected item is `obj`.
10. **Cargo / CBID path** via vfunc `+0x1dc` + `FUN_00574a90` → panel `+0x10a0` vfuncs `+0x448/+0x34c`.
11. **Always:** `FUN_007fdab0(obj)`, `FUN_008027e0(obj)`.
12. If clonebase class `obj[0x2a]+0x38 == 0x0E` (character-class): vfunc `+0x1d4` + `FUN_0044f5a0`.
13. **Selection list** at `client+0xf0c`: walk nodes; if MI-adjusted object `+0xa4 == obj` → **`Object_SetSelectedTarget(…, NULL)`**.
14. If vfunc `+0x1d8` non-null → `FUN_0044f5a0`.
15. **Global dialog** `DAT_00d1d8dc`: if null or `obj == DAT_00d1d8dc[0x146]` set flags + vfunc release.
16. `FUN_007fe140(&DAT_00d1a840)`.
17. Panel `client+0x113c`: if `+0x500 == obj` clear `+0x500/+0x4fc`, `FUN_0083dae0`, `FUN_007fbbb0`.
18. If `obj` is MI-adjusted local player (`client+0xe98`) and panel `+0x30a0` present: clear fields + vfuncs `+0x444/+0x34c`.
19. **Tail:** `FUN_00996ff0(obj[0x58], obj[0x59])` — COID notify.
