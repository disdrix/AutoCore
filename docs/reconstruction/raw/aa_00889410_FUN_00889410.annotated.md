## Machine-level notes

- **ABI (sealed):** hybrid `__usercall` — **EAX = tabIndex** `{0,1,2}`; stack **dialog\*** (`[ESP+4]` at entry → held in EBP), **force** byte (`[ESP+8]`); **`RET 8`**; void.
- **Entry:** `PUSH EBP; MOV EBP,[ESP+8]; PUSH ESI; MOV ESI,EAX` — first stack arg is dialog, not ECX this.
- **Gate:** dialog vtbl `+0x3d8` (is-visible) must be true; then (`force != 0` OR `tabIndex != dialog+0x530`).
- **State:** writes active tab to **`dialog+0x530`** (`[0x14c]`).
- **Three content panes** (show one / hide two):
  - `+0x50c` `[0x143]` ↔ tab **0** char
  - `+0x510` `[0x144]` ↔ tab **2** locker
  - `+0x514` `[0x145]` ↔ tab **1** achievements
- **Three tab buttons** (select one / deselect others via `FUN_00822cb0` + optional `FUN_00756c90`):
  - `+0x518` `[0x146]` char — XML `i_d_tabs_c_2d_tab_char.xml` (ctor `FUN_00889960`)
  - `+0x51c` `[0x147]` locker — `i_d_tabs_c_2d_tab_locker.xml`
  - `+0x520` `[0x148]` achievements — `i_d_tabs_c_2d_tab_achievements.xml`
- **Panel vtbl ops:** `+0x3d8` visible?; if show needed: `+0x43c` then `+0x4(1)`; if hide: `+0x4(0)` then `+0x440`.
- **Selected tab:** after `FUN_00822cb0` with BL=1, call tab vtbl **`+0x94`**.
- **Callee register ABI (decompiler hides as unaff_*):**
  - `FUN_00822cb0(force)`: **ESI = widget**, **BL = selected** (0/1)
  - `FUN_00756c90()`: **EDI = widget** (remove from parent vector @ `widget+0x88`)
- **Mode 1 early RET** after selecting achievements — does not fall into shared deselect-ach tail.
- **Host global:** `DAT_00d1b874` (parent `UI_Window_OnCommand_Class8_Inferred` case 4; input poll paths).
- **Sibling 2-tab switchers (not owned):** `FUN_00888b00` (`DAT_00d1b870`), `FUN_00889fb0` (`DAT_00d1b880`) — same pattern, different slot counts.
