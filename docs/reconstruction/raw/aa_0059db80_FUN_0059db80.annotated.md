## Purpose

Objective-side **nested eligibility / tracker-category probe**:

1. Resolve a **default code** from `objective+0x120`, falling back to `*(objective+0x14c)+0xfc` when the field is `-1`.
2. Look up a **pending state node** for this objective id (`objective+0x10`) in the character's pending-objectives CNDHash at **`character+0x55c`** (inline mask/bucket/chain walk — same shape as `CNDHash_LookupByKey`).
3. If no pending node (or empty evaluator range): return the default code.
4. Else walk evaluator pointers `[objective+0x158, +0x15c)`:
   - Call `eval->vtbl+0x8(character, pendingValue*)` (progress-aware eval; same slot family as `CVOGCharacter_IsObjectiveReady` mode-1).
   - If that returns **false** (`AL==0`) **and** `eval->vtbl+0x58()` returns a code that is neither `-1` nor `0`, **return that code**.
   - Otherwise advance to next evaluator; if exhausted, return default.

Parent gate `FUN_0059dc50` (`0x0059dc50`, MEGA-025 ownership) treats return **`== -1`** as **not eligible**. Tracker UI rebuild paths (`FUN_008a5240`, `FUN_008a2670`, `FUN_008a2df0`) treat the return as a **category/group id** matched against UI widget `+0x110`.

{

  char ready;
  int overrideCode;
  int defaultCode;
  int pendingValue;   /* node+0x8 after hash hit; 0 if miss */
  undefined4 *it;

  /* 1. Default code: objective+0x120, else def+0xfc when -1 */
  defaultCode = *(int *)(objective + 0x120);
  if (defaultCode == -1) {
    defaultCode = *(int *)(*(int *)(objective + 0x14c) + 0xfc);
  }

  /* 2. Inline pending hash lookup: character+0x55c, key = objective+0x10 */
  {
    int *hash = *(int **)(character + 0x55c);
    uint mask = *(uint *)(hash + 2);          /* hash+0x8 */
    int *bucket = *(int **)(hash + 4);        /* hash+0x10 */
    int node = *(int *)(*(int *)((char *)bucket +
                    ((mask & *(uint *)(objective + 0x10)) * 4)) + 4);
    if (node == 0) {
      pendingValue = 0;
    } else {
      do {
        if (*(uint *)(objective + 0x10) == *(uint *)(node + 0x10)) {
          if (node == 0) { pendingValue = 0; break; }
          pendingValue = *(int *)(node + 8);   /* value* */
          break;
        }
        node = *(int *)(node + 0xc);           /* chain next */
      } while (node != 0);
      if (node == 0) pendingValue = 0;
    }
  }

  if (pendingValue == 0) {
    return defaultCode;
  }

  /* 3. Evaluator walk: first false-eval with non-trivial +0x58 code wins */
  it = *(undefined4 **)(objective + 0x158);
  if (it != *(undefined4 **)(objective + 0x15c)) {
    while (true) {
      eval = (int *)*it;
      ready = (**(code **)(*eval + 8))(character, pendingValue);
      if (((ready == '\0') &&
           (overrideCode = (**(code **)(*eval + 0x58))(), overrideCode != -1)) &&
          (overrideCode != 0))
        break;
      it = it + 1;
      if (it == *(undefined4 **)(objective + 0x15c)) {
        return defaultCode;
      }
    }
    return overrideCode;
  }
  return defaultCode;
}
