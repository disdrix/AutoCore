## Machine-level notes

- **this** = mission **reqHost** (not escort HB). Sole live caller `CVOGHBMissionEscort_ctor` loads `ECX=EDI=reqHost` before the call.
- Gate: if `reqHost+0x44 != -1`, already resolved → return (no skill work).
- Else materialize ranked skill runtime via dualed `CVOGReaction_ResolveSkillTargets(skillId@+0x10, rank@+0x14)`:
  - On **null** (map miss): leave `+0x44` as **−1**, do not touch `+0x48`.
  - On **hit**: harvest **temporary** runtime then free:
    - `reqHost+0x44 ← skill+0x14c` (dword; template / match id; dualed skill layout)
    - `reqHost+0x48 ← (skill+0x22 != 0)` (bool; template-path / match-by-obj-ref mode)
    - `operator_delete(skill)` — **does return**; decompiler “does not return” is wrong.
- Decompiler `in_EAX` / `CONCAT22` is a phantom for `MOV AX,[ESI+0x14]; PUSH EAX` (rank word zero-extended in EAX low half).
- `puVar1[0x53]` ≡ byte offset **`0x14c`** (`0x53 * 4`).
- Escort ctor then copies filled fields into HB: `escort+0x2c = reqHost+0x44`, `escort+0x30 = reqHost+0x48`.
