- **Role:** base constructor for dual-vtable action-like objects (VehicleAction, flipper constraint, and sibling `FUN_00658bf0` all call this first, then overwrite with class vtables).
- **Refcount:** `*(u16*)(this+6) = 1` — matches Havok-like `hkReferencedObject` halfword at +6 (size/flags at +4 not written here; often pre-stamped by pool alloc).
- **Dual vtable construction order (MSVC MI pattern):**
  1. Write intermediate secondary `0x009e3a68` at `this+8`
  2. Zero `this+0xc`, `this+0x14`
  3. Write primary base `0x009e39f4` at `*this`
  4. Overwrite secondary with final `0x009e5e78` at `this+8`
- **Host link:** `this+0x18 = host`. If host ≠ 0:
  - Append **this** onto host's pointer vector via `FUN_00507290` (host ECX; action on stack) — list base **host+0x94**
  - **Addref host:** `*(u16*)(host+6) += 1`
- Decompiler display of `FUN_00507290(param_1)` **drops** the thiscall host-in-ECX — prefer machine seal.
