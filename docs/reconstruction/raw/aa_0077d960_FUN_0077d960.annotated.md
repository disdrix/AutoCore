## Purpose (sealed structural)

Base **BitStream C-string encoder** (no cache) — write twin of sealed `BitStream_readString` (`0x0077daf0`):

1. **Null string** (`EBX == 0`): write **flag bit 0**, then **u8 length 0**; return `1`.
2. Non-null: lazy-init Huffman tables when `DAT_00d17a28 == 0` via `FUN_0077d520`.
3. Compute `len = min(strlen(str), maxLen)`.
4. Sum Huffman bit-cost over alphabet entries (`DAT_00d1eabc + char*0xc + 4` = bit length).
5. Choose encoding:
   - If **`len*8 <= huffmanBitSum`** (raw cheaper or equal): write **flag=0**, **u8 len**, raw `writeBits(len*8, str)`.
   - Else: write **flag=1**, **u8 len**, per-char Huffman `writeBits(bitLen, &codeBits)` from alphabet `+4` / `+8`.
6. Always return `1`.

**Not** the cache layer — that is `BitStream_writeStringCached` (`0x0042bb40`), sole static caller of this unit, which may pass residual length after prefix compression.

## Control flow map

```
writeString(bs=EAX, str=EBX, maxLen):
  if str == null:
    writeFlagBit(0)
    writeBits(8, 0)
    return 1
  if !DAT_00d17a28: FUN_0077d520()
  len = min(strlen(str), maxLen)
  cost = sum_i alphabet[str[i]].bitLen
  if len*8 <= cost:
    writeFlagBit(0)
    writeBits(8, len)
    writeBits(len*8, str)
  else:
    writeFlagBit(1)
    writeBits(8, len)
    for i in 0..len-1:
      e = alphabet[str[i]]
      writeBits(e.bitLen, &e.codeBits)
  return 1
```
