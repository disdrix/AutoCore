## Machine-level notes

- **Role:** Assign / copy **src → dest** for a fixed-layout transform-like state (≥ `0xC0` bytes) with **per-block skip flags**.
- **ABI:** `__thiscall` — **ECX** = dest, stack = src*, **`ret 4`**. Body keeps dest in **EAX**, src in **EDX**.
- **Always-copied region (before flags):**
  - `+0x80..+0x8F` — 4 dwords
  - `+0x90..+0x98` — 3 dwords
  - `+0x9C..+0xA4` — 3 dwords
  - `+0xB8` — 1 byte
  - `+0xBC` — flags dword (from **src**)
- **Flag-gated (src flags, bit set = skip):**
  - bit0 clear → `rep movsd` 16 dwords `@+0x00` (4×4 matrix / 64 B)
  - bit1 clear → `rep movsd` 16 dwords `@+0x40` (second 4×4)
  - bit2 clear → 3 dwords `@+0xA8`
- **Always:** `*(dest+0xB4) += 1` — generation / revision counter.
- **Full assign wrapper:** `FUN_00416240` zeros `+0xBC` then calls this → all gated blocks copy.
- **MI adjustor:** `0x00464850` path `add ecx,0x10; jmp 00416160` — state may live as subobject at `+0x10`.
- **Scaffold alias** `Named_CalleeOf_Named_phySkeleton` is **caller-graph only** — multi-system xrefs (env, vehicle, fog) → shared util, not skeleton-exclusive.
- **Not** the same type as `Class_00a9bbe8` complete dtor at `0x00416110` (vptr class vs POD transform block).
