## Machine-level notes

- **stdcall** `RET 0x18` = 6 float stack args (start XYZ + end XYZ).
- Return **x87 ST0** distance (decompiler `float10`).
- **ESI** optional `int*` hit out — custom register param / caller-preserved out pointer (decompiler `unaff_ESI`).
- Loads **`DAT_00d1b644`** → `CVOGMap*`; cast uses **`*(map+0xe4a4)`** as `FUN_0055e530` this (same collision ctx field as `CVOGMap_CastTerrainHeight`).
- Filter hardcode **7** (`local_4c`); hit fraction init **1.0**; hit token init **0**.
- Success: lerp hit point, subtract start (via `FUN_004e9530` copy), return Euclidean length.
- Miss: optional `*esi=0`, return **0.0**.

## Semantics

```
// Client_Map_RaySegmentHitDistance_Inferred
// return distance from segment start to first map-collision hit, or 0 on miss
// optional ESI: *hitOut = hit token (or 0)
```
