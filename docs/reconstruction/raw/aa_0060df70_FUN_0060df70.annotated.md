## Machine-level notes

- **Virtual method** only: sole xref is DATA at vtbl slot `0x009dfc20`. No direct CALL sites.
- **ABI sealed by image:** `PUSH EBX/EBP/ESI/EDI`; `RET 0x1C` (7 stack dwords). Decompiler under-counted formals (shows 5); world object is **entry +0x1C**, not decompiler `Stack[0x14]`.
- **Event filter 9|10** is hard gate before any Eval/Match/Apply work.
- **Two success-ish arms after MatchTargetCore:**
  1. **Direct apply:** event **10** OR `req+0x34==0` → `ApplyObjectUseProgress` (`0x0060d630`); return its AL.
  2. **UI/logic packet arm:** event **9** AND `req+0x34≠0` → find self index in parent objective vector `parent+0x158`, then `FUN_005319d0` with mission key + object COID quad; then **always** `XOR AL,AL` (return 0) at shared epilogue.
- Fail paths share `LAB_0060e04f`: `XOR AL,AL; POP*; RET 0x1C`.
- Callee identities sealed by sibling duals:
  - vtbl+8 → `CVOGObjectiveRequirement_UseItem_Eval`
  - `0060d460` → `MatchTargetCore`
  - `0060d630` → `ApplyObjectUseProgress` (sole caller of that apply body)

// this = CVOGObjectiveRequirement_UseItem*
// stack: charCtx, progress, eventId, (pad×3 unread), worldObj  — RET 0x1C
// returns AL: Apply path forwards Apply AL; all other exits 0

uint8_t __thiscall ObjectEventDispatch(
    UseItemReq* self,
    void* charCtx,      // +0x04 → EBP
    void* progress,     // +0x08 → EBX
    int eventId,        // +0x0C → EDI; must be 9 or 10
    /* +0x10,+0x14,+0x18 unread */
    void* worldObj)     // +0x1C; COID @ +0x160..+0x16C
{
  if (eventId != 9 && eventId != 10)
    return 0;

  // Eval complete? (vtable +8) — only act while incomplete
  if ((*(char(**)(UseItemReq*, void*, void*))(*self + 8))(self, charCtx, progress) != 0)
    return 0;

  // Optional req+0x54 character-field gate (same family as MatchTargetCore)
  if (self->field_54 != -1) {
    void* mi = *(void**)(*(int*)(*(int*)(charCtx + 4) + 4) + 0xA8 + (int)charCtx);
    if (*(uint32_t*)((char*)mi + 0xFC) != (uint32_t)self->field_54)
      return 0;
  }

  if (!MatchTargetCore(self, charCtx, worldObj))  // FUN_0060d460
    return 0;

  // Direct apply: event 10, or flag req+0x34 cleared
  if (eventId == 10 || self->field_34 == 0)
    return ApplyObjectUseProgress(self, charCtx, progress, worldObj);  // FUN_0060d630

  // Event 9 + flag: locate this requirement in parent objective list, notify UI/logic
  Mission* parent = self->parent;           // req+4
  void** begin = parent->objVecBegin;       // parent+0x158
  int count = begin ? (parent->objVecEnd - begin) : 0;  // end @ +0x15c; >>2
  int index = 0;
  for (; index < count; ++index) {
    if (begin[index] == self)
      break;
  }
  if (index < count) {  // image also has dead CMP index,-1 after break
    // FUN_005319d0(charCtx as ECX, missionKey@parent+0x10, index, COID×4)
    FUN_005319d0(/*see image stack build from worldObj+0x160*/);
  }
  return 0;  // XOR AL after packet path
}
