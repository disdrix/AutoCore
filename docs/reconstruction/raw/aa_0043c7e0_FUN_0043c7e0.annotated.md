## Machine-level notes

- **ABI:** **EAX=container**, **ECX=new_size**; no stack formals; frame `SUB/ADD ESP,8`; plain `RET`.
- **Layout:** `+0x0c` begin, `+0x10` size (same GuardedVector ring header family; slots/cap used by callees).
- **Grow:** when `size < new_size`, sets fill seed `0`, sets `ECX = new_size - size`, calls `FUN_0043cb00` with stack `(container, container, begin+size, &fill0)`. Decompiler drops the ECX count — **bytes authoritative**.
- **Shrink:** when `new_size < size`, calls `FUN_0043c8c0` / `GuardedVector_EraseRange` for absolute range `[begin+new_size, begin+size)`.
- **Equal:** no-op.
- **Sole caller:** `FUN_0043c660` always passes `ECX=0` (clear ESI) before swapping headers with EDI — grow path not exercised by known xref, but body still implements full resize.
- Prefer bytes when decompiler call-arg lists disagree with stack/register setup.
