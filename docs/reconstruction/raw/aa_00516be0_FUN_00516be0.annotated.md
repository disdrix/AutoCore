## Machine-level notes

- Source: raw capture + live Ghidra `decompile_function` / `read_memory` 2026-07-29.
- Prefer assembly when decompiler conflicts — **no conflict**.
- Direct callee: `Object_RefreshActiveSkillEffects_Inferred` (`FUN_00516a00`) with **param=1** (refresh all active skills, not residual-only).
- Appears in multiple **DATA/vtable** slots; also called as plain helper from load/init paths.
- `CLoadNode::_initFull` calls this when not (player type `0xE` with flag path); `FUN_005d5140` stages `"DoFullInit Anim"` then calls this.
