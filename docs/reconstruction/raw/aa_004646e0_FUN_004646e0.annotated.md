## Machine-level notes

- **Role:** initialize a **pointer-vector shell** at `shell*`: zero begin/end/cap, optionally `operator_new(count*4)`, fill every slot with **`*fill_src`**, set end = end_cap = begin + count*4.
- **ABI (bytes win):** **stdcall 3 formals** — **`RET 0xC`**. Decompiler shows only 2 args and bare return — **incomplete**.
  | Slot | Formal |
  |---|---|
  | `[ebp+8]` | `shell*` (base; writes `shell+4/+8/+0xc`) |
  | `[ebp+0xc]` | `count` (element count, not bytes) |
  | `[ebp+0x10]` | `fill_src*` (pointer to dword value replicated) |
- **Shell layout written:**
  | Off | Field |
  |---|---|
  | +0x00 | **unwritten** by this function |
  | +0x04 | begin (`T**`) |
  | +0x08 | end |
  | +0x0c | end_cap |
- **Count gate:** `count == 0` → zeros only. `count > 0x3fffffff` → `FUN_004540b0` throws `"vector<T> too long"` (MSVC vector max-size).
- **Fill:** `FUN_00436ef0` register ABI — **ECX**=count, **EDX**=fill_src, **EAX**=begin; loop `*dst++ = *fill_src`.
- **SEH:** frame `LAB_009bd530` around allocation/fill.
- **Callers (10):** Ass-resolver twins push **count=9** and fill with circular sentinel; other hash-like inits also use this helper.
- **Does not** free prior storage — pure init (ctor-time).

## Control flow (annotated)

```
SEH prolog LAB_009bd530
shell->begin = shell->end = shell->end_cap = 0   // +4/+8/+0xc
if (count == 0) goto done
if (count > 0x3fffffff) FUN_004540b0()           // noreturn throw
byte_len = count * 4
p = operator_new(byte_len)
shell->end_cap = p + byte_len
shell->begin = shell->end = p
FUN_00436ef0(count, fill_src) with EAX=p         // replicate *fill_src
shell->end = p + byte_len                        // full
done:
SEH epilog
ret 12
```
