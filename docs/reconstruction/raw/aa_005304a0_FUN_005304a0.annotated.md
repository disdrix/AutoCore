## Machine-level notes

- **Role:** Character-local **skill bag upsert**: find existing runtime by skill id key at `skill+0x5fc`; on hit set rank + store meta; on miss materialize via `CVOGReaction_ResolveSkillTargets` and `push_back` a 0xC entry; always **re-apply local skill effects** by id via `FUN_00514e70` / `Skill_ApplyLocalById_Inferred` when a skill exists.
- **thiscall** ECX = character; stack: `skillId`, `rankPacked`, `param_4`; **`RET 0xC`**.
- **List walk:** `[begin=*(this+0x550), end=*(this+0x554))` stride **0xC** (`piVar1 + 3`).
- **Match key:** `*(skillRuntime + 0x5fc) == skillId` (dword/pointer-sized id field on 0x630 runtime).
- **Hit path:** `Skill_SetRankAndReevaluate(skill, rank)` — **one** stack arg (no `unaff_DI`); `entry[1] = param_4`; reapply.
- **Miss path:** `skill = ResolveSkillTargets(skillId, rank)` (`__cdecl`, dual sealed). If null, return. Else build stack triple `{skill*, param_4, flag=1}`, `FUN_0053aea0` with **ECX = this+0x54c** (vector push of 0xC elements), reapply.
- **Reapply this-adjust:** before `FUN_00514e70`, ECX becomes `*(*(this+4)+4) + this + 4` (host base for skill apply); stack arg = skillId. Matches dual of `aa_00514e70`.
- **Callers:**
  - `CVOGCharacter_AwardMedalById` (`0x00530550`): `(def+0x14, def+0x18, 0)` when chain id ≠ -1.
  - `CVOGCharacter_ApplyCreateFromPacket` path / create apply.
  - `FUN_00623960`: multiple skill ids with rank from object `+0x100`, meta 0.
