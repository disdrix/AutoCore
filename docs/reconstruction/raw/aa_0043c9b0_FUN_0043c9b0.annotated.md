## Machine-level notes

- **ABI:** **EBX = container**; stack **1** formal `min_grow`; frame `SUB ESP,0xC`; **`RET 0x4`**.
- **Entry bytes:** `8B 43 08` loads capacity from `[EBX+8]` before any stack formal use.
- **Epilogue bytes:** `01 7B 08 89 4B 04 5F 83 C4 0C C2 04 00` — commit `capacity += grow`, `slots = new_map`, clean and return.
- **Decompiler trap:** `operator_delete` is **not** noreturn. After delete, fall-through still commits map+capacity (same as null-map arm).
- **Overflow:** `FUN_00436860` builds `"deque<T> too long"` and throws — confirms MSVC **deque** map growth, not a plain vector realloc.
- **Callers:** only push-back (`FUN_0043c830`) and push-front (`FUN_0043ce10`) when map capacity is exhausted for +1 element; both pass `min_grow=1`.
- Prefer bytes when decompiler conflicts (post-delete path).

## Semantics (sealed)

1. `cap = [EBX+8]`.
2. If `0x0FFFFFFF - cap < min_grow` → `FUN_00436860()` (throw `"deque<T> too long"`).
3. `delta = max(cap >> 1, 8)`; if `min_grow < delta` and no overflow, `min_grow = delta` (geometric growth, floor 8).
4. `begin_block = [EBX+0xc] >> 2`.
5. `new_map = operator_new((cap + min_grow) * 4)`.
6. **Rebalance ring map into linear map with headroom:**
   - Copy tail block pointers (`[begin_block .. cap)`) into `new_map + begin_block`.
   - If `min_grow < begin_block`: wrap head into middle of new map, remainder to front; zero a strip of new slots.
   - Else: copy head `[0 .. begin_block)` after tail; zero `min_grow - begin_block` new slots after head; zero `begin_block` slots at front of new map.
7. If old map non-null → `operator_delete(old)`.
8. `[EBX+8] += min_grow`; `[EBX+4] = new_map`.

## Pseudocode (annotated)

```c
// EBX = container; stdcall min_grow; RET 0x4
void GuardedVector_GrowBlockMap(uint min_grow /*stack*/, /*EBX*/ GuardedHeader* self)
{
  uint cap = self->capacity;                 // +0x08
  if (0x0FFFFFFF - cap < min_grow)
    FUN_00436860();                          // "deque<T> too long"

  uint geo = cap >> 1;
  if (geo < 8) geo = 8;
  if (min_grow < geo && cap <= 0x0FFFFFFF - geo)
    min_grow = geo;

  uint begin_blk = self->begin >> 2;         // +0x0c
  uint32_t* neu = operator_new((cap + min_grow) * 4);

  // memmove rearrange of block pointers (see raw); zero new/unused slots

  if (self->slots != NULL)
    operator_delete(self->slots);            // then fall through (not noreturn)
  self->capacity += min_grow;
  self->slots = neu;
}
```
