## Machine-level notes

- **`thiscall`**: ECX = stream shell; stack args `void *dest`, `uint byteCount`; **`ret 8`**.
- **Success** returns `0` (`xor eax,eax`); **refill fail** returns `-1` (`or eax,-1`).
- **Payload window** at `this+0x18 + cursor`; cursor at `+4`, avail at `+0xC`, max-chunk gate at `+0x10`, base at `+8`.
- **Interface** at `*this`: vtbl slots **`+4`** (commit/seek-style) and **`+0x14`** (direct bulk read of remainder into dest).
- **Copies** use dword then tail-byte (`rep movsd` / `rep movsb` pattern in decompiler dword/byte loops).
- **Caller shape (owned evidence only):** `stoChunkReader_readF32Array` dual seals bulk path as `FUN_00435f30(reader+0x14, dest, count*4)`.
- Prefer bytes when decompiler invents `unaff_EBX` for the second vtbl call — stack holds advanced dest.
