## Purpose

Virtual method on a **CVOGHBSkillBase subclass** (`FUN_00614dc0` installs `PTR_FUN_009d0ec4`; this function is **vtbl+0x2c**). Spawns one or more creatures/templates near the caster (or mounted vehicle pose), snaps to terrain, applies orientation modes, arms a per-spawn HB (`operator_new(0x6d0)` + `FUN_00614dc0` + `CVOGHBList_Enqueue` + `CVOGHBBase_Start`), and optionally culls excess matching entities.

## Per-spawn algorithm (happy path)

1. **Virtual gate** `(*(this->vtbl+0x1c))(caster, skill)` — decompiler `local_94` is polluted; treat as `this` virtual. Non-zero → skip spawn (no count++).
2. **Offset**
   - If `skill+0x160 == 0`: two RNG ushorts → roughly `[-10,10]` XZ via `(u * 1/32768 - 1) * 10`, then ± radius.
   - Else: clamp offset length vs radius (± if negative mode), `FUN_004e8bf0` transform by basis.
3. **Terrain:** `CVOGMap_CastTerrainHeight(x, z, y+50, 0)` → Y.
4. **Orient** by mode 1/2/3; build basis (`FUN_004e8ad0` / `FUN_005a5970` / `FUN_004e9060`).
5. **Create** creature or template; apply optional floats; log+return 0 if null.
6. **HB:** `new(0x6d0)` → `FUN_00614dc0(...)`; if `pOwnerObject==0` destroy; else `CVOGHBList_Enqueue(map+0xe4ec)` + `CVOGHBBase_Start`.
7. **Cull** when `skill+0x16c == 100.0`: scan caster related TFIDs, count matches on template id `+0x14c`, if count > `skill+0xda` force first match state `+0xcc=2` + `FUN_004d0e90`.
