## Machine-level notes

- **ABI:** `__fastcall` / thiscall-like **ECX = head/sentinel**; no stack args; bare **`C3`**; void.
- **Layout (sealed):** links at **`+0`** and **`+4`**. Empty circular: both point at self.
- **Walk direction:** save `first = [head+4]`, re-ring both links to self, then walk **`node+4`** until back to head.
- **Free:** `operator_delete(node)` cdecl (`PUSH node; CALL; ADD ESP,4`) — **continues** (decompiler false-noreturn collapses loop).
- **No size field** written (differs from `StdList_Clear` `0x00404060` which zeros `list+8`).
- **ECX is the sentinel node itself**, not a list object holding a `_Myhead` pointer.
- **No element destructor** — bare heap free of each node.
