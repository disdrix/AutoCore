## Purpose

Read the next **int32** from a stoChunk **text** stream into a caller-provided `int32_t*`:

1. Bail if sticky status `reader+0x402c < 0`.
2. Either consume pushback string (`+0x4060` / `+0x404c`) or scan whitespace/quoted token from the window buffer.
3. If token is `"}"` → past-end log (`stoChunk.cpp:0x2a0`), sticky −1, re-push token.
4. Else parse via `FUN_00767600(out, 4, 1)` (**signed**, 4 bytes); success → return **0**.
5. Else log `"Expected int32 but got \"%s\" in chunk \"%s\""` (`stoChunk.cpp:0x414`) → return **−1**.

Text peer of unsigned `stoChunkReader_TextReadU32` @ `0x007689e0` (same scan/pushback; signedMode 0 vs 1).  
Binary fields that use this in text mode typically use `stoChunkReader_ReadU32` @ `0x00437050` in binary (identical LE dword bits).
