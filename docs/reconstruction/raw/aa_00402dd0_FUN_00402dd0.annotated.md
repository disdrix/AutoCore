## Machine-level notes

- **Role:** resize circular doubly-linked list shell to **EAX** element count.
  - **Grow** (`new > size`): insert `(new-size)` copies of stack **fill** via `FUN_004034c0` (loops `FUN_004040f0` insert-before-head).
  - **Shrink** (`new < size`): repeatedly unlink **`head->_Prev`** (back), `operator_delete`, **`size--`**.
  - **Equal:** return.
- **ABI:** **ESI** = list\*; **EAX** = `new_size`; stack = fill value; void; **`RET 4`** on both exits.
- **Layout:** list `+4` head/sentinel, `+8` size; node `+0` next, `+4` prev.
- **Decompiler traps:** reports `void()` with `unaff_ESI`/`in_EAX`; false-noreturn on `operator_delete` (misses `ADD ESP,4` / size-- / loop). Prefer assembly.
- **Consumers:** 5 CALL sites including dualed `Client_DebugListMissionsStatus` `0x009572e0` (clear local list before rebuild). All observed sites pass **EAX=0** (clear).
- **Do not merge** with clear-only `StdList_Clear_ESI` `0x00415e90` (no grow/fill, bare RET) or ECX clear twin `0x00404060`.

// List: head@+4, size@+8
// Node: next@0, prev@4  (circular; head->prev == back)
void StdList_Resize_EsiList_EaxCount_Inferred(ListShell* list /*esi*/,
                                              unsigned new_size /*eax*/,
                                              /* stack */ T fill)
{
  unsigned cur = list->size;                 // [ESI+8]
  if (cur < new_size) {
    unsigned n = new_size - cur;
    // ECX = &fill (caller stack); then insert n nodes
    FUN_004034c0(list, list->head, n /*, fill via ECX */);
    return;                                  // RET 4
  }
  while (new_size < list->size) {
    Node* head = list->head;                 // [ESI+4]
    Node* node = head->prev;                 // head->_Prev = back
    if (node != head) {
      // unlink node from ring
      node->prev->next = node->next;
      node->next->prev = node->prev;
      operator_delete(node);                 // cdecl; ADD ESP,4
      list->size--;                          // ADD [ESI+8], -1
    }
  }
  // RET 4
}
