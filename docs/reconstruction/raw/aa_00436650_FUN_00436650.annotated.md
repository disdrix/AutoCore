## Machine-level notes

- **ABI (custom):** buffer object **`this` in EBX**; **`uint grow_request`** at `[esp+4]`; **`ret 4`** (stdcall-style stack cleanup). Not `__thiscall` (ECX unused as this).
- **Layout (matches push sibling `aa_00436340`):**
  - `+0x04` — `void **slots` (heap pointer array)
  - `+0x08` — `uint capacity`
  - `+0x0C` — `uint head` (circular read index)
  - `+0x10` — `uint count` (not modified here)
- **Growth policy:** if `0x0CCCCCCC - capacity < grow_request` → `FUN_00436860` throws `"deque<T> too long"`. Else grow amount = `max(request, max(capacity/2, 8))` when that does not overflow the max map size.
- **Allocate:** `operator_new((capacity + grow) * sizeof(void*))`.
- **Rearrange:** `memmove` linearizes the circular map into the new buffer while preserving **head index** semantics; zeros newly introduced slots.
- **Commit:** if old `slots != NULL`, `operator_delete(old)`; then **`capacity += grow`**, **`slots = new`**. Decompiler marks `operator_delete` noreturn — **false**; bytes fall through to commit.
- **Sole caller:** `FUN_00436340` (`CircularPtrBuf_PushCopy_0x14`) when `capacity <= count + 1`, with `grow_request = 1`.

## Byte-accurate pseudocode (role)

```c
/* CircularPtrBuf_Grow — grow circular pointer map.
   Custom ABI: this in EBX; void Grow(uint grow_request) → ret 4 */

struct CircularPtrBuf {
  /* +0x00 unknown / unused here */
  void **slots;      /* +0x04 */
  unsigned capacity; /* +0x08 */
  unsigned head;     /* +0x0C */
  unsigned count;    /* +0x10 — untouched */
};

void CircularPtrBuf_Grow(/*EBX*/ CircularPtrBuf *self, unsigned grow_request)
{
  unsigned cap = self->capacity;
  if (0x0CCCCCCCu - cap < grow_request)
    FUN_00436860(); /* throw "deque<T> too long"; noreturn */

  unsigned chunk = cap >> 1;
  if (chunk < 8) chunk = 8;
  if (grow_request < chunk && cap <= 0x0CCCCCCCu - chunk)
    grow_request = chunk;

  unsigned head = self->head;
  void **neu = (void **)operator_new((cap + grow_request) * 4);

  /* Circular linearization (decompiler CF):
     1) copy old[head .. cap) → neu[head ..]
     2) if grow < head: split-copy old[0..head) across wrap + zero
        else: copy old[0..head) after tail, zero (grow-head) gap, zero neu[0..head) */
  /* ... memmove ×2–4 + stosd zero loops — see raw live decompile ... */

  void *old = self->slots;
  if (old != 0)
    operator_delete(old);

  self->capacity = cap + grow_request;
  self->slots = neu;
}
```
