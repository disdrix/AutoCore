## Machine-level notes

- **ABI:** `__thiscall` — ECX = outpost; stack arg0 = `factionIndex` (u32/int); epilogue **`ret 4`** (`c2 04 00`).
- **Entry:** `push ecx` / load stack faction into EAX / `test eax,eax` / `mov ebx, ecx` (preserve this).
- **Faction gate:** signed `faction < 0` or `faction >= 4` → early out (no bank walk).
- **Faction slot:** `lea esi, [ebx + eax*8 + eax*0x40?]` → bytes `8d 34 c3` after `8d 04 c0` scale: `factionBase = this + faction * 0x48`.
- **Skill bank:** `*(factionBase+0xd4)` begin, `*(factionBase+0xd8)` end; count = `(end-begin) >> 4` (entry **0x10**).
- **Entry flag:** `cmp byte [entry+0x0C], 0` — process **only when zero** (same polarity as BeaconShare process path; **no** float threshold @+0x8).
- **TFID list:** `*(factionBase+0xb4/0xb8)`, stride 8; `ResolveObjectTarget` mode **0** (same as BeaconShare, ≠ Faction mode 1).
- **Host chain:** `obj.vtbl[+0x1ec]()` → container; MI this-adjust `lea ecx, [edx+eax+4]`; `call [vtbl+0x220]` with `(skillId, 1)`.
- **Direct call only:** `e8` → `CVOGReaction_ResolveObjectTarget` @ `0x004bae70`. Virtuals not listed as callees.
