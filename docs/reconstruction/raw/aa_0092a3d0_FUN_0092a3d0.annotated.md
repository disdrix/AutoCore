## Machine-level notes

- **EDI** = MissionTracker host (custom register ABI). Callers seal this:
  - `FUN_0092a590`: `MOV EDI,ECX` then `CALL` (×2 clear/miss paths).
  - `FUN_0092a600`: `MOV EDI,[ESP+arg]` then `CALL` then buffer free.
  - `FUN_0092bf60` / `FUN_0092c080`: tracker in EAX → EDI before call.
- Vector triple at `+0x11c` / `+0x120` / `+0x124` (begin/end/capacity). This unit only mutates **end**.
- **Bytes authority over decompiler:** delete is a **loop** (`ADD ESI,4` / `JNZ`), not a single first-element free. `operator_delete` **does return** (cdecl + `ADD ESP,4`).
- After deletes: classic MSVC `vector::clear` / erase-to-end with `memmove(begin,end,0)` then `end = begin`. Buffer retained.
- Return always **`AL = 1`** (bool success). Bare `RET`.
- Sibling destroy path: `FUN_0092a600` calls this, then `operator_delete(begin)` and zeros `+0x11c/120/124`.
