## Purpose

**Near-identical twin** of `Map_EraseRange` (`0x0051c7c0`): MSVC red-black **range erase** for `isnil@+0x29` nodes, partial path via `Map_EraseNode`.

**Only structural difference vs A:** full-clear free-subtree is **`FUN_0051be90`** instead of **`FUN_0051bbc0`** (separate MSVC map instantiation / value dtor path).

## Control flow

Same as `Map_EraseRange`:

1. Full clear if `first == *head && last == head` → `FUN_0051be90(head->parent)` → reset head links → `size=0` → `*out=*head`.
2. Else loop: successor (isnil@+0x29) → `Map_EraseNode(this, &first, node)` → advance → `*out=first`.
