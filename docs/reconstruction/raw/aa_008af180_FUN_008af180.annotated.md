## Algorithm stages

1. **Guard:** `DAT_00d1b6d8 != 0` else return.
2. **Teardown** if `DAT_00af92d4 == 0`: Release all slot/companion/divider widgets.
3. **Per-slot visibility sync** for indices 0x155, 0x154, 0x153 against feature flags:
   - Flag off + visible → hide (`+0xcc(0)`) both primary and companion; set force.
   - Flag on + hidden → fade-in (`+0xfc(1, 0.5f)`); optional caption path; set force.
4. **Medals slot `+0x156`:** if `DAT_00af92d8 >= 0`, `FUN_0051a0e0(key)` → copy name, append `.dds`, compare/set texture; caption `0x00a4a27c` = **"Click to View Your Medals!"**; show/fade as needed. Else hide path.
5. **If !force:** return (no geometry work).
6. **Count** visible among 4 primaries (`+0xd0`).
7. **Layout by count:**
   - 0: hide dividers/rows → host `+0x34c`.
   - 1: single-slot centered layout using scale `DAT_00d1e818/81c * (0.000625/0.000833)`.
   - 2: dual layout.
   - 3–4: multi-row with dividers visible; place each visible slot + companion.
8. **Host** `vtbl+0x34c` invalidate.
