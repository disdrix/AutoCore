## Machine-level notes

- **Thiscall** manager in ECX + **two** stack dwords cleaned (`ret 8`).
- Body only loads stack formal #1 (object into EDI). Formal #2 is ABI-real but **unread** (callers often stage `1` via `mov byte [esp],1` before `push obj`).
- Decompiler surface omits manager `this` (shows only `param_1` object) — bytes fix: `mov esi,ecx` then both callees get ECX=manager.
- Sibling context: enroll `WorldObj_EnrollActivate` (`00560ec0`) uses bind helper `0055fa40`; remove `WorldObj_RemoveOrDefer` (`00561450`) uses unbind `0055fbf0`. This unit does **both** then sets a flag.
