## Purpose

Leaf **ActionMap slot-field clear / prologue**. Zeroes the bind-related fields of every slot in all four mode banks (counts `5 / 6 / 0x78 / 0x14`, stride `0x34`). Called once as the first action of `Client_InitDefaultKeybinds` so default DIK writes see customized-flag clear.

---

## Machine-level notes

- **ABI:** **ESI** = ActionMap base; no stack args; bare `RET`. Not ECX-thiscall (ECX is the loop cursor).
- **Leaf:** no callees, no SEH, no globals.
- **Per-slot clears (7 fields):** primary key/mod, alt key/mod, customized flag, two status bytes — same offsets as `ActionMap_TrySetSlotBind` mode tables.
- **Banks:** four sequential counted loops; cursor starts at each mode's `kMod1[0]` absolute offset.
- Prefer assembly when decompiler shows `unaff_ESI` — sealed real by caller `MOV ESI,EDI` @ `0x007f8723`.

## Pseudocode (annotated, ABI-corrected)

```c
// ESI = ActionMap*  (from caller MOV ESI,EDI)
// void; bare RET
void ActionMap_ClearAllSlotBindFields_Inferred(void /* ESI=map */)
{
  // ---- mode 0: 5 slots, cursor @ map+0x32 (mod1 of slot0) ----
  uint16_t* cur = (uint16_t*)((uint8_t*)map + 0x32);
  int n = 5;
  do {
    // relative to cur (== slot+0x32):
    //   cur[-0x16] → +0x06 key0
    //   cur[-0x15] → +0x08 key1
    //   cur[-1]    → +0x30 mod0
    //   cur[0]     → +0x32 mod1
    //   byte cur-0x28 → +0x0A clB
    //   byte cur-0x27 → +0x0B clA
    //   byte cur-0x26 → +0x0C flag
    cur[-0x15] = 0;                          // key1
    *cur = 0;                                // mod1
    cur[-0x16] = 0;                          // key0
    cur[-1] = 0;                             // mod0
    *(uint8_t*)((uint8_t*)cur - 0x27) = 0;  // clA
    *(uint8_t*)(cur - 0x14) = 0;             // clB  (-0x28 bytes)
    *(uint8_t*)(cur - 0x13) = 0;             // flag (-0x26 bytes)
    cur += 0x1a;                             // +0x34 bytes
    n--;
  } while (n != 0);

  // ---- mode 1: 6 slots @ map+0x136 ----
  cur = (uint16_t*)((uint8_t*)map + 0x136);
  n = 6;
  /* same 7-field zero + stride 0x34 */

  // ---- mode 2: 0x78 slots @ map+0x26e ----
  cur = (uint16_t*)((uint8_t*)map + 0x26e);
  n = 0x78;
  /* same */

  // ---- mode 3: 0x14 slots @ map+0x1ace ----
  cur = (uint16_t*)((uint8_t*)map + 0x1ace);
  n = 0x14;
  /* same */

  return;
}
```
