## Machine-level notes

- **memmove** half-open dword range `[srcBegin, srcEnd)` → `dest`.
- Size floors to whole dwords: `((end-begin)>>2)*4`.
- Returns **write end** (`dest + size`) for chaining.
- Custom ABI: **ECX=srcBegin, EAX=srcEnd, stack dest, `ret 4`**.
- Decompiler `__thiscall` label is a Ghidra artifact (ECX first arg) — not object-method semantics.
- Algorithm twin of `Mem_MoveDwordRange_ReturnEnd` (`0x004e2e80`, stdcall three stack args, `ret 0xC`).
- Overlap-safe (memmove, not memcpy).
- Pairs with fill helper `Mem_FillDwordN_ReturnEnd` (`0x004651d0`) on insert-N paths.

## Pseudocode (annotated)

```c
// ECX = srcBegin, EAX = srcEnd, [esp+4] = dest; ret 4
// Returns dest + size
void *Mem_MoveDwordRange_ReturnEnd_EcxEax(void *srcBegin /*ecx*/,
                                          int srcEnd /*eax*/,
                                          void *dest /*stack*/)
{
  size_t size = ((size_t)(srcEnd - (int)srcBegin) >> 2) * 4;
  void *p = memmove(dest, srcBegin, size);
  return (void *)((int)p + (int)size);
}
```
