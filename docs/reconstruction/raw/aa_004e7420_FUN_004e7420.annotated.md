- Source: raw capture + W23-M `decompile_function` / `read_memory` re-verify.
- Complements node factory `FUN_005ae2b0`: that factory does `operator_new(0x1c)`, zeros left/parent/right, sets `+0x18=1`, `+0x19=0`, but does **not** self-link or attach to a map header.
