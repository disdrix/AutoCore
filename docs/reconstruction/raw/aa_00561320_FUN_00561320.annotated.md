## Machine-level notes

- `mov esi, ecx` then all work via ESI ⇒ MSVC thiscall/fastcall **this in ECX**.
- Bare `ret` (`c3`) — **no stack args**.
- Decompiler call `FUN_00560a30(iVar1,iVar2)` is incomplete: bytes `push hostB; push hostA; mov ecx, world; call 00560a30`.
- `00560a30` is host-island **merge** (activate hosts, splice body/constraint lists, destroy merged host) — not dualed in this unit; sealed as callee only.
- Pair vector header: `this+0x20` = data ptr; `this+0x24` = count (cleared to 0 at end). Capacity at `+0x28` is **not** touched here.
