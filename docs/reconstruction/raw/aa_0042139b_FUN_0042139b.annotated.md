## Machine-level notes

- **SEH-split fragment** of a larger MSVC function: shares EBP frame with `FUN_00421362` (parent alloc) and `FUN_00421677` (CreateAccessor finalize).
- Pre-entry `0x00421390`: `mov ebx,[ebp+8]` — EBX = ctx throughout.
- Epilogue paths use **`ret 4`** (one stack formal = ctx*). Success **jmps** to `0x00421674` (sibling fragment pre-entry) rather than a portable call+ret.
- Null `ctx+0x10` → **E_OUTOFMEMORY** (`0x8007000E`), free `[ebp-0x1c]`, Release `[ebp-0x18]`.
- Column loop: count `ctx+0x0C`, column base `ctx+0x14`, stride `ctx+0x14` field is pointer to column array with stride in `ctx[5]`; max size gate `ctx+0x24`.
- DBTYPE ushort at column+0x14 maps to payload size (OLE DB DBTYPE-like enum: 2,3,4,5,0xb,0xc,0x10–0x15,0x40,0x48,0x80–0x83, default 0x20).
- Oversized / DBTYPE 0xd path forces wType `0x4082`, cbMaxLen=4, status flag=1.
- Binding record cursor advances by **0x34** bytes; per-column side state advances by **0x30**.
- Row size accumulated in `[ebp-0x24]`; alignment uses `FUN_00422900` result as mask (`~(align-1)`).
- If `*ctx==0`: `FUN_00422880()` (HRESULT); on success sets `*( *ctx + 4 ) = 1`.
- Allocates `operator_new[](rowSize)` into `ctx+0x08`, SEH level 6, continues into finalize.
