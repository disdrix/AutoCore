## Machine-level notes

- Source: raw capture + W22-R `decompile_function` / `read_memory` re-verify.
- Complements sealed `RbTree_AllocEmptyNode_Inferred` (`0x00439770`): that factory allocates + zeros links + sets `+0x14=1`, `+0x15=0` but does **not** self-link or attach to a map header.
- This unit: `thiscall` on **header** (ECX) → alloc node → store at `this+4` → force `node+0x15=1` → self-link left/parent/right → `this+8=0` → return this.
- Classic MSVC empty `std::_Tree` head setup (empty: L=P=R=head, size 0).
- Sibling `FUN_004e7420` uses alternate node size/flag (`+0x19`) — different map flavor.

}
