## Machine-level notes

- **Ghidra plate end is wrong.** Plate stops at `0x00572e7f` because `operator_delete` is marked noreturn. Bytes continue through consume-list free + `mov al, dirty` + SEH restore + **`C3`** at `0x00572ec6`.
- ECX = inventory grid `this`. Walk base `this+0x2c` via `List_TraversalLock` / `List_IterateNext` (same pattern as `InventoryGrid_RePlaceItems` `0x00572360`).
- Max-stack formula **inlined** (same as `Item_CanAcceptStackQty` `0x0040abf0`): type@clonebase+0x38==4 → **0x423F (16959)**; else u16@def+0x4BA, default **200**.
- Match key for merge peers: **clonebase+0x34** equality (not COID). Distinct from `InventoryGrid_MergeStackQty` (COID lookup).
- Temp structures: empty **std::list** sentinel (`0040fb90`) for fully-consumed items; empty **Val12 map** (`005ae2b0` head + isnil=1 self-links) for underfilled stackables keyed by item pointer (uint).
- Dirty: item(s) via `FUN_00512670`; optional owner at `grid+0x24`; grid flag **`this+0x21 = 1`**.
- Exit: leave CS if held; `RemoveItem(item, 1000000, 1)` + `Object_QueueDelete` for consume list; range-erase + free map; free list; **return AL = any-merge flag**.

## Algorithm (annotated)

```
dirty = 0
if (&this->listAt2c == NULL): return 0   // lea/cmp; degenerate
consumeList = empty list sentinel
partialMap  = empty Val12 map (head isnil=1, size=0)
TraversalLock(this+0x2c)
while List_IterateNext yields item:
  if item==null || !Item_IsStackEligible(item): continue
  max = MaxStack(item)   // type4→0x423F else def+0x4BA or 200
  if qty(item) >= max: continue          // already full — skip
  originXY = (vtbl+0x250, vtbl+0x254)    // recorded on insert value
  for each node in partialMap (Inc walk):
    peer = node.value item*
    if peer && peer.clonebase[+0x34] == item.clonebase[+0x34]:
      room = max(peer) - qty(peer)
      if room < qty(item):               // cannot fully absorb
        if room != 0:
          qty(peer) += room; qty(item) -= room
          dirty items + optional owner; this+0x21=1; dirty=1
        Erase peer from partialMap
        InsertOrFind partialMap {item,item,originXY}
      else:                              // full absorb
        qty(peer) += qty(item); qty(item) = 0
        append item to consumeList
        dirty; this+0x21=1; dirty=1
      break map walk (or continue loop bookkeeping)
  if no peer match for this underfilled item:
    InsertOrFind partialMap {item,item,originXY}

// end iteration (IterateNext nonzero):
LeaveCS if held
for each consumeList entry:
  InventoryGrid_RemoveItem(entry, 1000000, 1)
  Object_QueueDelete(entry)
range-erase + delete partialMap head
free consumeList nodes + head
return dirty
```
