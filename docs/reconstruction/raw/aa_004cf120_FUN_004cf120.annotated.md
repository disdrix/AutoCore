## Machine-level notes

- **Decompile ≈ body bytes** with traps listed below. No `disassemble_bytes`.
- **Product name High:** plate `"allocatenewobjectfromcbid failed %d"` @ `0x00a7f228`.
- **ABI:** `thiscall` — `ECX` = `CVOGSectorMap`-like host (`+0xe4e8` resolve ctx, `+0xe6e0` 64-bit alloc counter). Stack: `int cbid`, `int templateId`. **`RET 8`**. `this` stashed in **`EDI`** for the whole body.
- **templateId == -1:** use stack `cbid` directly; skip template apply block.
- **templateId != -1:** `FUN_00508e20(templateId)` → template record; `cbid = *(template+0x84)`; if lookup fails return 0; then after successful init apply template slots.
- **GiveItemByCbid** factory allocates raw object; failure logs plate string and returns 0.
- **Init:** `obj->vtbl[+8](cbid, this, 1)`; negative → return 0.
- **Template apply (flag path):** copy/bind helpers + five `vtbl+0x78` slots from `template+0x90` + five `vtbl+0x54` from `template+0xa4` + `vtbl+0x64` + `vtbl+0x9c(packedLocal)`.
- **Always on success:** `obj+0x17c |= 0x10`; `FUN_00512670`; bump `this+0xe6e0` (64-bit); `FUN_00512160(old,1)`; `vtbl+0x218(this)`; `vtbl+0x2a4(this->+0xe4e8)`; return `obj`.
