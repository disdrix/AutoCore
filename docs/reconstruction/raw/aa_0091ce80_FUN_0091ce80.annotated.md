## Machine-level notes

- Entry `MOV ESI,EAX` seals cam* in EAX (not pure stdcall this-on-stack).
- Epilog `C2 04 00` seals **one** stack formal.
- Mode id is **dword index** `cam[0x331]` = byte offset **0xCC4** (`0x331*4`).
- Default arm dual-sealed as `Client_Camera_DefaultModeUpdate_Inferred` (W24-D).
- Modes 2/5/7 share twin `Client_Camera_Modes257_ChaseUpdate_Inferred` (this wave).
- Post-switch FOV band clamps camera child `+0xf0` via vtbl `+0x1a0`.
- Mode 8 skips generic look rebuild when cam flags `+0xa81` ∈ {2,3}.
