## Machine-level notes

- **Bytes win** over decompiler: container in **ESI**, out-pair in **EDI**, **AL** success, plain **RET**.
- Lock gate `+0x2c` / CS object `+0x14` — same GuardedVector header family as W30 duals.
- Element stride **8** (`LEA [page+slot*8]`); wrap at **capacity×2** (2 slots/page) — **not** the dword `cap×4` of `GuardedVector_PopFront` @ `0x0040d980`.
- Page index = `begin >> 1`; in-page slot = `begin & 1` via `begin - 2*(begin>>1)`; if pageIdx ≥ cap, pageIdx -= cap.
- **Odd preserved:** first out-dword copied only when `EDI != slot_addr`; second dword **always** written.
- EBP holds CS* for Leave paths (`[EBP+0x18]` ≡ lockEnable @ container+`0x2c`).
- Sole production consumer: AssPreloader success-result drain (`host+0x4c`).

## Pseudocode (annotated, ABI-corrected)

```c
// ESI = GuardedVectorHeader* container
// EDI = uint32_t out[2]   // pair
// returns AL: 1 popped, 0 empty
// plain RET

uint8_t GuardedVector_TryPopFront_Stride8_OutPair_Inferred(void)
{
  CRITICAL_SECTION *cs = (CRITICAL_SECTION *)(container + 0x14);
  if (container->lockEnable) {              // +0x2c
    EnterCriticalSection(cs);
  }

  if (container->size == 0) {               // +0x10
    if (container->lockEnable) LeaveCriticalSection(cs);
    return 0;
  }

  uint32_t begin = container->begin;        // +0x0c
  uint32_t pageIdx = begin >> 1;
  uint32_t slot = begin - pageIdx * 2;      // begin & 1
  if (container->capacity /*+8*/ <= pageIdx)
    pageIdx -= container->capacity;

  uint32_t *slotp = (uint32_t *)(
      container->pages[pageIdx] + slot * 8);

  if (out != slotp)
    out[0] = slotp[0];
  out[1] = slotp[1];                        // always

  if (container->size != 0) {
    container->begin = begin + 1;
    if ((uint32_t)(container->capacity * 2) <= container->begin)
      container->begin = 0;
    container->size -= 1;
    if (container->size == 0)
      container->begin = 0;
  }

  if (container->lockEnable) LeaveCriticalSection(cs);
  return 1;
}
```
