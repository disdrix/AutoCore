## Purpose

Thread-safe **singly-linked list membership** test: return **1** if any node’s payload equals the queried pointer, else **0**. Twin of `CsSList_AppendPayload_Inferred` (`FUN_004024d0`) on the same list/node layout.

// ret 4
// return: AL/EAX 0 = not found, 1 = found

## Algorithm (annotated)

```c
// ECX = list*, stack = payload*
uint8_t __thiscall CsSList_ContainsPayload_Inferred(void *list, void *payload)
{
  // 1. Outer then inner CS (always both — unlike Append which gates +0x28 on count≤3)
  EnterCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x28));
  EnterCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x10));

  // 2. Walk head → next
  void *node = *(void**)((uint8_t*)list + 4);
  while (node != 0) {
    if (*(void**)((uint8_t*)node + 4) == payload) {
      LeaveCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x10));
      LeaveCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x28));
      return 1;
    }
    node = *(void**)((uint8_t*)node + 8);
  }

  LeaveCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x10));
  LeaveCriticalSection((CRITICAL_SECTION*)((uint8_t*)list + 0x28));
  return 0;
}
```
