## Machine-level notes

- **ABI (bytes):** ECX=`src*`; stack `dest*`; **`RET 4`**; returns **dest (EAX)**.
- **Not** classic `dest.operator=(src)` thiscall — **src is this**, dest is stack formal.
- **Size:** `(src.end - src.begin) / 0x1c` via magic `0x92492493` (null-safe).
- **`FUN_00431b30(dest, size)`:** zeros dest triad (**no free** of prior buffer), if size≠0 allocates `size*0x1c`, sets begin=end=buf, capEnd=buf+nbytes, returns 1; size==0 returns 0 with empty triad.
- **`FUN_0046a2c0`:** `StdUninitCopy_BasicString` (W33-G) — string copy-ctor per elem; sets `dest.end`.
- **Callers:** path expand / string-vec collectors (`FUN_009841d0`, `FUN_00984340` / `Fs_ExpandPathSpecToStringVec_Inferred`).
- Prefer bytes: `MOV ECX,EDI` before buy proves dest is ECX for `FUN_00431b30`.

## Pseudocode (annotated)

```c
// ECX = src; stack dest*; RET 4; returns dest*
VectorBasicString* __thiscall StdVector_AssignFrom_BasicString(
    VectorBasicString* src,
    VectorBasicString* dest)
{
  uint32_t n = 0;
  if (src->begin != nullptr)
    n = (src->end - src->begin) / 0x1c;

  // ECX = dest (bytes: MOV ECX, EDI)
  char ready = FUN_00431b30(dest, n);  // blank triad; buy capacity n
  if (ready) {
    // uninit_copy strings [src.begin, src.end) → dest.begin
    dest->end = StdUninitCopy_BasicString(
        src->begin, src->end, dest->begin /*, dest */);
  }
  return dest;
}
```

## Contract warning

`FUN_00431b30` **zeros without `operator_delete`**. Safe when dest is empty/default; **leaks** if dest already owned a buffer. Callers observed are collector→out paths that treat dest as assign target shell.
