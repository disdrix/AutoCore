## Machine-level notes

- **thiscall**: `ECX` = map shell (`+4` head/end, `+8` size).
- Stack: `[esp+4]` out-iterator*, `[esp+8]` hint node*, `[esp+0xC]` int* key; **`ret 0x0C`**.
- Frame: `sub esp,8` for pair scratch used by fallback `FUN_00569320`.
- Node family (shared sealed duals): left/parent/right, **key `+0x0C`**, color `+0x48`, **isnil `+0x49`**.
- `FUN_00537770` / `FUN_00568200` are predecessor/successor that rewrite the iterator in ECX (decompiler may drop the ECX formal).
- Empty map (`size==0`): insert as first child of head via `FUN_005690a0(..., addLeft=1, parent=head, key)`.
- Hint = leftmost (`hint == *head`): if `*key < hint->key` insert left of hint.
- Hint = end (`hint == head`): if `rightmost->key < *key` insert right of rightmost.
- Else: if key order allows local insert beside hint (after pred/succ checks + isnil on sibling), insert with `addLeft` 0|1; else **`FUN_00569320` full insert-or-find** and copy iterator out.
- Parent `FUN_005697d0`: lower-bound walk → this unit → return `*it + 0x10` (value payload).
