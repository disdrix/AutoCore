## Machine-level notes

- **ABI:** `__thiscall` — **ECX** = target **item**; stack arg0 = **character** (client avatar / `DAT_00d1b6d8`); stack arg1 = **`CVOGTinkeringKit*`**; return status in **EAX**; **`RET 8`**.
- Prefer assembly when decompiler conflicts:
  - Decompiler presents `param_2`/`param_3` order correctly (character, kit) relative to call sites `FUN_00513c10(DAT_00d1b6d8, kit)`.
  - Decompiler `(short*)(param_3+0xb0) != 0` is the **LEA address** of kit level field (always non-null for valid kit); real level read is `MOVSX EAX,word ptr [EBX]` at success tail.
  - Decompiler return `(sVar3+1 <= kitLevel)*2 + 2` ≡ assembly `SETGE CL; LEA ECX,[ECX+ECX*1+2]` → **4** ok / **2** primitive.
- Broken bit is **item+0x17c >> 19 & 1** (same bit as dualed `Item_SetBroken` / stack eligibility). Function returns **0** for broken; dualed UI caller re-checks broken and prints the dedicated broken string before the code-0 message.
- `FUN_00513bc0(item, kit)`: category match `kit+0xb4` vs `item.host+0x38`, with specials `0x44`↔def type 10 and `0x46`↔def type 0x0b.
- `FUN_00521eb0(character)`: maps `character+0x59b` rank byte → tier 0..5.
- `character+0x6b4 >= 1` bypasses the skill-tier fail (returns not-1 even if tier < need).
- Item vtbl **`+0x8c`**: opened / progress slot count (short). Compared to def max at **`def+0x4b4`** and to **kit level at `kit+0xb0`**.

## Purpose

**Validate whether a Tinkering Kit may be applied to a target item** for the local character. Pure predicate / status encoder — **no mutation**, no packet send. Status codes drive dualed UI tooltip (`FUN_0085ce20` mode 4) and apply dialog (`FUN_0085f660`).

| Code | Meaning (caller-sealed) |
|-----:|-------------------------|
| 0 | No openable slots (or early Broken inside this unit) |
| 1 | Character lacks Tinkering skill tier for next slot |
| 2 | Kit level too low for next slot (“too primitive”) |
| 3 | Null kit/character or category mismatch |
| 4 | OK — kit may be used (success-chance path) |

## Pseudocode (annotated)

```c
// thiscall: ECX = item*
// stack:    character*, CVOGTinkeringKit* kit
// returns:  char status 0..4; RET 8
char __thiscall Item_ValidateTinkerKitUse_Inferred(
    int *item, int *character, int *kit)
{
  char catOk;
  short curSlots;
  short maxSlots;
  int skillTier;
  int need;

  if (kit == 0)
    return 3;

  // LEA of kit+0xb0 always non-null if kit non-null; retained for CF parity
  if ((short *)((char *)kit + 0xb0) == 0)
    return 3;

  catOk = (char)FUN_00513bc0(item, kit);   // this=item, arg=kit
  if (catOk == 0)
    return 3;

  // Broken flag bit19 @ item+0x17c
  if (((uint)item[0x5f] >> 0x13 & 1) != 0)
    return 0;

  // max openable slots from item def blob
  maxSlots = *(short *)(*(int *)(item[0x2a] + 0x3c) + 0x4b4);
  curSlots = (**(code **)(*item + 0x8c))();  // vtbl opened-count
  if (maxSlots <= curSlots)
    return 0;                                 // no slots left

  if (character == 0)
    return 3;

  curSlots = (**(code **)(*item + 0x8c))();
  need = (int)curSlots + 1;
  skillTier = FUN_00521eb0();                 // ECX=character (fastcall/this)
  if ((skillTier < need) && (*(int *)((char *)character + 0x6b4) < 1))
    return 1;                                 // skill fail

  // kit level @ kit+0xb0 vs need → 4 ok / 2 primitive
  return ((need <= (int)*(short *)((char *)kit + 0xb0)) * 2) + 2;
}
```
