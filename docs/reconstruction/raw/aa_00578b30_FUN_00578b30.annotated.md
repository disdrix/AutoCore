## Purpose (sealed structural)

Shared **skill heartbeat fire tail** used by multiple skill HB OnFire/OnHeartBeat paths:

1. Call empty hook `FUN_004648a0` via `PTR_FUN_00af31e4` (`(this, 0)`).
2. **Resolve object target** via `CVOGReaction_ResolveObjectTarget` using skill fields at `+0x658/+0x65c/+0x660` (and intermediate at `+0x688` in decomp overlay).
3. If `pOwnerObject` (`this+0x18`) non-null:
   - Flag bit `0x10` at `this+0x639` → increment `*(char*)(owner+0x26)`.
   - `FxCache_EnsureMasterAndResolve(host, skillKey@+0x620, event=0x16, 1)`.
   - On FX hit: owner vtbl+`0x19c` gate → attach FX via owner or nested object vtbl+`0xf8`; then `CVOGReaction_FailMissionNotify` + `FUN_004b7e50` zero-vec path.
4. If resolved target non-null:
   - Target vtbl+`0x214` + flag bit `0x02` @ `+0x639` → `FUN_00518ca0` (skill payload from `+0x620` / `+0x678` band).
   - Flag char @ `this+0x140` (decomp `param_1[8].pVTable`) → target vtbl+`0x210`(0) → on success `FUN_0051f880(1)`.
5. **Period finalize:**
   - If `nPeriodSentinel(+0x0C) == -1000` **and** `nPeriodMs(+0x08) == 0`: `CVOGHBBase_Stop` then `StampLastFireTime`; return.
   - Else if `nPeriodSentinel != 1` **and** `nPeriodMs < 300`: log `"Skill %d has invalid frequency %d"` (skillId@`+0x620`, period@`+0x08`); clamp `nPeriodMs = 300`.
   - Always end with `CVOGHBBase_StampLastFireTime` (except early Stop path which also stamps).

**Not** the full cast pipeline — this is the common post-fire / period-stamp tail.

## Control flow map

```
entry(this)
  empty_hook(this,0)
  target = ResolveObjectTarget(...)
  if owner:
    if flags&0x10: owner.byte26++
    fx = FxCache_EnsureMasterAndResolve(skillKey, 0x16, 1)
    if fx:
      nest = owner.vtbl+0x19c()
      if !nest: owner.vtbl+0xf8(fx,0,&out@+0x6ac)
      else: nest_chain.vtbl+0xf8(...)
      FailMissionNotify; FUN_004b7e50 zeros
  if target:
    if target.vtbl+0x214() && flags&0x02: FUN_00518ca0(...)
    if flag@+0x140 && target.vtbl+0x210(0): FUN_0051f880(1)
  if sentinel==-1000 && periodMs==0:
    Stop(); Stamp(); return
  if sentinel!=1 && periodMs<300:
    log(skillId, periodMs); periodMs=300
  Stamp(); return
```
