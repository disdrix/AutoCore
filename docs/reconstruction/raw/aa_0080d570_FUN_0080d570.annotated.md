## Item resolve — dual grid (asm correction)

Decompiler shows two identical `FUN_00571010(coidLo,coidHi)` calls. **Bytes** set different `ECX` (this):

1. **Cargo:** `ECX = *(*(ESI+0xe98)+0x250) + 0x2B0` — same as DropResponse inventoryType **1**.
2. **If null, locker:** `ECX = *(ESI+0xe98) + 0xCBC` — DropResponse type **3**.

Entry hex (first ~128 B) confirms `+0x2b0` / `+0xcbc` loads before the two Find calls.
