## Machine-level notes

- **ABI:** ECX = out quat; stack `[esp+4]` = axis ptr, `[esp+8]` = angle (radians); **`RET 8`**.
- **Half-angle:** `DAT_00a0f298` = **0.5f** (`read_memory` `00 00 00 3f`).
- **x87 only:** `FSIN` / `FCOS` — no CALL callees.
- **Dead intermediate:** after scaling xyz, retail multiplies `sin(half)*axis[3]` into `out[3]`, then **`FCOS` overwrites `out[3]`**. Final w is always `cos(θ/2)`.
- **Axis width:** loads dword at `axis+0xC` → axis buffer must be ≥16 bytes readable (null axis faults even for θ=0).
- **No normalize** of axis or result.
- Ghidra `__thiscall` label: ECX is out buffer only, not a C++ object with vtable.
- Caller decompiles sometimes show 2 args; call-site bytes (e.g. `0x004f5510`) confirm **push angle; push axis; mov ecx,out**.

## Pseudocode (annotated)

// out = (sin(θ/2)*axis.xyz, cos(θ/2)); θ in radians
void FUN_00567ce0(float *pOut /*ECX*/, float *pAxis, float flAngleRad)
{

}
