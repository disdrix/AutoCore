## Machine-level notes

- **ABI:** item object* in **EAX**; button in **ESI**; plain **`ret`**; returns 0/1 in AL.
- **Not** the id-based twin `AssignItem` (`0x008283a0`: button EAX, itemId ECX).
- **Not** skill twin `AssignSkill` (`0x00826860`: skill EAX, button stack, `ret 4`).
- Item id: `*( *(item+0xa8) + 0x34 )` with `cdq` → button `+0x550/+0x554`. Cross-unit clonebase pattern (`*(obj+0xa8)+0x34` id).
- `payloadKind` @ `+0x548` forced **2** (item); `pSkill` @ `+0x558` forced **0**.
- Slot: `page*10+column` → character QB via sealed setters.
- Exclusive slot policy: **SetQuickBarItem** then **SetQuickBarSkill(−1)**.
- Icon path: `FUN_0085d970(item, pathBuf)` on live object (Inventory Texture default string inside helper). No `GiveItemByCbid`.
- Decompiler omits `FUN_0085d970` args; disasm seals `PUSH pathBuf; PUSH EDI; CALL`.
