## Purpose

Refresh a bank of optional child widgets on a UI host from a **tracked node** (id pair at `+8/+0xc` plus small fields). Early-out if host not visible (`vtbl+0x3d8`) or node null. When the node's id pair matches global selection (`DAT_00d1b6d8`), re-invoke highlight (`vtbl+0x464`) on each bound widget.
