## Purpose

Clear/destroy contents of an owned pointer table (this in **ESI**):

1. Spin live counter `+0x10` to 0; null cache `+0x0C` on final decrement.
2. `operator_delete` each non-null element in `data[0..count)`.
3. `operator_delete` the array buffer; zero `count` and `data`.

Used from resource-cache and ass-preloader cleanup paths (`NDResourceCache_LookupOrCreate`, etc.).
