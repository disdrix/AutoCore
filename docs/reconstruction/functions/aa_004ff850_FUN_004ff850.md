## Purpose

Walk the half-open **dword hardpoint-type table** at `templateFx+0x94` / `+0x98` and expand vehicle child FX instances:

1. **Empty table:** `FUN_005829d0(template,…)` then probe three slots at `this-0x330` via `FUN_004b7030`.
2. **Non-empty:** for each type id, switch:
   - `0x0B` → `%s_WHEELSET_%d`
   - `0x0F` → `%s_VEHICLE_EXHAUST_%d`
   - `0x10` → `%s_VEHICLE_BRAKES_%d`
   - `0x11` → `%s_VEHICLE_LIGHTS_%d`
   - `0x15` → `%s_VEHICLE_MELEE_%d`
3. Each expansion: zero name buf → `_snprintf` with prefix `template+0xD5` → `NDSpecialFX_InstantiateFromTemplate` (`0x004a0b90`) → optional `CVOGReaction_FailMissionNotify` if `param_4≠0` → `FUN_005829d0` on child.
4. After table: final `FUN_005829d0` on template.

Sole static caller: thin trampoline `CVOG_CreateFromPacketDispatch` @ `0x00507000`.
