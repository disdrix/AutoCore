## Purpose

Mission dialog **reward chrome** helper:

1. Stamp turn-in / claim-mode byte **`dialog+0x64c = param_3`** (first store).
2. Clear selected reward TFID `+0x578/+0x57c = −1` and resolved count `+0x514 = 0`.
3. Bind up to **4** reward TFIDs from `param_1` into `dialog+0x558[]`; resolve each; show or hide slot widgets.
4. Set reward-header / choose-hint / Mission Complete banner strings from `(resolvedCount, +0x64c)`.
5. If exactly one resolved reward **and** turn-in flag set → `FUN_008aa3f0(0)` auto-selects slot 0 into `+0x578/+0x57c`.

Does **not** send packets, set `+0x510` chrome mode, or set `+0x648` button router.
