## Purpose

Leaf predicate on `stoChunkReader*`: if `reader[+0] == 0` return false; else test a bit derived from that id against the bitset base at `reader[+8]`. Unserialize callers (`gfxGeometryPiece_Unserialize`, `gfxVertexBufferImpl_Unserialize`, morphed/skinned piece, …) treat **nonzero as soft-skip** (return **0** without reading body), distinct from hard fail **−1**.
