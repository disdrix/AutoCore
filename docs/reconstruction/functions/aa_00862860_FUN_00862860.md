## Purpose

Return whether the **currently selected hardpoint/equip UI mode** (`ESI->vtbl+0x3cc`) matches the **cloneBase class** (and weapon/ornament subtype flags) of the item in **ECX**. Gates hardpoint drop and equip UI state.

## Signature

```c
// customcc / fastcall-ish: ECX=item*, ESI=uiHost*
bool Client_ItemMatchesActiveHardpointMode_Inferred(void *item /*ECX*/, void *uiHost /*ESI*/);
// returns AL; bare RET
```

## Algorithm

1. If `item == null` → false.
2. `cb = *(item+0xA8)`; `cls = *(cb+0x38)`.
3. Jump-table switch on `cls` (range-reduced `cls-6`):
   - Map class/subtype/flags → expected mode int.
   - `mode = uiHost->vtbl[+0x3cc]()`; return `mode == expected`.
4. Default / unmatched subtype → false.
