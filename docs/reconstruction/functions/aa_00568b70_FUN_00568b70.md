## Purpose

Left-rotate red-black / map-set tree node `x` under map head: hoist `x->right` into `x`'s place and make `x` the left child of that former right child. Pure structural; does not recolor.

## Signature

```c
void __thiscall Tree_RotateLeft(MapShell *map, Node *x);
// ECX=map, [esp+4]=x; RET 4
```

## Algorithm

1. `y = x->right` (`+8`).
2. `x->right = y->left`; if `!isnil(y->left)` (`+0x49==0`) then `y->left->parent = x`.
3. `y->parent = x->parent`.
4. If `x` is root (`head->parent`): `root = y`; else if `x` is left of parent: `parent->left = y`; else `parent->right = y`.
5. `y->left = x`; `x->parent = y`.
