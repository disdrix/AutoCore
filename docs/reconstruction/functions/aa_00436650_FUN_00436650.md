## Purpose

Grow the circular pointer-slot map of a small buffer object: enforce max size (`"deque<T> too long"`), apply geometric growth, allocate a larger `void**` array, rearrange existing circular contents with `memmove`, zero new slots, free the old array, and publish new `slots` / `capacity`.

## Algorithm

1. If `0x0CCCCCCC - capacity < grow_request` → throw via `FUN_00436860`.
2. `grow = max(request, max(capacity/2, 8))` when that stays under the max map size.
3. `new_slots = operator_new((capacity + grow) * 4)`.
4. Circular `memmove` linearization preserving head index; zero new pointer slots.
5. `operator_delete(old_slots)` if non-null.
6. `capacity += grow`; `slots = new_slots`.
