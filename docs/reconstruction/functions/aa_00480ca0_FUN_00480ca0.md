## Purpose

Push **one 12-byte element** onto an MSVC-style vector header in **EAX**, value pointed by **EBX**. Fast path when `begin != 0` and size &lt; capacity; else grow/insert via `FUN_0042a710`.

## Algorithm

1. `begin = *(v+4)`.
2. If `begin != 0` and `(end-begin)/12 < (capEnd-begin)/12`:
   - `FUN_0042acc0(count=1, dest=end, src=EBX)` — copy three dwords.
   - `end += 0xC`; store back; return.
3. Else `FUN_0042a710` grow path (vector in EDI into callee).
