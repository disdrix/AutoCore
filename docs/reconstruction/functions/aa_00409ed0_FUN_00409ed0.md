## Purpose

Reverse-direction POD copy of half-open `[src_begin, src_end)` of **0x18-byte** SkillSet entries into a destination ending at `dest_end`. MSVC-style `copy_backward` kernel used by SkillSet vector insert/reallocate when shifting elements right (avoids overlap clobber). Returns `dest_begin`.

## Control flow

1. `if (EDX == ECX) ret` — empty.
2. Loop: `ECX-=0x18; EAX-=0x18;` copy 6 dwords `[ECX]→[EAX]`; until `ECX == EDX`.
3. Leaf; saves/restores EBX/ESI/EDI.
