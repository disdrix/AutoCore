## Purpose

Initialize a **0x30** timer sample block held in **ESI**:
1. Zero start QPC, accum, avg, count, last, max.
2. `QueryPerformanceFrequency` into `+0x10`.
3. Replace with **`QPF / 1_000_000`** via `__alldiv` → divisor in ticks per **microsecond**.
4. Return **this** in EAX.
