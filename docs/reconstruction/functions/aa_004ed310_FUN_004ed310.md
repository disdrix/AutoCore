## Purpose

1. If no preloader → return 1 (done).
2. Clamp relative `*cursor` into `[0, size)`.
3. For each absolute index `begin+cursor`…end:
   - If key **tracked** (`00971900` recurse=0): optional pending remove (`00971030` when flag set); erase slot via EraseRange_Thiscall; resume at out-iterator (no cursor++).
   - Else if flag==0 and not cache-present and not tree-ready: `EnqueueKeyAndDeps`; set flag=1; return 0 (yield).
   - Else if flag!=0 and not cache-present: if not tree-ready return 0; else advance.
   - Else advance cursor.
4. On exhaust: clear cursor+flag; return 1.
