## Purpose

Destroy one **0x28-byte** vector element:

1. Complete-dtor + free owned object at `+0x24` via `FUN_004be2a0` + `operator_delete`.
2. For each list-host pointer in vector `[+0x14, +0x18)`: free node payloads, empty list, free list storage.
3. Free vector storage; zero begin/end/cap.
4. Free buffer at `+0x4`; zero begin/end/cap.
