## Purpose

Append the Ogg Vorbis filename extension to a mutable path buffer. Host flag at **`+0x308`** selects plain **`.ogg`** (flag 0) vs localized/variant **`_lxx.ogg`** (flag nonzero). Used before existence probes and mission media preload enqueue.

```c
    void *host /*ECX; flag @ +0x308*/,

```

## Algorithm

1. If `*(char*)(host+0x308) == 0` → suffix = `".ogg"` (`0x00A9D9A4`); else `"_lxx.ogg"` (`0x00AA91A0`).
2. Measure suffix length including NUL; find end of `pathBuf`.
3. Copy suffix with `rep movsd` + residual `rep movsb` (includes NUL).
4. Return (void).
