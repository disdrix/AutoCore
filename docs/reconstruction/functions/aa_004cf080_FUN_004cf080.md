## Purpose

Roll a **critical-hit damage multiplier**:

- Null attacker → `1.0`.
- Else: `level = attacker.vtbl[+0x27c]()`, `chance = FUN_004cef70(attacker, target)`.
- If `(roll % 100) <= chance * 100.0` → return `level * 0.01 + ~1.2`.
- Else → `1.0`.

Callers scale damage when mult `> 1.0`.
