## Purpose

**Shared client end-quest drain / fail teardown** for missions whose ids were enqueued on the character end-quest vector (`char+0x564` triple, push via `CVOGReaction_FailMissionNotify` at `char+0x560`).

For each queued mission id:

1. Lookup mission def in active hash **`char+0x540`**.
2. Hash-remove from **`+0x540` and sibling `+0x544`**.
3. For each objective on the def (`def+0x130` count, `def+0x13c` list): optional skill scan when **`char+0xd6c == 1`** (vtbl type **`0xe`**, float `elem+0xA0` > 0 → LogicUI **`0x30`**); destroy pending **`+0x55c`**; remove active objective **`+0x548`**.
4. Destroy mission state blob in **`+0x530`** (`FUN_00537f30`).
5. If local player and (`skill-flag` or `char+0xd6c == 0`): LogicUI type **`0xd`**, toast **`"Failed" + title`**, audio **`gen_end_quest`**.
6. `FUN_004de9f0()`; `FUN_0052d8b0(0, -1)`.

On vector empty: free storage; zero `+0x564/568/56c`; clear **`+0xd6c`** and **`+0xd68`**.

**Does not** compute XP/credits, send `0x20B2`, or push the queue. Complements `CVOGReaction_FailMission` (thin apply + enqueue).

## Behavioral summary

| Branch | Condition | Effect |
|---|---|---|
| Vector empty / index past end | begin null or `i >= count` | free; zero triple; clear `+0xd6c/+0xd68`; return |
| Mission miss on `+0x540` | no live def | skip teardown for that id; next |
| Mission hit | live def | dual-hash remove, obj strip, blob destroy, optional Failed UX, helpers |
| Toast/audio | local player && (`flag` \|\| `+0xd6c==0`) | LogicUI `0xd` + `"Failed"` toast + `gen_end_quest` |
| Skill LogicUI | `+0xd6c==1` and type `0xe` float>0 | LogicUI `0x30`; sets toast-enabling flag |
