## Purpose

## Algorithm

1. Write SEH state `[ebp-4]` low byte **3**.
2. If `flag_hard == 0` → goto soft tail.
3. If `this+0x18 == 0` or `*(owner+0xb0) == 0` → goto soft tail.
4. `FUN_005085b0(*(owner+0xb0), this)` — ignore return.
5. Soft tail `FUN_0050846f`: `this+0x20 = 1`; `this+0x18 = 0`; restore ExceptionList / parent epilogue.
