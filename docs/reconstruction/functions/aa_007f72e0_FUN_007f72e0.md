## Purpose

Leaf **ActionMap slot bind writer**. Given a mode group (0..3), slot index, bind lane, and two DIK/mod codes, writes the primary or alt key pair **only if** the per-slot customized flag is clear. Used heavily by `Client_InitDefaultKeybinds` and the `keymap.ini` loader.

## Signature (asm-sealed)

```c
// AL  = slotIndex
// BL  = bindLane (0 primary, nonzero alt)
// SI  = keyCode u16
// DX  = modCode u16
// stack0 = ActionMap* base
// stack1 = mode (0..3)
// return AL success (1/0); RET 8
uint8_t ActionMap_TrySetSlotBind(
    uint8_t slotIndex,
    uint8_t bindLane,
    uint16_t keyCode,
    uint16_t modCode,
    void* actionMap,
    uint32_t mode);
```
