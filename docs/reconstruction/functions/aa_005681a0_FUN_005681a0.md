## Purpose

Right-rotate red-black / map-set tree node `x` under map head: hoist `x->left` into `x`'s place and make `x` the right child of that former left child. Pure structural; does not recolor. Twin of sealed `Tree_RotateLeft` (`0x00568b70`).

## Signature

```c
void __thiscall Tree_RotateRight(MapShell *map, Node *x);
// ECX=map, [esp+4]=x; RET 4
```

## Algorithm

1. `y = x->left` (`*x` / `+0`).
2. `x->left = y->right`; if `!isnil(y->right)` (`+0x49==0`) then `y->right->parent = x`.
3. `y->parent = x->parent`.
4. If `x` is root (`head->parent`): `root = y`; else if `x` is right of parent: `parent->right = y`; else `parent->left = y`.
5. `y->right = x`; `x->parent = y`.
