## Purpose

Copy three consecutive 32-bit floats (XYZ) from `src` to `dst`. Leaf helper. Does **not** copy a fourth (W) component when callers pass float4-aligned storage.

## Signature

```c
void __cdecl Vec3_Copy(float *dst, float const *src);
// stack: [esp+4]=dst, [esp+8]=src; bare RET
```

## Algorithm

1. Load `src[0]`, `src[1]`, `src[2]` via SSE `movss`.
2. Store to `dst[0]`, `dst[1]`, `dst[2]` via SSE `movss`.
3. Return.
