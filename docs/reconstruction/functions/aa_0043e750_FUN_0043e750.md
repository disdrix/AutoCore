## Algorithm

1. If lockEnable@`+0x2c`: `EnterCriticalSection(+0x14)`.
2. If size@`+0x10` == 0: leave CS if needed; return 0.
3. Resolve front: `pageIdx = begin>>1` (wrap `-= capacity` if needed); `slot = begin&1`; `slotp = pages[pageIdx] + slot*8`.
4. If `out != slotp`: `out[0] = slotp[0]`; always `out[1] = slotp[1]`.
5. `begin++`; wrap at `capacity*2`; `size--`; if size==0 force `begin=0`.
6. Leave CS if locked; return 1.
