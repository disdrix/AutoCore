## Purpose

Extract chassis **forward (+Z)** world direction from a unit quaternion `q=(x,y,z,w)`:

```
out = ( 2(xz+yw),  2(yz−xw),  1−2(x²+y²),  0 )
```

Used by drive path consumers (`VehicleEntity_PushDriveAxesToController`, `MoveToTarget3DPoint`, `VehicleAction_applyAction`, AI heading) for `dot(vel, forward)` / align dots. Does **not** write thr/steer/HB.
