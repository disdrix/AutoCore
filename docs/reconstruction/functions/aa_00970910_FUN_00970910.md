## Purpose

Once-init a static table of five MSVC `basic_string` extensions (`.geo`, `.dds`, `.ogg`, `.xml`, `OTHER`), then classify a path/name by `strstr` against the first four extensions. Return bucket index **0..3** on match, else **4** (OTHER default — the `OTHER` string is not scanned).

AssPreloader tally/untally paths use the return as index into `host+0xe8` (byte totals) and `host+0xfc` (counts).
