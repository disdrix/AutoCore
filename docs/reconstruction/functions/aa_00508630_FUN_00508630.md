## Purpose

MSVC-style **scalar deleting destructor** for `CVOGHBBase`:

1. Restore base vtbl `PTR_FUN_009cdab0` at `this+0`.
2. If `this+0x18` (owner) and `*(owner+0xB0)` (list manager) non-null → `FUN_005085b0(listMgr, this)` detach.
3. If `(flags & 1)` → `operator_delete(this)`.
4. Return `this` (EAX).

Complete body **without** free is sibling `CVOGHBBase_dtor` @ `0x00508390`.
