## Purpose

MSVC-style **vector insert-n** for **0x28-byte POD** elements. Growth 1.5× + three-way relocate, or in-place near/mid insert. Engine behind InsertOne rebind `FUN_00406de0` (count forced to 1).


## Algorithm

1. Snap 10 dwords of `*value` to stack template.
2. `cap = (capEnd-begin)/0x28`; early out if `count==0`.
3. Max-size check vs `0x06666666` → `FUN_00418130`.
4. Grow if `cap < size+count`: 1.5× then size+count; `new` + prefix/Ufill/suffix + `delete` + triad.
5. Else in-place near-end Ufill vs mid relocate + assign-fill.
6. `ret 8`.
