## Purpose

If the client is not busy and the host has a live inventory grid, run full-grid partial-stack auto-merge. On any merge, stamp a host side-byte from a global table, refresh inventory reactions, send sector packet `0x204a` (8 bytes), return success. Otherwise return 0.
