## Purpose

Append a localized **Requires:** block for an item to a UI text widget: Level, race name, class name, Combat, Tech, Theory, Perception. Colors lines white (met) or red (failed) against the local player (`DAT_00d1b6d8`). Returns the number of lines written (0 if disabled / wrong type / no player / no requirements).
