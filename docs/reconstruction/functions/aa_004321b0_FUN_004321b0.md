## Purpose

Release owned heap payloads on an image object (**ESI**): gate on **`+0x38`**, vtbl-release entries of the **`+0x1b4`** pointer array (count **`+0x1a4`**), free the array, free **`+0x1ac` / `+0x1b0` / `+4`**. Return **1** on success, **0** if busy (no frees).

Same ownership slots moved by `NDAssetImage_TransferFields_Inferred` (`0x00432580`). No product string/RTTI on this VA — name is structural + sibling field family.
