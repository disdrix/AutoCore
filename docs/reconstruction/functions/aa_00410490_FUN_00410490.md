## Purpose

Erase range `[first, last)` from a MSVC-style `vector`-shaped dword container:

1. If non-empty range: `memmove` tail `[last, end)` down to `first`; set `end = first + tail_bytes`.
2. Write `*outIt = first`.

Used by dword **resize-shrink** paths (`FUN_004367f0`, `FUN_00410420`) and other consumers.
