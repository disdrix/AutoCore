## Purpose

Walk the binding table pointed by `ESI[2]`. For each **active** entry (stride 8, flag byte at `entry+4 != 0`), call `vtbl+0x10` on the COM iface at `*ESI[0]` with args `(iface, ESI[3], entry_dword, table[2])`. Return the first negative HRESULT; otherwise return the last result (0 if no failures / empty).

Sole caller `OleDb_RebindAccessor` (`aa_0041c000`) uses a negative return as a post-bind failure signal to re-release the accessor handle.
