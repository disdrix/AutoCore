## Algorithm

1. If preload vector empty → DB enter (`FUN_007e1d80`) → load rows (`FUN_007c0350`) → DB leave (`FUN_007b7df0`); else count = vector length.
2. Construct four hashes into `this[0..3]`; OOM → log + `VOG_DEBUG_STOP`.
3. For each mission def: insert primary / optional index A / index B / all objectives into objective hash.
4. Free DB COM buffers when cold path.
5. Return `this`.
