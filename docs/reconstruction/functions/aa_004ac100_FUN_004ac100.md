## Purpose

Rebuild map-child spatial tables after map link:

1. Guard `*(this+0x3d8) != 0` else `VOG_DEBUG_STOP` / return 0.
2. Call `Host_RebuildElem0x28ArrayFromMap_Inferred` with host=`*(mapCtx+0xe898)`, mapCtx=`*(this+0x340)`.
3. Store tile dims = signed `/16` of extents `+0x10`/`+0x14` into `+0x384`/`+0x388`.
4. Replace zeroed int grid at `+0x38c` (`dimX*dimY` dwords).
5. Run follow-up helpers; optional `DAT_00b03631` branch; return 1.
