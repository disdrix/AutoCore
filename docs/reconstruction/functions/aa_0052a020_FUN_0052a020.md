## Purpose

Character-side **objective readiness** check used by turn-in (`FUN_0052b420` / ShowNpcMissionDialogUI) and journal (`FUN_0052b3b0`).

* Non-empty evaluator vector `[obj+0x158, obj+0x15c)`: lookup pending node in **`char+0x55c`** by **`obj+0x10`**, then **AND** every evaluator virtual:
  * **mode 0** → `vtbl+0xc()` (lightweight)
  * **mode 1** → `vtbl+0x8(character, pending*)` (progress-aware)
* Empty / null begin: ready iff **`obj+0x138 != 0`**.

Does **not** implement CompleteCount (`+0x164`); that lives in `CVOGCharacter_EvaluatePendingObjectives`.

```c
// Result in AL as 0/1. Callee cleans 8.

```

## Behavioral summary

1. Null objective → false.
2. If evaluators present: pending lookup; AND-loop; first false exits false; all pass → true.
3. Else: `return *(int*)(objectiveDef + 0x138) != 0`.
