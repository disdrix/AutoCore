## Purpose

Configure and show the client **timed progress bar** widget at `client+0x1120`. Dismisses any prior bar (`FUN_007fb640`), optionally attaches under UI host `client+0xf40`, then sets title, status text, three color dwords, start value, max `1.0`, fill rate `(1 - start) / durationSec`, show, refresh.

On the **RequestCast** path this presents optimistic **"...Activating Skill..."** chrome while charge > 0. Same body also serves crafting / INC contact / training / generic "Working.." UIs.
