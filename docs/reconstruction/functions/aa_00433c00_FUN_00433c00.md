## Purpose

Grow-if-needed helper for the Huffman alphabet dynarray (12-byte entries). If `capacity < need`, allocate `newCap * 0xC` with `newCap = need + (0x10 − (need & 0xF))`, copy live elements via `FUN_00433ca0`, free old buffer, commit pointer and capacity.
