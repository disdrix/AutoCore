## Purpose

Virtual **precheck** for the HB multi-entity spawn skill effect (sibling of `Skill_HB_SpawnEntities_Execute_Inferred` at vtbl+0x2c). Casts object to `CVOGCreature`, optionally enforces total summon cap (return `0x10`), builds a per-type histogram of resolved summons, and fails with **8** when skill key `+0x14c` already has count ≥ threshold `+0xda` (“You have too many of that summon.”).
