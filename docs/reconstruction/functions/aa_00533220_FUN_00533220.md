## Purpose

Set character **absolute level** and **selectively rebuild** skill / attribute / research point pools from `tExperienceLevel` (levels 2..newLevel), clamp total XP to the level band, refresh skills/vehicle/missions, and rebind vehicle equipment slots.

Distinct from `CVOGCharacter_LevelUp` (`0x00532d30`, +1 with UI) and `CVOGCharacter_LevelDown` (`0x005330e0`, −1 reverse).

## Algorithm

1. Flag-gated zero of pools; optional `FUN_00521230` race seed.
2. `nLevel = newLevel`; track changed / leveled-up.
3. Loop L=2..newLevel: map lower_bound; accumulate grants; XP clamp on change.
4. Flag `0x4`: skill HB reevaluate + wipe.
5. Vehicle combat pools; vtable `+0x5c`; SearchAutoMissions if local.
6. Vehicle equip rebind block; buff/item list pool additives.
