## Purpose

Fill a caller-provided 16-byte `sockaddr_in`-layout buffer with the **invalid endpoint**:

- `sin_family = AF_INET (2)`
- `sin_port = htons(0xFFFF) = 0xFFFF`
- `sin_addr = 0xFFFFFFFF` (`INADDR_NONE`)
- remaining bytes zero

via shared helper `FUN_0067b0a0`, then return the same pointer. Used when no real peer address is available (auth client + many net helpers).
