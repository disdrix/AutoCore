## Purpose

MT19937 **seed / state fill** over `uint32 mt[624]`. Writes `mt[0] = seed`, then fills `mt[1..623]` with the standard initialization recurrence using multiplier `0x6c078965`.

Does **not** reset extract cursor/remaining — sibling `Rng_Mt19937_Twist` (`0x004248c0`) does that after a full twist. Callers that allocate the `0x9c8` engine block typically call seed then twist.
