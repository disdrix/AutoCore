## Purpose

Move the half-open range `[src, srcEnd)` to `dest` in fixed **200-byte** (`0xC8`) blocks using `REP MOVSD` (`ECX=0x32`). Leaf helper used by sound-record / 200-byte vector erase paths to shift the tail left after removing one element.

```c
// bare RET; some callers push a 4th dummy and ADD ESP,0x10
```

## Algorithm

1. While `src != srcEnd`:
   - Copy **0x32 dwords** (`0xC8` bytes) from `src` → `dest` (`rep movsd`).
   - `src += 0xC8`; `dest += 0xC8`.
2. Return.
