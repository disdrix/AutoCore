## Purpose

`__thiscall` **leaf** map lookup: walk MSVC-style binary tree at `this`, compare signed int keys at `node+0x10`, write matching **node\*** or **head/end** through out-param.

- **Hit:** `*ppOut = node` with `node.key == *pKey`
- **Miss:** `*ppOut = *(this+4)` (head / end sentinel)

Does **not** read value/payload (reward region at `node+0x18` is caller-side).

## Control flow

```
head = *(map+4)
node = head->parent          // root
candidate = head
if !isnil(node):
  loop:
    if node.key < *key: node = node.right
    else: candidate = node; node = node.left
    while !isnil(node)
if candidate == head OR *key < candidate.key:
  *ppOut = head              // miss
else:
  *ppOut = candidate         // exact hit
ret 8
```
