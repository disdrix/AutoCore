## Purpose

Shared requirement virtual called after S2C `0x2071` slot writes (mask bits in `Client_RecvObjectiveState`) and any other path that invokes `vtbl+0x20`. Builds a progress string via `vtbl+0x1c` (often trampoline `0x00637dd0` → SlotAction at `+0x18`) and enqueues a UI toast via `FUN_0040c5c0`. Skips when requirement type dword at `req+0x0c` is **7** or **8** (Probable: Km / TimePlayed). Does **not** mutate slots, complete objectives, or call `EvaluatePendingObjectives`.

## Body summary

1. If `req[3]` (`+0x0c`) ∈ {7, 8}: return.
2. Zero local string; call `req->vtbl[+0x1c](character, stateNode, buf, 0x7f)`.
3. Pack toast trailer: color `0xffeee3d8`, float **2.0** (`0x00a10e74`), float **1.5** (`0x00aaa68c`), zero dword, entity id from `*stateNode+0x10` (i64 via CDQ) or −1.
4. `FUN_0040c5c0(toastQueue, &element)` — growable push, **elem size 0x98**.
5. Queue this-ptr: `*(*(X+4) + character + 0xA8) + 0xE8C8` (class open).
